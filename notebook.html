📝 Для тетради

Краткие определения для записи в тетрадь. Занятия 1-10.

Основные понятия
ПонятиеОпределение
ИнтернетВсемирная система объединённых компьютерных сетей для обмена данными и общения.
Всемирная паутина (WWW)Система веб-страниц, связанных гиперссылками, которые можно просматривать через браузер.
БраузерПрограмма для просмотра веб-страниц — Chrome, Firefox, Safari, Edge.
Веб-разработкаПроцесс создания веб-сайтов и веб-приложений, включающий вёрстку, программирование и дизайн.
FrontendКлиентская часть сайта — то, что пользователь видит и с чем взаимодействует (HTML, CSS, JavaScript).
BackendСерверная часть сайта — обработка данных, база данных, логика приложения (не видна пользователю).
HTMLЯзык гипертекстовой разметки — определяет структуру и содержание веб-страницы с помощью тегов.
CSSКаскадные таблицы стилей — отвечает за внешний вид страницы: цвета, шрифты, отступы, расположение.
JavaScriptЯзык программирования, который добавляет интерактивность на веб-страницы — анимации, обработку кликов, динамику.
ТегКоманда в HTML, записанная в угловых скобках (<p>, <h1>), которая сообщает браузеру, что отобразить.
АтрибутДополнительная информация в открывающем теге — например, href, src, class, id.
ЭлементОткрывающий тег + содержимое + закрывающий тег — например, <p>Текст</p>.
Структура документа
ЭлементОпределение
<!DOCTYPE html>Объявление, которое говорит браузеру, что страница написана на HTML5.
<html>Корневой элемент, который оборачивает всё содержимое HTML-страницы.
<head>Раздел для служебной информации (заголовок, кодировка, стили) — не отображается на странице.
<meta charset="UTF-8">Устанавливает кодировку символов, чтобы браузер правильно показывал кириллицу и другие символы.
<meta name="viewport">Настраивает правильное отображение страницы на мобильных устройствах.
<meta name="description">Описание страницы, которое отображается в результатах поиска Google.
<title>Заголовок страницы, который отображается во вкладке браузера.
<body>Тело документа — всё видимое содержимое страницы находится внутри этого тега.
<!-- ... -->Комментарий в коде, который виден только разработчику и не отображается на странице.
Подключение ресурсов
ЭлементОпределение
<link rel="stylesheet">Подключает внешний CSS-файл со стилями к HTML-странице.
<link rel="icon">Подключает фавиконку — маленькую иконку во вкладке браузера.
<style>Позволяет писать CSS-стили прямо внутри HTML-документа в разделе <head>.
Заголовки и текст
ЭлементОпределение
<h1> ... <h6>Заголовки шести уровней: <h1> — главный и самый крупный, <h6> — самый мелкий.
<p>Абзац текста — основной элемент для обычного текста на странице.
<br>Перенос строки внутри текста без создания нового абзаца.
<hr>Горизонтальная линия-разделитель для визуального разделения контента.
<strong>Важный текст — отображается жирным и имеет смысловое значение для браузера и поисковиков.
<b>Жирный текст визуально, но без смыслового значения.
<em>Выделенный текст с акцентом — отображается курсивом и имеет смысловое значение.
<i>Курсивный текст визуально, но без смыслового значения.
<u>Подчёркнутый текст.
<s>Зачёркнутый текст — используется для устаревшей или неактуальной информации.
<mark>Выделенный (подсвеченный) текст — по умолчанию с жёлтым фоном.
<small>Мелкий текст — для примечаний, копирайтов и пояснений.
<sub>Подстрочный текст — для химических формул (H₂O) и сносок.
<sup>Надстрочный текст — для степеней (x²) и сносок.
<span>Строчный контейнер без собственного значения — используется для стилизации части текста через CSS.
<div>Универсальный блочный контейнер — используется для группировки элементов и стилизации через CSS.
Ссылки и навигация
ЭлементОпределение
<a href="...">Гиперссылка — переход на другую страницу, файл, email (mailto:) или телефон (tel:).
<nav>Семантический блок навигации — оборачивает группу ссылок-меню сайта.
Изображения
ЭлементОпределение
<img src="..." alt="...">Изображение на странице: src — путь к файлу, alt — описание для незрячих и поисковиков.
<figure> + <figcaption>Контейнер для изображения с подписью — <figcaption> содержит текст подписи.
Списки
ЭлементОпределение
<ul>Маркированный (ненумерованный) список — каждый пункт обозначается маркером.
<ol>Нумерованный список — каждый пункт имеет порядковый номер.
<li>Элемент списка — один пункт внутри <ul> или <ol>.
<dl> + <dt> + <dd>Список определений: <dt> — термин, <dd> — его описание.
Таблицы
ЭлементОпределение
<table>Контейнер таблицы — содержит строки и ячейки для отображения табличных данных.
<tr>Строка таблицы (table row) — содержит ячейки <td> или <th>.
<td>Ячейка с данными (table data) — обычная ячейка таблицы.
<th>Ячейка-заголовок (table header) — автоматически жирный и центрированный текст.
<thead>Шапка таблицы — оборачивает строку с заголовками столбцов.
<tbody>Тело таблицы — оборачивает основные строки с данными.
<tfoot>Подвал таблицы — для итогов, сумм и общей информации.
<caption>Подпись таблицы — заголовок, который ставится сразу после <table>.
colspan="N"Атрибут, который заставляет ячейку занять N столбцов по горизонтали.
rowspan="N"Атрибут, который заставляет ячейку занять N строк по вертикали.
Семантические теги
ЭлементОпределение
<header>Шапка страницы или секции — обычно содержит логотип, навигацию и заголовок.
<main>Основное содержимое страницы — только один <main> на страницу.
<section>Тематическая секция — группирует связанный по смыслу контент.
<article>Самостоятельный контент — статья, пост или новость, которая имеет смысл отдельно от страницы.
<aside>Боковой контент — сайдбар, дополнительная информация или реклама.
<footer>Подвал страницы — контакты, копирайт, ссылки на документы.
<details> + <summary>Раскрывающийся блок без JavaScript — <summary> это видимый заголовок, по клику раскрывается содержимое.
<time datetime="...">Дата или время в машиночитаемом формате — помогает поисковикам понять дату.
Формы
ЭлементОпределение
<form>Контейнер формы — группирует поля ввода и знает, куда отправлять данные (action, method).
<input>Поле ввода — универсальный элемент, который меняет поведение в зависимости от атрибута type.
<label>Подпись к полю ввода — атрибут for связывает её с input через id.
<textarea>Многострочное поле ввода для длинных текстов — сообщений, комментариев, отзывов.
<select> + <option>Выпадающий список — пользователь выбирает один вариант из нескольких предложенных.
<button>Кнопка — тип submit отправляет форму, reset очищает, button для JavaScript.
type="text"Обычное текстовое поле для ввода имени, адреса и других коротких текстов.
type="email"Поле для email — браузер проверяет наличие символа @ и показывает специальную клавиатуру.
type="password"Поле для пароля — скрывает вводимые символы точками.
type="number"Поле для чисел — появляются стрелки и нельзя ввести буквы.
type="radio"Переключатель — можно выбрать только один вариант из группы с одинаковым name.
type="checkbox"Флажок — можно выбрать несколько вариантов одновременно.
type="date"Поле выбора даты — браузер показывает встроенный календарь.
type="file"Кнопка загрузки файла — открывает диалог выбора файла на компьютере.
requiredАтрибут, который делает поле обязательным — форма не отправится без заполнения.
placeholderПодсказка внутри поля — серый текст, который исчезает при вводе и не отправляется на сервер.
minlength / maxlengthМинимальное и максимальное количество символов, которое можно ввести в поле.
Универсальные атрибуты
АтрибутОпределение
classCSS-класс элемента — можно указать несколько через пробел и применять к многим элементам.
idУникальный идентификатор элемента — только один элемент с таким id на странице.
styleИнлайн-стили — CSS прямо в атрибуте тега (не рекомендуется использовать часто).
hrefАдрес ссылки — URL страницы, путь к файлу, mailto: или tel:.
srcИсточник (путь) для изображений, видео и других медиа-файлов.
altАльтернативный текст для изображения — описание для незрячих пользователей и поисковиков.
target="_blank"Открывает ссылку в новой вкладке браузера.
Синтаксис и подключение CSS
Правило / ПонятиеОпределение
селектор { свойство: значение; }Базовая структура CSS-правила — селектор выбирает элемент, в фигурных скобках задаются стили.
/* комментарий */Комментарий в CSS-коде — не влияет на стили, виден только в коде.
Внешний CSS (<link>)Стили в отдельном .css файле — лучший способ, кэшируется браузером.
Внутренний CSS (<style>)Стили прямо в <head> HTML-документа — подходит для маленьких страниц.
Инлайн CSS (style="...")Стили прямо в атрибуте тега — самый высокий приоритет, но сложно поддерживать.
Селекторы
СелекторОпределение
* { }Универсальный селектор — выбирает все элементы на странице; часто используется для сброса стилей.
тег { }Селектор по тегу — выбирает все элементы данного типа на странице (вес: 0-0-1).
.класс { }Селектор по классу — выбирает все элементы с указанным классом (вес: 0-1-0).
#id { }Селектор по ID — выбирает один уникальный элемент (вес: 1-0-0).
селектор селектор { }Вложенный селектор — выбирает элемент, который находится внутри другого элемента.
:hoverПсевдокласс — стили при наведении курсора мыши на элемент.
:focusПсевдокласс — стили когда элемент получает фокус (курсор в поле ввода, Tab-навигация).
:nth-child(even/odd)Псевдокласс — выбирает чётные (even) или нечётные (odd) элементы по порядку.
СпецифичностьПриоритет стилей при конфликте: тег (0-0-1) < класс (0-1-0) < ID (1-0-0) < инлайн.
Цвета и фон
СвойствоОпределение
colorЦвет текста элемента — принимает имя цвета, HEX, RGB или HSL.
background-colorЦвет фона элемента.
backgroundСокращённое свойство фона — принимает цвет, изображение или градиент.
linear-gradient()Градиентный фон — плавный переход от одного цвета к другому.
HEX-цвета (#ff0000)Шестнадцатеричный код цвета — 6 или 3 символа после знака #.
rgb() / rgba()Цвет через три числа (красный, зелёный, синий); rgba добавляет прозрачность от 0 до 1.
hsl()Цвет через тон, насыщенность и светлоту — удобно подбирать оттенки.
Шрифты и текст
СвойствоОпределение
font-familyШрифт текста — указывается стек с запасными шрифтами через запятую.
font-sizeРазмер шрифта — задаётся в пикселях (px) или относительных единицах (rem).
font-weightТолщина (жирность) шрифта — normal (400), bold (700) или число от 100 до 900.
font-styleСтиль шрифта — normal (обычный) или italic (курсив).
text-alignГоризонтальное выравнивание текста — left, center, right или justify.
text-decorationОформление текста — none (убрать подчёркивание), underline, line-through (зачёркнутый).
text-transformРегистр текста — uppercase (ВСЕ БОЛЬШИЕ), lowercase (все маленькие), capitalize (Каждое Слово).
line-heightВысота строки (межстрочный интервал) — рекомендуется 1.5-1.8 для удобного чтения.
letter-spacingРасстояние между буквами — задаётся в пикселях.
text-shadowТень текста — задаётся сдвиг по X, Y, размытие и цвет.
Box Model — модель коробки
СвойствоОпределение
width / heightШирина и высота элемента — работают только для блочных и inline-block элементов.
paddingВнутренний отступ — расстояние от границы элемента до его содержимого.
marginВнешний отступ — расстояние от элемента до соседних элементов; margin: 0 auto центрирует блок.
borderРамка элемента — задаётся толщина, стиль (solid, dashed, dotted) и цвет.
border-radiusСкругление углов — 8px для кнопок, 50% для круга, 9999px для «таблетки».
box-shadowТень блока — задаётся сдвиг по X, Y, размытие, растяжение и цвет.
box-sizing: border-boxРежим расчёта размеров, при котором width включает padding и border.
max-widthМаксимальная ширина элемента — часто используется для контейнеров по центру.
min-heightМинимальная высота — min-height: 100vh делает элемент не меньше высоты экрана.
overflowЧто делать с содержимым, которое не помещается — visible, hidden, scroll или auto.
Отображение и единицы
СвойствоОпределение
display: blockЭлемент занимает всю ширину и начинается с новой строки.
display: inlineЭлемент занимает только ширину своего содержимого и не переносится на новую строку.
display: inline-blockКак inline (в строке), но можно задавать width, height, padding и margin.
display: noneПолностью скрывает элемент — он не занимает места на странице.
px (пиксели)Фиксированная единица измерения — 16px означает ровно 16 пикселей.
remОтносительная единица — зависит от корневого font-size (обычно 16px), 1.5rem = 24px.
vh / vwЕдиницы окна браузера — 1vh = 1% высоты экрана, 1vw = 1% ширины экрана.
Flexbox (превью)
СвойствоОпределение
display: flexВключает Flexbox-раскладку — дочерние элементы становятся гибкими flex-элементами.
justify-contentВыравнивание flex-элементов по горизонтали — center, flex-start, flex-end, space-between.
align-itemsВыравнивание flex-элементов по вертикали — center, flex-start, flex-end, stretch.
gapОтступ между flex-элементами — заменяет margin между элементами.
Переходы и интерактивность
СвойствоОпределение
transitionПлавный переход при изменении свойства — задаётся свойство, длительность и функция (ease).
cursorВид курсора мыши — pointer (рука для кнопок), default (стрелка), not-allowed (запрещено).
CSS для таблиц
СвойствоОпределение
border-collapse: collapseРамки соседних ячеек сливаются в одну — убирает двойные линии между ячейками.
vertical-alignВертикальное выравнивание содержимого в ячейке — top, middle или bottom.
tr:nth-child(even)Выбирает каждую чётную строку — используется для полосатого эффекта (зебра).
tr:hoverПодсветка строки таблицы при наведении курсора мыши.
CSS для форм
СвойствоОпределение
outline: noneУбирает стандартный контур браузера при фокусе — обязательно замените на свой :focus стиль.
input:focus { ... }Стили поля ввода при фокусе — обычно меняют цвет рамки и добавляют лёгкую тень.
font-family: inheritЗаставляет поля формы наследовать шрифт страницы вместо системного шрифта.
resizeКонтролирует изменение размера textarea пользователем — vertical, none или both.
