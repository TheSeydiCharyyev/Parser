# Парсер объявлений Avito → Telegram

Сервис мониторинга объявлений на Avito с уведомлениями в Telegram.
Работает **24/7**, поддерживает **150+ клиентов**, масштабируется горизонтально.

## Возможности

- Мониторинг объявлений по ссылке (поиск/категория/город)
- Уведомления о новых объявлениях в Telegram
- Проверка каждые 5 минут (настраивается)
- Быстрый старт через кнопки в боте
- Дедупликация (одно объявление = одно уведомление)
- Авто-пауза при блокировках (429/403)
- Поддержка прокси для обхода ограничений
- Django Admin для управления

## Быстрый старт

### 1. Клонировать репозиторий
```bash
git clone https://github.com/vitalivo/Parser.git
cd Parser
```

### 2. Настроить окружение
```bash
cp .env.example .env
# Отредактировать .env - указать BOT_TOKEN и прокси (опционально)
```

### 3. Запустить
```bash
docker compose up -d
```

### 4. Использовать
Найдите бота в Telegram (указан в BOT_TOKEN) и нажмите `/start`.

## Что изменено (v2.0)
