1. Зачем нужен CSS Grid

1. Why we need CSS Grid

CSS Grid — это система раскладки, которая позволяет создавать двумерные сетки (строки И столбцы одновременно). Если Flexbox работает в одном направлении, то Grid — в двух.

CSS Grid is a layout system that creates two-dimensional grids (rows AND columns simultaneously). While Flexbox works in one direction, Grid works in two.

Flexbox vs Grid — верёвка vs шахматная доска. Flexbox — это верёвка с бельём: элементы вешаются в ряд (или столбец), один за другим. Grid — это шахматная доска: вы размечаете всю площадь на ячейки и размещаете элементы в любой ячейке, любого размера.

Flexbox vs Grid — clothesline vs chessboard. Flexbox is a clothesline: items hang in a row (or column), one after another. Grid is a chessboard: you mark the entire area into cells and place items in any cell, of any size.

Ещё одна аналогия — Excel. Представьте таблицу в Excel: столбцы A, B, C и строки 1, 2, 3. Вы можете поместить данные в конкретную ячейку B2, объединить ячейки A1:C1 для заголовка. CSS Grid работает точно так же — вы создаёте сетку и размещаете элементы в нужных ячейках.

Another analogy — Excel. Imagine a spreadsheet: columns A, B, C and rows 1, 2, 3. You can place data in a specific cell B2, merge cells A1:C1 for a header. CSS Grid works exactly the same — you create a grid and place items in the cells you want.

Где Grid используется в реальных проектах:

  • Фотогалереи — Instagram, Pinterest, Google Photos
  • Макеты страниц — header + sidebar + content + footer
  • Карточки товаров — Amazon, Ozon, любой интернет-магазин
  • Дашборды — панели управления с виджетами разного размера
  • Портфолио — сетки работ на сайтах дизайнеров

Where Grid is used in real projects:

  • Photo galleries — Instagram, Pinterest, Google Photos
  • Page layouts — header + sidebar + content + footer
  • Product cards — Amazon, any online store
  • Dashboards — admin panels with widgets of different sizes
  • Portfolios — project grids on designer websites

CSS Grid появился в браузерах в 2017 году. До этого разработчики 20 лет мучились с float и таблицами для создания сеток. Представьте: чтобы сделать 3 колонки, нужно было писать ~30 строк CSS с float, clearfix и хаками. С Grid — одна строка: grid-template-columns: 1fr 1fr 1fr.

CSS Grid appeared in browsers in 2017. Before that, developers struggled for 20 years with floats and tables to create grids. Imagine: to make 3 columns, you needed ~30 lines of CSS with float, clearfix, and hacks. With Grid — one line: grid-template-columns: 1fr 1fr 1fr.

2. Flexbox vs Grid

2. Flexbox vs Grid

Новички часто спрашивают: «Зачем мне Grid, если есть Flexbox?» Это как спрашивать «Зачем мне молоток, если есть отвёртка?» — каждый инструмент для своей задачи. Понимание разницы избавит вас от часов мучений, когда вы пытаетесь сделать Grid-задачу Flexbox-ом.

Beginners often ask: "Why do I need Grid if I have Flexbox?" It's like asking "Why do I need a hammer if I have a screwdriver?" — each tool is for its task. Understanding the difference will save you hours of struggle when you try to do a Grid-task with Flexbox.

Flexbox и Grid — не конкуренты! Они дополняют друг друга. Используйте Grid для общей раскладки страницы (макет из колонок), а Flexbox — для компонентов внутри (навигация, кнопки в ряд, карточка товара). На реальных проектах вы будете использовать оба.
Flexbox and Grid are not competitors! They complement each other. Use Grid for overall page layout (column-based layouts), and Flexbox for components inside (navigation, buttons in a row, product cards). In real projects you'll use both.
Простое правило выбора:
  • Элементы в одну линию (навигация, кнопки, хлебные крошки) → Flexbox
  • Элементы в сетку (карточки товаров, галерея, макет страницы) → Grid
  • Не уверены? Начните с Flexbox. Если не хватает — переключитесь на Grid
Simple selection rule:
  • Items in one line (navigation, buttons, breadcrumbs) → Flexbox
  • Items in a grid (product cards, gallery, page layout) → Grid
  • Not sure? Start with Flexbox. If it's not enough — switch to Grid

Grid-элемент — только прямой потомок! Если у вас такая структура:

<div class="grid">       <!-- Grid-контейнер -->
    <div>Item 1</div>    <!-- Grid-элемент ✅ -->
    <div>                 <!-- Grid-элемент ✅ -->
        <p>Текст</p>     <!-- НЕ grid-элемент ❌ (вложенный) -->
    </div>

Только <div>-ы, которые напрямую внутри контейнера — это grid-элементы. Вложенные элементы — обычные, на них Grid не действует.

Grid items are direct children only! If you have this structure:

<div class="grid">       <!-- Grid container -->
    <div>Item 1</div>    <!-- Grid item ✅ -->
    <div>                 <!-- Grid item ✅ -->
        <p>Text</p>      <!-- NOT a grid item ❌ (nested) -->
    </div>
</div>

Only <div>s directly inside the container are grid items. Nested elements are regular — Grid doesn't affect them.

Линии нумеруются с 1, а не с 0! У сетки с 3 столбцами будет 4 вертикальных линии (1, 2, 3, 4). Это как забор: 3 секции — 4 столба. Новички часто путаются, потому что в программировании нумерация обычно с 0. В Grid — с 1.

Lines are numbered from 1, not 0! A grid with 3 columns has 4 vertical lines (1, 2, 3, 4). It's like a fence: 3 sections — 4 posts. Beginners often get confused because in programming numbering usually starts from 0. In Grid — from 1.

4. display: grid

4. display: grid

Так же, как display: flex превращает элемент в flex-контейнер, display: grid превращает его в grid-контейнер. Все прямые дочерние элементы автоматически становятся grid-элементами.

Just as display: flex turns an element into a flex container, display: grid turns it into a grid container. All direct children automatically become grid items.

<div class="grid-container">
    <div class="item">1</div>
    <div class="item">2</div>
    <div class="item">3</div>
    <div class="item">4</div>
    <div class="item">5</div>
    <div class="item">6</div>
</div>
.grid-container {
    display: grid;
    grid-template-columns: 200px 200px 200px;  /* 3 столбца по 200px */
}

display: grid включает Grid. grid-template-columns задаёт количество и ширину столбцов. В примере — 3 столбца по 200px. Элементы автоматически распределяются по ячейкам: первые 3 — в первую строку, следующие 3 — во вторую.

display: grid enables Grid. grid-template-columns defines the number and width of columns. In this example — 3 columns of 200px each. Items automatically fill cells: first 3 go to row 1, next 3 to row 2.

5. grid-template-columns

5. grid-template-columns

Это самое важное свойство в Grid. Именно grid-template-columns определяет, сколько столбцов будет в сетке и какой ширины. Всё остальное — настройка поверх этого.

This is the most important property in Grid. grid-template-columns defines how many columns the grid has and how wide they are. Everything else is fine-tuning on top of this.

Можно задавать колонки в разных единицах:

You can define columns in different units:

/* 3 фиксированных столбца */

/* Проценты */
grid-template-columns: 25% 50% 25%;

/* Смешанные: sidebar фиксированный + контент растягивается */
grid-template-columns: 250px auto 250px;
/* auto = занимает оставшееся место */

6. Единица fr

6. The fr unit

fr — это главная единица CSS Grid. Без неё вы будете мучиться с процентами, вычитать gap из ширины и ловить баги на разных экранах. fr решает все эти проблемы автоматически.

fr is the main unit of CSS Grid. Without it, you'll struggle with percentages, subtract gaps from widths, and catch bugs on different screens. fr solves all these problems automatically.

fr (fraction) — доля свободного пространства. Как если бы вы делили пирог: 1fr — одна часть, 2fr — две части.

fr (fraction) — a share of available space. Like dividing a pie: 1fr — one slice, 2fr — two slices.

Пирог. Представьте круглый пирог. 1fr 1fr 1fr — делим на 3 равные части (по 1/3). 1fr 2fr 1fr — первый получает 1/4, второй 2/4 (половину!), третий 1/4. Число fr — это «аппетит» колонки: чем больше, тем больше места она «съест».

Pie. Imagine a round pie. 1fr 1fr 1fr — divide into 3 equal parts (1/3 each). 1fr 2fr 1fr — first gets 1/4, second gets 2/4 (half!), third gets 1/4. The fr number is the column's "appetite": the bigger it is, the more space it "eats".

/* 3 равных столбца */
grid-template-columns: 1fr 1fr 1fr;

/* Средний в 2 раза шире */
grid-template-columns: 1fr 2fr 1fr;

/* Sidebar 250px + content на всё остальное */
grid-template-columns: 250px 1fr;

fr vs %: fr распределяет свободное пространство (после фиксированных колонок и gap). % считается от общей ширины и не учитывает gap — из-за этого 3 колонки по 33.33% + gap = не помещаются! fr всегда помещается, потому что он умнее.
fr vs %: fr distributes available space (after fixed columns and gap). % is calculated from total width and doesn't account for gap — so 3 columns at 33.33% + gap = overflow! fr always fits because it's smarter.

Использование % вместо fr. Новички пишут:

.grid {
    display: grid;
    grid-template-columns: 33.33% 33.33% 33.33%;
    gap: 20px;  /* ← ПРОБЛЕМА! */
}

Итого: 33.33% + 33.33% + 33.33% = 100% + 40px gap = больше 100%! Появится горизонтальная прокрутка.

Решение: используйте fr:

grid-template-columns: 1fr 1fr 1fr;
gap: 20px;  /* fr автоматически учитывает gap ✅ */

Using % instead of fr. Beginners write:

.grid {
    display: grid;
    grid-template-columns: 33.33% 33.33% 33.33%;
    gap: 20px;  /* ← PROBLEM! */
}

Total: 33.33% + 33.33% + 33.33% = 100% + 40px gap = more than 100%! Horizontal scrollbar appears.

Solution: use fr:

grid-template-columns: 1fr 1fr 1fr;
gap: 20px;  /* fr automatically accounts for gap ✅ */

Смешивайте fr и px! Это суперспособность Grid. Фиксированный sidebar + гибкий контент:

grid-template-columns: 250px 1fr;     /* sidebar + контент */
grid-template-columns: 80px 1fr 80px; /* иконка + текст + иконка */
grid-template-columns: 1fr 300px;     /* контент + правая панель */

fr заберёт всё оставшееся пространство после фиксированных колонок. На любом экране!

Mix fr and px! This is Grid's superpower. Fixed sidebar + flexible content:

grid-template-columns: 250px 1fr;     /* sidebar + content */
grid-template-columns: 80px 1fr 80px; /* icon + text + icon */
grid-template-columns: 1fr 300px;     /* content + right panel */

fr will take all remaining space after fixed columns. On any screen!

7. repeat() — повторение

7. repeat() — repetition

Представьте, что вам нужна сетка из 12 колонок (как в Bootstrap). Писать 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr — мучение. repeat() делает это в одно слово.

Imagine you need a 12-column grid (like Bootstrap). Writing 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr 1fr is painful. repeat() does it in one word.

Вместо повторения одинаковых значений — используйте repeat():

Instead of repeating identical values — use repeat():

/* Вместо: */
grid-template-columns: 1fr 1fr 1fr 1fr;

/* Пишем: */
grid-template-columns: repeat(4, 1fr);

/* 12 колонок (как Bootstrap) */
grid-template-columns: repeat(12, 1fr);

/* Смешанно: sidebar + 3 равные колонки */
grid-template-columns: 250px repeat(3, 1fr);

12. auto-fill и auto-fit

12. auto-fill and auto-fit

До сих пор мы указывали точное количество колонок: 3, 4, 12. Но что если вы хотите, чтобы количество колонок менялось автоматически в зависимости от ширины экрана? 4 колонки на десктопе, 2 на планшете, 1 на телефоне — и всё без media queries? Для этого существуют auto-fill и auto-fit.

Until now we specified an exact number of columns: 3, 4, 12. But what if you want the number of columns to change automatically based on screen width? 4 columns on desktop, 2 on tablet, 1 on phone — all without media queries? That's what auto-fill and auto-fit are for.

Вместо фиксированного количества колонок — пусть браузер решит сам:

Instead of a fixed number of columns — let the browser decide:

/* auto-fill: создай столько колонок по 200px, сколько поместится */

/* auto-fit: как auto-fill, но пустые колонки схлопываются */
grid-template-columns: repeat(auto-fit, 200px);

13. minmax() — адаптивные колонки

13. minmax() — responsive columns

Мы подошли к самому мощному паттерну Grid — комбинации auto-fit + minmax(). Эта одна строка CSS заменяет десятки строк с media queries и делает сетку полностью адаптивной.

We've reached Grid's most powerful pattern — the combination of auto-fit + minmax(). This single CSS line replaces dozens of media query lines and makes the grid fully responsive.

minmax(min, max) — задаёт минимальный и максимальный размер трека:

minmax(min, max) — sets minimum and maximum track size:

This single line creates a fully responsive grid:

  • auto-fit — столько колонок, сколько поместится

  • Stretch up to 1fr (evenly) — no wasted space
  • auto-fit — as many columns as will fit
  • Automatically: 3 columns on desktop, 2 on tablet, 1 on mobile!
