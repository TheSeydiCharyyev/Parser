📚 ЕДИНИЦА FR И REPEAT

📚 FR UNIT AND REPEAT

fr (fraction) — доля свободного пространства. 1fr 2fr 1fr = первый 25%, второй 50%, третий 25%.
fr (fraction) — a share of available space. 1fr 2fr 1fr = first 25%, second 50%, third 25%. 
/* 3 равных столбца */
grid-template-columns: repeat(3, 1fr);

/* 4 столбца по 200px */
grid-template-columns: repeat(4, 200px);

/* sidebar + content */
grid-template-columns: 250px 1fr;

📚 АДАПТИВНАЯ СЕТКА (САМОЕ ВАЖНОЕ!)

📚 RESPONSIVE GRID (MOST IMPORTANT!)

grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
Эта одна строка создаёт полностью адаптивную сетку:
  • Минимум 280px на колонку
  • Максимум 1fr (равномерное растяжение)
  • auto-fit = столько колонок, сколько поместится
  • Без media queries!
This single line creates a fully responsive grid:
  • Minimum 280px per column
  • Maximum 1fr (even stretching)
  • auto-fit = as many columns as will fit
  • No media queries!
