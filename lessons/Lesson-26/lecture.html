Navbar, Cards, Carousel, Modal, Forms — and building a landing page

В 24-м уроке мы освоили основу Bootstrap: сетка, кнопки, утилиты, цвета. Но самое мощное в Bootstrap — это его компоненты: готовые интерактивные блоки. Navbar с автоматическим бургер-меню. 1. Navbar — навигационная панель

1. Navbar — navigation bar

Помните, сколько CSS мы писали для бургер-меню в 20-м уроке? Checkbox hack, :checked ~ .nav, 3 span с rotate на крестик... В Bootstrap всё это уже готово. Вы пишете HTML с правильными классами (navbar, navbar-expand-lg) — и получаете полнофункциональную адаптивную навигацию с бургер-меню, анимацией сворачивания и автоматическим скрытием на мобильном.

Remember how much CSS we wrote for the burger menu in lesson 20? Checkbox hack, :checked ~ .nav, 3 spans with rotate to cross... In Bootstrap it's all ready. You write HTML with the right classes (navbar, navbar-expand-lg) — and get fully functional responsive nav with burger menu, collapse animation, and automatic mobile hiding.

Bootstrap Navbar — готовая адаптивная навигация с бургер-меню. Не нужен checkbox hack!

Bootstrap Navbar — ready-made responsive navigation with burger menu. No checkbox hack needed!

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
    <div class="container">
        <a class="navbar-brand" href="#">MySite</a>

        <!-- Бургер-кнопка (автоматически на мобильном) -->
        <button class="navbar-toggler" type="button"
                data-bs-toggle="collapse" data-bs-target="#navMenu">
            <span class="navbar-toggler-icon"></span>
        </button>

        <!-- Меню (сворачивается на мобильном) -->
        <div class="collapse navbar-collapse" id="navMenu">
            <ul class="navbar-nav ms-auto">
                <li class="nav-item">
                    <a class="nav-link active" href="#">Home</a>
                </li>
                <li class="nav-item">
                    <a class="nav-link" href="#">About</a>
                </li>
                <li class="nav-item">
                    <a class="nav-link" href="#">Contact</a>
                </li>
            </ul>
        </div>
    </div>
</nav>

navbar-darkСветлый текст (для тёмного фона)
bg-darkТёмный фон

data-bs-toggle="collapse" и data-bs-target="#navMenu" — это Bootstrap JS. Бургер работает автоматически, без вашего JavaScript!
data-bs-toggle="collapse" and data-bs-target="#navMenu" — this is Bootstrap JS. The burger works automatically, no custom JavaScript needed!

Три частые ошибки при работе с navbar:

  1. data-bs-target="#navMenu" и id="navMenu" должны совпадать. Если опечатка — бургер не сработает.
  2. Забыли подключить Bootstrap JS перед </body>. CSS без JS = мёртвый бургер.
  3. Используете navbar-light на тёмном фоне (или наоборот) — текст нечитаем. Правило: navbar-dark bg-dark или navbar-light bg-light.

Three common navbar mistakes:

  1. data-bs-target="#navMenu" and id="navMenu" must match. Typo = burger doesn't work.
  2. Forgot to include Bootstrap JS before </body>. CSS without JS = dead burger.
  3. Using navbar-light on dark background (or vice versa) — text unreadable. Rule: navbar-dark bg-dark or navbar-light bg-light.

Breakpoint у navbar-expand-*. navbar-expand-lg значит: «становится горизонтальной с 992px, до — бургер». Варианты: sm (576px), md (768px), lg (992px), xl (1200px). Если ссылок много — используйте xl, чтобы бургер появлялся позже.

Breakpoint on navbar-expand-*. navbar-expand-lg means: "becomes horizontal from 992px, below — burger". Options: sm (576px), md (768px), lg (992px), xl (1200px). Many links — use xl so the burger shows up later.

2. Cards — карточки

2. Cards

Карточка — строительный блок №1 современного веба. Товары в магазине, посты в блоге, участники команды, тарифы, отзывы — всё делается карточками. Bootstrap предоставляет структуру card → card-body → card-title/card-text/card-footer. Готовые отступы, границы, скругления.

A card is the #1 building block of the modern web. Products in stores, blog posts, team members, pricing plans, testimonials — all done with cards. Bootstrap provides the card → card-body → card-title/card-text/card-footer structure. Ready spacing, borders, rounding.

<div class="card">
    <img src="https://picsum.photos/400/200" class="card-img-top" alt="...">
    <div class="card-body">
        <h5 class="card-title">Card Title</h5>
        <p class="card-text">Some quick example text.</p>
        <a href="#" class="btn btn-primary">Go somewhere</a>
    </div>
</div>

<!-- Карточка с header и footer -->
<div class="card">
    <div class="card-header">Featured</div>
    <div class="card-body">
        <h5 class="card-title">Title</h5>
        <p class="card-text">Text content.</p>
    </div>
    <div class="card-footer text-muted">2 days ago</div>
</div>

Карточки — самый используемый компонент Bootstrap. Сетка карточек:

Cards — the most used Bootstrap component. Card grid:

<div class="row g-4">
    <div class="col-12 col-md-6 col-lg-4">
        <div class="card h-100">...</div>
    </div>
    <!-- ещё карточки -->
</div>
h-100 на карточке делает все карточки в строке одинаковой высоты. Без этого карточки с разным количеством текста будут разной высоты.
h-100 on the card makes all cards in a row equal height. Without it, cards with different text amounts will have different heights.

Карточки — каркас, а не стены. Bootstrap даёт «скелет» карточки: рамку, скругление, отступы. Чтобы карточка выглядела «вашей» — добавьте: shadow-sm (лёгкая тень), border-0 (убрать рамку), свой цвет фона. Карточка без теней выглядит дёшево, с теней — премиум.

Cards are the frame, not the walls. Bootstrap gives the card "skeleton": border, rounding, padding. To make it feel "yours" — add: shadow-sm (light shadow), border-0 (remove border), your own bg color. Cards without shadows look cheap, with shadows — premium.

3. Carousel — карусель

3. Carousel

Карусель = автоматически переключающиеся слайды. Часто используется для hero-секции ресторана (фото блюд), отзывов клиентов, баннеров. На чистом JS это 100+ строк кода — в Bootstrap несколько <div> с правильными классами.

A carousel = auto-switching slides. Often used for restaurant hero (dish photos), client testimonials, banners. In pure JS that's 100+ lines of code — in Bootstrap just a few <div>s with the right classes.

<div id="myCarousel" class="carousel slide" data-bs-ride="carousel">
    <!-- Индикаторы -->
    <div class="carousel-indicators">
        <button data-bs-target="#myCarousel" data-bs-slide-to="0" class="active"></button>
        <button data-bs-target="#myCarousel" data-bs-slide-to="1"></button>
        <button data-bs-target="#myCarousel" data-bs-slide-to="2"></button>
    </div>

    <!-- Слайды -->
    <div class="carousel-inner">
        <div class="carousel-item active">
            <img src="https://picsum.photos/1200/400?random=1" class="d-block w-100" alt="">
            <div class="carousel-caption">
                <h5>Slide 1</h5>
                <p>Description</p>
            </div>
        </div>
        <div class="carousel-item">
            <img src="https://picsum.photos/1200/400?random=2" class="d-block w-100" alt="">
        </div>
        <div class="carousel-item">
            <img src="https://picsum.photos/1200/400?random=3" class="d-block w-100" alt="">
        </div>
    </div>

    <!-- Стрелки -->
    <button class="carousel-control-prev" data-bs-target="#myCarousel" data-bs-slide="prev">
        <span class="carousel-control-prev-icon"></span>
    </button>
    <button class="carousel-control-next" data-bs-target="#myCarousel" data-bs-slide="next">
        <span class="carousel-control-next-icon"></span>
    </button>
</div>

Карусель автоматически переключает слайды (data-bs-ride="carousel"). Стрелки и индикаторы работают через Bootstrap JS.

Carousel auto-switches slides (data-bs-ride="carousel"). Arrows and indicators work via Bootstrap JS.

Карусели — спорный паттерн. UX-исследования (Nielsen Norman Group) показывают: пользователи редко смотрят дальше первого слайда. Если делаете hero-карусель — делайте её медленной (data-bs-interval="5000" = 5 секунд) и ставьте самое важное на первый слайд. А лучше — hero-секция со статичным фоном + разделитель + карусель только для отзывов или галереи.

Carousels are a controversial pattern. UX research (Nielsen Norman Group) shows: users rarely look past the first slide. If you do a hero carousel — make it slow (data-bs-interval="5000" = 5s) and put the most important thing on slide 1. Better yet — static hero background + carousel only for testimonials or gallery.

4. Modal — модальное окно

4. Modal

Модальное окно — это «всплывашка» поверх страницы с затемнённым фоном. Используется для: формы регистрации, подтверждения удаления («Вы уверены?»), диалога «Заказать звонок». Преимущество перед отдельной страницей: пользователь не теряет контекст.

Bootstrap даёт полноценный модал с затемнением, анимацией появления, закрытием по клавише Escape и клику вне окна — бесплатно.

A modal is a "popup" over the page with a dimmed background. Used for: signup form, delete confirmation ("Are you sure?"), "Request a call" dialog. Advantage over a separate page: user doesn't lose context.

Bootstrap gives a full modal with dimming, fade-in animation, Escape-key closing, and click-outside dismiss — for free.

<!-- Кнопка открытия -->
<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">
    Open Modal
</button>

<!-- Модальное окно -->
<div class="modal fade" id="myModal">
    <div class="modal-dialog">
        <div class="modal-content">
            <div class="modal-header">
                <h5 class="modal-title">Modal Title</h5>
                <button class="btn-close" data-bs-dismiss="modal"></button>
            </div>
            <div class="modal-body">
                <p>Modal content goes here...</p>
            </div>
            <div class="modal-footer">
                <button class="btn btn-secondary" data-bs-dismiss="modal">Close</button>
                <button class="btn btn-primary">Save</button>
            </div>
        </div>
    </div>
</div>
Связка кнопка ↔ модал идёт через data-bs-target="#myModal" на кнопке и id="myModal" на модале. data-bs-dismiss="modal" — закрывает (например, на кнопке «Отмена» или крестик).
Button-modal link is via data-bs-target="#myModal" on the button and id="myModal" on the modal. data-bs-dismiss="modal" — closes (e.g., on "Cancel" button or close icon).

5. Forms — формы

5. Forms

Стилизовать формы вручную — мучительно: input, textarea, select, radio, checkbox — у каждого свои странности кросс-браузерности. Bootstrap решает это одним классом: form-control. Все инпуты получают единообразный вид, focus-состояние с синей обводкой, правильные размеры.

Styling forms by hand is painful: input, textarea, select, radio, checkbox — each has cross-browser quirks. Bootstrap solves it with one class: form-control. All inputs get uniform look, focus state with blue outline, proper sizing.

<form>
    <div class="mb-3">
        <label for="name" class="form-label">Name</label>
        <input type="text" class="form-control" id="name" placeholder="Your name">
    </div>
    <div class="mb-3">
        <label for="email" class="form-label">Email</label>
        <input type="email" class="form-control" id="email" placeholder="name@example.com">
    </div>
    <div class="mb-3">
        <label for="message" class="form-label">Message</label>
        <textarea class="form-control" id="message" rows="3"></textarea>
    </div>
    <div class="mb-3 form-check">
        <input type="checkbox" class="form-check-input" id="agree">
        <label class="form-check-label" for="agree">I agree</label>
    </div>
    <button type="submit" class="btn btn-primary">Submit</button>
</form>

form-control — стилизованный input. form-label — label. mb-3 — отступ между полями.

form-control — styled input. form-label — label. mb-3 — spacing between fields.

Форма в две колонки (name + email в один ряд): используйте сетку внутри формы.

<form>
    <div class="row g-3 mb-3">
        <div class="col-md-6">
            <label class="form-label">Name</label>
            <input type="text" class="form-control">
        </div>
        <div class="col-md-6">
            <label class="form-label">Email</label>
            <input type="email" class="form-control">
        </div>
    </div>
</form>

На мобильном — стопка, на десктопе — два поля в ряд.

Two-column form (name + email in one row): use grid inside the form.

<form>
    <div class="row g-3 mb-3">
        <div class="col-md-6">
            <label class="form-label">Name</label>
            <input type="text" class="form-control">
        </div>
        <div class="col-md-6">
            <label class="form-label">Email</label>
            <input type="email" class="form-control">
        </div>
    </div>
</form>

On mobile — stack, on desktop — two fields in a row.

6. Alerts и Badges

6. Alerts and Badges

Alert — уведомление-плашка: «Данные сохранены», «Ошибка отправки», «Внимание: обновите пароль». Цвет = смысл (success/danger/warning/info). Badge — маленькая метка: «New», «Hot», «99+». Ставится рядом с заголовками, в счётчиках уведомлений.

Alert — a notification bar: "Data saved", "Send failed", "Notice: update password". Color = meaning (success/danger/warning/info). Badge — a small label: "New", "Hot", "99+". Placed next to headings, in notification counters.

<!-- Alerts -->
<div class="alert alert-success">Success message!</div>
<div class="alert alert-danger">Error message!</div>
<div class="alert alert-warning alert-dismissible fade show">
    Warning!
    <button class="btn-close" data-bs-dismiss="alert"></button>
</div>

<!-- Badges -->
<span class="badge bg-primary">New</span>
<span class="badge bg-danger">Hot</span>
<span class="badge rounded-pill bg-success">99+</span>

7. Accordion

7. Accordion

Accordion = раскрывающиеся блоки. Идеальный компонент для FAQ (частых вопросов): вопрос-заголовок, клик — открывается ответ. Экономит место: 20 вопросов в свёрнутом виде помещаются на пол-экрана.

Accordion = expandable blocks. Perfect component for FAQ: question-heading, click — answer opens. Saves space: 20 questions collapsed fit on half a screen.

<div class="accordion" id="faqAccordion">
    <div class="accordion-item">
        <h2 class="accordion-header">
            <button class="accordion-button" data-bs-toggle="collapse"
                    data-bs-target="#faq1">Question 1?</button>
        </h2>
        <div id="faq1" class="accordion-collapse collapse show"
             data-bs-parent="#faqAccordion">
            <div class="accordion-body">Answer 1...</div>
        </div>
    </div>
    <div class="accordion-item">
        <h2 class="accordion-header">
            <button class="accordion-button collapsed" data-bs-toggle="collapse"
                    data-bs-target="#faq2">Question 2?</button>
        </h2>
        <div id="faq2" class="accordion-collapse collapse"
             data-bs-parent="#faqAccordion">
            <div class="accordion-body">Answer 2...</div>
        </div>
    </div>
</div>

8. Bootstrap Icons

8. Bootstrap Icons

Иконки нужны везде: в меню, кнопках, списках, футере. Раньше разработчики использовали Font Awesome, но сейчас для Bootstrap-проектов лучше Bootstrap Icons — они бесплатны (Font Awesome — платный с 2018 года для коммерческого использования), имеют 2000+ SVG и идеально интегрируются с Bootstrap-классами.

Icons are needed everywhere: in menus, buttons, lists, footers. Earlier, devs used Font Awesome, but now for Bootstrap projects Bootstrap Icons is better — they're free (Font Awesome has been paid since 2018 for commercial use), have 2000+ SVGs, and integrate perfectly with Bootstrap classes.
