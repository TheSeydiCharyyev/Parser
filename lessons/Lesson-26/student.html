📚 ЧТО ТАКОЕ КОМПОНЕНТЫ BOOTSTRAP

📚 WHAT ARE BOOTSTRAP COMPONENTS

Компоненты — готовые интерактивные блоки (navbar, modal, carousel, accordion). Логика работы написана в Bootstrap JS и «включается» через data-атрибуты. Вы пишете только HTML.
Components — ready interactive blocks (navbar, modal, carousel, accordion). Logic lives in Bootstrap JS and "activates" via data attributes. You only write HTML.
Все интерактивные компоненты требуют Bootstrap JS (подключение bootstrap.bundle.min.js перед </body>). Без JS: бургер не открывается, модалка не появляется, карусель не двигается.
All interactive components require Bootstrap JS (include bootstrap.bundle.min.js before </body>). Without JS: burger doesn't open, modal doesn't appear, carousel doesn't slide.

📚 NAVBAR (ШАБЛОН)

📚 NAVBAR (TEMPLATE)

<nav class="navbar navbar-expand-lg navbar-dark bg-dark">
  <div class="container">
    <a class="navbar-brand" href="#">Logo</a>
    <button class="navbar-toggler" data-bs-toggle="collapse"
            data-bs-target="#nav">
      <span class="navbar-toggler-icon"></span>
    </button>
    <div class="collapse navbar-collapse" id="nav">
      <ul class="navbar-nav ms-auto">
        <li class="nav-item"><a class="nav-link" href="#">Link</a></li>
      </ul>
    </div>
  </div>
</nav>

📚 CARD (ШАБЛОН)

📚 CARD (TEMPLATE)

<div class="card h-100">
  <img src="..." class="card-img-top" alt="">
  <div class="card-body">
    <h5 class="card-title">Title</h5>
    <p class="card-text">Text</p>
    <a href="#" class="btn btn-primary">Button</a>
  </div>
</div>
h-100 = все карточки одинаковой высоты в строке.
h-100 = all cards same height in a row.
