🎯 Lesson 26.1: COMPONENTS

Задание 25.1: Витрина компонентов Task 25.1: Component showcase
Лёгкое Easy 15 минут 15 min
Собрать на одной странице все основные компоненты Bootstrap
Assemble all main Bootstrap components on one page

Условие:

Instructions:

Создайте файл components.html. Разместите на одной странице:

Create a file components.html. Place on one page:

  1. Navbar (тёмная, с бургером и 4 ссылками)
  2. 4 Alerts (success, danger, warning, info)
  3. 3 Cards в row g-4 (с изображениями и кнопками, h-100)
  4. Carousel (3 слайда с изображениями)
  5. Accordion (3 вопроса-ответа)
  6. Modal (кнопка → модальное окно с формой)
  7. Form (name, email, select, checkbox, submit)
  1. Navbar (dark, with burger and 4 links)
  2. 4 Alerts (success, danger, warning, info)
  3. 3 Cards in row g-4 (with images and buttons, h-100)
  4. Carousel (3 slides with images)
  5. Accordion (3 Q&A items)
  6. Modal (button → modal with form)
  7. Form (name, email, select, checkbox, submit)
Секретный ингредиент — Bootstrap JS. Без него бургер, модалка, карусель, accordion — мертвы. Проверьте, что в конце <body> есть: 
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
Именно bundle.min.js (включает Popper.js для тултипов).
Secret ingredient — Bootstrap JS. Without it, burger, modal, carousel, accordion — are dead. Check that the end of <body> has: 
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
Specifically bundle.min.js (includes Popper.js for tooltips).
  • Все 7 компонентов на одной странице
  • Подзаголовки над каждым блоком (<h3>)
  • Navbar с работающим бургером на мобильном
  • Carousel с автопрокруткой (data-bs-ride="carousel")
  • Все 4 alert-а (success, danger, warning, info)
  • 3 card в row g-4 с h-100
  • Modal открывается по кнопке и закрывается по Escape
  • Accordion раскрывается по клику (один открыт — остальные закрыты)
  • Form: все поля обёрнуты в mb-3, submit как btn btn-primary
  • Bootstrap CSS + JS подключены
  • All 7 components on one page
  • Subheadings above each block (<h3>)
  • Navbar with working burger on mobile
  • Carousel with auto-slide (data-bs-ride="carousel")
  • All 4 alerts (success, danger, warning, info)
  • 3 cards in row g-4 with h-100
  • Modal opens on button click and closes on Escape
  • Accordion expands on click (one open — others closed)
  • Form: all fields wrapped in mb-3, submit as btn btn-primary
  • Bootstrap CSS + JS connected

🎯 Lesson 26.2: ANALYZING A READY SITE

Задание 25.2: Анализ Bootstrap-сайта Task 25.2: Bootstrap site analysis
Лёгкое Easy 10 минут 10 min
Научиться читать и понимать Bootstrap-код
Learn to read and understand Bootstrap code

Условие:

Instructions:

Откройте любой сайт из примеров Bootstrap (getbootstrap.com/docs/5.3/examples/). Выберите один, откройте в DevTools и запишите:

Open any Bootstrap example site (getbootstrap.com/docs/5.3/examples/). Choose one, open DevTools and write down:

  1. Какие компоненты используются (navbar, card, carousel...)?
  2. Какие breakpoints (col-md-, col-lg-) применены к сетке?
  3. Какие утилиты чаще всего встречаются?
  4. Есть ли свой CSS поверх Bootstrap?
  1. Which components are used (navbar, card, carousel...)?
  2. Which breakpoints (col-md-, col-lg-) are applied to the grid?
  3. Which utilities are most common?
  4. Is there custom CSS on top of Bootstrap?
  • Список компонентов записан
  • Breakpoints определены
  • Самые частые утилиты выписаны
  • Component list written
  • Breakpoints identified
  • Most common utilities listed

🎯 УРОК 26.3: ЛЕНДИНГ НА BOOTSTRAP

🎯 Lesson 26.3: BOOTSTRAP LANDING PAGE

Задание 25.3: Лендинг на Bootstrap Task 25.3: Bootstrap landing page
Среднее Medium 25 минут 25 min
Собрать полный лендинг из Bootstrap-компонентов
Build a complete landing page from Bootstrap components

Условие:

Instructions:

Создайте файл landing.html. Соберите лендинг для любого продукта/сервиса:

Create a file landing.html. Build a landing page for any product/service:

  1. Navbar: navbar-dark bg-dark navbar-expand-lg с 4 ссылками + кнопка «Get Started» (btn btn-outline-light)
  2. Hero: bg-primary text-white text-center py-5, display-4 заголовок, lead описание, кнопка btn-light btn-lg
  3. Features: row g-4 py-5, 3 колонки (col-md-4), в каждой: Bootstrap Icon (bi bi-... fs-1 text-primary), заголовок, описание
  4. Cards: row g-4, 3 карточки (card h-100) с изображениями, текстом, кнопками
  5. Testimonial: carousel с 3 текстовыми отзывами (имя, текст, оценка звёздами bi bi-star-fill)
  6. FAQ: accordion с 4 вопросами
  7. Contact: row: col-md-6 информация + col-md-6 форма (form-control)
  8. CTA: секция с кнопкой, открывающей modal с формой подписки
  9. Footer: bg-dark text-white, row: 3 колонки + копирайт
  1. Navbar: navbar-dark bg-dark navbar-expand-lg with 4 links + "Get Started" button (btn btn-outline-light)
  2. Hero: bg-primary text-white text-center py-5, display-4 heading, lead description, btn-light btn-lg button
  3. Features: row g-4 py-5, 3 columns (col-md-4), each: Bootstrap Icon (bi bi-... fs-1 text-primary), title, description
  4. Cards: row g-4, 3 cards (card h-100) with images, text, buttons
  5. Testimonial: carousel with 3 text reviews (name, text, star rating bi bi-star-fill)
  6. FAQ: accordion with 4 questions
  7. Contact: row: col-md-6 info + col-md-6 form (form-control)
  8. CTA: section with button opening a modal with subscribe form
  9. Footer: bg-dark text-white, row: 3 columns + copyright
Подключения (всё в <head> кроме JS): 
<!-- Bootstrap CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Bootstrap Icons -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">

<!-- Bootstrap JS (перед </body>) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
И проверьте, что Bootstrap JS подключён (для navbar, carousel, modal, accordion).
Connections (all in <head> except JS): 
<!-- Bootstrap CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Bootstrap Icons -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css" rel="stylesheet">

<!-- Bootstrap JS (before </body>) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
And check that Bootstrap JS is connected (for navbar, carousel, modal, accordion).

  • Минимум 5 компонентов: navbar, card, carousel, modal, accordion
  • Bootstrap Icons в минимум 3 местах (navbar, features, footer)
  • Адаптивная сетка (col-md-*, col-lg-*)
  • Modal открывается и закрывается (Escape, крестик, «Отмена»)
  • Carousel переключается вручную (стрелки) и авто
  • Navbar с бургером на мобильном (< 992px)
  • Accordion: один открыт, остальные закрыты (data-bs-parent)
  • Form: все form-control, кнопка btn btn-primary
  • Минимум своего CSS (или ноль)
  • Проверено на мобильном в DevTools (375px) и десктопе

  • Modal opens and closes (Escape, X, "Cancel")

Задание 25.4: Свой стиль поверх Bootstrap Task 25.4: Custom style on top of Bootstrap
Сложное Hard 15 минут 15 min
Добавить свой CSS поверх Bootstrap для уникального дизайна
Add custom CSS on top of Bootstrap for unique design

Условие:

Instructions:

Возьмите лендинг из задания 25.3 и добавьте файл custom.css (подключите после Bootstrap):

Take the landing from task 25.3 and add custom.css (connect it after Bootstrap):

  1. Замените шрифт на Google Fonts (например, 'Poppins')
  2. Измените основной цвет (.btn-primary, .bg-primary) на свой через переопределение
  3. Добавьте hover-анимации на карточки (transform: translateY(-8px) + box-shadow)
  4. Hero: фоновое изображение вместо bg-primary
  5. Плавная прокрутка (scroll-behavior: smooth)
  1. Replace font with Google Fonts (e.g., 'Poppins')
  2. Change primary color (.btn-primary, .bg-primary) to yours via override
  3. Add hover animations on cards (transform: translateY(-8px) + box-shadow)
  4. Hero: background image instead of bg-primary
  5. Smooth scrolling (scroll-behavior: smooth)
Подключайте свой CSS после Bootstrap: <link href="bootstrap.css"> <link href="custom.css">. Ваши стили перезапишут Bootstrap благодаря каскаду!
Connect your CSS after Bootstrap: <link href="bootstrap.css"> <link href="custom.css">. Your styles will override Bootstrap thanks to the cascade!
