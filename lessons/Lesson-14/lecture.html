1. Зачем нужен Flexbox

1. Why we need Flexbox

Flexbox (Flexible Box Layout) — это CSS-модуль для создания гибких раскладок. Он решает задачи, которые раньше были сложными:

Flexbox (Flexible Box Layout) is a CSS module for creating flexible layouts. It solves problems that used to be difficult:

  • Расположить элементы в ряд с равными отступами
  • Центрировать элемент по горизонтали И вертикали
  • Сделать колонки одинаковой высоты
  • Разместить логотип слева, а ссылки справа
  • Перенести элементы на новую строку при нехватке места
  • Arrange elements in a row with equal spacing
  • Center an element both horizontally AND vertically
  • Make columns of equal height
  • Place a logo on the left and links on the right
  • Wrap elements to a new line when there's not enough space

После этого занятия вы сможете:

After this lesson you will be able to:

  • Создавать flex-контейнеры и управлять расположением дочерних элементов
  • Менять направление элементов (горизонтально, вертикально, в обратном порядке)
  • Включать перенос элементов на новую строку
  • Выравнивать элементы по главной оси (justify-content)
  • Выравнивать элементы по поперечной оси (align-items)
  • Добавлять отступы между элементами через gap
  • Идеально центрировать любой элемент на странице
  • Создать профессиональную навигационную панель
  • Create flex containers and control the layout of child elements
  • Change element direction (horizontal, vertical, reversed)
  • Enable wrapping of elements to a new line
  • Align elements along the main axis (justify-content)
  • Align elements along the cross axis (align-items)
  • Add spacing between elements using gap
  • Perfectly center any element on the page
  • Build a professional navigation bar

Представь полку с книгами. Flexbox позволяет: расставить книги в ряд, прижать к левому или правому краю, равномерно распределить, выровнять по высоте. Полка — это контейнер, книги — элементы.

Imagine a bookshelf. Flexbox lets you: arrange books in a row, align them left or right, distribute evenly, align by height. The shelf is the container, books are the items.

Where Flexbox is used in real projects:

  • Карточки товаров — ряды карточек на Wildberries, Amazon, любом интернет-магазине
  • Footer (подвал) — колонки с контактами, ссылками, соцсетями
  • Hero-секции — большой заголовок, идеально отцентрированный на экране
  • Дашборды — панели управления с виджетами в ряд
  • Мессенджеры — IMO, Telegram: список чатов, сообщения выравниваются слева/справа
  • Каждый современный сайт — Flexbox используется буквально везде
  • Navigation bars — logo on the left, links in the center, login button on the right (any website)
  • Product cards — rows of cards on Amazon, eBay, any e-commerce site
  • Footer — columns with contacts, links, social media

  • Every modern website — Flexbox is literally used everywhere
До Flexbox разработчики использовали float, display: inline-block и даже таблицы для раскладки. Это было как строить дом из спичек. Flexbox — это настоящие кирпичи!
Before Flexbox, developers used float, display: inline-block, and even tables for layout. It was like building a house from matchsticks. Flexbox is the real bricks!

2. Container and items

В Flexbox всегда есть два участника:

Представь поезд. Локомотив задаёт направление движения — это flex-контейнер. Вагоны следуют за ним — это flex-элементы. Машинист (ты!) решает: поезд едет горизонтально (row) или поднимается вертикально в гору (column). Вагоны можно расставить плотно, с промежутками или равномерно по всему составу. Но каждый вагон сам по себе не решает, куда ехать — это решает контейнер!

Imagine a train. The locomotive sets the direction of travel — it's the flex container. The wagons follow it — they are the flex items. The driver (you!) decides: the train goes horizontally (row) or climbs vertically uphill (column). Wagons can be packed tightly, spaced out, or spread evenly across the whole train. But each wagon doesn't decide where to go on its own — the container decides!

Flex container (parent) ┌──────────────────────────────────────┐ │ ┌────────┐ ┌────────┐ ┌────────┐ │ │ │ Item 1 │ │ Item 2 │ │ Item 3 │ │ │ └────────┘ └────────┘ └────────┘ │ └──────────────────────────────────────┘ Flex items (children)
Только прямые дети! Flexbox управляет только прямыми дочерними элементами. Вложенные элементы (внуки) не затрагиваются.
Direct children only! Flexbox controls only direct child elements. Nested elements (grandchildren) are not affected.

Частая ошибка: новичок ставит display: flex на дочерний элемент вместо родителя. Flexbox включается на контейнере, а не на элементах внутри!

Common mistake: a beginner puts display: flex on the child element instead of the parent. Flexbox is enabled on the container, not on the items inside!

<!-- WRONG: flex on children -->
<div class="parent">
    <div style="display: flex;">Item 1</div>
    <div style="display: flex;">Item 2</div>
</div>

<!-- RIGHT: flex on parent -->
<div class="parent" style="display: flex;">
    <div>Item 1</div>
    <div>Item 2</div>
</div>

4. Главная и поперечная оси

4. Main and cross axes

Flexbox работает по двум осям:

Flexbox works along two axes:

Главная ось (main axis) ──────────────────► │ │ ┌─────┐ ┌─────┐ ┌─────┐ │ │ 1 │ │ 2 │ │ 3 │ │ └─────┘ └─────┘ └─────┘ ▼ Поперечная ось (cross axis)
Main axis ─────────────────────────► │ │ ┌─────┐ ┌─────┐ ┌─────┐ │ │ 1 │ │ 2 │ │ 3 │ │ └─────┘ └─────┘ └─────┘ ▼ Cross axis

Представь, что ты идёшь по улице. Направление, в котором ты идёшь — это главная ось (main axis). Улицы, которые пересекают твою дорогу — это поперечная ось (cross axis). justify-content управляет расположением вдоль твоего пути. align-items управляет расположением поперёк дороги.

Imagine you're walking down a street. The direction you're walking is the main axis. The streets that cross your path are the cross axis. justify-content controls placement along your path. align-items controls placement across the road.

ОсьНаправление по умолчаниюСвойство выравнивания
Главная (main)→ горизонтально (слева направо)justify-content
Поперечная (cross)↓ вертикально (сверху вниз)align-items
AxisDefault directionAlignment property
Main→ horizontal (left to right)justify-content
Cross↓ vertical (top to bottom)align-items

Частая путаница: новичок хочет выровнять элементы по вертикали и пишет justify-content: center. Но justify-content работает по главной оси (горизонтально по умолчанию). Для вертикального выравнивания нужен align-items: center!

Common confusion: a beginner wants to vertically align items and writes justify-content: center. But justify-content works along the main axis (horizontal by default). For vertical alignment, use align-items: center!

/* WRONG: this centers HORIZONTALLY */
.container {
    display: flex;
    justify-content: center;
}

/* RIGHT: this centers VERTICALLY */
.container {
    display: flex;
    align-items: center;
    height: 200px;
}
Запомни: justify-content = главная ось. align-items = поперечная ось. Оси меняются при изменении flex-direction!
Remember: justify-content = main axis. align-items = cross axis. Axes change when flex-direction changes!

6. flex-wrap

6. flex-wrap

По умолчанию все flex-элементы пытаются поместиться в одну строку (даже если не помещаются — сжимаются). flex-wrap разрешает перенос:

By default, all flex items try to fit in one line (even if they don't fit — they shrink). flex-wrap allows wrapping:

Перенос строк в Microsoft Word — знакомая аналогия. Когда слово не помещается в строку, оно автоматически переносится на следующую. flex-wrap: wrap делает то же самое с flex-элементами: если блок не помещается в ряд — он перепрыгивает на новую строку. А nowrap — это как если бы Word сжимал текст, чтобы всё влезло в одну строку.

Word wrapping in Microsoft Word is a familiar analogy. When a word doesn't fit on a line, it automatically wraps to the next line. flex-wrap: wrap does the same with flex items: if a block doesn't fit in the row, it jumps to a new line. And nowrap is like Word squeezing the text so everything fits on one line.

7. flex-flow (сокращение)

7. flex-flow (shorthand)

flex-flow — это сокращение для flex-direction и flex-wrap в одну строку:

flex-flow is a shorthand for flex-direction and flex-wrap in one line:

/* Вместо: */
flex-direction: row;
flex-wrap: wrap;

/* Можно написать: */
flex-flow: row wrap;

Совет: на практике flex-flow используется реже, чем отдельные свойства. Многие разработчики предпочитают писать flex-direction и flex-wrap отдельно — так код читабельнее. Но знать про сокращение полезно, чтобы понимать чужой код.

Tip: in practice, flex-flow is used less often than the individual properties. Many developers prefer writing flex-direction and flex-wrap separately — it's more readable. But knowing the shorthand is useful to understand other people's code.

space-between vs space-evenly — когда что?

space-between vs space-evenly — when to use which?

  • space-between — первый элемент прижат к левому краю, последний к правому. Идеально для навигации: логотип слева, кнопка справа.
  • space-evenly — абсолютно равные промежутки, включая отступы от краёв. Идеально для карточек товаров или иконок, где нужна визуальная симметрия.
  • space-around — компромисс: равные промежутки вокруг каждого элемента, но крайние отступы в 2 раза меньше внутренних.
  • space-between — first item flush to the left edge, last to the right. Perfect for navigation: logo on the left, button on the right.
  • space-evenly — absolutely equal gaps, including the edges. Perfect for product cards or icons where you need visual symmetry.
  • space-around — a compromise: equal space around each item, but edge gaps are half the inner gaps.

10. align-content — многострочное выравнивание

10. align-content — multi-line alignment

align-content работает как justify-content, но для строк (при flex-wrap: wrap). Выравнивает строки вдоль поперечной оси.

align-content works like justify-content, but for lines (with flex-wrap: wrap). Aligns lines along the cross axis.

Значения те же: flex-start, flex-end, center, space-between, space-around, stretch.

Same values: flex-start, flex-end, center, space-between, space-around, stretch.

Многие новички путают align-items и align-content. Запомни: align-items выравнивает элементы внутри одной строки. align-content выравнивает сами строки друг относительно друга. Если у тебя одна строка — align-content ничего не делает!
Many beginners confuse align-items and align-content. Remember: align-items aligns items within a single line. align-content aligns the lines themselves relative to each other. If you have a single line — align-content does nothing!
Когда работает: align-content работает ТОЛЬКО при flex-wrap: wrap и когда есть несколько строк.
When it works: align-content ONLY works with flex-wrap: wrap and when there are multiple lines.

11. gap — spacing between items

gap — простой способ задать отступы между flex-элементами (без margin):

gap — a simple way to set spacing between flex items (without margin):

.flex-container {
    display: flex;
    gap: 20px;          /* одинаковый отступ */
}

/* Или разный по осям: */
.flex-container {
    display: flex;
    gap: 20px 30px;     /* row-gap column-gap */
}
gap vs margin: gap добавляет отступы только между элементами, а не по краям. Это гораздо удобнее, чем margin на каждом элементе!
gap vs margin: gap adds spacing only between items, not at the edges. Much more convenient than margin on each item!

12. Идеальное центрирование

12. Perfect centering

Самый частый вопрос в CSS: «Как центрировать элемент?» С Flexbox — 3 строки:

The most common CSS question: "How to center an element?" With Flexbox — 3 lines:

.center-me {
    display: flex;
    justify-content: center;  /* по горизонтали */
    align-items: center;      /* по вертикали */
    height: 100vh;            /* чтобы было куда центрировать */
}

Идеальное центрирование:

Perfect centering:

Я по центру!
I'm centered!

3 строки CSS = идеально по центру горизонтально и вертикально

3 lines of CSS = perfectly centered horizontally and vertically

min-height: 100vh для полноэкранного центрирования. Если вы хотите центрировать элемент на всю высоту экрана (например, экран загрузки, hero-секция, страница 404), используйте min-height: 100vh вместо height: 100vh. Разница: min-height позволяет контенту расти, если он не помещается, а height обрежет его.

min-height: 100vh for full-page centering. If you want to center an element across the full screen height (e.g., loading screen, hero section, 404 page), use min-height: 100vh instead of height: 100vh. The difference: min-height lets content grow if it doesn't fit, while height will clip it.

/* Full-page centering — best practice */
.hero {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;  /* min-height, not height! */
}
До Flexbox вертикальное центрирование было «вечной проблемой CSS». Разработчики шутили: «Два самых сложных вопроса в программировании: именование переменных, инвалидация кеша и вертикальное центрирование в CSS».
Before Flexbox, vertical centering was an "eternal CSS problem." Developers joked: "The two hardest problems in programming: naming variables, cache invalidation, and vertical centering in CSS."

Создай страницу с одним <div> в центре экрана. Используй display: flex, justify-content: center, align-items: center и min-height: 100vh на <body>. Попробуй вставить туда текст «Привет, Туркменистан!» — он должен быть идеально по центру на любом размере экрана.

Create a page with a single <div> centered on the screen. Use display: flex, justify-content: center, align-items: center and min-height: 100vh on the <body>. Try putting the text "Hello, Turkmenistan!" inside — it should be perfectly centered at any screen size.

14. Итоги

14. Summary

Свойства flex-контейнера (родителя):
  • display: flex — включает Flexbox
  • flex-direction — направление: row, column, row-reverse, column-reverse
  • flex-wrap — перенос: nowrap, wrap, wrap-reverse
  • justify-content — выравнивание по главной оси
  • align-items — выравнивание по поперечной оси
  • align-content — выравнивание строк (при wrap)
  • gap — отступы между элементами
Ключевые идеи:
  • display: flex ставится на родителя, не на детей
  • justify-content = главная ось, align-items = поперечная ось
  • При flex-direction: column оси меняются местами
  • gap лучше margin — отступы только между элементами
  • Идеальное центрирование: display: flex + justify-content: center + align-items: center
  • Flex можно вкладывать (flex внутри flex) — это нормально
Flex container (parent) properties:
  • display: flex — enables Flexbox
  • flex-direction — direction: row, column, row-reverse, column-reverse
  • flex-wrap — wrapping: nowrap, wrap, wrap-reverse
  • justify-content — alignment along the main axis
  • align-items — alignment along the cross axis
  • align-content — alignment of lines (with wrap)
  • gap — spacing between items
Key ideas:
  • display: flex goes on the parent, not the children
  • justify-content = main axis, align-items = cross axis
  • With flex-direction: column, axes swap
  • gap is better than margin — spacing only between items
  • Perfect centering: display: flex + justify-content: center + align-items: center
  • Flex can be nested (flex inside flex) — this is normal
Flexbox поддерживается всеми современными браузерами с 2015 года: Chrome, Firefox, Safari, Edge, Opera. Глобальная поддержка — более 99%! Можно смело использовать без каких-либо полифиллов. А вот в 2012 году было 3 разных синтаксиса Flexbox, и разработчики писали код с префиксами -webkit- и -ms-. Сейчас это уже не нужно.
Flexbox has been supported by all modern browsers since 2015: Chrome, Firefox, Safari, Edge, Opera. Global support is over 99%! You can safely use it without any polyfills. Back in 2012 there were 3 different Flexbox syntaxes, and developers had to write code with -webkit- and -ms- prefixes. That's no longer necessary.
