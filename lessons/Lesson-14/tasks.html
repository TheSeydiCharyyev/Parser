Задание 13.1: Лаборатория Flexbox Task 13.1: Flexbox Laboratory
Лёгкое Easy 15 минут 15 min
Попробовать все свойства flex-контейнера
Try all flex container properties

Условие:

Instructions:

Создайте файл flex-lab.html. Сделайте контейнер с 5 цветными блоками:

Create a file flex-lab.html. Make a container with 5 colored blocks:

<div class="container">
    <div class="box" style="background:#ef4444">1</div>
    <div class="box" style="background:#f97316">2</div>
    <div class="box" style="background:#eab308">3</div>
    <div class="box" style="background:#22c55e">4</div>
    <div class="box" style="background:#3b82f6">5</div>
</div>

Последовательно примените к .container и запишите результат:

Apply each to .container and note the result:

  1. display: flex — что изменилось?
  2. flex-direction: column — как расположились блоки?
  3. flex-direction: row-reverse — что произошло?
  4. justify-content: center — куда переместились?
  5. justify-content: space-between
  6. justify-content: space-evenly
  7. Добавьте height: 300px контейнеру, затем align-items: center
  8. align-items: flex-end
  9. flex-wrap: wrap (задайте блокам width: 200px)
  10. gap: 20px
  1. display: flex — what changed?
  2. flex-direction: column — how are blocks arranged?
  3. flex-direction: row-reverse — what happened?
  4. justify-content: center — where did they move?
  5. justify-content: space-between
  6. justify-content: space-evenly
  7. Add height: 300px to container, then align-items: center
  8. align-items: flex-end
  9. flex-wrap: wrap (set blocks to width: 200px)
  10. gap: 20px

Требования:

Requirements:

  • CSS пишите в теге <style> внутри файла
  • Каждый эксперимент должен иметь видимый комментарий или подпись (<h3> или HTML-комментарий), чтобы вы могли вернуться и повторить
  • Блоки должны иметь min-width и min-height, чтобы разница была чётко видна
  • Контейнер должен иметь border, чтобы было видно его границы
  • Write CSS in a <style> tag inside the file
  • Each experiment should have a visible comment or label (<h3> or HTML comment) so you can review later
  • Blocks should have min-width and min-height so the difference is clearly visible
  • Container should have a border so its boundaries are visible
Базовые стили для блоков, чтобы эксперименты были наглядными: 
.box {
    color: white;
    padding: 20px;
    text-align: center;
    font-size: 1.5rem;
    font-weight: bold;
    min-width: 80px;
    min-height: 80px;
    border-radius: 8px;
}

.container {
    border: 2px dashed #cbd5e1;
    padding: 10px;
    margin-bottom: 20px;
}

Visually compare all justify-content values

Instructions:

Создайте файл justify.html. На одной странице покажите 6 контейнеров — каждый с разным значением justify-content:

Create a file justify.html. On one page show 6 containers — each with a different justify-content value:

  1. flex-start
  2. flex-end
  3. center
  4. space-between
  5. space-around
  6. space-evenly
  1. flex-start
  2. flex-end
  3. center
  4. space-between
  5. space-around
  6. space-evenly

Каждый контейнер: серый фон, height: 80px, 3 цветных блока внутри. Над каждым — подпись с названием значения.

Each container: gray background, height: 80px, 3 colored blocks inside. Above each — a label with the value name.

Требования:

Requirements:

  • Каждый контейнер подписан через <h3> с названием значения
  • Блоки одинаково стилизованы во всех контейнерах (одинаковый размер, цвет, отступы)
  • Контейнеры имеют border, чтобы было видно где заканчиваются границы
  • Все контейнеры должны иметь одинаковую ширину для честного сравнения
  • Each container is labeled with an <h3> showing the value name

  • Containers have a border so boundaries are visible
  • All containers should have the same width for a fair comparison

    height: 50px;

    align-items: center;
    justify-content: center;

🎯 УРОК 14.3: НАВИГАЦИЯ

🎯 Lesson 14.3: NAVIGATION

Задание 13.3: Навигационная панель на Flexbox Task 13.3: Flexbox navigation bar
Среднее Medium 20 минут 20 min
Создать полноценную навигационную панель с помощью Flexbox
Create a complete navigation bar using Flexbox

Условие:

Instructions:

Создайте папку navbar с файлами index.html и style.css. Сделайте навигационную панель:

Create a folder navbar with files index.html and style.css. Make a navigation bar:

  1. Логотип — слева (текст или emoji), выделяется стилем (жирный, крупнее, другой цвет)
  2. Ссылки — по центру: Главная, Курсы, О нас, Блог, Контакты
  3. Кнопка — справа: «Войти» (стилизованная)
  4. Раскладка: display: flex + justify-content: space-between + align-items: center
  5. Ссылки находятся в своём собственном flex-контейнере (.nav-links) с gap
  1. Logo — on the left (text or emoji), stands out with styling (bold, larger, different color)
  2. Links — in the center: Home, Courses, About, Blog, Contacts
  3. Button — on the right: "Login" (styled)
  4. Layout: display: flex + justify-content: space-between + align-items: center
  5. Links are in their own flex container (.nav-links) with gap

CSS-требования:

CSS requirements:

  • Белый фон, лёгкая тень (box-shadow)
  • Ссылки без подчёркивания, hover-эффект (цвет)
  • Кнопка: цветной фон, белый текст, border-radius, hover
  • Навигация прилипает к верху (position: sticky)
  • Padding для отступов
  • Логотип визуально выделяется (font-weight: bold, крупнее, другой цвет)
  • White background, light shadow (box-shadow)
  • Links without underline, hover effect (color)
  • Button: colored background, white text, border-radius, hover
  • Nav sticks to top (position: sticky)
  • Padding for spacing
  • Logo is visually distinct (font-weight: bold, larger, different color)
Структура HTML: 
<nav class="navbar">
    <a class="logo">...</a>
    <div class="nav-links">    <!-- flex внутри flex! -->
        <a>...</a> <a>...</a> ...
    </div>
    <a class="btn">Войти</a>
</nav>
HTML structure: 
<nav class="navbar">
    <a class="logo">...</a>
    <div class="nav-links">    <!-- flex inside flex! -->
        <a>...</a> <a>...</a> ...
    </div>
    <a class="btn">Login</a>
</nav>
Подумайте о разных ширинах экрана: что произойдёт, если окно браузера станет узким? Ссылки начнут «сжиматься» или вылезать за пределы? Пока не нужно это исправлять (media queries будут позже), но обратите внимание на поведение. Попробуйте уменьшить окно браузера и посмотрите, что происходит!
Think about different screen widths: what happens if the browser window becomes narrow? Will links start to "squeeze" or overflow? You don't need to fix this yet (media queries come later), but notice the behavior. Try resizing the browser window and see what happens!
  • Логотип слева, ссылки в центре, кнопка справа
  • Всё на одной линии, вертикально выровнено
  • Flexbox используется (display: flex)
  • Ссылки находятся в собственном flex-контейнере (.nav-links)
  • gap для отступов между ссылками
  • Логотип визуально выделяется
  • Hover-эффекты работают
  • Nav прилипает (sticky)
  • CSS в отдельном файле
  • Logo left, links center, button right
  • All on one line, vertically aligned
  • Flexbox is used (display: flex)
  • Links are in their own flex container (.nav-links)
  • gap for spacing between links
  • Logo is visually distinct
  • Hover effects work
  • Nav is sticky
  • CSS in separate file

Flexbox Froggy — это бесплатная игра, где нужно расположить лягушек на лилиях с помощью CSS Flexbox. Очень наглядно! Игра охватывает свойства из этого занятия (justify-content, align-items, flex-direction, flex-wrap) и немного из следующего (order, align-self). Не волнуйтесь, если встретите незнакомые свойства — это отличная возможность заглянуть вперёд!
Flexbox Froggy is a free game where you need to position frogs on lily pads using CSS Flexbox. Very visual! The game covers properties from this lesson (justify-content, align-items, flex-direction, flex-wrap) and a few from the next one (order, align-self). Don't worry if you encounter unfamiliar properties — it's a great chance to peek ahead!
