📚 ЧТО ТАКОЕ FLEXBOX

📚 WHAT IS FLEXBOX

Flexbox — CSS-модуль для гибкой раскладки элементов. Включается через display: flex на родителе. Управляет расположением прямых дочерних элементов.
Flexbox — a CSS module for flexible element layout. Enabled via display: flex on the parent. Controls placement of direct children.
display: flex ставится на РОДИТЕЛЯ, а не на детей! Дочерние элементы автоматически становятся flex-элементами. Это самая частая ошибка новичков — писать display: flex на самих элементах вместо их контейнера.
display: flex goes on the PARENT, not children! Child elements automatically become flex items. This is the most common beginner mistake — writing display: flex on the items themselves instead of their container.

📚 ДВЕ ОСИ

📚 TWO AXES

Главная ось (Main Axis) — направление, в котором выстраиваются flex-элементы. По умолчанию — горизонтально (слева направо). Управляется свойством justify-content.
Main Axis — the direction in which flex items are laid out. By default — horizontal (left to right). Controlled by the justify-content property.
Поперечная ось (Cross Axis) — ось, перпендикулярная главной. По умолчанию — вертикально (сверху вниз). Управляется свойством align-items.
Cross Axis — the axis perpendicular to the main axis. By default — vertical (top to bottom). Controlled by the align-items property.

Оси меняются местами! При flex-direction: column главная ось становится вертикальной, а поперечная — горизонтальной. Это значит: justify-content будет работать по вертикали, а align-items — по горизонтали. Всегда помни, какое направление у контейнера!
Axes swap! With flex-direction: column the main axis becomes vertical and the cross axis becomes horizontal. This means: justify-content will work vertically, and align-items — horizontally. Always remember which direction the container uses!

📚 GAP И ПЕРЕНОС

📚 GAP AND WRAPPING

gap vs margin — в чём разница?
gap добавляет отступы только между элементами, но НЕ по краям контейнера. margin добавляет отступ вокруг каждого элемента (включая первый и последний). Используй gap — это проще, чище, и не нужно убирать лишний margin у крайних элементов.
gap vs margin — what's the difference?
gap adds spacing only between items, but NOT at the container edges. margin adds spacing around every element (including the first and last). Use gap — it's simpler, cleaner, and you don't need to remove extra margin from edge items. 
/* gap — отступы только между элементами */
.container {
    display: flex;
    gap: 20px;        /* 20px между [1] и [2], между [2] и [3] */
}                     /* но 0px перед [1] и после [3] */

/* margin — отступ у каждого элемента */
.item {
    margin: 10px;     /* 10px со ВСЕХ сторон каждого элемента */
}
flex-wrap: wrap — ключ к адаптивности! Без wrap все элементы сжимаются в одну строку, даже если не помещаются. С flex-wrap: wrap элементы переносятся на новую строку, когда места не хватает. Это основа адаптивных сеток без медиа-запросов.
flex-wrap: wrap — key to responsiveness! Without wrap, all items squeeze into one line even if they don't fit. With flex-wrap: wrap, items move to a new line when there's not enough space. This is the foundation of responsive grids without media queries.

📚 ПОЛЕЗНЫЕ ПАТТЕРНЫ

📚 USEFUL PATTERNS

Когда что использовать:
  • Центрирование — для модальных окон, hero-секций, страниц загрузки
  • space-between навбар — для шапок сайта (лого + меню + кнопки)
  • Карточки с wrap — для каталогов, галерей, списков товаров
  • Колонка (column) — для боковых панелей, форм, вертикальных меню
When to use each pattern:
  • Centering — for modals, hero sections, loading pages
  • space-between navbar — for site headers (logo + menu + buttons)
  • Cards with wrap — for catalogs, galleries, product lists
  • Column — for sidebars, forms, vertical menus

1. Идеальное центрирование

1. Perfect centering

.center {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;      /* на всю высоту экрана */
}

2. Навигация: лого слева, ссылки справа

2. Nav: logo left, links right

.navbar {
    display: flex;
    justify-content: space-between;

}

3. Карточки в ряд с переносом

3. Cards in a row with wrapping

    display: flex;

}
.card {

4. Вертикальная колонка (sidebar / форма)

4. Vertical column (sidebar / form)

    display: flex;
    flex-direction: column;
    gap: 12px;
}

5. Футер: элементы равномерно

5. Footer: items evenly spaced

.footer {
    display: flex;
    justify-content: space-evenly;
    align-items: center;
    padding: 20px;
}

  • Без wrap элементы сжимаются в одну строку — не забывай!
  • display: flex — on the parent, not the children!
  • Flexbox has two axes: main and cross
  • With flex-direction: column the axes swap

  • align-items = cross axis (vertical with row)
