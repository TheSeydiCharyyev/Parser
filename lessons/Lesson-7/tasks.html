Задание 7.1: Block vs Inline — эксперимент
Лёгкое 10 минут
Увидеть разницу между блочными и строчными элементами

Условие:

Создайте файл block-inline.html. Добавьте стили с рамкой для наглядности:

<style>
    .block-demo { border: 3px solid blue; margin: 8px 0; padding: 8px; }
    .inline-demo { border: 3px solid red; padding: 4px; }
</style>

Затем создайте:

  1. 3 блочных элемента с классом block-demo: <div>, <p>, <h3>
  2. 4 строчных элемента с классом inline-demo внутри одного <p>: <span>, <a>, <strong>, <em>
Блочные элементы занимают: ________________________________
Строчные элементы занимают: ________________________________
Главное отличие: ________________________________
  • Блочные элементы с синей рамкой — каждый на новой строке, вся ширина
  • Строчные элементы с красной рамкой — все в одной строке
  • Записаны наблюдения

Задание 7.3: Box Model — рассчитай размер
Среднее 5 минут
Понять как складываются размеры в Box Model

Условие:

Рассчитайте итоговую ширину элемента на экране для каждого примера:

Пример 1 (box-sizing: content-box):
width: 300px, padding: 20px, border: 5px solid black
Итоговая ширина: ________

Пример 2 (box-sizing: border-box):
width: 300px, padding: 20px, border: 5px solid black
Итоговая ширина: ________

Пример 3 (box-sizing: content-box):
width: 200px, padding: 10px 30px, border: 2px solid blue
Итоговая ширина: ________
  1. 300 + 20*2 + 5*2 = 350px
  2. 300px (border-box — всё включено!)
  3. 200 + 30*2 + 2*2 = 264px (padding: 10px 30px = 30px лево + 30px право)
  • Все 3 расчёта выполнены правильно
Задание 7.4: Padding и Margin — практика
Среднее 10 минут
Отработать padding и margin на реальных элементах

Условие:

Создайте файл box-model.html. Добавьте 4 блока <div> и задайте им стили:

  1. Блок 1: фон #dbeafe, padding: 10px, без margin
  2. Блок 2: фон #dcfce7, padding: 30px, margin-top: 20px
  3. Блок 3: фон #fef3c7, padding: 20px 40px, margin: 20px 0, border: 2px solid #f59e0b
  4. Блок 4: фон #fce7f3, width: 400px, padding: 20px, margin: 20px auto (центрирован!)
Не забудьте добавить * { box-sizing: border-box; } в начало CSS!
После создания — откройте DevTools (F12), выберите каждый блок и посмотрите Box Model в панели Styles.
  • 4 блока с разными padding и margin
  • Блок 4 центрирован через margin: 20px auto
  • Использован box-sizing: border-box
  • Просмотрена Box Model в DevTools

Задание 7.5: display — эксперимент
Среднее 10 минут
Увидеть разницу между block, inline, inline-block

Условие:

Создайте файл display.html. Создайте 3 секции, в каждой — 3 одинаковых элемента <span> с текстом «Элемент 1», «Элемент 2», «Элемент 3».

  1. В первой секции: display: block — каждый элемент на новой строке, width: 200px
  2. Во второй секции: display: inline — все в одной строке (попробуйте задать width — не сработает!)
  3. В третьей секции: display: inline-block — все в одной строке, но width: 200px работает
.block { display: block; width: 200px; padding: 10px; background: #dbeafe; margin: 4px 0; border-radius: 8px; }
.inline { display: inline; width: 200px; padding: 10px; background: #dcfce7; border-radius: 8px; }
.inline-block { display: inline-block; width: 200px; padding: 10px; background: #fef3c7; border-radius: 8px; }
block — элементы стоят: ________________________________
inline — width работает? ________________________________
inline-block — элементы стоят: ________________, width работает? ________
  • 3 секции с разными display
  • Видна разница между block, inline и inline-block
  • Записаны наблюдения
Задание 7.6: Стилизованные кнопки
Среднее 10 минут
Отработать inline-block, border-radius и box-shadow

Условие:

Создайте файл buttons.html. Сделайте 4 кнопки-ссылки (<a>) в ряд, каждая с разным стилем:

  1. Кнопка 1: синий фон (#3b82f6), белый текст, скругление 8px, лёгкая тень
  2. Кнопка 2: зелёный фон (#22c55e), скругление 9999px (таблетка), средняя тень
  3. Кнопка 3: без фона, рамка 2px solid #7c3aed, фиолетовый текст, скругление 8px
  4. Кнопка 4: красный фон (#ef4444), белый текст, скругление 50% (круглая, одинаковые width и height)

Все кнопки должны использовать:

  • display: inline-block
  • padding: 12px 24px (для кнопок 1-3)
  • text-decoration: none
  • font-weight: 600
  • 4 кнопки стоят в ряд (inline-block)
  • Каждая кнопка с уникальным стилем
  • Использованы border-radius и box-shadow
  • Кнопка 4 — круглая

🎯 УРОК 7.3: ПРАКТИЧЕСКИЙ ПРОЕКТ

Задание 7.7: Карточки товаров
Продвинутое 20 минут
Создать набор карточек товаров, используя все знания занятия

Условие:

Создайте файл cards.html с набором из 3-4 карточек товаров. Выберите тему: техника, одежда, еда, игры и т.д.

Требования к каждой карточке:

ЭлементCSS
Карточка (<div>)display: inline-block, width: 220px, padding: 20px, border-radius: 12px, box-shadow, белый фон
Изображение (<img>)width: 100%, border-radius: 8px
Название (<h3>)margin сверху
ЦенаКрупный зелёный текст, старая цена зачёркнута (<s>)
Кнопка «Купить» (<a>)display: inline-block, width: 100%, text-align: center, padding, border-radius, цветной фон

Дополнительные требования:

  • * { box-sizing: border-box; }
  • Фон страницы — светло-серый (#f1f5f9)
  • Карточки центрированы на странице (контейнер с text-align: center или margin: 0 auto)
  • Между карточками есть расстояние (margin)
  • Минимум у одного товара есть старая цена (зачёркнутая)
Для изображений можно использовать placeholder:
<img src="https://via.placeholder.com/200x150/dbeafe/1d4ed8?text=Товар" alt="Товар">
Или найдите бесплатные картинки на unsplash.com, pexels.com.
  • 3-4 карточки стоят в ряд (inline-block)
  • У карточек: padding, border-radius, box-shadow
  • Картинка, название, цена, кнопка в каждой карточке
  • box-sizing: border-box применён
  • Есть старая зачёркнутая цена
  • Кнопка «Купить» на всю ширину карточки
  • Страница выглядит аккуратно и цельно
