1. Что такое Landing Page

1. What is a Landing Page

Landing page (лендинг) — это одностраничный сайт, цель которого — побудить посетителя совершить одно конкретное действие: зарегистрироваться, купить, скачать, подписаться.

A landing page is a single-page website whose goal is to encourage the visitor to perform one specific action: sign up, buy, download, subscribe.

Обычный сайт — это супермаркет: много страниц, разделов, товаров. Лендинг — это рекламный стенд: одна страница, один продукт, одна кнопка «Купить».

A regular website is a supermarket: many pages, sections, products. A landing page is a promotional stand: one page, one product, one "Buy" button.

Примеры лендингов:

Landing page examples:

  • Страница мобильного приложения (скачать)
  • Страница онлайн-курса (записаться)
  • Рекламная страница продукта (купить)
  • Страница мероприятия (зарегистрироваться)
  • Страница стартапа (подписка на бета)
  • Mobile app page (download)
  • Online course page (enroll)
  • Product promo page (buy)
  • Event page (register)
  • Startup page (beta signup)

CTA (Call to Action) — «призыв к действию». Это главная кнопка лендинга: «Купить», «Скачать», «Зарегистрироваться». Она должна быть яркой и заметной.
CTA (Call to Action) — the main button of a landing page: "Buy", "Download", "Sign Up". It should be bright and noticeable.

.nav-links { display: flex; align-items: center; gap: 24px; }
.nav-links a { font-weight: 500; color: #475569; }
.nav-links a:hover { color: #3b82f6; }

.btn-nav {
    background: #3b82f6;
    color: #fff !important;
    padding: 10px 20px;
}
.btn-nav:hover { background: #2563eb; }

position: sticky; top: 0 — навигация «прилипает» к верху при скролле. display: flex + justify-content: space-between — логотип слева, ссылки справа.

position: sticky; top: 0 — navigation "sticks" to the top on scroll. display: flex + justify-content: space-between — logo on the left, links on the right.
