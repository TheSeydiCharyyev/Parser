🎯 УРОК 13.1: ПЛАНИРОВАНИЕ

🎯 Lesson 13.1: PLANNING

Задание 12.1: Спланируй лендинг Task 12.1: Plan a landing page
Лёгкое Easy 10 минут 10 min
Спланировать структуру и содержание лендинга
Plan the structure and content of a landing page

Условие:

Instructions:

Выберите тему и на бумаге (или в тетради) запишите:

Choose a topic and on paper (or in a notebook) write down:

  1. Тема — для чего лендинг? (приложение, курсы, кафе, мероприятие...)
  2. Название / бренд
  3. Содержание каждой секции:
    • Nav: логотип, какие ссылки, текст CTA-кнопки
    • Hero: заголовок (1 предложение), описание (2-3 предложения), текст кнопки
    • Features: 3 преимущества (название + описание каждого)
    • CTA: призыв + текст кнопки
    • Footer: копирайт, какие соцсети
  4. Цветовая схема: основной цвет, градиент, цвет кнопки
  1. Topic — what's the landing for? (app, courses, cafe, event...)
  2. Name / brand
  3. Content for each section:
    • Nav: logo, which links, CTA button text
    • Hero: headline (1 sentence), description (2-3 sentences), button text
    • Features: 3 benefits (title + description for each)
    • CTA: call to action + button text
    • Footer: copyright, which social links
  4. Color scheme: main color, gradient, button color
  • Тема выбрана
  • Содержание всех 5 секций записано
  • Цветовая схема определена
  • Topic is chosen
  • Content for all 5 sections is written
  • Color scheme is defined

🎯 Lesson 13.2: REPRODUCING THE EXAMPLE

Задание 12.2: Повтори лендинг LearnCode Task 12.2: Reproduce the LearnCode landing
Среднее Medium 20 минут 20 min
Самостоятельно воспроизвести лендинг из лекции
Independently reproduce the landing page from the lecture

Условие:

Instructions:

  1. Создайте папку learncode с файлами index.html и style.css
  2. Самостоятельно (не копируя!) напишите HTML: nav, hero, features (3 карточки), CTA, footer
  3. Напишите CSS для каждой секции
  4. Проверьте: навигация прилипает? Карточки в ряд? Кнопки с hover? Градиенты?
  1. Create a folder learncode with files index.html and style.css
  2. Independently (without copying!) write HTML: nav, hero, features (3 cards), CTA, footer
  3. Write CSS for each section
  4. Check: does nav stick? Cards in a row? Buttons with hover? Gradients?
  • 5 секций (nav, hero, features, cta, footer)
  • Nav с логотипом, ссылками, CTA-кнопкой
  • Hero с заголовком, текстом, кнопкой на градиентном фоне
  • 3 карточки features с hover-эффектом
  • CTA с кнопкой на тёмном фоне
  • Footer с копирайтом и ссылками
  • CSS в отдельном файле
  • .container ограничивает ширину
  • 5 sections (nav, hero, features, cta, footer)
  • Nav with logo, links, CTA button
  • Hero with headline, text, button on gradient background
  • 3 feature cards with hover effect
  • CTA with button on dark background
  • Footer with copyright and links

🎯 Lesson 13.3: YOUR OWN LANDING

Задание 12.3: Создай свой уникальный лендинг Task 12.3: Create your own unique landing page
Среднее Medium 25 минут 25 min
Создать уникальный лендинг на свою тему
Create a unique landing page on your own topic

Условие:

Instructions:

Используя план из задания 12.1, создайте полноценный лендинг:

Using your plan from task 12.1, create a complete landing page:

Обязательные элементы:

Required elements:

  1. Nav: Логотип, минимум 3 ссылки, CTA-кнопка. Прилипающая (sticky).
  2. Hero: Заголовок, описание, CTA-кнопка. Градиентный фон. Текст по центру.
  3. Features: Минимум 3 карточки в ряд. Иконка + заголовок + описание. Hover-эффект.
  4. CTA: Призыв + кнопка. Тёмный или цветной фон.
  5. Footer: Копирайт + соцсети.
  1. Nav: Logo, at least 3 links, CTA button. Sticky.
  2. Hero: Headline, description, CTA button. Gradient background. Centered text.
  3. Features: At least 3 cards in a row. Icon + title + description. Hover effect.
  4. CTA: Call to action + button. Dark or colored background.
  5. Footer: Copyright + social links.

CSS-требования:

CSS requirements:

  • CSS в отдельном файле
  • .container ограничивает ширину
  • Минимум 1 градиент
  • Hover-эффекты на карточках и кнопках
  • Своя цветовая тема (не из примера!)
  • Мета-теги: description, author
  • CSS in a separate file
  • .container limits width
  • At least 1 gradient
  • Hover effects on cards and buttons
  • Your own color theme (not from example!)
  • Meta tags: description, author

Задание 12.4: Дополнительные секции Task 12.4: Additional sections
Сложное Hard 15 минут 15 min
Расширить лендинг дополнительными секциями
Extend the landing page with additional sections

Условие:

Instructions:

Добавьте к вашему лендингу одну или две дополнительных секции:

Add one or two additional sections to your landing page:

  • Секция «Отзывы»: 2-3 карточки с цитатами, именем и фото (pravatar.cc)
  • Секция «Цены»: 3 тарифа в карточках (можно таблицу из занятия 9)
  • Секция «FAQ»: 4-5 вопросов и ответов
  • Форма подписки в CTA: email-поле + кнопка (из занятия 10)
  • YouTube-видео в hero или отдельной секции (из занятия 11)
  • "Testimonials" section: 2-3 cards with quotes, name, and photo (pravatar.cc)
  • "Pricing" section: 3 plans in cards (can use table from lesson 9)
  • "FAQ" section: 4-5 questions and answers
  • Subscription form in CTA: email field + button (from lesson 10)
  • YouTube video in hero or separate section (from lesson 11)
  • Минимум 1 дополнительная секция
  • Секция стилизована в общем стиле лендинга
  • Навигация обновлена (ссылка на новую секцию)
  • At least 1 additional section
  • Section styled consistently with the landing
  • Navigation updated (link to new section)
