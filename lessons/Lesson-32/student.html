📚 ГЛАВНЫЙ ПРИНЦИП

📚 MAIN PRINCIPLE

Сегодня — только HTML. Никаких стилей. Никаких цветов. Только разметка. В браузере будет «поток текста» — это нормально. Красота завтра (занятие 32).
Today — HTML only. No styles. No colors. Just markup. Browser shows "stream of text" — that's fine. Beauty tomorrow (lesson 32).

📚 ШАБЛОН <head>

📚 <head> TEMPLATE

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>[Page] | [Brand]</title>
    <meta name="description" content="..." (до 160 симв.)>

    <!-- Open Graph -->
    <meta property="og:title" content="...">
    <meta property="og:description" content="...">
    <meta property="og:image" content="https://...">
    <meta property="og:url" content="https://...">

    <!-- Favicon -->
    <link rel="icon" href="favicon.ico">

    <!-- Fonts -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link href="https://fonts.googleapis.com/..." rel="stylesheet">

    <!-- CSS (порядок!) -->
    <link rel="stylesheet" href="css/tokens.css">
    <link rel="stylesheet" href="css/base.css">
    <link rel="stylesheet" href="css/components.css">
    <link rel="stylesheet" href="css/style.css">
</head>
Каждая страница имеет свой <title> и description! Формат: [Page] | [Brand].
Each page has its own <title> and description! Format: [Page] | [Brand].

📚 SEMANTIC TAGS — CHEAT SHEET

ТегКогда
<header>Шапка сайта ИЛИ секции
<nav>Блок навигации
<main>Основной контент (1 на страницу)
<section>Раздел с заголовком (Hero, Features)
<article>Самодостаточный блок (карточка товара, пост)
<aside>Сайдбар, сопутствующий контент

<figure>+<figcaption>Изображение с подписью
<time>Дата/время
<address>Контакты
TagWhen
<header>Site OR section header
<nav>Navigation block
<main>Main content (1 per page)
<section>Section with heading (Hero, Features)
<article>Self-contained block (product card, post)
<aside>Sidebar, related content
<footer>Site OR section footer
<figure>+<figcaption>Image with caption
<time>Date/time
<address>Contacts
section vs article: section — раздел страницы (только в контексте). article — самодостаточный блок (можно «вынести»). Сомневаетесь → section.
section vs article: section — page section (only in context). article — self-contained block (can be "taken out"). When in doubt → section.

📚 ИЕРАРХИЯ ЗАГОЛОВКОВ

📚 HEADING HIERARCHY

  • Ровно один h1 на страницу (обычно в Hero)
  • Не пропускать уровни: h1 → h2 → h3
  • h2 — заголовки секций
  • h3 — заголовки внутри секций (карточки, фичи)
  • Exactly one h1 per page (usually in Hero)
  • Don't skip levels: h1 → h2 → h3
  • h2 — section headings
  • h3 — headings inside sections (cards, features)

📚 СТРУКТУРА HTML-СТРАНИЦЫ

📚 HTML PAGE STRUCTURE

<body>
    <header class="header">
        <div class="container">
            <a class="logo" href="index.html">Brand</a>
            <nav class="nav">
                <ul>
                    <li><a href="index.html" class="active">Главная</a></li>
                    <li><a href="about.html">О нас</a></li>
                    <li><a href="contact.html">Контакты</a></li>
                </ul>
            </nav>
        </div>
    </header>

    <main>
        <section class="hero">
            <h1>Главный заголовок</h1>
        </section>

        <section class="features">
            <h2>Преимущества</h2>
            <article class="feature">...</article>
        </section>
    </main>

    <footer class="footer">
        <div class="container">
            <p>© 2026</p>
        </div>
    </footer>
</body>

📚 НАВИГАЦИЯ — ТИПЫ ССЫЛОК

📚 NAVIGATION — LINK TYPES

<!-- Между страницами -->
<a href="about.html">О нас</a>

<!-- Якорь на текущей странице -->
<a href="#services">Услуги</a>

<!-- Якорь на другой странице -->
<a href="index.html#menu">Меню</a>

<!-- Внешняя ссылка (новая вкладка) -->
<a href="https://..." target="_blank" rel="noopener">Site</a>

<!-- Email -->
<a href="mailto:hello@site.com">hello@site.com</a>

<!-- Телефон -->
<a href="tel:+99312000000">+993 12 00-00-00</a>
На текущей странице ссылка имеет class="active" (и aria-current="page" для доступности).
On the current page, the link has class="active" (and aria-current="page" for accessibility).

📚 ИЗОБРАЖЕНИЯ

📚 IMAGES

<!-- Со смыслом -->
<img src="hero.jpg" alt="Торт Наполеон на столе">

<!-- Декоративное (фон, узор) -->
<img src="pattern.svg" alt="">

<!-- Ленивая загрузка (ниже first-screen) -->
<img src="gallery.jpg" alt="..." loading="lazy">

<!-- С фиксированными размерами (против layout shift) -->
<img src="card.jpg" alt="..." width="400" height="300">
alt обязателен всегда. Для декоративных — пустой: alt="". Не пишите «картинка», «фото» — бессмысленно.
alt always required. For decorative — empty: alt="". Don't write "image", "photo" — meaningless.

📚 FORMS

<form action="#" method="POST">
    <div class="form-group">
        <label for="name">Имя *</label>
        <input type="text" id="name" name="name" required>
    </div>
    <div class="form-group">
        <label for="email">Email *</label>
        <input type="email" id="email" name="email" required>
    </div>
    <div class="form-group">
        <label for="message">Сообщение</label>
        <textarea id="message" name="message" rows="4"></textarea>
    </div>
    <button type="submit">Отправить</button>
</form>
АтрибутЧто делает
<label for="id">Привязка к input — клик по label фокусирует
type="email/tel/url"Валидация + мобильная клавиатура
requiredНе отправится без заполнения
placeholder="..."Подсказка в поле
name="..."Для отправки на сервер
AttributeWhat it does
<label for="id">Link to input — click label focuses input
type="email/tel/url"Validation + mobile keyboard
requiredWon't submit without fill
placeholder="..."Hint in field
name="..."For server submission

📚 ACCESSIBILITY — ЧТО ДЕЛАТЬ

📚 ACCESSIBILITY — WHAT TO DO

Минимум обязательно:
  • lang="ru" на <html>
  • alt у всех <img>
  • <label> у каждого <input>
  • Семантические теги (не только div)
  • Правильная иерархия h1-h6
  • Ссылки понятны вне контекста
  • Контраст цветов (webaim.org)
Minimum required:
  • lang="en" on <html>
  • alt on all <img>
  • <label> for every <input>
  • Semantic tags (not just div)
  • Proper h1-h6 hierarchy
  • Links clear out of context
  • Color contrast (webaim.org)

📚 ПОРЯДОК РАБОТЫ

📚 WORK ORDER

  1. Главная страница (самая сложная) → сверху вниз
  2. Копировать header и footer на остальные страницы
  3. Заменить <main> контент на своё
  4. Проверить навигацию (все ссылки работают)
  5. Проставить .active на текущей странице в меню
  1. Home page first (most complex) → top-down
  2. Copy header and footer to other pages
  3. Replace <main> content with your own
  4. Check navigation (all links work)
  5. Mark .active on current page in menu
