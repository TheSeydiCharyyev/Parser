Объединение ячеек

Merging cells

АтрибутЧто делаетПример
colspan="3"Ячейка занимает 3 столбца<td colspan="3">
rowspan="2"Ячейка занимает 2 строки<td rowspan="2">
AttributeWhat it doesExample
colspan="3"Cell spans 3 columns<td colspan="3">
rowspan="2"Cell spans 2 rows<td rowspan="2">
Важно: Если ячейка с colspan="3", в этой строке нужно на 2 ячейки <td> меньше. Если rowspan="2", в следующей строке нужно на 1 ячейку меньше.
Important: If a cell has colspan="3", that row needs 2 fewer <td> cells. If rowspan="2", the next row needs 1 fewer cell.

Базовый CSS для таблицы

Basic table CSS

table {
    width: 100%;
    border-collapse: collapse;
}
th, td {
    padding: 12px 16px;
    border: 1px solid #e2e8f0;
    text-align: left;
}
th {
    background: #f1f5f9;
    font-weight: 600;
}
tbody tr:nth-child(even) {
    background: #f8fafc;
}
tbody tr:hover {
    background: #dbeafe;
}
