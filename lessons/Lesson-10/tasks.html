Задание 9.1: Таблица одноклассников Task 9.1: Classmates table
Лёгкое Easy 10 минут 10 min
Научиться создавать базовую таблицу с заголовками
Learn to create a basic table with headers

Условие:

Instructions:

Создайте файл classmates.html. Сделайте таблицу с данными о 5 одноклассниках (можно вымышленных):

Create a file classmates.html. Make a table with data about 5 classmates (can be fictional):

СтолбецПример
ИмяМерген
Возраст16
ГородАшхабад
ХоббиПрограммирование
ColumnExample
NameMergen
Age16
CityAshgabat
HobbyProgramming

Требования:

Requirements:

  1. Первая строка — заголовки (<th>): Имя, Возраст, Город, Хобби
  2. 5 строк с данными (<td>)
  3. Добавьте в <style> базовый CSS: border-collapse: collapse, рамки, padding
  1. First row — headers (<th>): Name, Age, City, Hobby
  2. 5 data rows (<td>)
  3. Add basic CSS in <style>: border-collapse: collapse, borders, padding
Минимальный CSS для красивой таблицы: 
table { width: 100%; border-collapse: collapse; }
th, td { padding: 10px; border: 1px solid #ddd; text-align: left; }
th { background: #f1f5f9; }

  • 4 столбца
  • border-collapse: collapse применён
  • Ячейки имеют padding и рамки
  • Table has headers (<th>)
  • At least 5 data rows
  • 4 columns
  • border-collapse: collapse is applied
  • Cells have padding and borders
Задание 9.2: Таблица с colspan и rowspan Task 9.2: Table with colspan and rowspan
Среднее Medium 15 минут 15 min
Научиться объединять ячейки с помощью colspan и rowspan
Learn to merge cells using colspan and rowspan

Условие:

Instructions:

Создайте файл schedule.html. Сделайте таблицу-расписание занятий на 3 дня:

Create a file schedule.html. Make a class schedule table for 3 days:

  1. Первая строка: общий заголовок «Расписание на неделю» с colspan на всю ширину
  2. Вторая строка: заголовки столбцов — День, Время, Предмет, Кабинет
  3. Понедельник — 3 урока (используй rowspan="3" для ячейки «Понедельник»)
  4. Среда — 2 урока (используй rowspan="2")
  5. Пятница — 2 урока (используй rowspan="2")
  1. First row: main title "Weekly Schedule" with colspan spanning full width
  2. Second row: column headers — Day, Time, Subject, Room
  3. Monday — 3 lessons (use rowspan="3" for the "Monday" cell)
  4. Wednesday — 2 lessons (use rowspan="2")
  5. Friday — 2 lessons (use rowspan="2")

Примерный вид:

|           Расписание на неделю            |  <-- colspan="4"
|    День    | Время |  Предмет  | Кабинет  |
|            | 09:00 | HTML      |   101    |
| Понедельник| 10:00 | CSS       |   101    |  <-- rowspan="3"
|            | 11:00 | JavaScript|   102    |
|    Среда   | 09:00 | Git       |   103    |  <-- rowspan="2"
|            | 10:00 | Практика  |   101    |
|   Пятница  | 09:00 | Проект    |   101    |  <-- rowspan="2"
|            | 10:00 | Ревью     |   102    |

Expected result:

|              Weekly Schedule               |  <-- colspan="4"
|    Day     | Time  |  Subject  |   Room   |
|            | 09:00 | HTML      |   101    |
|   Monday   | 10:00 | CSS       |   101    |  <-- rowspan="3"
|            | 11:00 | JavaScript|   102    |
|  Wednesday | 09:00 | Git       |   103    |  <-- rowspan="2"
|            | 10:00 | Practice  |   101    |
|   Friday   | 09:00 | Project   |   101    |  <-- rowspan="2"
|            | 10:00 | Review    |   102    |
  • colspan используется для общего заголовка
  • rowspan используется для дней недели
  • Минимум 7 строк данных
  • Таблица стилизована (рамки, padding, фон заголовков)
  • colspan is used for the main title
  • rowspan is used for weekdays
  • At least 7 data rows
  • Table is styled (borders, padding, header background)

Задание 9.3: Полосатая таблица с hover Task 9.3: Striped table with hover
Лёгкое Easy 10 минут 10 min
Научиться применять zebra-эффект и hover к таблицам
Learn to apply zebra effect and hover to tables

Условие:

Instructions:

Возьмите таблицу из задания 9.1 (одноклассники) и добавьте стили:

Take the table from task 9.1 (classmates) and add styles:

  1. Используйте thead, tbody для семантичности
  2. Добавьте полосатый эффект: каждая чётная строка — другого цвета (:nth-child(even))
  3. Добавьте hover-эффект: при наведении строка подсвечивается (tr:hover)
  4. Добавьте плавный переход: transition: background 0.2s ease
  5. Стилизуйте заголовок: тёмный фон, белый текст
  1. Use thead, tbody for semantics
  2. Add striped effect: every even row has a different color (:nth-child(even))
  3. Add hover effect: rows highlight on mouse hover (tr:hover)
  4. Add smooth transition: transition: background 0.2s ease
  5. Style the header: dark background, white text
thead th {
    background: #1e293b;
    color: #fff;
}
tbody tr:nth-child(even) {
    background: #f8fafc;
}
tbody tr:hover {
    background: #dbeafe;
}
tbody tr {
    transition: background 0.2s ease;
}

Задание 9.4: Таблица тарифов Task 9.4: Pricing table
Среднее Medium 20 минут 20 min
Создать красивую таблицу тарифов с выделенным столбцом
Create a beautiful pricing table with a highlighted column

Условие:

Instructions:

Создайте файл pricing.html с внешним CSS-файлом pricing.css. Сделайте таблицу тарифов:

Create a file pricing.html with an external CSS file pricing.css. Make a pricing table:

  1. 3 тарифных плана: Базовый, Про, Бизнес
  2. Минимум 5 строк параметров: Цена, Проекты, Хранилище, Поддержка, Аналитика (или свои)
  3. Выделить рекомендуемый план (например, «Про») с помощью CSS-класса .popular
  4. Используйте thead и tbody
  5. Стилизация:
    • Заголовки — тёмный фон
    • Столбец «Про» — выделен цветом (фон в thead и tbody)
    • Hover на строках
    • Скруглённые углы таблицы и/или тень
  6. Используйте символы ✓ и ✗ для «да» и «нет»
  1. 3 pricing plans: Basic, Pro, Business
  2. At least 5 parameter rows: Price, Projects, Storage, Support, Analytics (or your own)
  3. Highlight the recommended plan (e.g., "Pro") using a CSS class .popular
  4. Use thead and tbody
  5. Styling:
    • Headers — dark background
    • "Pro" column — highlighted with color (background in thead and tbody)
    • Hover on rows
    • Rounded table corners and/or shadow
  6. Use symbols ✓ and ✗ for "yes" and "no"

Примерный вид:

|          | Базовый  |   ПРО    |  Бизнес  |
|----------|----------|----------|----------|
| Цена     | $0       |   $9     |   $29    |
| Проекты  | 3        | Безлимит | Безлимит |
| Место    | 1 ГБ     |  50 ГБ   |  500 ГБ  |
| Поддержка| Email    | Чат 24/7 | Менеджер |
| Аналитика| ✗        |    ✓     |    ✓     |

Столбец «ПРО» выделен синим цветом

Expected result:

|          |  Basic   |   PRO    | Business |
|----------|----------|----------|----------|
| Price    | $0       |   $9     |   $29    |
| Projects | 3        | Unlimited| Unlimited|
| Storage  | 1 GB     |  50 GB   |  500 GB  |
| Support  | Email    | Chat 24/7| Manager  |
| Analytics| ✗        |    ✓     |    ✓     |

"PRO" column is highlighted in blue

└── pricing.css    ← все стили

Для ✓ используйте &#x2713;, для ✗ используйте &#x2717;

File structure:

├── pricing.html   ← HTML table + <link href="pricing.css">
└── pricing.css    ← all styles

For ✓ use &#x2713;, for ✗ use &#x2717;

  • Минимум 5 строк параметров
  • Рекомендуемый столбец выделен цветом
  • thead и tbody используются
  • CSS подключён через <link> (external)
  • Hover-эффект на строках
  • Таблица выглядит профессионально

Задание 9.5: Турнирная таблица Task 9.5: League standings table
Сложное Hard 15 минут 15 min
Создать сложную стилизованную таблицу с tfoot
Create a complex styled table with tfoot

Условие:

Instructions:

Создайте турнирную таблицу футбольной лиги:

Create a football league standings table:

  1. Столбцы: #, Команда, Игры, Победы, Ничьи, Поражения, Очки
  2. 6-8 команд (реальных или вымышленных)
  3. Используйте thead, tbody, tfoot
  4. В tfoot — строка «Всего игр» с colspan
  5. Используйте <caption> для названия лиги
  6. Стилизация: полосатая, hover, первые 3 команды — зелёный фон (зона Лиги чемпионов), последние 2 — красный (зона вылета)
  1. Columns: #, Team, Games, Wins, Draws, Losses, Points
  2. 6-8 teams (real or fictional)
  3. Use thead, tbody, tfoot
  4. In tfoot — a "Total games" row with colspan
  5. Use <caption> for the league name
  6. Styling: striped, hover, top 3 teams — green background (Champions League zone), bottom 2 — red (relegation zone)
Для выделения первых/последних строк используйте: 
tbody tr:nth-child(-n+3) { /* первые 3 */
    background: #f0fdf4;
}
tbody tr:nth-last-child(-n+2) { /* последние 2 */
    background: #fef2f2;
}
To highlight first/last rows: 
tbody tr:nth-child(-n+3) { /* first 3 */
    background: #f0fdf4;
}
tbody tr:nth-last-child(-n+2) { /* last 2 */
    background: #fef2f2;
}
  • 7 столбцов, 6-8 команд
  • thead, tbody, tfoot используются
  • caption присутствует
  • Зелёная зона (топ-3) и красная зона (последние 2) выделены
  • Hover-эффект работает
