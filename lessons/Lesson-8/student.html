CSS Position — позиционирование элементов

CSS Position — element positioning

📌 5 ЗНАЧЕНИЙ POSITION

📌 5 POSITION VALUES

position В потоке? In flow? Откуда считает координаты Reference point
static да yes — (top/left не работают) — (top/left don't work)
relative да (место сохраняется) yes (place preserved) от исходного места from original place
absolute нет (вырван) no (pulled out) от ближайшего relative-родителя from nearest relative parent
fixed нет no от окна браузера (viewport) from browser window (viewport)
sticky да, потом «прилипает» yes, then "sticks" от исходного места, потом от viewport from original place, then viewport

📐 TOP / RIGHT / BOTTOM / LEFT

📐 TOP / RIGHT / BOTTOM / LEFT

Эти свойства задают отступ от соответствующего края родителя (для absolute/fixed/sticky) или от исходного места (для relative).

top: 20px — элемент опустится на 20px вниз
right: 20px — элемент сдвинется на 20px влево от правого края
bottom: 20px — элемент поднимется на 20px от нижнего края
left: 20px — элемент сдвинется на 20px вправо

These properties set the offset from the corresponding edge of the parent (for absolute/fixed/sticky) or from original place (for relative).

top: 20px — element moves 20px down
right: 20px — element moves 20px left from right edge
bottom: 20px — element moves 20px up from bottom edge
left: 20px — element moves 20px right

Отрицательные значения: элемент уходит в противоположную сторону. top: -10px — поднимается на 10px выше.

Negative values: element moves in opposite direction. top: -10px — moves 10px higher.

🎯 ГЛАВНЫЙ ПАТТЕРН: relative + absolute

🎯 KEY PATTERN: relative + absolute

Абсолютная позиция считается от ближайшего предка с position отличным от static. Если такого нет — от <html> (всей страницы).

Absolute position is counted from the nearest ancestor with position other than static. If none — from <html> (whole page).

/* Шаблон "бейдж в углу карточки" */
.card {
    position: relative;   /* привязка для бейджа */
}
.badge {
    position: absolute;
    top: 10px;
    right: 10px;
}

99% случаев: хочешь absolute у ребёнка — поставь position: relative на родителя. Без координат — это просто «привязка».

99% of cases: want absolute on a child — set position: relative on the parent. Without coordinates, it's just an "anchor."

🔝 STICKY-ШАПКА

🔝 STICKY HEADER

.site-header {
    position: sticky;
    top: 0;             /* обязательно! */
    background: white;  /* обязательно, иначе текст просвечивает */
    z-index: 100;       /* поверх контента */
}

Sticky не работает? Проверь:

  1. Указан top (или другая сторона)?
  2. На каком-то родителе нет overflow: hidden/scroll/auto?
  3. Родитель выше самой sticky-шапки?

Sticky doesn't work? Check:

  1. Is top (or another side) set?
  2. Does any parent have overflow: hidden/scroll/auto?
  3. Is the parent taller than the sticky element itself?

📌 FIXED-ЭЛЕМЕНТЫ

📌 FIXED ELEMENTS

/* Кнопка "Наверх" */
.back-to-top {
    position: fixed;
    bottom: 24px;
    right: 24px;
    z-index: 50;
}

/* Модалка-фон на весь экран */
.modal-backdrop {
    position: fixed;
    top: 0; left: 0; right: 0; bottom: 0;
    background: rgba(0,0,0,0.5);
    z-index: 1000;
}

Fixed-шапка ≠ sticky-шапка. Fixed вырвана из потока, контент уходит ПОД неё. Если используешь fixed-шапку высотой 70px — добавь padding-top: 70px на main.

Fixed header ≠ sticky header. Fixed is pulled from flow, content goes UNDER it. If you use a 70px fixed header — add padding-top: 70px to main.

🔢 Z-INDEX — ШКАЛА

🔢 Z-INDEX — SCALE

z-indexЧтоWhat
-1Декоративный фон под контентомDecorative background under content
1-10Бейджи, иконкиBadges, icons
50-100Sticky/fixed шапка, dropdownSticky/fixed header, dropdown
1000+Модалки, тостыModals, toasts

z-index работает только если у элемента position ≠ static. На обычном элементе z-index игнорируется.

z-index only works if the element has position ≠ static. On a regular element z-index is ignored.

🚫 ТОП-5 ОШИБОК

🚫 TOP-5 MISTAKES

  1. absolute без relative-родителя → улетает в угол страницы
  2. sticky без top → не прилипает
  3. sticky с overflow:hidden на родителе → не работает
  4. прозрачная sticky-шапка → текст просвечивает
  5. z-index без position → игнорируется
  1. absolute without relative parent → flies to page corner
  2. sticky without top → doesn't stick
  3. sticky with overflow:hidden on parent → doesn't work
  4. transparent sticky header → text shows through
  5. z-index without position → ignored
