🎯 Lesson 21.1: RESPONSIVE UNITS

Задание 20.1: Лаборатория единиц Task 20.1: Units laboratory
Лёгкое Easy 10 минут 10 min
Увидеть разницу между px, %, vw, rem, clamp() на практике
See the difference between px, %, vw, rem, clamp() in practice

Условие:

Instructions:

Создайте файл units-lab.html. Сделайте 5 цветных блоков, каждый с разной шириной:

Create a file units-lab.html. Make 5 colored blocks, each with a different width:

  1. Блок 1: width: 300px — красный фон (#fee2e2), подпись «300px — фиксированный»
  2. Блок 2: width: 50% — жёлтый фон (#fef3c7), подпись «50% — половина родителя»
  3. Блок 3: width: 50vw — зелёный фон (#dcfce7), подпись «50vw — половина viewport»
  4. Блок 4: width: 20rem — синий фон (#dbeafe), подпись «20rem = 320px»
  5. Блок 5: width: clamp(200px, 50vw, 600px) — фиолетовый фон (#ede9fe), подпись «clamp — адаптивный»
  1. Block 1: width: 300px — red background (#fee2e2), label "300px — fixed"
  2. Block 2: width: 50% — yellow background (#fef3c7), label "50% — half of parent"
  3. Block 3: width: 50vw — green background (#dcfce7), label "50vw — half of viewport"
  4. Block 4: width: 20rem — blue background (#dbeafe), label "20rem = 320px"
  5. Block 5: width: clamp(200px, 50vw, 600px) — purple background (#ede9fe), label "clamp — responsive"

Каждый блок: padding: 16px, margin-bottom: 12px, border-radius: 8px, шрифт жирный. Сужайте окно и наблюдайте, какие блоки меняются, а какие — нет!

Each block: padding: 16px, margin-bottom: 12px, border-radius: 8px, bold font. Resize the window and observe which blocks change and which don't!

Добавьте также 3 заголовка с разными шрифтами для сравнения:
h1 { font-size: 32px; } (фиксированный)
h2 { font-size: 2rem; } (относительный)
h3 { font-size: clamp(1rem, 3vw, 2rem); } (плавный)
Also add 3 headings with different fonts for comparison:
h1 { font-size: 32px; } (fixed)
h2 { font-size: 2rem; } (relative)
h3 { font-size: clamp(1rem, 3vw, 2rem); } (fluid)
  • 5 блоков с разными единицами ширины
  • Подписи на каждом блоке
  • 3 заголовка с разными единицами шрифта
  • Видна разница при изменении размера окна
  • Проверено в DevTools (iPhone + Desktop)
  • 5 blocks with different width units
  • Labels on each block
  • 3 headings with different font units
  • Difference visible when resizing window
  • Tested in DevTools (iPhone + Desktop)

🎯 Lesson 21.2: BURGER MENU

Задание 20.2: Бургер-меню на CSS Task 20.2: CSS burger menu
Среднее Medium 20 минут 20 min
Создать header с бургер-меню на чистом CSS (без JavaScript)
Create a header with pure CSS burger menu (no JavaScript)

Условие:

Instructions:

Создайте файл burger-menu.html. Постройте header с навигацией по шагам:

Create a file burger-menu.html. Build a header with navigation step by step:

  1. HTML-структура:
    • <header class="header"> с flexbox
    • Лого слева: <a class="logo">MySite</a>
    • Чекбокс: <input type="checkbox" id="menu-toggle" class="menu-toggle">
    • Бургер-иконка: <label for="menu-toggle" class="burger"> с 3 <span>
    • Навигация: <nav class="nav"> с 4 ссылками (Home, About, Services, Contact)
  2. Десктоп (≥ 769px):
    • Навигация горизонтальная (display: flex; gap: 20px)
    • Бургер скрыт (display: none)
    • Чекбокс скрыт (display: none)
  3. Мобильный (≤ 768px):
    • Бургер виден (display: flex; flex-direction: column)
    • Навигация скрыта (display: none)
    • Клик по бургеру → навигация появляется вертикально: .menu-toggle:checked ~ .nav { display: flex; }
    • Бургер превращается в крестик через transform: rotate()
  1. HTML structure:
    • <header class="header"> with flexbox
    • Logo on left: <a class="logo">MySite</a>
    • Checkbox: <input type="checkbox" id="menu-toggle" class="menu-toggle">
    • Burger icon: <label for="menu-toggle" class="burger"> with 3 <span>s
    • Navigation: <nav class="nav"> with 4 links (Home, About, Services, Contact)
  2. Desktop (≥ 769px):
    • Horizontal navigation (display: flex; gap: 20px)
    • Burger hidden (display: none)
    • Checkbox hidden (display: none)
  3. Mobile (≤ 768px):
    • Burger visible (display: flex; flex-direction: column)
    • Navigation hidden (display: none)
    • Click burger → navigation appears vertically: .menu-toggle:checked ~ .nav { display: flex; }
    • Burger turns into X via transform: rotate()
Порядок в HTML критически важен! Чекбокс и label должны быть перед nav, потому что селектор ~ работает только вперёд. Если nav стоит перед input — ничего не заработает.
HTML order is critical! Checkbox and label must be before nav, because the ~ selector only works forward. If nav is before input — nothing will work.
  • Без JavaScript (только CSS)
  • На десктопе: горизонтальная навигация, бургер скрыт
  • На мобильном: бургер виден, клик → вертикальное меню
  • Бургер → крестик анимация (transform: rotate)
  • Плавный transition: 0.3s на полосках бургера
  • for/id совпадают у label и input
  • Проверено: iPhone + Desktop в DevTools
  • No JavaScript (CSS only)
  • On desktop: horizontal navigation, burger hidden
  • On mobile: burger visible, click → vertical menu
  • Burger → X animation (transform: rotate)
  • Smooth transition: 0.3s on burger lines
  • for/id match between label and input
  • Tested: iPhone + Desktop in DevTools

🎯 Lesson 21.3: FULL RESPONSIVE PAGE

Задание 20.3: Адаптивная навигация + сетка карточек Task 20.3: Responsive nav + card grid
Среднее Medium 25 минут 25 min
Собрать полную адаптивную страницу, объединив бургер-меню, hero, карточки и sticky footer
Build a full responsive page combining burger menu, hero, cards and sticky footer

Условие:

Instructions:

Создайте папку responsive-full с index.html и style.css. Страница состоит из 4 секций:

Create a folder responsive-full with index.html and style.css. The page has 4 sections:

  1. Header с бургер-меню (из задания 20.2):
    • Лого + навигация (4 ссылки)
    • Десктоп: горизонтальная навигация
    • Мобильный: бургер-меню (checkbox hack)
  2. Hero-секция:
    • height: 100vh
    • Фоновый градиент: linear-gradient(135deg, #667eea, #764ba2)
    • Заголовок: font-size: clamp(2rem, 5vw, 4rem)
    • Подзаголовок: font-size: clamp(1rem, 2vw, 1.25rem)
    • Кнопка CTA (белая, border-radius: 8px)
    • Центрирование через Flexbox
  3. Секция карточек:
    • Контейнер: width: 90%; max-width: 1200px; margin: 0 auto
    • 6 карточек с изображениями (picsum.photos)
    • Картинки: width: 100%; height: 200px; object-fit: cover
    • Mobile: 1 колонка, Tablet (768px+): 2, Desktop (1024px+): 3
    • Шрифты в rem
  4. Footer:
    • Sticky footer: body { display: grid; grid-template-rows: auto 1fr auto; min-height: 100vh; }
    • Тёмный фон, светлый текст
  1. Header with burger menu (from task 20.2):
    • Logo + navigation (4 links)
    • Desktop: horizontal navigation
    • Mobile: burger menu (checkbox hack)
  2. Hero section:
    • height: 100vh
    • Background gradient: linear-gradient(135deg, #667eea, #764ba2)
    • Heading: font-size: clamp(2rem, 5vw, 4rem)
    • Subheading: font-size: clamp(1rem, 2vw, 1.25rem)
    • CTA button (white, border-radius: 8px)
    • Centering via Flexbox
  3. Cards section:
    • Container: width: 90%; max-width: 1200px; margin: 0 auto
    • 6 cards with images (picsum.photos)
    • Images: width: 100%; height: 200px; object-fit: cover
    • Mobile: 1 column, Tablet (768px+): 2, Desktop (1024px+): 3
    • Fonts in rem
  4. Footer:
    • Sticky footer: body { display: grid; grid-template-rows: auto 1fr auto; min-height: 100vh; }
    • Dark background, light text
Начните с мобильной версии (mobile-first): базовые стили для телефона, потом @media (min-width: 768px) и @media (min-width: 1024px). Для бургера используйте @media (max-width: 768px).
Start with mobile version (mobile-first): base styles for phone, then @media (min-width: 768px) and @media (min-width: 1024px). For burger use @media (max-width: 768px).
  • Бургер-меню работает без JS
  • Hero = 100vh + clamp() шрифт + кнопка CTA
  • Контейнер: width: 90% + max-width: 1200px
  • Адаптивные картинки: max-width: 100% + object-fit: cover
  • Карточки: 1 → 2 → 3 колонки
  • Sticky footer (footer внизу даже при малом контенте)
  • rem для шрифтов
  • CSS в отдельном файле (style.css)
  • Протестировано на iPhone, iPad, Desktop в DevTools
