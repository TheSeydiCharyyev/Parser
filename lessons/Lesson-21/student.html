📚 RESPONSIVE UNITS

Вместо фиксированных px используем относительные единицы, которые подстраиваются под экран:
Instead of fixed px we use relative units that adapt to the screen:

Simple rule: rem for fonts, % for container widths, vh for hero height, px for small things (border, shadow). clamp() for headings.

📚 КЛЮЧЕВЫЕ ФОРМУЛЫ

📚 KEY FORMULAS

/* Адаптивный контейнер */
.container {
    width: 90%;
    max-width: 1200px;
    margin: 0 auto;
}

/* Адаптивные картинки (ОБЯЗАТЕЛЬНО!) */
img {
    max-width: 100%;
    height: auto;
}

/* Заполнение с обрезкой */
.card img {
    width: 100%;
    height: 200px;
    object-fit: cover;
}

/* Плавный шрифт (без media queries!) */
h1 { font-size: clamp(1.5rem, 4vw, 3rem); }

/* Hero на весь экран */
.hero { height: 100vh; }
clamp(min, ideal, max) — шрифт плавно растёт от min до max. Центральное значение (4vw) определяет скорость роста. Заменяет несколько media queries одной строкой!
clamp(min, ideal, max) — font smoothly grows from min to max. The middle value (4vw) determines the growth speed. Replaces several media queries with one line!

html { font-size: 16px; }
h1 { font-size: 2rem; }      /* = 32px, всегда */
h2 { font-size: 1.5rem; }    /* = 24px, всегда */

📚 RESPONSIVE IMAGES

Без max-width: 100% картинка вылезет за экран на мобильном. Это правило ставят в начало CSS.
Without max-width: 100% an image will overflow the screen on mobile. This rule goes at the top of CSS.

📚 БУРГЕР-МЕНЮ (CSS-ONLY)

📚 BURGER MENU (CSS-ONLY)

Принцип: скрытый <input type="checkbox"> + <label> (иконка) + <nav>. Когда чекбокс checked → показать nav через :checked ~ .nav. Без JavaScript!
Principle: hidden <input type="checkbox"> + <label> (icon) + <nav>. When checkbox checked → show nav via :checked ~ .nav. No JavaScript! 
/* HTML (порядок важен!): */
<input type="checkbox" id="toggle" class="menu-toggle">
<label for="toggle" class="burger">
    <span></span><span></span><span></span>
</label>
<nav class="nav">...</nav>

/* CSS: */
.menu-toggle { display: none; }    /* скрыть чекбокс */
.burger { display: none; }          /* скрыт на десктопе */

@media (max-width: 768px) {
    .burger { display: flex; flex-direction: column; }
    .nav { display: none; }          /* навигация скрыта */
    .menu-toggle:checked ~ .nav { display: flex; }  /* показать! */

    /* Бургер → крестик */
    .menu-toggle:checked ~ .burger span:nth-child(1) {
        transform: rotate(45deg) translate(5px, 6px);
    }
    .menu-toggle:checked ~ .burger span:nth-child(2) { opacity: 0; }
    .menu-toggle:checked ~ .burger span:nth-child(3) {
        transform: rotate(-45deg) translate(5px, -6px);
    }
}
Три частые ошибки: 1) for="" у label не совпадает с id="" чекбокса. 2) <nav> стоит перед <input> (селектор ~ работает только вперёд). 3) Забыли display: none на чекбоксе.
Three common mistakes: 1) label for="" doesn't match checkbox id="". 2) <nav> is before <input> (the ~ selector only works forward). 3) Forgot display: none on checkbox.
