Master basic Tailwind utility classes

Условие:

Instructions:

Создайте файл tailwind-lab.html с подключённым Tailwind CDN. Покажите на одной странице:

Create a file tailwind-lab.html with Tailwind CDN connected. Show on one page:

  1. Цвета: 8 блоков с разными bg-{color}-500 + text-white p-4 rounded-lg mb-2
  2. Типография: text-sm, text-base, text-lg, text-xl, text-3xl, text-5xl — каждый с подписью размера
  3. Тени: 5 блоков: shadow-sm, shadow, shadow-md, shadow-lg, shadow-xl
  4. Скругления: 5 блоков: rounded, rounded-lg, rounded-xl, rounded-2xl, rounded-full
  5. Spacing: блоки с p-1 по p-8 (видна разница отступов)
  1. Colors: 8 blocks with different bg-{color}-500 + text-white p-4 rounded-lg mb-2
  2. Typography: text-sm, text-base, text-lg, text-xl, text-3xl, text-5xl — each with size label
  3. Shadows: 5 blocks: shadow-sm, shadow, shadow-md, shadow-lg, shadow-xl
  4. Rounded: 5 blocks: rounded, rounded-lg, rounded-xl, rounded-2xl, rounded-full
  5. Spacing: blocks with p-1 through p-8 (visible padding difference)
Важно: подключение — через <script>, не <link>! 
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Tailwind Lab</title>
    <script src="https://cdn.tailwindcss.com"></script>
</head>
<body class="bg-gray-100 p-8">
    <!-- содержимое -->
</body>
</html>
Формула: p-N = N × 4 пикселей. p-4 = 16px, p-8 = 32px.
Important: connect via <script>, not <link>! 
<!DOCTYPE html>
<html lang="en">

    <!-- content -->
</body>
</html>
Formula: p-N = N × 4 pixels. p-4 = 16px, p-8 = 32px.

  1. Header: flex items-center justify-between p-4 bg-white shadow — logo + 3 links + button
  2. 3-column Grid: grid grid-cols-3 gap-6 p-8 — 6 colored blocks
  3. 4-column Grid: grid grid-cols-4 gap-4 — 8 small blocks
  4. Flex column: flex flex-col gap-4 — sidebar with 5 links
  5. Centering: flex items-center justify-center h-64 bg-gray-100 — centered text
Шпаргалка соответствий: 
display: flex           → flex
flex-direction: column  → flex-col
align-items: center     → items-center
justify-content: center → justify-center
justify-content: space-between → justify-between
gap: 16px               → gap-4
display: grid           → grid
grid-template-columns: repeat(3, 1fr) → grid-cols-3

Задание 26.4: Bootstrap vs Tailwind Task 26.4: Bootstrap vs Tailwind
Сложное Hard 15 минут 15 min
Создать одинаковую карточку на Bootstrap и Tailwind
Create the same card on Bootstrap and Tailwind

Условие:

Instructions:

Создайте 2 файла — одинаковая карточка товара:

Create 2 files — the same product card:

  1. card-bootstrap.html — карточка на Bootstrap (card card-body...)
  2. card-tailwind.html — та же карточка на Tailwind (bg-white rounded-xl shadow-md...)
  3. Сравните: сколько классов, насколько гибко, какой код читаемее
  1. card-bootstrap.html — card with Bootstrap (card card-body...)
  2. card-tailwind.html — same card with Tailwind (bg-white rounded-xl shadow-md...)
  3. Compare: how many classes, how flexible, which code is more readable
Подумайте перед сравнением над вопросами:
  • Какой подход вам показался быстрее?
  • В каком коде легче увидеть «что он делает»?
  • Что если бы надо было 10 карточек в разных стилях?
  • Что если клиент попросит «поменять основной цвет»?
Ответы запишите в комментариях (<!-- -->) в каждом из файлов.
Think about these questions before comparing:
  • Which approach felt faster?
  • Which code is easier to "see what it does"?
  • What if you needed 10 cards in different styles?
  • What if the client asks to "change the primary color"?
Write answers in comments (<!-- -->) in each file.

  • В каждом файле — комментарии с ответами на вопросы выше
