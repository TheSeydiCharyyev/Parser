📚 ЧТО ТАКОЕ TAILWIND

📚 WHAT IS TAILWIND

Tailwind CSS — utility-first фреймворк. Вместо готовых компонентов (как Bootstrap) даёт маленькие классы (p-4, bg-blue-500, rounded-lg), из которых собираете что угодно. Используется Vercel, Netflix, Shopify.
Tailwind CSS — utility-first framework. Instead of ready components (like Bootstrap), gives small classes (p-4, bg-blue-500, rounded-lg) to build anything. Used by Vercel, Netflix, Shopify.
Bootstrap = IKEA (готовые шкафы). Tailwind = LEGO (кирпичики, строй что хочешь).
Bootstrap = IKEA (ready furniture). Tailwind = LEGO (bricks, build anything).

📚 ФОРМУЛА РАЗМЕРОВ

📚 SIZE FORMULA

Число × 4 = пиксели. p-2 = 8px, p-4 = 16px, p-8 = 32px, p-16 = 64px, p-24 = 96px. Запомните — и отступы станут интуитивными.
Number × 4 = pixels. p-2 = 8px, p-4 = 16px, p-8 = 32px, p-16 = 64px, p-24 = 96px. Memorize — and spacing becomes intuitive.

📚 COLOR PALETTE

22 цвета × 11 оттенков (от 50 до 950). Формат: text-{цвет}-{оттенок}, bg-{цвет}-{оттенок}.
22 colors × 11 shades (from 50 to 950). Format: text-{color}-{shade}, bg-{color}-{shade}.

Правило контраста: разница оттенков фона и текста ≥ 400. bg-gray-200 + text-gray-800 — хорошо, bg-gray-200 + text-gray-400 — нечитаемо.
Contrast rule: bg/text shade difference ≥ 400. bg-gray-200 + text-gray-800 — good, bg-gray-200 + text-gray-400 — unreadable.
