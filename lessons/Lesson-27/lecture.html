1. Что такое Tailwind CSS

1. What is Tailwind CSS

Tailwind CSS — utility-first CSS-фреймворк. Вместо готовых компонентов (как Bootstrap) он даёт маленькие утилити-классы, из которых вы собираете дизайн.

Tailwind CSS — a utility-first CSS framework. Instead of ready components (like Bootstrap), it gives you small utility classes that you combine to build designs.

Обычный CSS
Regular CSS
<div class="card">...</div>

.card {
    padding: 24px;
    background: white;
    border-radius: 12px;
    box-shadow: 0 4px 6px
        rgba(0,0,0,0.1);
}
Tailwind ✅
<div class="p-6 bg-white
     rounded-xl shadow-md">
    ...
</div>

/* Ноль строк CSS! */

Bootstrap — это IKEA: готовые шкафы, просто собирай. Tailwind — это LEGO: маленькие кирпичики, строй что хочешь.

Bootstrap is IKEA: ready furniture, just assemble. Tailwind is LEGO: small bricks, build whatever you want.

Как это работает на практике. В файле index.html вы пишете <div class="p-6 bg-white rounded-xl shadow-md">. Tailwind читает ваш HTML, видит эти классы и генерирует CSS только для них: .p-6 { padding: 24px } .bg-white { background: white } .... В итоге CSS-файл получается крошечный (15-30 KB) — в нём только те классы, которые реально использованы. Это делает Tailwind-сайты быстрее, чем Bootstrap.

How it works in practice. In index.html you write <div class="p-6 bg-white rounded-xl shadow-md">. Tailwind reads your HTML, sees these classes, and generates CSS only for them: .p-6 { padding: 24px } .bg-white { background: white } .... The result is a tiny CSS file (15-30 KB) — containing only used classes. That makes Tailwind sites faster than Bootstrap.

2. Tailwind vs Bootstrap

2. Tailwind vs Bootstrap

Это главный вопрос, который задаст любой начинающий: «Какой выбрать?» Правильный ответ: зависит от проекта. Оба инструмента живы и востребованы. Bootstrap царит в админ-панелях и старых проектах. Tailwind — в современных стартапах и Jamstack-приложениях.

This is the main question every beginner asks: "Which one to pick?" Correct answer: depends on the project. Both tools are alive and in demand. Bootstrap rules in admin panels and legacy projects. Tailwind — in modern startups and Jamstack apps.

Когда что выбирать:

  • Bootstrap — если нужен быстрый результат, нет времени на дизайн, клиент не требует уникальности. Админки, MVP, CRUD-приложения.
  • Tailwind — если дизайн критичен (стартап, продуктовый лендинг), проект на React/Vue/Next, команда знает CSS и хочет свободы.
  • Чистый CSS — для небольших сайтов и учебных проектов, когда важно понимать фундамент.

When to pick what:

  • Bootstrap — for fast results, no time for design, client doesn't need uniqueness. Admins, MVPs, CRUD apps.
  • Tailwind — when design matters (startup, product landing), React/Vue/Next project, team knows CSS and wants freedom.
  • Pure CSS — for small sites and learning projects, where understanding fundamentals matters.

«Tailwind пишется прямо в HTML — это ужасно!» — самая частая критика новичков. Но вспомните: класс p-4 — это имя, как card. Разница в том, что card описан в CSS (нужно искать, понимать), а p-4 сразу говорит что делает. В больших проектах меньше файлов и быстрее находить нужное.

"Tailwind writes CSS in HTML — that's awful!" — the most common beginner critique. But remember: p-4 is a name, like card. Difference: card lives in CSS (you have to find it, understand it), p-4 instantly tells what it does. In large projects — fewer files and faster to find things.

3. CDN setup

CDN — только для обучения! В реальных проектах Tailwind устанавливается через npm. Но для наших занятий CDN идеально подходит.
CDN is for learning only! In real projects Tailwind is installed via npm. But for our lessons CDN works perfectly.

Tailwind — это <script>, а не <link>! В отличие от Bootstrap, где CDN это <link rel="stylesheet">, Tailwind CDN работает как JavaScript: он сканирует ваш HTML и генерирует CSS «на лету». Ставить нужно именно через <script src="https://cdn.tailwindcss.com">. Это один из самых частых вопросов новичков.

Tailwind is <script>, not <link>! Unlike Bootstrap where CDN is <link rel="stylesheet">, Tailwind CDN works as JavaScript: it scans your HTML and generates CSS on the fly. Connect via <script src="https://cdn.tailwindcss.com">. One of the most common beginner questions.

4. Spacing: отступы и размеры

4. Spacing: padding and margins

Отступы — самое частое действие в CSS. Tailwind даёт десятки классов (p-0 до p-96) — покрывает все размеры от 0px до 384px. Формат похож на Bootstrap, но шкала гораздо детальнее: там были значения 1-5 (4/8/16/24/48px), в Tailwind — от 0 до 96 с шагом 4px. Больше контроля.

Spacing is the most common CSS action. Tailwind gives dozens of classes (p-0 to p-96) — covers all sizes from 0px to 384px. Format is like Bootstrap, but the scale is much more detailed: there it was values 1-5 (4/8/16/24/48px), in Tailwind — from 0 to 96 with 4px step. More control.

Быстрая математика Tailwind: число × 4 = пиксели. p-2 = 8px. p-4 = 16px. p-8 = 32px. p-16 = 64px. p-24 = 96px. Есть исключение: p-px = 1px, p-0.5 = 2px, p-1.5 = 6px. Запомните формулу — и отступы станут интуитивными.

Quick Tailwind math: number × 4 = pixels. p-2 = 8px. p-4 = 16px. p-8 = 32px. p-16 = 64px. p-24 = 96px. Exceptions: p-px = 1px, p-0.5 = 2px, p-1.5 = 6px. Memorize the formula — and spacing becomes intuitive.

5. Цвета

5. Colors

В Bootstrap было 8 цветов (primary, danger, success...). В Tailwind — 22 цвета × 11 оттенков = 242 варианта. Это даёт огромную свободу дизайна. Каждый цвет имеет оттенки от 50 (почти белый) до 950 (почти чёрный). 500 — базовый средний оттенок.

Это главная причина, почему Tailwind-сайты выглядят разнообразно, а Bootstrap-сайты — однообразно (все используют один и тот же синий #0d6efd).

Bootstrap had 8 colors (primary, danger, success...). Tailwind has 22 colors × 11 shades = 242 variants. Huge design freedom. Each color has shades from 50 (nearly white) to 950 (nearly black). 500 — base middle shade.

This is the main reason Tailwind sites look diverse, while Bootstrap sites look uniform (everyone uses the same blue #0d6efd).

Формула хорошей пары «фон + текст»:

  • Тёмный фон (bg-blue-600/700) + белый текст (text-white)
  • Светлый фон (bg-blue-50/100) + тёмный текст (text-blue-900)
  • Серые иконки (text-gray-400) + чёрный текст (text-gray-900)

Правило: разница между оттенками фона и текста должна быть ≥ 400. bg-gray-200 + text-gray-400 — нечитаемо. bg-gray-200 + text-gray-800 — хорошо.

Formula for good bg+text pair:

  • Dark bg (bg-blue-600/700) + white text (text-white)
  • Light bg (bg-blue-50/100) + dark text (text-blue-900)
  • Gray icons (text-gray-400) + black text (text-gray-900)

Rule: difference between bg and text shades should be ≥ 400. bg-gray-200 + text-gray-400 — unreadable. bg-gray-200 + text-gray-800 — good.

6. Типография

6. Typography

Типография = как выглядит текст. В Tailwind размеры шрифта — относительные: text-sm (14px), text-base (16px), text-lg (18px), text-xl (20px), text-2xl (24px) — и так до text-9xl (128px). Вместо запоминания точных пикселей — запоминаете имена размеров.

Typography = how text looks. In Tailwind, font sizes are relative: text-sm (14px), text-base (16px), text-lg (18px), text-xl (20px), text-2xl (24px) — all the way to text-9xl (128px). Instead of memorizing exact pixels — you remember size names.

7. Layout: Flexbox и Grid

7. Layout: Flexbox and Grid

Вот где Tailwind ярко показывает свою силу. В отличие от Bootstrap (у которого «своя» 12-колоночная сетка с row/col), Tailwind напрямую маппит на CSS flexbox/grid: flex = display: flex, grid-cols-3 = grid-template-columns: repeat(3, 1fr). Если вы знаете flexbox и grid — вы уже знаете layout в Tailwind.

Here Tailwind shows its strength. Unlike Bootstrap (with its 12-column grid via row/col), Tailwind maps directly to CSS flexbox/grid: flex = display: flex, grid-cols-3 = grid-template-columns: repeat(3, 1fr). If you know flexbox and grid — you already know Tailwind layout.

<!-- Flexbox -->
<div class="flex items-center justify-between gap-4">
    <span>Logo</span>
    <nav class="flex gap-6">
        <a href="#">Home</a>
        <a href="#">About</a>
    </nav>
</div>

<!-- Flex column -->
<div class="flex flex-col gap-4">...</div>

<!-- Grid -->
<div class="grid grid-cols-3 gap-6">
    <div>1</div>
    <div>2</div>
    <div>3</div>
</div>

<!-- Центрирование -->
<div class="flex items-center justify-center min-h-screen">
    <h1>Centered!</h1>
</div>
