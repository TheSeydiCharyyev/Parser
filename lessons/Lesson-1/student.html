📚 УРОК 1.1: КАК РАБОТАЕТ ИНТЕРНЕТ И ВЕБ

Клиент и сервер

Клиент — ваш компьютер и браузер. Он запрашивает информацию.
Сервер — мощный компьютер, который хранит файлы сайта и отдаёт их клиенту.
ВЫ (клиент) СЕРВЕР ┌──────────────┐ ┌──────────────┐ │ Браузер │ ── 1. Запрос ──────► │ Компьютер │ │ (Chrome) │ │ с файлами │ │ │ ◄── 2. Ответ ─────── │ сайта │ └──────────────┘ (HTML, CSS, JS) └──────────────┘
Аналогия: Клиент = посетитель ресторана, Сервер = кухня, Интернет = официант

URL — адрес сайта

https://www.google.com/search?q=html https:// — протокол (безопасное соединение) www. — поддомен google.com — доменное имя (имя сайта) /search — путь (конкретная страница) ?q=html — параметры запроса

HTTP и HTTPS

  • HTTP — протокол общения клиента и сервера
  • HTTPS — то же, но с шифрованием (замочек 🔒 в браузере)
Запоминалка: HTTP = открытка (все могут прочитать), HTTPS = письмо в запечатанном конверте. Видишь замочек 🔒 в браузере — данные защищены!
  • Клиент — ваш браузер (отправляет запросы)
  • Сервер — хранит сайт (отвечает на запросы)
  • URL — адрес сайта (https://google.com)
  • DNS — переводит имя сайта в IP-адрес
  • HTTPS — безопасное соединение с шифрованием

📚 УРОК 1.2: HTML, CSS, JAVASCRIPT — ПОДРОБНЕЕ

HTML — HyperText Markup Language

HTML — язык гипертекстовой разметки. Это НЕ язык программирования! Он определяет структуру и содержимое страницы.

Основные HTML-теги:

ТегЧто делает
<h1>...</h1>Заголовок (самый важный)
<h2>...</h2>Подзаголовок
<p>...</p>Параграф текста
<a href="...">...</a>Ссылка
<img src="...">Картинка
<ul><li>...</li></ul>Список
<button>...</button>Кнопка

Пример HTML:

<h1>Привет, мир!</h1>
<p>Это мой первый сайт.</p>
<a href="https://google.com">Перейти в Google</a>
Запоминалка: HTML = чертёж дома. Говорит ЧТО есть на странице, но не КАК это выглядит.
  • HTML — это НЕ язык программирования (он не считает и не решает)
  • Теги работают парами: <p>...</p>
  • Некоторые теги — одиночные: <img>, <br>, <hr>
  • Теги вкладываются друг в друга — как матрёшки

CSS — Cascading Style Sheets

CSS — каскадные таблицы стилей. Отвечает за внешний вид страницы: цвета, шрифты, размеры, расположение.

Пример CSS:

h1 {
    color: red;          /* цвет текста */
    font-size: 48px;     /* размер шрифта */
    text-align: center;  /* выравнивание по центру */
}

body {
    background-color: #1a1a2e;  /* цвет фона */
    font-family: Arial;         /* шрифт */
}

Что может CSS:

  • Цвета — фон, текст, рамки
  • Шрифты — размер, жирность, семейство
  • Размеры — ширина, высота, отступы
  • Расположение — где что находится на странице
  • Анимации — плавные переходы
Запоминалка: CSS = дизайн интерьера. Говорит КАК выглядит страница.
Синтаксис CSS: селектор { свойство: значение; } Пример: h1 { color: red; ← свойство: значение; font-size: 48px; ← свойство: значение; }
Один и тот же HTML с разным CSS выглядит совершенно по-разному! Без CSS сайт — просто чёрный текст на белом фоне. CSS добавляет красоту.

JavaScript (JS)

JavaScript — настоящий язык программирования. Добавляет интерактивность: клики, анимации, загрузка данных.

Примеры JavaScript на сайтах:

  • Нажали «Нравится» → счётчик увеличился
  • Печатаете в поиске → появляются подсказки
  • Скроллите вниз → загружаются новые посты
  • Ошибка в форме → появляется предупреждение
На этом курсе мы изучаем HTML и CSS. JavaScript — следующий этап!

Структура HTML-документа

HTML-документ — это «матрёшка»: ┌─── <html> ─────────────────────────────────┐ │ │ │ ┌─── <head> ──────────────────────────┐ │ │ │ Для БРАУЗЕРА (не видно на странице) │ │ │ │ • charset (кодировка) │ │ │ │ • viewport (мобильные) │ │ │ │ • title (вкладка браузера) │ │ │ └─────────────────────────────────────┘ │ │ │ │ ┌─── <body> ──────────────────────────┐ │ │ │ Для ПОЛЬЗОВАТЕЛЯ (видно!) │ │ │ │ • заголовки, текст, картинки │ │ │ │ • ссылки, списки, кнопки │ │ │ └─────────────────────────────────────┘ │ │ │ └─────────────────────────────────────────────┘
<!DOCTYPE html>        <!-- Тип документа: HTML5 -->
<html lang="ru">        <!-- Начало документа, язык: русский -->
<head>                  <!-- Голова: информация для браузера -->
    <meta charset="UTF-8">              <!-- Кодировка -->
    <meta name="viewport" ...>          <!-- Для мобильных -->
    <title>Заголовок вкладки</title>    <!-- Название вкладки -->
</head>
<body>                  <!-- Тело: видимое содержимое -->

    <!-- Здесь пишем контент страницы -->

</body>
</html>
  • <head> — информация ДЛЯ БРАУЗЕРА (не видна на странице)
  • <body> — содержимое ДЛЯ ПОЛЬЗОВАТЕЛЯ (видно на странице)
  • ! + Tab в VS Code — создаёт весь шаблон автоматически
  • Не забудьте сменить lang="en" на lang="ru"!
Запоминалка: head = голова (думает, но не видна снаружи). body = тело (видно всем).

Моя первая страница

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Мой первый сайт</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Меня зовут ________. Это мой первый сайт!</p>

    <h2>Обо мне</h2>
    <p>Я учусь создавать сайты.</p>

    <h2>Мои увлечения</h2>
    <ul>
        <li>________</li>
        <li>________</li>
        <li>________</li>
    </ul>
</body>
</html>
Как запустить: Правый клик по файлу в VS Code → Open with Live Server
  • Файл главной страницы всегда называется index.html
  • Live Server запускает локальный сервер — адрес будет 127.0.0.1:5500
  • При каждом сохранении (Ctrl+S) страница обновляется автоматически

📝 ИТОГИ ЗАНЯТИЯ 1

Сегодня мы узнали:

  • Интернет работает по принципу клиент ↔ сервер (вы запрашиваете → сервер отвечает)
  • Веб-страница = HTML (что) + CSS (как выглядит) + JavaScript (что происходит)
  • URL — адрес сайта, DNS — переводит имя в IP, HTTPS — шифрование
  • Браузер рендерит (рисует) страницу из HTML/CSS/JS файлов
  • DevTools (F12) — инструмент для изучения и редактирования кода любого сайта
  • Frontend = видимая часть (HTML+CSS+JS), Backend = невидимая (сервер, БД)
  • VS Code — наш редактор кода (расширения: Live Server, Prettier, Auto Rename Tag)
  • ! + Tab — мгновенный шаблон HTML в VS Code
  • Live Server — автообновление страницы при сохранении
  • <head> — для браузера (невидимо), <body> — для пользователя (видимо)
