1. Краткая история интернета и веба

Прежде чем создавать сайты, полезно узнать, как появился интернет и веб — это поможет лучше понять, почему всё устроено именно так.

От военной сети до World Wide Web

1969 — ARPANET

Всё началось с военного проекта в США. Министерство обороны создало сеть ARPANET — она соединила 4 университетских компьютера. Цель была простая: если один компьютер выйдет из строя, остальные продолжат работать. Это была первая компьютерная сеть в истории.

1983 — Интернет

Был создан протокол TCP/IP — единый «язык», который позволил разным сетям общаться друг с другом. Именно эту дату считают рождением интернета. Но интернет тогда выглядел совсем не так, как сейчас — никаких сайтов, только текст в терминале.

1989 — Тим Бернерс-Ли изобретает веб

Британский учёный Тим Бернерс-Ли, работавший в CERN (Европейская организация по ядерным исследованиям), предложил систему, которая изменила мир. Он придумал три вещи: HTML (язык для создания страниц), URL (адреса страниц) и HTTP (протокол для передачи страниц).

1991 — Первый в мире сайт

Тим Бернерс-Ли запустил первый в мире веб-сайт. Он выглядел как простая текстовая страница с ссылками — никаких картинок, цветов или анимаций. Но это было начало эпохи, в которой мы живём сегодня.

1993 — Браузер Mosaic

Появился первый браузер с графическим интерфейсом — Mosaic. Впервые можно было видеть картинки рядом с текстом! Это сделало веб доступным для обычных людей, а не только для учёных.

1996 — CSS

Появился CSS — язык для оформления веб-страниц. До CSS весь дизайн делался прямо внутри HTML, что было неудобно. CSS позволил отделить содержимое от внешнего вида.

1995–2000 — Бум интернета

Появились Yahoo, Amazon, Google, eBay. Каждый хотел быть в интернете. Это время называют «пузырём доткомов» — тысячи компаний создавали сайты, и веб-разработчики стали невероятно востребованы.

2004–2010 — Web 2.0

Появились Facebook, YouTube, Twitter, Instagram. Веб стал интерактивным — пользователи начали создавать контент сами. JavaScript стал важнейшей технологией.

Сегодня

В интернете более 1.9 миллиарда сайтов. Мы смотрим видео, общаемся, учимся, покупаем, работаем — всё через веб. А основа всего этого по-прежнему те же три технологии: HTML, CSS и JavaScript.

Сэр Тим Бернерс-Ли
Изобретатель World Wide Web

Британский учёный, который в 1989 году придумал HTML, URL и HTTP — три кита, на которых стоит весь современный веб. Он мог бы стать миллиардером, но сделал свои изобретения бесплатными для всех. Благодаря этому решению интернет стал открытым и доступным для каждого человека на планете. В 2004 году он был посвящён в рыцари Королевой Великобритании.

Первый в мире сайт всё ещё работает! Его можно открыть по адресу info.cern.ch. Это простая текстовая страница — ни дизайна, ни картинок. Сравните его с любым современным сайтом, и вы увидите, какой путь прошёл веб за 30+ лет.

Когда вы на собеседовании расскажете историю веба — это произведёт впечатление. Большинство новичков не знают, откуда взялись технологии, которые они используют. А понимание контекста показывает глубину вашего мышления.

2. Как работает интернет

Когда вы вводите адрес сайта в браузере и нажимаете Enter — что происходит? За долю секунды запускается целая цепочка событий.

Клиент и сервер

Интернет работает по принципу «клиент — сервер»:

  • Клиент — это ваш компьютер и браузер (Chrome, Firefox, Edge). Он отправляет запрос: «Покажи мне этот сайт!»
  • Сервер — это мощный компьютер, который хранит файлы сайта. Он получает запрос и отправляет нужные файлы обратно.
ВЫ (клиент) СЕРВЕР ┌──────────────┐ ┌──────────────┐ │ Браузер │ ── 1. Запрос ──────► │ Компьютер │ │ (Chrome) │ │ с файлами │ │ │ ◄── 2. Ответ ─────── │ сайта │ └──────────────┘ (HTML, CSS, JS) └──────────────┘

Ресторан: Вы (клиент) — посетитель ресторана. Вы делаете заказ (запрос). Официант (интернет) несёт заказ на кухню (сервер). Кухня готовит блюдо (находит файлы) и официант приносит его вам (ответ).

Библиотека: Вы приходите в библиотеку (интернет) и просите книгу (запрос). Библиотекарь (DNS) находит нужную полку (IP-адрес), достаёт книгу (файлы сайта) и даёт вам почитать (ответ). Вы не знаете, на какой полке она лежала — вам просто нужно было название.

URL — адрес сайта

Каждый сайт имеет свой уникальный адрес — URL (Uniform Resource Locator). Давайте разберём, из чего он состоит:

https://www.google.com/search?q=html https:// — протокол (безопасное соединение) www. — поддомен (необязательная часть) google.com — доменное имя (имя сайта) /search — путь (конкретная страница) ?q=html — параметры (данные запроса)

Доменное имя — это человеко-понятное имя сайта. На самом деле компьютеры общаются через числовые IP-адреса (например, 142.250.74.206), но нам удобнее запоминать google.com. Специальная система DNS (Domain Name System) переводит доменные имена в IP-адреса — как телефонная книга.

HTTP и HTTPS

HTTP (HyperText Transfer Protocol) — это протокол (набор правил), по которому общаются клиент и сервер. HTTPS — то же самое, но с шифрованием.

Почта: HTTP — это открытка, которую может прочитать любой почтальон. HTTPS — письмо в запечатанном конверте, которое прочитает только получатель. Когда вы видите замочек 🔒 в адресной строке — ваши данные защищены.

«Интернет и веб — это одно и то же»

Нет! Интернет — это глобальная сеть компьютеров (инфраструктура). Веб (World Wide Web) — это лишь одна из служб, работающих поверх интернета. Email, мессенджеры, онлайн-игры — тоже используют интернет, но они не являются «вебом». Веб — это именно сайты, доступные через браузер.

  • Клиент — ваш браузер, отправляет запросы
  • Сервер — хранит сайт, отвечает на запросы
  • URL — адрес сайта (https://google.com)
  • DNS — переводит доменное имя в IP-адрес
  • HTTPS — безопасный протокол с шифрованием

Мысленно ответьте:

  1. Ваш браузер — это клиент или сервер? (Клиент — он отправляет запросы)
  2. Что делает DNS? (Переводит доменное имя в IP-адрес, как телефонная книга)
  3. Чем HTTP отличается от HTTPS? (HTTPS шифрует данные — замочек в браузере)
  4. Что произойдёт, если набрать в браузере google.com? Опишите цепочку. (Браузер → DNS → IP-адрес → запрос серверу → сервер отдаёт файлы → браузер рисует страницу)

3. Из чего состоит веб-страница

Когда сервер отвечает на запрос, он отправляет браузеру файлы. Любая веб-страница состоит из трёх технологий:

📄 HTML — структура и содержимое (скелет) 🎨 CSS — внешний вид и стили (одежда) ⚡ JS — интерактивность (движения) ┌─────────────────────────────────────────┐ │ Веб-страница │ │ │ │ HTML + CSS + JavaScript │ │ (что) (как это (что │ │ выглядит) происходит) │ └─────────────────────────────────────────┘

Любой сайт, который вы видите — Facebook, YouTube, TikTok, Google — всё это HTML + CSS + JavaScript. Даже самый красивый и сложный сайт построен на этих трёх технологиях.

Человек:

  • HTML = скелет и органы (структура тела)
  • CSS = одежда, причёска, макияж (внешний вид)
  • JavaScript = мышцы и нервная система (движения и реакции)

Без скелета — нет тела. Без одежды — некрасиво. Без мышц — не двигается.

Эксперимент: отключи CSS на любом сайте!

  1. Откройте любой красивый сайт (например, apple.com)
  2. Нажмите F12 — откроются DevTools
  3. Перейдите на вкладку Console
  4. Скопируйте и вставьте эту команду:
document.querySelectorAll('style, link[rel="stylesheet"]').forEach(el => el.remove())

Нажмите Enter и посмотрите, что произошло! Без CSS сайт превращается в простой текст — как в 90-х. Вся красота — это CSS. А HTML — это содержимое, которое осталось. Чтобы вернуть всё назад, просто обновите страницу (F5).

🎨

  • JavaScript — интерактивность (движения)
  • Любой сайт в мире (Google, YouTube, TikTok) построен на этих 3 технологиях
  • CSS можно отключить в DevTools — и увидеть «голый» HTML

4. HTML — структура страницы

HTML расшифровывается как HyperText Markup Language — язык гипертекстовой разметки.

HTML — это НЕ язык программирования! Это язык разметки. Он не может складывать числа или принимать решения. HTML просто говорит браузеру: «Вот заголовок, вот параграф, вот картинка, вот ссылка».

HTML-код состоит из тегов — специальных слов в угловых скобках. Большинство тегов работают в парах: открывающий и закрывающий:

<h1>Это заголовок</h1>
<p>Это параграф текста.</p>

Тег <h1> открывает заголовок, а </h1> (с косой чертой) — закрывает. Всё, что между ними — содержимое тега.

Вот пример простой HTML-страницы:

<!DOCTYPE html>
<html>
<head>
    <title>Мой первый сайт</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Это мой первый сайт.</p>
    <img src="photo.jpg" alt="Фото">
    <a href="https://google.com">Перейти в Google</a>
</body>
</html>

Обратите внимание на несколько вещей:

  • Теги можно вкладывать друг в друга — как матрёшки
  • Некоторые теги не имеют закрывающей части (например, <img> и <br>)
  • Теги могут иметь атрибуты — дополнительную информацию (например, src="photo.jpg")

Основные HTML-теги

<h1> — <h6>Заголовки (от главного до мелкого)Название страницы, заголовки разделов

Строительство дома: HTML — это чертёж. Он говорит: здесь стена, здесь дверь, здесь окно. Но чертёж не говорит, какого цвета стены и какие обои клеить — это уже работа CSS.

«Буду учить только CSS, HTML скучный»

CSS без HTML — как одежда без тела. Вы не можете стилизовать то, чего не существует. Сначала вы создаёте структуру (HTML), потом её украшаете (CSS). Попытка учить CSS без понимания HTML — гарантированный путь к путанице.

5. CSS — внешний вид

CSS расшифровывается как Cascading Style Sheets — каскадные таблицы стилей. CSS отвечает за то, КАК выглядит страница: цвета, шрифты, размеры, расположение элементов.

Один и тот же HTML с разным CSS может выглядеть совершенно по-разному:

HTML (одинаковый):

<h1>Привет, мир!</h1>
<p>Это мой первый сайт.</p>
<button>Нажми меня</button>

Без CSS — браузер покажет стандартный чёрный текст на белом фоне. Скучно.

С CSS — тот же HTML, но со стилями:

body {
    background-color: #1a1a2e;   /* тёмный фон */
    color: white;                /* белый текст */
    font-family: Arial;          /* шрифт */
    text-align: center;          /* выравнивание по центру */
    padding: 50px;               /* внутренние отступы */
}

h1 {
    color: #e94560;              /* красный заголовок */
    font-size: 48px;             /* крупный шрифт */
}

button {
    background: #e94560;         /* красная кнопка */
    color: white;                /* белый текст на кнопке */
    border: none;                /* без рамки */
    padding: 15px 40px;          /* отступы внутри кнопки */
    font-size: 18px;             /* размер текста */
    border-radius: 25px;         /* скруглённые углы */
    cursor: pointer;             /* курсор-указатель */
}

Тот же HTML — но теперь это стильная страница с тёмным фоном, красным заголовком и красивой кнопкой! Вот что делает CSS:

  • Цвета — фон, текст, рамки, кнопки
  • Шрифты — размер, жирность, семейство шрифтов
  • Размеры — ширина, высота, отступы
  • Расположение — где что находится на странице
  • Анимации — плавные переходы, эффекты при наведении
До появления CSS в 1996 году весь дизайн делался прямо в HTML. Цвета, шрифты, расположение — всё в одном файле. Это было настолько неудобно, что разработчики прозвали такой код «спагетти». CSS навёл порядок: содержимое (HTML) отдельно, стили (CSS) отдельно.

Когда вы видите красивый сайт — не пугайтесь. За каждым эффектом стоит всего несколько строк CSS. К концу нашего курса вы сможете повторить дизайн большинства сайтов, которые видите в интернете. Главное — практика.

6. JavaScript — интерактивность

JavaScript (JS) — это настоящий язык программирования. Он добавляет поведение странице: реакцию на клики, анимации, загрузку данных, проверку форм.

HTML и CSS — это статика (неподвижная картинка). JavaScript добавляет динамику — страница начинает «оживать».

Примеры JavaScript на сайтах:

  • Нажали кнопку «Нравится» → счётчик лайков увеличился
  • Начали печатать в поиске Google → появились подсказки
  • Проскроллили ленту Instagram → загрузились новые посты
  • Неправильно заполнили форму → появилось сообщение об ошибке
  • Навели мышку на меню → выпал список подменю

Вы можете прямо сейчас попробовать JavaScript! Откройте любой сайт, нажмите F12, перейдите на вкладку Console и введите:

// Показать всплывающее окно
alert('Привет! Я JavaScript!');

// Изменить цвет фона страницы
document.body.style.backgroundColor = 'lightblue';

// Изменить текст заголовка
document.querySelector('h1').textContent = 'Я изменил заголовок!';

Изменения видны только вам и пропадут при обновлении страницы.

На нашем курсе мы будем изучать HTML и CSS. Этого достаточно, чтобы создавать красивые, адаптивные сайты. JavaScript — это следующий этап, но знать о нём полезно для понимания общей картины.

HTML, CSS, JavaScript — сравнение на реальных сайтах

Определите — это HTML, CSS или JavaScript?

  1. Текст «Добро пожаловать» на странице (HTML — содержимое)
  2. Красный цвет кнопки (CSS — стиль)
  3. При нажатии на кнопку появляется окно (JavaScript — действие)
  4. Картинка логотипа (HTML — элемент)
  5. Скруглённые углы у карточки (CSS — стиль)
  6. Автоподсказки при вводе в поиск (JavaScript — динамика)
  7. Список «Главная, О нас, Контакты» (HTML — структура навигации)
  8. Шрифт Arial размером 18px (CSS — стиль текста)

7. Браузеры и DevTools

Браузер — это программа, которая читает HTML, CSS и JavaScript и рисует из них красивую страницу на экране. Этот процесс называется рендеринг.

БраузерКомпанияДвижокДоля рынка
🌐 Google ChromeGoogleBlink / V8~65%
🧭 SafariAppleWebKit~19%
📘 Microsoft EdgeMicrosoftBlink~5%
🦊 Mozilla FirefoxMozillaGecko~3%

Разные браузеры могут немного по-разному отображать ваш сайт. Поэтому профессиональные веб-разработчики всегда проверяют свои сайты в нескольких браузерах. Мы будем работать в Google Chrome — он самый популярный и имеет лучшие инструменты для разработчиков.

DevTools — инструменты разработчика

В каждом современном браузере есть встроенные DevTools (Developer Tools) — мощный инструмент, который позволяет заглянуть «под капот» любого сайта.

Как открыть DevTools:

  • Нажмите F12
  • Или правый клик по любому элементу → «Просмотреть код» (Inspect)

Что можно делать в DevTools:

  • Elements — просматривать HTML-структуру любой страницы
  • Styles — видеть и менять CSS-стили любого элемента
  • Console — выполнять JavaScript-код
  • Наводить мышку на элементы в коде — они подсвечиваются на странице
  • Менять текст, цвета, размеры прямо в DevTools и сразу видеть результат
Все изменения в DevTools — временные. Они видны только вам и исчезают при обновлении страницы. Вы ничего не сломаете — можете экспериментировать свободно!

DevTools — это ваш лучший друг на всём пути обучения. Видите красивый элемент на чужом сайте? Кликните правой кнопкой → Inspect — и вы увидите, какой HTML и CSS за ним стоят. Это лучший способ учиться: смотреть, как делают профессионалы, и повторять.

Откройте DevTools на вашем любимом сайте и попробуйте:

  1. Найдите заголовок страницы и измените его текст
  2. Измените цвет какого-нибудь элемента
  3. Увеличьте размер шрифта

Вот как выглядит DevTools — три главные вкладки:

Elements Console Sources Network

Вкладка Elements показывает HTML-код страницы. Справа — CSS-стили выбранного элемента. Вы можете кликать, менять и сразу видеть результат!

  • Браузер = программа, которая рендерит (рисует) HTML+CSS+JS в красивую страницу
  • Chrome — самый популярный (~65%), мы работаем в нём
  • DevTools (F12) — инструменты разработчика: просмотр HTML, CSS, выполнение JS
  • Все изменения в DevTools — временные (пропадают при обновлении)
  • DevTools — лучший способ учиться: исследовать код любого сайта

8. Кто такие веб-разработчики

Веб-разработчик — это специалист, который создаёт сайты и веб-приложения. Но «веб-разработка» — это очень широкое понятие. Есть несколько направлений:

Frontend-разработчик (фронтенд)

Занимается видимой частью сайта — тем, что видит и с чем взаимодействует пользователь. Это кнопки, меню, анимации, формы, карточки товаров — всё, что вы видите на экране.

  • Технологии: HTML, CSS, JavaScript, React, Vue, Angular
  • Задачи: верстка макетов, создание интерфейсов, адаптивный дизайн, анимации

Backend-разработчик (бэкенд)

Занимается невидимой частью — серверной логикой. Это обработка данных, работа с базами данных, авторизация, оплата — всё, что происходит «за кулисами».

  • Технологии: Python, Node.js, PHP, Java, базы данных (SQL, MongoDB)
  • Задачи: обработка запросов, хранение данных, безопасность, API

Fullstack-разработчик (фулстек)

Умеет и то, и другое — работает и с фронтендом, и с бэкендом. Это как универсальный солдат в мире веб-разработки.

Строительство здания: Frontend — это архитектор и дизайнер интерьеров (то, что видят жильцы). Backend — это инженеры, которые прокладывают трубы, провода и фундамент (то, что скрыто в стенах). Fullstack — это мастер, который умеет и то, и другое.

Веб-разработка — одна из самых востребованных профессий в мире. Каждой компании нужен сайт. Можно работать удалённо из любой точки мира. Порог входа низкий — начать можно с нуля. А результат виден сразу — вы создаёте то, что люди видят и используют каждый день.

9. VS Code — наш редактор кода

Visual Studio Code (VS Code) — бесплатный редактор кода от Microsoft. Это самый популярный редактор в мире: его используют миллионы разработчиков.

Есть и другие редакторы — Sublime Text, Atom, Notepad++, WebStorm. Но VS Code выделяется тем, что он бесплатный, быстрый, и имеет огромное количество расширений (плагинов).

Почему именно VS Code, а не обычный Блокнот? Потому что VS Code умеет подсвечивать синтаксис (разные цвета для тегов, атрибутов, значений), подсказывать код, автоматически закрывать теги, форматировать код одним нажатием. Блокнот — это как ехать на велосипеде, когда есть машина.

Установка VS Code

  1. Откройте браузер и перейдите на code.visualstudio.com
  2. Нажмите «Download for Windows»
  3. Запустите скачанный файл
  4. При установке обязательно отметьте:
    • ✅ Add to PATH
    • ✅ Add "Open with Code" to context menu
    • ✅ Register Code as an editor for supported file types
  5. Завершите установку и запустите VS Code

Расширения (Extensions)

Расширения — это плагины, которые добавляют новые возможности в VS Code. Установите эти 4 расширения для нашего курса:

РасширениеЗачем нужно
Live ServerАвтоматически обновляет страницу в браузере при сохранении файла. Не нужно каждый раз нажимать F5!
PrettierАвтоматически форматирует код — делает его красивым и аккуратным
Auto Rename TagЕсли переименовать открывающий тег — закрывающий переименуется автоматически
HTML CSS SupportПодсказки при написании CSS — предлагает имена классов и свойства

Как установить расширение: нажмите Ctrl+Shift+X, введите название расширения в поиске и нажмите «Install».

«Я не установил Live Server»

Без Live Server вам придётся каждый раз вручную обновлять страницу (F5) после каждого изменения. При 100+ изменениях в день это съедает кучу времени и нервов. Установите Live Server — это займёт 10 секунд и сэкономит вам часы.

Горячие клавиши

Горячие клавиши экономят время. Вот самые важные для начала:

КлавишиДействие
Ctrl + SСохранить файл
Ctrl + ZОтменить последнее действие
Ctrl + C / Ctrl + VКопировать / Вставить

Emmet — встроенный инструмент VS Code, который умеет генерировать HTML-код по коротким командам. Напишите ! и нажмите Tab — VS Code мгновенно создаст полный шаблон HTML-страницы. Это одна из самых полезных функций для веб-разработчика.

Запоминайте горячие клавиши постепенно. Начните с Ctrl+S (сохранить) и Ctrl+Z (отменить). Потом добавляйте по одной новой комбинации в день. Через месяц вы будете летать по редактору без мыши.

10. Твоя первая HTML-страница

Теперь, когда всё готово, давайте создадим первую веб-страницу!

Шаг 1: Создай папку проекта

Создайте на рабочем столе папку my-first-site. Правый клик по папке → Open with Code.

Шаг 2: Создай файл

В VS Code: File → New File. Сохраните его как index.html.

Почему index.html? Потому что это стандартное имя для главной страницы сайта. Когда вы открываете google.com, сервер отдаёт именно файл index.html.

Шаг 3: Создай шаблон

Напишите ! и нажмите Tab. VS Code сгенерирует шаблон:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>

</body>
</html>

Давайте разберём каждую строку:

СтрокаЧто означает
<!DOCTYPE html>Сообщает браузеру, что это HTML5-документ
<html lang="en">Начало документа. Смените en на ru для русского языка
<head>«Голова» — информация для браузера (не видна на странице)
<meta charset="UTF-8">Кодировка символов. UTF-8 поддерживает русский язык
<meta name="viewport"...>Настройка для корректного отображения на мобильных
<title>Текст на вкладке браузера
<body>«Тело» — всё видимое содержимое страницы

Шаг 4: Добавь содержимое

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Мой первый сайт</title>
</head>
<body>
    <h1>Привет, мир!</h1>
    <p>Меня зовут [ваше имя]. Это мой первый сайт!</p>

    <h2>Обо мне</h2>
    <p>Я учусь создавать сайты с нуля.</p>

    <h2>Мои увлечения</h2>
    <ul>
        <li>Программирование</li>
        <li>Музыка</li>
        <li>Спорт</li>
    </ul>

    <h2>Контакты</h2>
    <p>Напишите мне: <a href="mailto:email@example.com">email@example.com</a></p>
</body>
</html>

Шаг 5: Запусти в браузере

Сохраните файл (Ctrl+S). В VS Code нажмите правой кнопкой по файлу → Open with Live Server. Ваша страница откроется в браузере!

Теперь попробуйте изменить текст в VS Code и сохранить — страница в браузере обновится автоматически. Это работает благодаря расширению Live Server.
