Задание 1.2: DevTools — измени сайт
Лёгкое 5 минут
Научиться открывать и использовать DevTools

Условие:

  1. Откройте любой сайт
  2. Нажмите F12 — откроются DevTools
  3. Нажмите на иконку 🔍 (Select element) в левом верхнем углу DevTools
  4. Наведите мышку на заголовок страницы — он подсветится
  5. Кликните по нему
  6. В DevTools найдите текст заголовка и измените его (двойной клик по тексту)
  7. Покажите результат преподавателю
Не бойтесь — изменения видны только вам и исчезнут при обновлении страницы (F5). Вы ничего не сломаете!

Бонус — измени CSS:

  1. Выберите элемент в DevTools (как выше)
  2. Справа найдите панель Styles
  3. Найдите свойство color и кликните на значение
  4. Измените его на red — текст станет красным!
  5. Попробуйте также изменить font-size на 48px

Задание 1.4: Отключи CSS на сайте
Среднее 5 минут
Увидеть разницу между HTML (содержимое) и CSS (стили)

Условие:

  1. Откройте любой красивый сайт
  2. Откройте DevTools (F12)
  3. Перейдите на вкладку Console
  4. Скопируйте и вставьте эту команду:
document.querySelectorAll('style, link[rel="stylesheet"]').forEach(el => el.remove())
  1. Нажмите Enter
  2. Посмотрите, как изменился сайт!

Задание 1.6: Моя первая HTML-страница
Среднее 15 минут
Создать свою первую HTML-страницу и запустить её в браузере

Условие:

  1. Создайте папку my-first-site на рабочем столе
  2. Откройте её в VS Code
  3. Создайте файл index.html
  4. Напишите ! + Tab для шаблона
  5. Измените lang="en" на lang="ru"
  6. Измените <title> на своё название
  7. Внутри <body> добавьте:
    • Заголовок <h1> со своим именем
    • Параграф <p> с приветствием
    • Подзаголовок <h2> «Обо мне»
    • Параграф с рассказом о себе
    • Подзаголовок <h2> «Мои увлечения»
    • Список <ul> с 3+ увлечениями
  8. Запустите через Live Server
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Страница Алексея</title>
</head>
<body>
    <h1>Привет! Я Алексей</h1>
    <p>Добро пожаловать на мой первый сайт!</p>

    <h2>Обо мне</h2>
    <p>Мне 16 лет. Я учусь в школе и мечтаю стать веб-разработчиком.</p>

    <h2>Мои увлечения</h2>
    <ul>
        <li>Компьютерные игры</li>
        <li>Футбол</li>
        <li>Музыка</li>
    </ul>

    <h2>Мои цели</h2>
    <p>Научиться создавать красивые сайты и найти работу в IT.</p>
</body>
</html>
Шпаргалка — частые ошибки новичков:
  • Забыли <!DOCTYPE html> в самом начале
  • Написали lang="en" вместо lang="ru"
  • Забыли закрыть тег: написали <h1>, но не написали </h1>
  • Не сохранили файл перед просмотром (Ctrl+S!)
  • Назвали файл не index.html, а Index.HTML (регистр важен!)
  • Файл назван index.html
  • Есть <!DOCTYPE html> и правильная структура
  • Есть заголовок <h1> с именем
  • Есть минимум 2 подзаголовка <h2>
  • Есть минимум 2 параграфа <p>
  • Есть список <ul> с минимум 3 пунктами
  • Страница открывается в браузере через Live Server
Задание 1.7: Добавь ещё контент (бонусное)
Среднее 5 минут
Закрепить работу с основными HTML-тегами

Условие:

  • Использованы теги <hr>, <strong>, <em>

ДЗ 1: Расширь свою страницу
Среднее 20 минут
Закрепить все знания первого занятия

Часть 1: Дополни страницу

Добавь на свою страницу index.html ещё минимум 3 раздела. Идеи:

  • «Мои любимые предметы в школе/вузе»
  • «Что я хочу научиться делать»
  • «Мои друзья»
  • «Любимая музыка / фильмы / игры»
  • «Мой распорядок дня»

Используйте теги: <h2>, <p>, <ul> или <ol>, <a>, <strong>, <em>

Пример нового раздела:

<hr>
<h2>Мой ТОП-3 фильмов</h2>
<p>Вот мои <strong>самые любимые</strong> фильмы:</p>
<ol>
    <li>Интерстеллар — <em>лучший фильм о космосе</em></li>
    <li>Начало — <em>невероятный сюжет</em></li>
    <li>Матрица — <em>классика</em></li>
</ol>
<p>Подробнее о фильмах: <a href="https://imdb.com">IMDb</a></p>

Часть 2: Исследуй сайты

  1. Откройте DevTools (F12) на 3 любимых сайтах

    • Тег <h1> — главный заголовок
    • Тег <img> — картинку
    • Тег <a> — ссылку
  3. Попробуйте изменить текст и цвет через DevTools
