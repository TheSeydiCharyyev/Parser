🎯 Lesson 29.1: REGISTRATION AND NAVIGATION

Задание 28.1: Первые шаги в Figma Task 28.1: First steps in Figma
Лёгкое Easy 15 минут 15 min
Зарегистрироваться в Figma и освоить базовую навигацию
Register in Figma and learn basic navigation

Условие:

Instructions:

  1. Зарегистрируйтесь на figma.com (бесплатно)
  2. Откройте Figma Community (вкладка «Explore» или community.figma.com)
  3. Найдите бесплатный макет (поиск: «landing page», «website template», «free UI kit»)
  4. Нажмите «Duplicate» (или «Open in Figma»)
  5. Научитесь навигации:
    • Зум: колёсико мыши или Ctrl + + / -
    • Перемещение: Пробел + перетаскивание
    • Выбрать элемент: клик
    • Войти внутрь группы: двойной клик
  1. Register at figma.com (free)
  2. Open Figma Community ("Explore" tab or community.figma.com)
  3. Find a free layout (search: "landing page", "website template", "free UI kit")
  4. Click "Duplicate" (or "Open in Figma")
  5. Learn navigation:
    • Zoom: mouse wheel or Ctrl + + / -
    • Pan: Space + drag
    • Select element: click
    • Enter group: double-click
Хорошие поисковые запросы в Community:
  • «free landing page» — бесплатные лендинги
  • «website template» — полные сайты
  • «restaurant landing» — под конкретную тему
  • «free UI kit» — набор компонентов
Фильтруйте по «Free» (бесплатным). Рекомендуемые авторы с хорошими макетами: Figma (официальные), Untitled UI.
Good Community search queries:
  • "free landing page" — free landings
  • "website template" — full sites
  • "restaurant landing" — specific themes
  • "free UI kit" — component sets
Filter by "Free". Recommended authors with good layouts: Figma (official), Untitled UI.
  • Аккаунт Figma создан (через Google или email)
  • Макет из Community скопирован в аккаунт (кнопка «Duplicate»)
  • Макет открывается в редакторе Figma
  • Умеете зумить (колесо), перемещаться (Space + drag)
  • Умеете выделять элементы (клик) и заходить в группы (двойной клик)
  • Бонус: горячие клавиши Shift+1 (fit) и Shift+2 (zoom to selection)
  • Figma account created (via Google or email)
  • Community layout copied to account ("Duplicate" button)
  • Layout opens in Figma editor
  • Can zoom (scroll), pan (Space + drag)
  • Can select elements (click) and enter groups (double-click)
  • Bonus: hotkeys Shift+1 (fit) and Shift+2 (zoom to selection)

Как узнать HEX-цвета:
  1. Кликните на блок с нужным цветом
  2. В правой панели найдите Fill (заливка)
  3. Кликните на цветной квадратик рядом с названием
  4. Откроется пикер — видите HEX (например, #3B82F6)
  5. Кликните на HEX-строку → «Copy»
Как узнать размер шрифта:
  1. Кликните на текст (двойной клик, если в группе)
  2. В правой панели — Font, Size, Weight, Line height
  3. Если Weight: Semi Bold — в CSS это font-weight: 600
How to find HEX colors:
  1. Click the block with the needed color
  2. In right panel find Fill
  3. Click the color square next to the name
  4. Picker opens — see HEX (e.g., #3B82F6)
  5. Click the HEX string → "Copy"
How to find font size:
  1. Click the text (double-click if in a group)
  2. In right panel — Font, Size, Weight, Line height
  3. If Weight: Semi Bold — CSS is font-weight: 600
  • Минимум 5 цветов выписаны (HEX-коды)

🎯 Lesson 29.3: IDENTIFYING STRUCTURE

Задание 28.3: Определи HTML/CSS структуру Task 28.3: Identify HTML/CSS structure
Среднее Medium 15 минут 15 min
Научиться видеть HTML-структуру и CSS-раскладку в макете
Learn to see HTML structure and CSS layout in a design

Условие:

Instructions:

Глядя на макет из Figma, запишите для каждой секции:

Looking at the Figma layout, write for each section:

  1. Какие секции на странице? (header, hero, features, cards, footer...)
  2. Для каждой секции: какая раскладка? (Flexbox row, Grid 3 col, стопка...)
  3. Для каждой секции: какие HTML-теги? (header, section, nav, div, img, h2, p...)
  4. Сколько колонок в секции карточек?
  5. Нарисуйте wireframe на бумаге: прямоугольники для каждого блока
  1. What sections on the page? (header, hero, features, cards, footer...)
  2. For each section: what layout? (Flexbox row, Grid 3 col, stack...)
  3. For each section: what HTML tags? (header, section, nav, div, img, h2, p...)
  4. How many columns in the cards section?
  5. Draw a wireframe on paper: rectangles for each block
Смотрите на Layers (слои) в левой панели Figma — они часто совпадают с HTML-структурой! Группы = div, Frame = section/div.

Пример записи в structure.md: 
Header
  - Layout: Flex row, justify-between
  - HTML: <header class="..."> + <nav> + <button>

Hero
  - Layout: Flex column, items-center
  - HTML: <section> + <h1> + <p> + <button>

Features
  - Layout: Grid 3 col (desktop), 1 col (mobile)
  - HTML: <section> + 3 × <div> (icon + h3 + p)

Cards
  - Layout: Grid 3 col → 2 → 1
  - HTML: <section> + 6 × <article> (img + h3 + p + button)

Footer
  - Layout: Grid 3 col
  - HTML: <footer> + 3 × <div>
Look at Layers in the left Figma panel — they often match HTML structure! Groups = div, Frame = section/div.

  • HTML-теги предложены (семантические: header, section, article, footer)

  • Wireframe нарисован на бумаге или в tldraw/excalidraw
  • Бонус: файл structure.md с описанием по шаблону из подсказки

⭐ BONUS TASK

Задание 28.4: Экспорт ресурсов Task 28.4: Export assets
Лёгкое Easy 10 минут 10 min
Экспортировать изображения и иконки из макета
Export images and icons from the layout

Условие:

Instructions:

  1. Создайте папку figma-assets
  2. Экспортируйте из макета:
    • 2 фотографии → JPG (1x)
    • 2 иконки → SVG
    • Логотип → PNG (2x для Retina)
  3. Сохраните файлы в папку
  1. Create a folder figma-assets
  2. Export from the layout:
    • 2 photos → JPG (1x)
    • 2 icons → SVG
    • Logo → PNG (2x for Retina)
  3. Save files to the folder
Как экспортировать:
  1. Выделите элемент (клик по картинке/иконке)
  2. В правой панели прокрутите вниз до блока Export
  3. Нажмите + (добавить формат экспорта)
  4. Выберите формат (PNG/JPG/SVG) и масштаб (1x / 2x / 3x)
  5. Нажмите Export [ElementName] внизу
Быстрый способ: Ctrl/Cmd + Shift + E после выделения.
How to export:
  1. Select the element (click image/icon)
  2. Scroll the right panel down to Export block
  3. Click + (add export format)
  4. Choose format (PNG/JPG/SVG) and scale (1x / 2x / 3x)
  5. Click Export [ElementName] at the bottom
Quick way: Ctrl/Cmd + Shift + E after selecting.
  • Папка figma-assets создана
  • 2 фото в JPG (2x для Retina, не 1x!)
  • 2 иконки в SVG (1x, поскольку вектор)
  • 1 логотип в PNG (2x, для прозрачности)
  • Всего минимум 5 файлов в папке
  • Имена файлов осмысленные: hero-bg.jpg, icon-check.svg, не image1.jpg
  • Бонус: открыть SVG в VS Code и убедиться, что это XML (текстовый формат)
  • figma-assets folder created
  • 2 photos in JPG (2x for Retina, not 1x!)
  • 2 icons in SVG (1x, since vector)
  • 1 logo in PNG (2x, for transparency)
  • At least 5 files in the folder
  • Meaningful filenames: hero-bg.jpg, icon-check.svg, not image1.jpg
  • Bonus: open SVG in VS Code and verify it's XML (text format)

⭐ FINAL BONUS: PIXEL-PERFECT HERO

Задание 28.5: Свёрстай hero-секцию по макету Task 28.5: Code a hero section from the layout
Сложное Hard 30 минут 30 min
Применить все знания из урока — сверстать hero-секцию pixel-perfect по Figma-макету
Apply all lesson knowledge — code a hero section pixel-perfect from a Figma layout

Условие:

Instructions:

  1. Возьмите только hero-секцию из макета (не весь лендинг)
  2. Создайте hero.html + hero.css
  3. Подключите Google Fonts с нужными весами
  4. Используйте CSS-переменные из задания 28.2 (tokens.css)
  5. Экспортируйте фоновое изображение (если есть) из задания 28.4
  6. Свёрстайте pixel-perfect: откройте Figma и браузер рядом, сравнивайте
  7. Проверьте: все размеры, отступы, цвета, шрифты совпадают с макетом
  1. Take only the hero section from the layout (not the whole landing)
  2. Create hero.html + hero.css
  3. Load Google Fonts with needed weights
  4. Use CSS variables from task 28.2 (tokens.css)
  5. Export background image (if any) from task 28.4
  6. Code pixel-perfect: open Figma and browser side by side, compare
  7. Verify: all sizes, spacing, colors, fonts match the layout
Как проверить pixel-perfect: сделайте скриншот hero из Figma и скриншот браузера, наложите друг на друга в графическом редакторе (Paint/Photoshop/PowerPoint). Если расхождение > 2px — дизайнер скажет «не pixel-perfect».
How to verify pixel-perfect: screenshot the hero from Figma and the browser, overlay them in a graphics editor (Paint/Photoshop/PowerPoint). If the difference is > 2px — designer will say "not pixel-perfect".

  • Шрифт, размеры, веса соответствуют макету
