1. Что такое Figma и зачем она разработчику

1. What is Figma and why developers need it

Figma запущена в 2016, а к 2022 стала стандартом индустрии для дизайна интерфейсов. Adobe хотел купить её за $20 млрд в 2022, но антимонопольные органы блокировали сделку. Это говорит о масштабе: Figma используют 90% всех UX/UI дизайнеров в мире. Google, Microsoft, Airbnb, Spotify — все работают в Figma.

Для разработчика это означает одно: если вы идёте работать в команду — вы будете получать макеты в Figma. Других вариантов практически нет. Photoshop и Sketch — устарели.

Figma launched in 2016 and became the industry standard for interface design by 2022. Adobe tried to buy it for $20bn in 2022, but antitrust regulators blocked the deal. That's the scale: 90% of all UX/UI designers use Figma. Google, Microsoft, Airbnb, Spotify — all work in Figma.

For a developer this means one thing: if you join a team — you'll get layouts in Figma. There's barely any other option. Photoshop and Sketch are outdated.

Figma — это инструмент для дизайна интерфейсов. Дизайнер рисует макет в Figma, а разработчик верстает по этому макету.

Figma is an interface design tool. A designer creates a layout in Figma, and a developer codes it based on that layout.

Разработчику не нужно уметь рисовать в Figma! Нужно уметь читать макет: определять размеры, цвета, шрифты, отступы, и переводить это в CSS.
Developers don't need to draw in Figma! They need to read the layout: determine sizes, colors, fonts, spacing, and translate it to CSS.

Строитель и архитектор. Архитектор рисует чертёж дома (Figma). Строитель читает чертёж и возводит здание (HTML + CSS). Строителю не нужно уметь проектировать — достаточно уметь читать планы. Если строитель не умеет читать — дом не построить.

Builder and architect. Architect draws the house blueprint (Figma). Builder reads the blueprint and erects the building (HTML + CSS). The builder doesn't need to design — just to read plans. A builder who can't read blueprints can't build.

Как это реально происходит в команде:

  1. Менеджер ставит задачу: «нужна страница регистрации»
  2. Дизайнер рисует макет в Figma и пишет в Slack: «готово, ссылка: figma.com/file/...»
  3. Разработчик открывает макет, переключается в Dev Mode, смотрит CSS-свойства
  4. Разработчик собирает HTML + CSS по макету, коммитит в git
  5. Ревью: дизайнер открывает задеплоенную страницу рядом с макетом и ищет расхождения
  6. Если есть баги («отступ 24px, а ты сделал 20px») — задача возвращается

Цикл повторяется до тех пор, пока страница не станет pixel-perfect.

How it actually works on a team:

  1. PM sets a task: "need a signup page"
  2. Designer draws layout in Figma, pings in Slack: "done, link: figma.com/file/..."
  3. Developer opens layout, switches to Dev Mode, reads CSS properties
  4. Developer builds HTML + CSS from layout, commits to git
  5. Review: designer opens deployed page next to layout, looks for differences
  6. If there are bugs ("spacing should be 24px, you did 20px") — task comes back

Cycle repeats until the page is pixel-perfect.

2. Регистрация и первый вход

2. Registration and first login

Хорошая новость: Figma бесплатна для разработчиков. Бесплатного плана более чем достаточно, чтобы читать чужие макеты (именно это и нужно junior-разработчику). Платный план нужен только дизайнерам или в больших командах с расширенными функциями.

Good news: Figma is free for developers. The free plan is more than enough to read others' layouts (exactly what a junior dev needs). Paid plan is only for designers or large teams with advanced features.

  1. Откройте figma.com
  2. Нажмите Sign up (бесплатно)
  3. Зарегистрируйтесь через Google или email
  4. Figma работает в браузере — ничего устанавливать не нужно!
  5. Также есть десктопное приложение (опционально)
  1. Go to figma.com
  2. Click Sign up (free)
  3. Register with Google or email
  4. Figma works in the browser — no installation needed!
  5. Desktop app is also available (optional)

Бесплатный план Figma позволяет работать с 3 проектами и неограниченным количеством файлов. Для обучения и работы с чужими макетами этого более чем достаточно.

Figma's free plan allows 3 projects and unlimited files. For learning and working with shared layouts, this is more than enough.

Community — ваш учебный полигон. На figma.com/community тысячи бесплатных макетов (landing, дашборды, мобильные приложения) от дизайнеров. Нажимаете «Duplicate» — макет копируется в ваш аккаунт. Идеально для практики чтения макетов и pixel-perfect вёрстки, пока нет реального клиента.

Community — your training ground. On figma.com/community there are thousands of free layouts (landings, dashboards, mobile apps) from designers. Click "Duplicate" — layout is copied to your account. Perfect for practicing layout reading and pixel-perfect coding before you have a real client.

4. Dev Mode — режим разработчика

4. Dev Mode — developer mode

Dev Mode — это подарок разработчикам от команды Figma (запущен в 2023). До этого приходилось вручную измерять всё в Inspect-панели. Теперь Figma сама генерирует CSS-код для выделенного элемента: готовые строки background: #3B82F6; border-radius: 12px; и т.д. — копируй и вставляй.

Dev Mode экономит часы: не нужно запоминать HEX-цвета, выписывать font-weight вручную, переводить rem в px. Всё уже в правой панели.

Dev Mode is a gift to developers from the Figma team (launched 2023). Previously you had to manually measure everything in the Inspect panel. Now Figma generates CSS code for the selected element: ready lines background: #3B82F6; border-radius: 12px; etc. — copy and paste.

Dev Mode saves hours: no memorizing HEX colors, no writing font-weight by hand, no converting rem to px. It's all in the right panel.

В Figma есть специальный Dev Mode (кнопка </> в правом верхнем углу). Он показывает:

Figma has a special Dev Mode (button </> in top-right corner). It shows:

  • CSS-код выделенного элемента (копируй и вставляй!)
  • Размеры в пикселях
  • Расстояния между элементами (наведи на элемент, зажми Alt)
  • Цвета в HEX, RGB, HSL
  • Шрифты: название, размер, вес, межстрочный
  • CSS code of selected element (copy and paste!)
  • Sizes in pixels
  • Distances between elements (hover over element, hold Alt)
  • Colors in HEX, RGB, HSL
  • Fonts: name, size, weight, line-height
Dev Mode может быть ограничен на бесплатном плане. Альтернатива: вкладка Inspect в правой панели (доступна всегда). Она показывает те же данные.
Dev Mode may be limited on the free plan. Alternative: Inspect tab in the right panel (always available). It shows the same data.

Осторожно: Dev Mode — не «магия». CSS, который генерирует Figma — сырой. Там будут position: absolute и явные top/left — потому что Figma не знает о Flexbox или Grid. Используйте сгенерированный CSS как справку (размеры, цвета), но layout пишите сами через flex/grid.

Warning: Dev Mode isn't "magic". The CSS Figma generates is raw. It'll have position: absolute and explicit top/left — because Figma doesn't know about Flexbox or Grid. Use the generated CSS as a reference (sizes, colors), but write layout yourself with flex/grid.

6. Как читать размеры и отступы

6. How to read sizes and spacing

Отступы — самое частое, что спрашивает дизайнер. «Между кнопкой и заголовком должно быть 24px» — это то, что вы услышите на каждом ревью. Figma даёт идеальный способ измерять: Alt + hover. Это сочетание — главный навык для работы с макетами.

Spacing is what designers ask about most. "There should be 24px between button and heading" — you'll hear this at every review. Figma gives a perfect way to measure: Alt + hover. This combo is the key skill for working with layouts.

  1. Кликните на элемент — размеры W×H видны в правой панели
  2. Alt + наведение — показывает расстояние от выделенного элемента до того, на который навели
  3. Padding — кликните на контейнер, Figma покажет внутренние отступы (Auto layout → padding)
  4. Gap — расстояние между элементами в Auto layout
  1. Click on element — W×H sizes shown in right panel
  2. Alt + hover — shows distance from selected element to hovered one
  3. Padding — click container, Figma shows inner padding (Auto layout → padding)
  4. Gap — distance between elements in Auto layout

Выделите элемент в Figma, зажмите Alt и наводите на другие элементы. Красные линии покажут расстояние в пикселях!

Select an element in Figma, hold Alt and hover over other elements. Red lines will show the distance in pixels!

Не пишите width и height буквально из Figma! Дизайнер рисует макет на фиксированной ширине (обычно 1440px или 1920px). Если вы поставите width: 560px на карточку — она не будет адаптивной. Правильно: используйте max-width, проценты, grid-cols-3. Буквальные пиксели — только для мелких вещей (иконки, border-radius, padding).

Don't copy width and height literally from Figma! Designer draws layout at fixed width (usually 1440px or 1920px). If you set width: 560px on a card — it won't be responsive. Right way: use max-width, percentages, grid-cols-3. Literal pixels — only for small things (icons, border-radius, padding).

7. Как читать цвета

7. How to read colors

Цвет в Figma — это Fill (заливка) и Stroke (обводка). Это те же background и border из CSS, но с другими именами. Важно запомнить эту терминологию — дизайнеры говорят на этом языке.

Color in Figma is Fill and Stroke. Same as CSS background and border, but with different names. Memorize this terminology — designers speak this language.

Кликните на элемент → в правой панели найдите Fill (заливка) или Stroke (обводка):

Click on element → in right panel find Fill or Stroke:

  • Кликните на цветной квадрат — откроется пипетка с HEX-кодом
  • Можно переключить на RGB, HSL
  • Копируйте HEX (например, #3B82F6) и вставляйте в CSS
  • Click the color square — color picker opens with HEX code
  • Can switch to RGB, HSL
  • Copy HEX (e.g., #3B82F6) and paste into CSS

Design tokens — выписывайте цвета в переменные. В макете обычно 5-8 цветов повторяются везде. Выпишите их из Figma сразу и сохраните как CSS-переменные:

:root {
    --color-primary: #3B82F6;
    --color-primary-dark: #1D4ED8;
    --color-text: #1E293B;
    --color-text-muted: #64748B;
    --color-bg: #F8FAFC;
    --color-border: #E2E8F0;
}

Сделаете это один раз в начале — все остальные стили пишете через var(--color-primary). Если дизайнер попросит поменять основной цвет — правите одну строку.

Design tokens — save colors as variables. A layout usually reuses 5-8 colors everywhere. Extract them from Figma upfront and save as CSS variables:

:root {
    --color-primary: #3B82F6;
    --color-primary-dark: #1D4ED8;
    --color-text: #1E293B;
    --color-text-muted: #64748B;
    --color-bg: #F8FAFC;
    --color-border: #E2E8F0;
}

Do this once at the start — write all other styles via var(--color-primary). If the designer asks to change the primary color — you edit one line.

8. Как читать шрифты

8. How to read fonts

Шрифт — это целая система: family, size, weight, line-height, letter-spacing, color. Дизайнер в Figma задаёт все шесть параметров. Вы должны прочитать и перенести. Часто в макете используется не-системный шрифт (Inter, Poppins, Montserrat) — его нужно подключить через Google Fonts.

Font is an entire system: family, size, weight, line-height, letter-spacing, color. The designer sets all six in Figma. You need to read and transfer them. Often layouts use a non-system font (Inter, Poppins, Montserrat) — connect it via Google Fonts.

9. Как измерять расстояния между элементами

9. How to measure distances between elements

  1. Выделите первый элемент (кликните)
  2. Зажмите Alt
  3. Наведите на второй элемент — появится расстояние в px

10. Exporting images and icons

Картинки и иконки в макете — это ресурсы, которые нужно выгрузить из Figma в ваш проект. Дизайнер не будет присылать вам файлы в Telegram — вы сами заходите и экспортируете. Формат важен: SVG для иконок (масштабируется без потери качества), JPG для фото (меньше размер), PNG для логотипов с прозрачностью.

Images and icons in a layout are assets that need to be exported from Figma into your project. The designer won't send files in Telegram — you export them yourself. Format matters: SVG for icons (scales without quality loss), JPG for photos (smaller size), PNG for logos with transparency.

  1. Выделите изображение или иконку
  2. В правой панели внизу найдите Export
  3. Выберите формат: PNG (фото), SVG (иконки), JPG (большие фото)
  4. Выберите масштаб: 1x (обычный), 2x (для Retina)
  5. Нажмите Export
  1. Select the image or icon
  2. In the right panel at the bottom find Export
  3. Choose format: PNG (photos), SVG (icons), JPG (large photos)

11. От Figma к CSS — алгоритм

11. From Figma to CSS — algorithm

Получили макет — что делать? Хаотично прыгать от элемента к элементу? Нет. Есть чёткий алгоритм из 7 шагов, которому следуют все профессионалы. Он экономит часы и гарантирует pixel-perfect результат. Выучите его — и вы будете работать как senior.

Got a layout — what now? Jump chaotically between elements? No. There's a clear 7-step algorithm all pros follow. Saves hours and guarantees a pixel-perfect result. Learn it — and you'll work like a senior.

  1. Изучите макет целиком: определите секции (header, hero, features, footer)
  2. Определите сетку: сколько колонок, какие отступы, max-width
  3. Выпишите цвета: основной, фон, текст, акцент (создайте CSS-переменные)
  4. Выпишите шрифты: название, размеры для h1-h6, body (подключите Google Fonts)
  5. Экспортируйте ресурсы: изображения (JPG), иконки (SVG), логотип
  6. Начните вёрстку: сверху вниз, секция за секцией
  7. Сверяйтесь: открывайте Figma рядом с VS Code, проверяйте pixel-perfect
  1. Study the entire layout: identify sections (header, hero, features, footer)
  2. Determine the grid: how many columns, spacing, max-width
  3. List colors: primary, background, text, accent (create CSS variables)
  4. List fonts: name, sizes for h1-h6, body (connect Google Fonts)
  5. Export assets: images (JPG), icons (SVG), logo
  6. Start coding: top to bottom, section by section
  7. Compare: keep Figma open next to VS Code, check pixel-perfect
