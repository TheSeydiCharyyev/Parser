📚 ЧТО ТАКОЕ FIGMA

📚 WHAT IS FIGMA

Figma — стандарт индустрии для дизайна интерфейсов. 90% дизайнеров в мире работают в Figma. Используют Google, Microsoft, Airbnb. Разработчик получает готовый макет от дизайнера и верстает по нему.
Figma is the industry standard for interface design. 90% of designers worldwide use it. Google, Microsoft, Airbnb use it. Developer receives a ready layout from a designer and codes based on it.
Разработчик не рисует — разработчик читает макет. Аналогия: строитель не проектирует дом, а строит по чертежу архитектора.
Developer doesn't draw — developer reads the layout. Analogy: a builder doesn't design the house, they build from the architect's blueprint.

📚 КАК ИЗМЕРЯТЬ РАССТОЯНИЯ

📚 HOW TO MEASURE DISTANCES

  1. Кликни на элемент (выдели)
  2. Зажми Alt
  3. Наведи на другой элемент
  4. Красные линии покажут расстояние в px
  1. Click on element (select it)
  2. Hold Alt
  3. Hover over another element
  4. Red lines show distance in px

📚 DESIGN TOKENS — ПЕРЕМЕННЫЕ

📚 DESIGN TOKENS — VARIABLES

В начале работы выпишите все цвета и шрифты из Figma в CSS-переменные. Потом во всех стилях ссылайтесь на них. Если дизайнер попросит сменить основной цвет — правите одну строку.
At the start, extract all colors and fonts from Figma into CSS variables. Then reference them in all styles. If the designer asks to change the primary color — edit one line. 
:root {
    --color-primary: #3B82F6;
    --color-primary-dark: #1D4ED8;
    --color-text: #1E293B;
    --color-text-muted: #64748B;
    --color-bg: #F8FAFC;
    --color-border: #E2E8F0;
}

📚 АЛГОРИТМ: ОТ МАКЕТА К КОДУ

📚 ALGORITHM: FROM LAYOUT TO CODE

  1. Изучить макет целиком → определить секции
  2. Определить сетку (колонки, max-width, gap)
  3. Выписать цвета → CSS-переменные
  4. Выписать шрифты → Google Fonts
  5. Экспортировать изображения и иконки
  6. Верстать сверху вниз, секция за секцией
  7. Сверять с Figma (Alt + расстояния)
  1. Study entire layout → identify sections
  2. Determine grid (columns, max-width, gap)
  3. List colors → CSS variables
  4. List fonts → Google Fonts
  5. Export images and icons
  6. Code top to bottom, section by section
  7. Compare with Figma (Alt + distances)
