📚 TRANSITION vs ANIMATION

📚 TRANSITION vs ANIMATION

transitionanimation
ЗапускПо событию (hover, focus)Автоматически (при загрузке)
Состояний2 (из A в B)Любое количество (@keyframes)
ПовторНетinfinite — бесконечно
ИспользоватьКнопки, ссылки, карточкиСпиннеры, появление, пульс
transitionanimation
TriggerOn event (hover, focus)Automatic (on load)
States2 (A to B)Any count (@keyframes)
RepeatNoinfinite — forever
Use forButtons, links, cardsSpinners, appearance, pulse
Аналогия: transition — дверь (открывается, когда толкнул). animation — часы (идут сами).
Analogy: transition is a door (opens when pushed). animation is a clock (runs by itself).

📚 @KEYFRAMES — ОПРЕДЕЛЕНИЕ АНИМАЦИИ

📚 @KEYFRAMES — DEFINING ANIMATION

/* Шаг 1: создаём */
@keyframes fadeInUp {
    from {
        opacity: 0;
        transform: translateY(30px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

/* Шаг 2: применяем */
.element {
    animation: fadeInUp 0.8s ease forwards;
}

📚 ГОТОВЫЕ АНИМАЦИИ

📚 READY-MADE ANIMATIONS

/* Появление */
@keyframes fadeIn {
    from { opacity: 0; } to { opacity: 1; }
}

/* Появление снизу */
@keyframes fadeInUp {
    from { opacity: 0; transform: translateY(30px); }
    to   { opacity: 1; transform: translateY(0); }
}

/* Выезд слева */
@keyframes slideInLeft {
    from { opacity: 0; transform: translateX(-60px); }
    to   { opacity: 1; transform: translateX(0); }
}

/* Спиннер */
@keyframes spin {
    to { transform: rotate(360deg); }
}

/* Пульсация */
@keyframes pulse {
    0%, 100% { transform: scale(1); }
    50% { transform: scale(1.05); }
}

📚 КАСКАДНОЕ ПОЯВЛЕНИЕ

📚 CASCADING APPEARANCE

.hero h1  { animation: fadeInUp 0.8s ease forwards; }
.hero p   { animation: fadeInUp 0.8s ease 0.2s forwards; opacity: 0; }
.hero btn { animation: fadeInUp 0.8s ease 0.4s forwards; opacity: 0; }

/* Элементы с delay: обязательно opacity: 0! */
Каскадная задержка: каждый следующий элемент получает delay на 0.15–0.2s больше предыдущего → элементы появляются один за другим.
Cascading delay: each next element gets 0.15–0.2s more delay → elements appear one by one.

📚 3 СТАНДАРТНЫХ РЕЦЕПТА

📚 3 STANDARD RECIPES

/* 1. Одноразовая (появление) */
animation: fadeIn 0.6s ease forwards;

/* 2. Бесконечная (спиннер) */
animation: spin 1s linear infinite;

/* 3. Бесконечная туда-обратно (пульс) */
animation: pulse 2s ease-in-out infinite alternate;
Для спиннера — linear, не ease! С ease спиннер будет «дёргаться» — ускоряется и замедляется на каждом обороте.
For spinners — linear, not ease! With ease the spinner jerks — speeds up and slows down each rotation.

📚 ДОСТУПНОСТЬ

📚 ACCESSIBILITY

@media (prefers-reduced-motion: reduce) {
    *, *::before, *::after {
        animation-duration: 0.01ms !important;
        animation-iteration-count: 1 !important;
        transition-duration: 0.01ms !important;
    }
}
Отключает анимации для пользователей с вестибулярными нарушениями. В продакшене — обязательно.
Disables animations for users with vestibular issues. Mandatory in production.
