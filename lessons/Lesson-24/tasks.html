🎯 Lesson 24.1: LOADERS

Задание 23.1: Коллекция загрузчиков Task 23.1: Loader collection
Лёгкое Easy 15 минут 15 min
Создать 3 разных CSS-загрузчика с @keyframes
Create 3 different CSS loaders with @keyframes

Условие:

Instructions:

Создайте файл loaders.html. Сделайте 3 загрузчика:

Create a file loaders.html. Make 3 loaders:

  1. Вращающийся круг: border-круг с одной синей стороной, animation: spin 0.8s linear infinite
  2. 3 пульсирующие точки: 3 круга, animation: dotPulse 1.4s ease infinite, каскадная задержка
  3. Растущий бар: полоска расширяется от 0% до 100% и обратно, animation: barGrow 1.5s ease infinite alternate
  1. Spinning circle: border-circle with one blue side, animation: spin 0.8s linear infinite
  2. 3 pulsing dots: 3 circles, animation: dotPulse 1.4s ease infinite, cascading delay
  3. Growing bar: bar expands from 0% to 100% and back, animation: barGrow 1.5s ease infinite alternate
Готовый код спиннера: 
@keyframes spin {
    to { transform: rotate(360deg); }
}
.spinner {
    width: 40px; height: 40px;
    border: 4px solid #e2e8f0;
    border-top-color: #3b82f6;
    border-radius: 50%;
    animation: spin 0.8s linear infinite;
}
Важно: linear, не ease! С ease спиннер будет ускоряться и замедляться на каждом обороте.
Ready spinner code: 
@keyframes spin {
    to { transform: rotate(360deg); }
}
.spinner {
    width: 40px; height: 40px;
    border: 4px solid #e2e8f0;
    border-top-color: #3b82f6;
    border-radius: 50%;
    animation: spin 0.8s linear infinite;
}
Important: linear, not ease! With ease the spinner speeds up and slows down each rotation.
  • 3 разных загрузчика
  • Все используют @keyframes
  • Все бесконечные (infinite)
  • Спиннер: linear, точки: ease, бар: ease + alternate
  • У точек каскадная задержка (animation-delay: 0.16s, 0.32s)
  • Подписи под каждым (какой keyframe, какой timing)
  • 3 different loaders
  • All use @keyframes
  • All infinite (infinite)
  • Spinner: linear, dots: ease, bar: ease + alternate
  • Dots have cascading delays (animation-delay: 0.16s, 0.32s)
  • Labels under each (which keyframe, which timing)

🎯 УРОК 24.2: АНИМИРОВАННЫЙ HERO

🎯 Lesson 24.2: ANIMATED HERO

Задание 23.2: Hero с каскадным появлением Task 23.2: Hero with cascading appearance
Среднее Medium 15 минут 15 min
Создать hero-секцию с анимированным появлением элементов
Create a hero section with animated element appearance

Условие:

Instructions:

  1. Hero: height: 100vh, градиент или фоновое изображение с overlay, Flexbox-центрирование
  2. Заголовок: animation: fadeInUp 0.8s ease forwards
  3. Описание: animation: fadeInUp 0.8s ease 0.2s forwards; opacity: 0
  4. Кнопка: animation: fadeInUp 0.8s ease 0.4s forwards; opacity: 0
  5. Кнопка после появления: добавьте пульсацию (pulse 2s ease-in-out infinite через второй animation после задержки)
  1. Hero: height: 100vh, gradient or background image with overlay, Flexbox centering
  2. Heading: animation: fadeInUp 0.8s ease forwards
  3. Description: animation: fadeInUp 0.8s ease 0.2s forwards; opacity: 0
  4. Button: animation: fadeInUp 0.8s ease 0.4s forwards; opacity: 0
  5. Button after appearance: add pulse (pulse 2s ease-in-out infinite via second animation after delay)
Не забудьте opacity: 0 на элементах с delay! Иначе они будут видны до начала анимации, а потом исчезнут и появятся заново.
Don't forget opacity: 0 on elements with delay! Otherwise they'll be visible before animation starts, then disappear and reappear.
  • Hero на весь экран (height: 100vh)
  • 3 элемента появляются каскадом (0s → 0.2s → 0.4s)
  • fadeInUp (opacity: 0 → 1 + translateY(30px) → 0)
  • Кнопка пульсирует после появления (два animation через запятую или с delay)
  • animation-fill-mode: forwards
  • opacity: 0 на элементах с delay
  • Переоткрыть страницу несколько раз — анимация всегда работает
  • Full-screen hero (height: 100vh)
  • 3 elements appear in cascade (0s → 0.2s → 0.4s)
  • fadeInUp (opacity: 0 → 1 + translateY(30px) → 0)
  • Button pulses after appearing (two animations comma-separated or via delay)
  • animation-fill-mode: forwards
  • opacity: 0 on elements with delay
  • Reload page multiple times — animation always works

🎯 Lesson 24.3: COMPLETE PROMO PAGE

Задание 23.3: Анимированная промо-страница Task 23.3: Animated promo page
Среднее Medium 25 минут 25 min
Создать промо-страницу с анимациями и hover-эффектами
Create a promo page with animations and hover effects

Условие:

Instructions:

Создайте папку promo с index.html и style.css. Сделайте промо-страницу из 4 секций:

Create a folder promo with index.html and style.css. Build a promo page with 4 sections:

  1. Hero: fadeInUp каскадом (h1, p, кнопка). Фон с градиентом. Кнопка с hover (transition) + пульсация (animation).
  2. Features (3 фичи): иконка + заголовок + описание. Анимации: 1-я слева (slideInLeft), 2-я снизу (fadeInUp), 3-я справа (slideInRight). Каскадная задержка.
  3. Карточки (3 штуки): fadeInUp с каскадной задержкой (0.15s × n). Hover: translateY(-8px) + shadow (transition).
  4. CTA-секция: fadeIn. Кнопка с пульсирующей тенью (glowPulse).
  1. Hero: cascading fadeInUp (h1, p, button). Gradient background. Button with hover (transition) + pulse (animation).
  2. Features (3 items): icon + title + description. Animations: 1st from left (slideInLeft), 2nd from below (fadeInUp), 3rd from right (slideInRight). Cascading delay.
  3. Cards (3 items): fadeInUp with cascading delay (0.15s × n). Hover: translateY(-8px) + shadow (transition).
  4. CTA section: fadeIn. Button with pulsing shadow (glowPulse).
Разделяйте animation (при загрузке) и transition (при hover). Они не мешают друг другу на одном элементе!
Separate animation (on load) and transition (on hover). They don't conflict on the same element!
  • 4 секции с анимациями при загрузке
  • Минимум 3 разных @keyframes (fadeInUp, slideInLeft/Right, glowPulse)
  • Каскадное появление (animation-delay)
  • Hover-эффекты на карточках и кнопках (через transition, не animation!)
  • animation-fill-mode: forwards
  • opacity: 0 на элементах с delay
  • Блок @media (prefers-reduced-motion: reduce) в конце CSS
  • CSS в отдельном файле style.css
  • Адаптивность: работает на мобильном (опционально)
  • 4 sections with load animations
  • At least 3 different @keyframes (fadeInUp, slideInLeft/Right, glowPulse)
  • Cascading appearance (animation-delay)
  • Hover effects on cards and buttons (via transition, not animation!)
  • animation-fill-mode: forwards
  • opacity: 0 on elements with delay
  • @media (prefers-reduced-motion: reduce) block at the end of CSS
  • CSS in separate file style.css
  • Responsive: works on mobile (optional)

Задание 23.4: Анимированный текст Task 23.4: Animated text
Сложное Hard 15 минут 15 min
Создать эффект печатающегося текста на CSS
Create a typing text effect with CSS

Условие:

Instructions:

Создайте заголовок, который «печатается» посимвольно:

Create a heading that "types" character by character:

@keyframes typing {
    from { width: 0; }
    to { width: 100%; }
}

@keyframes blink {
    50% { border-color: transparent; }
}

.typing-text {
    overflow: hidden;
    white-space: nowrap;
    border-right: 3px solid #1e293b;
    width: 0;
    animation:
        typing 3s steps(30) forwards,
        blink 0.7s step-end infinite;
}
  1. Текст «печатается» слева направо
  2. Мигающий курсор справа
  3. steps(30) — количество шагов ≈ количество символов
  4. Разместите на hero-секции с тёмным фоном
  1. Text "types" from left to right
  2. Blinking cursor on the right
  3. steps(30) — number of steps ≈ number of characters
  4. Place on a hero section with dark background
  • Текст появляется посимвольно
  • Курсор мигает
  • steps() соответствует длине текста
  • Text appears character by character
  • Cursor blinks
  • steps() matches text length
