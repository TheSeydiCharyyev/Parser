Задание 2.1: Горячие клавиши — тренировка Task 2.1: Keyboard Shortcuts — Practice
Лёгкое Easy 10 минут 10 min
Отработать основные горячие клавиши VS Code
Practice essential VS Code keyboard shortcuts

Условие:

Instructions:

Создайте файл shortcuts-practice.html и выполните каждое действие:

Create a file shortcuts-practice.html and perform each action:

  1. Напишите строку <p>Привет, мир!</p>
  2. Дублируйте её 5 раз (Alt + Shift + ↓)
  3. Переместите третью строку наверх (Alt + ↑)
  4. Удалите четвёртую строку (Ctrl + Shift + K)
  5. Закомментируйте вторую строку (Ctrl + /)
  6. Выделите слово «мир» во всех строках одновременно (Ctrl + D несколько раз)
  7. Замените «мир» на своё имя (просто начните печатать)
  8. Сохраните (Ctrl + S)
  1. Write the line <p>Привет, мир!</p>
  2. Duplicate it 5 times (Alt + Shift + ↓)
  3. Move the third line to the top (Alt + ↑)
  4. Delete the fourth line (Ctrl + Shift + K)
  5. Comment out the second line (Ctrl + /)
  6. Select the word "мир" in all lines at once (Ctrl + D several times)
  7. Replace "мир" with your name (just start typing)
  8. Save (Ctrl + S)
  • Все 8 действий выполнены
  • Использованы горячие клавиши (не мышка!)
  • All 8 actions completed
  • Keyboard shortcuts were used (not the mouse!)
Задание 2.2: Emmet — скоростной набор Task 2.2: Emmet — Speed Coding
Среднее Medium 10 минут 10 min
Научиться генерировать HTML с помощью Emmet
Learn to generate HTML using Emmet

Условие:

Instructions:

Создайте файл emmet-practice.html. Используйте ТОЛЬКО Emmet (не печатайте теги вручную):

Create a file emmet-practice.html. Use ONLY Emmet (do not type tags manually):

  1. ! + Tab → шаблон страницы
  2. h1{Мой сайт} + Tab → заголовок
  3. p{Добро пожаловать на мой сайт} + Tab → параграф
  4. h2{Навигация} + Tab → подзаголовок
  5. nav>ul>li*4>a{Страница $} + Tab → навигация с 4 ссылками
  6. h2{Карточки} + Tab → подзаголовок
  7. div.card*3>h3{Карточка $}+p>lorem + Tab → 3 карточки с текстом
  8. footer>p{Сделано на занятии 2} + Tab → подвал
  1. ! + Tab → page template
  2. h1{Мой сайт} + Tab → heading
  3. p{Добро пожаловать на мой сайт} + Tab → paragraph
  4. h2{Навигация} + Tab → subheading
  5. nav>ul>li*4>a{Страница $} + Tab → navigation with 4 links
  6. h2{Карточки} + Tab → subheading
  7. div.card*3>h3{Карточка $}+p>lorem + Tab → 3 cards with text
  8. footer>p{Сделано на занятии 2} + Tab → footer
Если Emmet не работает — убедитесь, что файл сохранён как .html и курсор стоит внутри <body>.
If Emmet is not working — make sure the file is saved as .html and the cursor is inside <body>.

  • Ни один тег не набран вручную

  • No tags typed manually

Задание 2.4: Измени дизайн сайта Task 2.4: Change a Website's Design
Среднее Medium 10 минут 10 min
Научиться менять CSS-стили через DevTools
Learn to modify CSS styles using DevTools

Условие:

Instructions:

Откройте google.com (или другой сайт) и с помощью DevTools сделайте:

Open google.com (or another website) and use DevTools to do the following:

  1. Измените цвет фона страницы на любой другой (background-color)
  2. Измените цвет главного заголовка или логотипа
  3. Увеличьте размер текста какого-нибудь элемента до 36px
  4. Добавьте рамку к любому элементу: border: 3px solid red
  5. Скруглите углы у какого-нибудь блока: border-radius: 20px
  6. Скройте какой-нибудь элемент: display: none
  1. Change the page background color to any other (background-color)
  2. Change the color of the main heading or logo
  3. Increase the text size of any element to 36px
  4. Add a border to any element: border: 3px solid red
  5. Round the corners of any block: border-radius: 20px
  6. Hide any element: display: none
Чтобы добавить новое CSS-свойство: выберите элемент → в панели Styles нажмите на пустое место внутри любого правила → начните печатать имя свойства.
To add a new CSS property: select an element → in the Styles panel click on an empty space inside any rule → start typing the property name.
  • Выполнены все 6 изменений
  • Результат показан преподавателю (или сделан скриншот)
  • All 6 changes completed
  • Result shown to the instructor (or a screenshot taken)

Задание 2.5: Страница «Мои любимые [тема]» Task 2.5: "My Favorite [topic]" Page
Среднее Medium 20 минут 20 min
Создать стилизованную HTML-страницу, используя Emmet и внутренние стили
Create a styled HTML page using Emmet and internal styles

Условие:

Instructions:

Создайте страницу на одну из тем:

Create a page on one of the following topics:

  • Мои любимые фильмы / сериалы
  • Мои любимые игры
  • Мои любимые музыканты / песни
  • Мои любимые блюда
  • Своя тема
  • My favorite movies / TV shows
  • My favorite games
  • My favorite musicians / songs
  • My favorite dishes
  • Your own topic

Требования:

Requirements:

  1. Создайте папку с понятным именем, откройте в VS Code
  2. Используйте Emmet для набора HTML (не печатайте теги вручную!)
  3. Добавьте внутренние CSS-стили (тег <style> в <head>)
  4. Обязательные элементы:
    • Заголовок <h1>
    • Минимум 2 подзаголовка <h2>
    • Минимум 3 «карточки» (блоки <div> с информацией)
    • Список <ul> или <ol>
    • Минимум 1 ссылка <a>
  5. Обязательные CSS-стили:
    • Цвет фона страницы (background-color)
    • Шрифт (font-family)
    • Цвет заголовка (color)
    • Стилизация карточек (фон, отступы, рамка или тень)
    • Скругление углов (border-radius)
  6. Запустите через Live Server
  7. Поэкспериментируйте со стилями в DevTools, перенесите лучшие в код
  1. Create a folder with a clear name, open it in VS Code
  2. Use Emmet to write HTML (do not type tags manually!)
  3. Add internal CSS styles (<style> tag in <head>)
  4. Required elements:
    • Heading <h1>
    • At least 2 subheadings <h2>
    • At least 3 "cards" (<div> blocks with information)
    • A list <ul> or <ol>
    • At least 1 link <a>
  5. Required CSS styles:
    • Page background color (background-color)
    • Font (font-family)
    • Heading color (color)
    • Card styling (background, padding, border or shadow)
    • Rounded corners (border-radius)
  6. Launch via Live Server
  7. Experiment with styles in DevTools, transfer the best ones to your code
<style>
    body {
        font-family: Arial, sans-serif;
        background-color: #f5f5f5;
        max-width: 700px;
        margin: 0 auto;
        padding: 20px;
    }
    h1 { color: #e94560; text-align: center; }
    .card {
        background: white;
        padding: 15px;
        margin: 10px 0;
        border-radius: 10px;
        border-left: 4px solid #e94560;
    }
</style>
  • HTML набран с помощью Emmet
  • Есть h1, минимум 2 h2, минимум 3 карточки, список, ссылка
  • Есть внутренние CSS-стили (минимум 5 свойств)
  • Страница запущена через Live Server
  • Тема — уникальная (не копия примера)
  • HTML written using Emmet
  • Contains h1, at least 2 h2, at least 3 cards, a list, a link
  • Has internal CSS styles (at least 5 properties)
  • Page launched via Live Server
  • Topic is unique (not a copy of the example)
