📚 EMMET — БЫСТРЫЙ НАБОР HTML

📚 EMMET — FAST HTML INPUT

Emmet — встроенный инструмент VS Code. Пишешь короткую команду + Tab = получаешь HTML-код.
Emmet — a built-in VS Code tool. You type a short command + Tab = you get HTML code.
ПишешьПолучаешь
!Шаблон HTML-страницы
h1{Текст}<h1>Текст</h1>
ul>li*3Список из 3 пунктов
div.card<div class="card"></div>
div#main<div id="main"></div>
p*3>lorem3 параграфа с текстом-заглушкой
nav>ul>li*4>a{Пункт $}Навигация с 4 ссылками (нумерованными)
You typeYou get
!HTML page template
h1{Text}<h1>Text</h1>
ul>li*3List with 3 items
div.card<div class="card"></div>
div#main<div id="main"></div>
p*3>lorem3 paragraphs with placeholder text
nav>ul>li*4>a{Item $}Navigation with 4 numbered links
Операторы Emmet — запомни 7 символов:
  • > — вложенность (ребёнок): ul>li = li внутри ul
  • *3 — повторить: li*3 = три li
  • . — добавить class: div.card
  • # — добавить id: div#main
  • {текст} — текст внутри: a{Ссылка}
  • $ — автонумерация: li{Пункт $}*3 → 1, 2, 3
  • + — соседний элемент: h1+p = h1, потом p
  • > — nesting (child element)
  • *3 — repeat 3 times
  • .name — add a class
  • #name — add an id
  • {text} — text inside the tag
  • $ — auto-numbering (1, 2, 3...)
  • lorem — placeholder text

📚 DEVTOOLS — ИНСТРУМЕНТЫ РАЗРАБОТЧИКА

📚 DEVTOOLS — DEVELOPER TOOLS

DevTools — встроенные инструменты браузера для просмотра и редактирования HTML/CSS любого сайта.
DevTools — built-in browser tools for viewing and editing HTML/CSS of any website.

Как открыть: F12 или правый клик → «Просмотреть код»

How to open: F12 or right-click → "Inspect"

Вкладка Elements

Elements Tab

  • Показывает HTML-структуру страницы (дерево тегов)
  • 🔍 — выбрать элемент на странице (инспектирование)
  • Двойной клик по тексту → редактирование
  • Delete — удалить элемент
  • Shows the HTML structure of the page (tag tree)
  • 🔍 — select an element on the page (inspect)
  • Double-click on text → edit it
  • Delete — remove an element

Вкладка Styles

Styles Tab

  • Показывает CSS-стили выбранного элемента
  • Клик на значение → изменить
  • Галочка → включить/отключить свойство
  • Клик на пустое место → добавить новое свойство
  • Цветной квадратик → палитра цветов (color picker)
  • Shows CSS styles of the selected element
  • Click on a value → change it
  • Checkbox → enable/disable a property
  • Click on empty space → add a new property
  • Colored square → color picker

Дополнительные возможности

Additional Features

  • Ctrl + Shift + M — адаптивный режим (просмотр на мобильных)
  • Console → document.designMode = 'on' — редактирование текста прямо на странице
  • Computed — итоговые стили + Box Model
  • Ctrl + Shift + M — responsive mode (mobile preview)
  • Console → document.designMode = 'on' — edit text directly on the page
  • Computed — final computed styles + Box Model
Изменения в DevTools временные! Они пропадут при обновлении (F5). Понравившиеся стили нужно перенести в CSS-файл в VS Code.
Changes in DevTools are temporary! They will disappear when you refresh (F5). You need to copy the styles you like into a CSS file in VS Code.
