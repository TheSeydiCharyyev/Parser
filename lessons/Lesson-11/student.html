Форма — это способ получить данные от пользователя: текст, выбор, файлы. Все поля находятся внутри тега <form>.
Form — a way to collect data from the user: text, choices, files. All fields are inside the <form> tag.

Шаблон поля с подписью

Field with label template

<label for="name">Имя:</label>
<input type="text" id="name" name="name" placeholder="Ваше имя">
Связь label ↔ input: Атрибут for у label = id у input. При клике на подпись — фокус переходит на поле.
label ↔ input connection: The for attribute in label = id in input. Clicking the label focuses the field.

Ключевые CSS для форм

Key CSS for forms

input, select, textarea {
    width: 100%;
    padding: 12px 16px;
    border: 2px solid #e2e8f0;
    border-radius: 8px;
    font-size: 1rem;
    font-family: inherit;
    outline: none;
}

input:focus, select:focus, textarea:focus {
    border-color: #3b82f6;
    box-shadow: 0 0 0 3px rgba(59,130,246,0.1);
}

button[type="submit"] {
    background: #3b82f6;
    color: #fff;
    border: none;
    border-radius: 8px;
    padding: 14px;
    cursor: pointer;
}

button[type="submit"]:hover {
    background: #2563eb;
}

  • <label for="id"> + <input id="id"> — always link them!
  • radio — one from group, checkbox — multiple
  • Radio buttons in one group have the same name
  • required — mandatory field

  • font-family: inherit — so fields use page font
