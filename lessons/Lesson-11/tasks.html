Instructions:

Create a folder registration with files index.html and style.css. Make a beautiful registration form:

Поля формы:

Form fields:

  1. Полное имя — type="text", required, minlength="2"
  2. Email — type="email", required
  3. Пароль — type="password", required, minlength="8"
  4. Повторите пароль — type="password", required
  5. Дата рождения — type="date"
  6. Город — <select> с 5 городами
  7. Пол — radio (Мужской / Женский)
  8. Навыки — checkbox (HTML, CSS, JS, Git — минимум 4)
  9. О себе — <textarea>
  10. Согласие — checkbox + required
  11. Кнопка — «Зарегистрироваться»
  1. Full name — type="text", required, minlength="2"
  2. Email — type="email", required
  3. Password — type="password", required, minlength="8"
  4. Repeat password — type="password", required
  5. Date of birth — type="date"
  6. City — <select> with 5 cities
  7. Gender — radio (Male / Female)
  8. Skills — checkbox (HTML, CSS, JS, Git — at least 4)
  9. About me — <textarea>
  10. Agreement — checkbox + required
  11. Button — "Register"

CSS-требования:

CSS requirements:

  • Форма в белой карточке с тенью, отцентрирована на странице
  • Все поля стилизованы (padding, border-radius, border)
  • :focus — синяя рамка при фокусе
  • Кнопка стилизована с :hover
  • CSS подключён через <link>
  • Form in a white card with shadow, centered on page

  • :focus — blue border on focus

  • CSS linked via <link>

}
