📚 РАЗМЕЩЕНИЕ ЭЛЕМЕНТОВ (grid-column / grid-row)

📚 ITEM PLACEMENT (grid-column / grid-row)

Grid-линии — границы между столбцами и строками. Нумеруются с 1. У сетки из 3 столбцов — 4 линии столбцов.
Grid lines — boundaries between columns and rows. Numbered from 1. A 3-column grid has 4 column lines.
СвойствоЧто делаетПример
grid-columnРазмещение по столбцам1 / 3 или span 2
grid-rowРазмещение по строкам1 / 3 или span 2
grid-areaПривязка к именованной областиheader
PropertyWhat it doesExample
grid-columnColumn placement1 / 3 or span 2
grid-rowRow placement1 / 3 or span 2
grid-areaAssign to named areaheader
/* Занять 2 столбца */
grid-column: span 2;

/* Занять 3 строки */
grid-row: span 3;

/* От линии 1 до линии 4 (= 3 столбца) */
grid-column: 1 / 4;

📚 ИМЕНОВАННЫЕ ОБЛАСТИ (grid-template-areas)

📚 NAMED AREAS (grid-template-areas)

grid-template-areas — визуальный способ описать макет. Каждая строка в кавычках = строка сетки. Одинаковые имена = одна область.
grid-template-areas — a visual way to describe a layout. Each quoted string = one grid row. Same names = one area. 
/* Контейнер */
.layout {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-rows: 60px 1fr 50px;
    grid-template-areas:
        "header  header"
        "sidebar content"
        "footer  footer";
}

/* Элементы */
.head { grid-area: header; }
.side { grid-area: sidebar; }
.main { grid-area: content; }
.foot { grid-area: footer; }
Правила grid-template-areas:
  • Область = только прямоугольник (нельзя Г-образная)
  • Одинаковое количество слов в каждой строке
  • Точка . = пустая ячейка
  • Порядок элементов в HTML не важен!
grid-template-areas rules:
  • Area = only a rectangle (no L-shapes)
  • Same number of words in each row
  • Dot . = empty cell
  • HTML element order doesn't matter!

Главное правило: Grid = макет (2D, «снаружи внутрь»), Flexbox = компоненты (1D, «изнутри наружу»). Используй вместе!
Main rule: Grid = layout (2D, "outside in"), Flexbox = components (1D, "inside out"). Use them together!
