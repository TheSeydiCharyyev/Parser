🎯 Lesson 18.1: GRID-COLUMN AND GRID-ROW

Задание 17.1: Объединение ячеек Task 17.1: Merging cells
Лёгкое Easy 15 минут 15 min
Научиться размещать элементы по линиям и объединять ячейки
Learn to place items by lines and merge cells

Условие:

Instructions:

Создайте файл grid-span.html. Сделайте Grid 4 столбца x 3 строки с 8 цветными блоками. Настройте:

Create a file grid-span.html. Make a Grid of 4 columns x 3 rows with 8 colored blocks. Configure:

  1. Блок 1: grid-column: span 2 — занимает 2 столбца
  2. Блок 2: grid-row: span 2 — занимает 2 строки
  3. Блок 5: grid-column: span 3 — занимает 3 столбца
  4. Блок 7: grid-column: 1 / -1 — от первой до последней линии (вся строка)
  1. Block 1: grid-column: span 2 — spans 2 columns
  2. Block 2: grid-row: span 2 — spans 2 rows
  3. Block 5: grid-column: span 3 — spans 3 columns
  4. Block 7: grid-column: 1 / -1 — from first to last line (full row)
grid-column: 1 / -1 — отрицательная линия -1 означает «последняя линия». Полезно, когда не хочется считать количество столбцов!
grid-column: 1 / -1 — negative line -1 means "last line". Useful when you don't want to count columns!
  • Grid 4x3 с gap
  • Блоки разных размеров (span 2, span 3, полная строка)
  • Каждый блок — свой цвет фона
  • Номера блоков отображаются в каждом
  • 4x3 Grid with gap
  • Blocks of different sizes (span 2, span 3, full row)
  • Each block has its own background color
  • Block numbers displayed in each one

Задание 17.2: Макет страницы с grid-template-areas Task 17.2: Page layout with grid-template-areas
Среднее Medium 20 минут 20 min
Создать макет страницы с помощью именованных областей
Create a page layout using named areas

Условие:

Instructions:

Создайте папку grid-layout с файлами index.html и style.css. Сделайте классический макет:

Create a folder grid-layout with files index.html and style.css. Build a classic layout:

grid-template-areas:
    "header  header"
    "sidebar content"
    "footer  footer";
  1. Grid-контейнер: grid-template-columns: 250px 1fr, min-height: 100vh
  2. Header: высота 60px, фон #1e293b, белый текст, Flexbox внутри (justify-content: space-between)
  3. Sidebar: фон #f1f5f9, padding 20px, 5 ссылок в столбец (Flexbox)
  4. Content: padding 24px, заголовок + 2 параграфа текста
  5. Footer: высота 50px, фон #1e293b, белый текст, текст по центру
  1. Grid container: grid-template-columns: 250px 1fr, min-height: 100vh
  2. Header: height 60px, background #1e293b, white text, Flexbox inside (justify-content: space-between)
  3. Sidebar: background #f1f5f9, padding 20px, 5 links in column (Flexbox)
  4. Content: padding 24px, heading + 2 paragraphs of text
  5. Footer: height 50px, background #1e293b, white text, centered text

🎯 Lesson 18.3: DASHBOARD

Задание 17.3: Dashboard-макет Task 17.3: Dashboard layout
Среднее Medium 25 минут 25 min
Создать Dashboard с Grid-областями и виджетами
Create a Dashboard with Grid areas and widgets

Условие:

Instructions:

Создайте папку dashboard с файлами index.html и style.css. Сделайте Dashboard:

Create a folder dashboard with files index.html and style.css. Build a Dashboard:

Структура (grid-template-areas):

Structure (grid-template-areas):

"sidebar header  header"
"sidebar main    aside"
"sidebar main    aside"
  1. Общий Grid: grid-template-columns: 220px 1fr 280px, grid-template-rows: 60px 1fr 1fr, min-height: 100vh
  2. Sidebar (220px): фон #1e293b, белый текст, лого сверху + 4 ссылки навигации (Flexbox column)
  3. Header (60px): фон белый, тень снизу, текст «Dashboard» + кнопка справа (Flexbox)
  4. Main: фон #f1f5f9, padding 20px, внутри Grid-сетка из 4 виджетов:
    • Виджеты: белые карточки с border-radius: 12px, padding: 20px, box-shadow
    • Сетка виджетов: repeat(auto-fit, minmax(200px, 1fr))
    • Первый виджет: grid-column: span 2 (широкий)
  5. Aside (280px): фон белый, border-left, padding 20px, заголовок «Notifications» + 3 уведомления
  1. Overall Grid: grid-template-columns: 220px 1fr 280px, grid-template-rows: 60px 1fr 1fr, min-height: 100vh
  2. Sidebar (220px): background #1e293b, white text, logo on top + 4 nav links (Flexbox column)
  3. Header (60px): white background, bottom shadow, "Dashboard" text + button on right (Flexbox)
  4. Main: background #f1f5f9, padding 20px, inside a Grid of 4 widgets:
    • Widgets: white cards with border-radius: 12px, padding: 20px, box-shadow
    • Widget grid: repeat(auto-fit, minmax(200px, 1fr))
    • First widget: grid-column: span 2 (wide)
  5. Aside (280px): white background, border-left, padding 20px, "Notifications" title + 3 notifications
Совет: используйте Grid для общего макета (sidebar, header, main, aside) и вложенный Grid для виджетов внутри main. Навигацию в sidebar делайте через Flexbox.
Tip: use Grid for the overall layout (sidebar, header, main, aside) and a nested Grid for widgets inside main. Make sidebar navigation with Flexbox.
  • grid-template-areas для общего макета
  • Sidebar занимает все строки (3 ряда)
  • Вложенный Grid для виджетов в main
  • Первый виджет = span 2
  • Flexbox для sidebar-навигации и header
  • Карточки виджетов с тенями
  • CSS в отдельном файле
  • grid-template-areas for overall layout
  • Sidebar spans all rows (3 rows)
  • Nested Grid for widgets in main
  • First widget = span 2
  • Flexbox for sidebar navigation and header
  • Widget cards with shadows
  • CSS in separate file

  6. Hover: transform: translateY(-4px) + box-shadow
