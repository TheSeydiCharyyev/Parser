1. Повторение: что мы знаем о Grid

1. Recap: what we know about Grid

На прошлом занятии мы изучили свойства Grid-контейнера — как создавать сетку:

In the previous lesson we learned Grid container properties — how to create a grid:

.grid {
    display: grid;                                        /* включить Grid */
    grid-template-columns: repeat(3, 1fr);                /* 3 равных столбца */
    grid-template-rows: auto;                             /* строки по содержимому */
    gap: 20px;                                            /* отступы между ячейками */
    place-items: center;                                  /* выравнивание в ячейках */
}

/* Адаптивная сетка: */
grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));

Все эти свойства задаются контейнеру (родителю). Элементы внутри распределяются автоматически — по порядку, слева направо, сверху вниз.

All these properties are set on the container (parent). Items inside are distributed automatically — in order, left to right, top to bottom.

Если Grid-контейнер — это шахматная доска, то до сих пор фигуры расставлялись автоматически: первая — в A1, вторая — в B1, третья — в C1 и так далее. Сегодня мы научимся ставить фигуры на конкретные клетки и объединять клетки в большие территории.

If the Grid container is a chessboard, until now pieces were placed automatically: first in A1, second in B1, third in C1, and so on. Today we'll learn to place pieces on specific squares and merge squares into large territories.

2. Линии Grid — нумерация

2. Grid lines — numbering

Чтобы разместить элемент в конкретном месте сетки, нам нужна система координат. В Grid координаты задаются через линии — невидимые границы между столбцами и строками. Каждая линия имеет номер, и мы говорим элементу: «займи пространство от линии 1 до линии 3».

To place an element in a specific grid position, we need a coordinate system. In Grid, coordinates are defined by lines — invisible boundaries between columns and rows. Each line has a number, and we tell an element: "occupy space from line 1 to line 3".

Каждый столбец и строка ограничены линиями. Линии нумеруются с 1:

Each column and row is bounded by lines. Lines are numbered starting from 1:

grid-template-columns: 1fr 1fr 1fr; (3 столбца) grid-template-rows: auto auto; (2 строки) Линии столбцов: 1 2 3 4 │ │ │ │ ┌────────┬────────┬────────┐ 1 ── │ A │ B │ C │ ← строка 1 ├────────┼────────┼────────┤ 2 ── │ D │ E │ F │ ← строка 2 └────────┴────────┴────────┘ 3 ── 3 столбца → 4 вертикальных линии (1, 2, 3, 4) 2 строки → 3 горизонтальных линии (1, 2, 3) Формула: N столбцов = N+1 линий
grid-template-columns: 1fr 1fr 1fr; (3 columns) grid-template-rows: auto auto; (2 rows) Column lines: 1 2 3 4 │ │ │ │ ┌────────┬────────┬────────┐ 1 ── │ A │ B │ C │ ← row 1 ├────────┼────────┼────────┤ 2 ── │ D │ E │ F │ ← row 2 └────────┴────────┴────────┘ 3 ── 3 columns → 4 vertical lines (1, 2, 3, 4) 2 rows → 3 horizontal lines (1, 2, 3) Formula: N columns = N+1 lines

Забор. Если у вас забор из 3 секций, то столбов будет 4 (один в начале, один в конце, два между секциями). Линии Grid — это столбы забора, а ячейки — секции между ними.

Fence. If you have a fence with 3 sections, there are 4 posts (one at the start, one at the end, two between sections). Grid lines are fence posts, and cells are the sections between them.

Формула: N столбцов = N+1 линий столбцов. N строк = N+1 линий строк. Это важно запомнить!
Formula: N columns = N+1 column lines. N rows = N+1 row lines. Important to remember!

Откройте DevTools (F12) на этой странице. Найдите любой grid-контейнер и нажмите на значок «grid». Chrome подсветит номера линий прямо на странице! Это лучший способ понять нумерацию.

Open DevTools (F12) on this page. Find any grid container and click the "grid" badge. Chrome will highlight line numbers right on the page! This is the best way to understand numbering.

3. grid-column — размещение по столбцам

3. grid-column — column placement

Теперь, зная номера линий, мы можем сказать элементу: «займи место от линии 1 до линии 3» — и он растянется на 2 столбца. Это как в Excel объединить две ячейки.

Now, knowing line numbers, we can tell an element: "occupy space from line 1 to line 3" — and it stretches across 2 columns. Like merging two cells in Excel.

grid-column указывает, от какой до какой линии столбца занимает элемент:

grid-column specifies from which to which column line an item occupies:

.item-a {
    grid-column: 1 / 3;  /* от линии 1 до линии 3 = 2 столбца */
}

/* Можно записать отдельно: */
grid-column-start: 1;
grid-column-end: 3;

/* Или сокращённо: */
grid-column: 1 / 3;   /* start / end */

grid-column: 1 / 3; (item A spans 2 columns) 1 2 3 4 ┌────────────────┬────────┐ │ A (2 col) │ B │ ← row 1 ├────────┬────────┼────────┤ │ C │ D │ E │ ← row 2 └────────┴────────┴────────┘ A starts at line 1, ends at line 3 → occupies 2 columns (between lines 1 and 3)

grid-row works the same way, but for rows. Perfect for a sidebar that should span multiple rows:

Где используется grid-row в реальных проектах:

  • Sidebar — боковая панель на всю высоту (grid-row: 1 / -1)
  • Featured-карточка — главная карточка в галерее, которая выше остальных
  • Реклама — баннер, занимающий несколько строк сетки

Where grid-row is used in real projects:

  • Sidebar — side panel full height (grid-row: 1 / -1)
  • Featured card — main card in a gallery, taller than others
  • Advertising — banner spanning multiple grid rows

Ошибка на единицу (off-by-one). Новички путают номера линий и номера столбцов/строк:

/* НЕПРАВИЛЬНО: «хочу 2 столбца, пишу 1/2» */
grid-column: 1 / 2;  /* Это только 1 столбец! (между линиями 1 и 2) */

/* ПРАВИЛЬНО: 2 столбца = от линии 1 до линии 3 */
grid-column: 1 / 3;  /* ✅ 2 столбца */

Помните: числа — это номера линий, а не столбцов. 2 столбца = 3 линии (1, 2, 3).

Off-by-one error. Beginners confuse line numbers with column/row numbers:

/* WRONG: "I want 2 columns, so I write 1/2" */
grid-column: 1 / 2;  /* This is only 1 column! (between lines 1 and 2) */

/* CORRECT: 2 columns = from line 1 to line 3 */
grid-column: 1 / 3;  /* ✅ 2 columns */

Remember: numbers are line numbers, not column numbers. 2 columns = 3 lines (1, 2, 3).

5. span — объединение ячеек

5. span — merging cells

Считать номера линий неудобно, особенно в больших сетках. Гораздо проще сказать: «займи 2 столбца» — без подсчёта линий. Для этого есть ключевое слово span.

Counting line numbers is inconvenient, especially in large grids. It's much easier to say: "take up 2 columns" — without counting lines. That's what the span keyword is for.

Вместо указания конечной линии можно использовать span — сколько ячеек занять:

Instead of specifying the end line, you can use span — how many cells to occupy:

/* Все три записи делают ОДНО И ТО ЖЕ: */

/* Способ 1: от линии до линии */
grid-column: 1 / 3;

/* Способ 2: span — занять 2 столбца (от текущей позиции) */
grid-column: span 2;

/* Способ 3: начало + span */
grid-column: 1 / span 2;

/* Для строк аналогично: */
grid-row: span 3;  /* занять 3 строки */

6. grid-template-areas — именованные области

6. grid-template-areas — named areas

Номера линий и span работают, но когда макет сложный (header + sidebar + content + footer), код с числами становится трудно читать. Попробуйте понять, что делает grid-column: 2 / 4; grid-row: 1 / 3; — нужно держать в голове всю сетку.

grid-template-areas решает эту проблему: вы буквально рисуете макет текстом. Код читается как визуальная карта — сразу видно, где header, где sidebar, где content.

Line numbers and span work, but when the layout is complex (header + sidebar + content + footer), numeric code becomes hard to read. Try understanding what grid-column: 2 / 4; grid-row: 1 / 3; does — you have to keep the entire grid in your head.

grid-template-areas solves this: you literally draw the layout with text. The code reads like a visual map — you immediately see where the header, sidebar, and content are.

.layout {
    display: grid;
    grid-template-areas:
        "header  header  header"
        "sidebar content content"
        "footer  footer  footer";
}

План квартиры. Представьте, что вы архитектор. Вы рисуете план: «Здесь кухня, здесь спальня, здесь гостиная». Каждое слово — это комната (область). Одинаковые слова — это одна большая комната, занимающая несколько клеток.

Точно так же работает grid-template-areas: вы описываете, какой элемент где стоит, просто написав его имя в нужных ячейках.

Floor plan. Imagine you're an architect. You draw a plan: "Kitchen here, bedroom here, living room here". Each word is a room (area). Identical words form one large room spanning multiple cells.

grid-template-areas works exactly like this: you describe which element goes where by writing its name in the right cells.

grid-template-areas — одна из самых любимых фич CSS Grid среди разработчиков. Многие говорят, что это самый читаемый CSS-код, который они когда-либо видели. Вы буквально «видите» макет в коде!

grid-template-areas is one of the most beloved CSS Grid features among developers. Many say it's the most readable CSS code they've ever seen. You literally "see" the layout in the code!

7. Синтаксис grid-template-areas

7. grid-template-areas syntax

.layout {
    display: grid;
    grid-template-columns: 250px 1fr 1fr;
    grid-template-rows: 60px 1fr 50px;
    grid-template-areas:
        "header  header  header"
        "sidebar content content"
        "footer  footer  footer";
    gap: 16px;
    min-height: 100vh;
}

Каждая строка в кавычках — это одна строка сетки. Количество слов в строке = количество столбцов. Одинаковые слова = одна область, растянутая на несколько ячеек.

Each quoted string is one grid row. Number of words per string = number of columns. Identical words = one area stretched across multiple cells.

"header header header" ← строка 1: header на все 3 столбца "sidebar content content" ← строка 2: sidebar (1 col) + content (2 col) "footer footer footer" ← строка 3: footer на все 3 столбца ┌───────────────────────────────┐ │ HEADER │ 60px ├────────┬──────────────────────┤ │ SIDE │ │ │ BAR │ CONTENT │ 1fr │ 250px │ │ ├────────┴──────────────────────┤ │ FOOTER │ 50px └───────────────────────────────┘
"header header header" ← row 1: header across all 3 columns "sidebar content content" ← row 2: sidebar (1 col) + content (2 col) "footer footer footer" ← row 3: footer across all 3 columns ┌───────────────────────────────┐ │ HEADER │ 60px ├────────┬──────────────────────┤ │ SIDE │ │ │ BAR │ CONTENT │ 1fr │ 250px │ │ ├────────┴──────────────────────┤ │ FOOTER │ 50px └───────────────────────────────┘

8. Правила именованных областей

8. Named areas rules

Правила, которые нельзя нарушать:
  1. Область должна быть прямоугольной (нельзя Г-образная или Т-образная)
  2. Количество слов в каждой строке должно быть одинаковым
  3. Используйте . (точку) для пустых ячеек
  4. Имена областей — без кавычек, только буквы, цифры, дефис
Rules that must not be broken:
  1. An area must be rectangular (no L-shapes or T-shapes)
  2. Number of words in each row must be the same
  3. Use . (dot) for empty cells
  4. Area names — no quotes, only letters, numbers, hyphens
/* Пустая ячейка — точка */
grid-template-areas:
    "header header header"
    "sidebar content ."       /* точка = пустая ячейка */
    "footer  footer  footer";
❌ Неправильно — L-образная область
❌ Wrong — L-shaped area
"header header ."
"header sidebar sidebar"

header — не прямоугольник! CSS выдаст ошибку, Grid сломается.

header is not a rectangle! CSS will throw an error, Grid will break.

✅ Правильно — прямоугольные области
✅ Correct — rectangular areas
"header  header  header"
".       sidebar sidebar"

Все области — прямоугольники. Точка = пустое место.

All areas are rectangles. Dot = empty space.

Самая частая ошибка — непрямоугольная область. Grid молча ломается — никакой красной ошибки в браузере. Элементы просто расположатся хаотично, и вы потратите 30 минут на отладку.

Если макет с areas выглядит сломанным — первым делом проверьте, что все области прямоугольные.

The most common mistake — non-rectangular area. Grid silently breaks — no red error in the browser. Elements just get placed chaotically, and you'll spend 30 minutes debugging.

If an areas layout looks broken — first check that all areas are rectangular.

9. grid-area — привязка элемента к области

9. grid-area — assigning element to area

Мы нарисовали карту макета. Теперь нужно сказать каждому HTML-элементу: «Ты — header, встань в область header». Это делает свойство grid-area.

We drew the layout map. Now we need to tell each HTML element: "You're the header, go to the header area." That's what grid-area does.

После определения областей в контейнере, каждому элементу нужно указать его область:

After defining areas in the container, each element needs to be assigned its area:

<div class="layout">
    <header class="head">Header</header>
    <aside class="side">Sidebar</aside>
    <main class="main">Content</main>
    <footer class="foot">Footer</footer>
</div>
.layout {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-rows: 60px 1fr 50px;
    grid-template-areas:
        "header  header"
        "sidebar content"
        "footer  footer";
    gap: 16px;
    min-height: 100vh;
}

/* Привязка: имя в CSS = имя в grid-template-areas */
.head { grid-area: header; }
.side { grid-area: sidebar; }
.main { grid-area: content; }
.foot { grid-area: footer; }
Магия grid-area: порядок элементов в HTML не важен! Grid размещает их по именам областей. Вы можете поставить <footer> первым в HTML — он всё равно окажется внизу, потому что grid-area: footer ставит его в зону «footer».
grid-area magic: the order of elements in HTML doesn't matter! Grid places them by area names. You can put <footer> first in HTML — it will still be at the bottom, because grid-area: footer places it in the "footer" zone.

Забыли написать grid-area для элемента. Если вы определили areas в контейнере, но не назначили grid-area элементу, он разместится автоматически (как обычно), игнорируя вашу красивую карту. Результат — хаос.

Правило: если используете grid-template-areas, каждому элементу нужен grid-area.

Forgot to write grid-area for an element. If you defined areas in the container but didn't assign grid-area to an element, it will be placed automatically (as usual), ignoring your beautiful map. Result — chaos.

Rule: if using grid-template-areas, every element needs a grid-area.

12. Комбинирование Grid и Flexbox

12. Combining Grid and Flexbox

На реальных сайтах Grid и Flexbox используются вместе. Grid отвечает за общую структуру страницы, а Flexbox — за компоненты внутри. Это не «или-или» — это «и-и»!

In real websites Grid and Flexbox are used together. Grid handles the overall page structure, Flexbox handles components inside. It's not "either-or" — it's "both-and"!

Типичный паттерн: Grid для макета, Flexbox для компонентов внутри:

Typical pattern: Grid for layout, Flexbox for components inside:

/* Grid — общая раскладка страницы */
.page {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-areas:
        "header header"
        "sidebar content"
        "footer footer";
}

/* Flexbox — навигация внутри header */
.header {
    grid-area: header;
    display: flex;               /* ← Flexbox внутри Grid-элемента! */
    justify-content: space-between;
    align-items: center;
}

/* Grid — сетка карточек внутри content */
.content {
    grid-area: content;
    display: grid;               /* ← Grid внутри Grid-элемента! */
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 20px;
}

/* Flexbox — карточка товара */
.card {
    display: flex;               /* ← Flexbox внутри Grid-элемента! */
    flex-direction: column;
    gap: 12px;
}

Архитектор и дизайнер интерьера. Grid — это архитектор, который проектирует этажи и комнаты здания (макет страницы). Flexbox — это дизайнер интерьера, который расставляет мебель внутри комнат (компоненты внутри секций). Они работают вместе — один создаёт структуру, другой наполняет деталями.

Architect and interior designer. Grid is the architect who designs the floors and rooms of a building (page layout). Flexbox is the interior designer who arranges furniture inside rooms (components inside sections). They work together — one creates structure, the other fills in details.

Элемент может быть одновременно grid-элементом (в макете) и flex/grid-контейнером (для своих потомков). Это как комната в здании: она часть этажа (grid-элемент) и при этом имеет собственную мебель (flex/grid-контейнер).

An element can be simultaneously a grid item (in the layout) and a flex/grid container (for its children). Like a room in a building: it's part of a floor (grid item) and has its own furniture inside (flex/grid container).

Lesson 18 Summary

Свойства Grid-элементов (новые):
  • grid-column: 1 / 3 — занять от линии 1 до линии 3 (2 столбца)
  • grid-column: span 2 — занять 2 столбца (проще!)
  • grid-column: 1 / -1 — на всю ширину (от первой до последней линии)
  • grid-row: 1 / 3 — занять 2 строки
  • grid-row: span 2 — занять 2 строки (проще!)
  • grid-area: name — привязать к именованной области
Свойства Grid-контейнера (новые):
  • grid-template-areas — визуальная карта макета (самый читаемый способ!)
Ключевые правила:
  • N столбцов = N+1 линий. Числа в grid-column/row — это линии, не столбцы!
  • Области в grid-template-areas должны быть прямоугольными
  • Точка (.) = пустая ячейка в areas
  • Grid — для макета (2D). Flexbox — для компонентов (1D). Используйте вместе!
Grid item properties (new):
  • grid-column: 1 / 3 — span from line 1 to line 3 (2 columns)
  • grid-column: span 2 — span 2 columns (easier!)
  • grid-column: 1 / -1 — full width (first to last line)
  • grid-row: 1 / 3 — span 2 rows
  • grid-row: span 2 — span 2 rows (easier!)
  • grid-area: name — assign to named area
Grid container properties (new):
  • grid-template-areas — visual layout map (most readable way!)
Key rules:
  • N columns = N+1 lines. Numbers in grid-column/row are lines, not columns!
  • Areas in grid-template-areas must be rectangular
  • Dot (.) = empty cell in areas
  • Grid — for layout (2D). Flexbox — for components (1D). Use them together!
