📚 ТЕГИ

Тег — команда для браузера в угловых скобках < >.

Парные теги

<h1>Содержимое</h1>
 ↑ открывающий    ↑ закрывающий (с /)

Одиночные теги (без закрывающего)

<br> — перенос строки, <hr> — линия, <img> — картинка, <input> — поле ввода

Парный тег = коробка с крышкой (кладёшь содержимое, закрываешь).
Одиночный тег = наклейка (просто есть, ничего внутрь не кладёшь).

📚 АТРИБУТЫ

Атрибуты — дополнительная информация о теге. Пишутся в открывающем теге: имя="значение" 
<a href="https://google.com" target="_blank">Ссылка</a>
<img src="photo.jpg" alt="Описание" width="300">
АтрибутТегЧто делает
href<a>Адрес ссылки
src<img>Путь к картинке
alt<img>Описание картинки
classЛюбойCSS-класс
idЛюбойУникальный идентификатор
target="_blank"<a>Открыть в новой вкладке

📚 ВЛОЖЕННОСТЬ

Теги закрываются в обратном порядке открытия!
✅ <p><strong>текст</strong></p>
❌ <p><strong>текст</p></strong>

Каждый уровень вложенности — отступ в 1 Tab:

<div>
    <h1>Заголовок</h1>
    <p>Параграф</p>
</div>
Совет: Shift + Alt + F в VS Code — автоматическое выравнивание отступов.

📚 СТРУКТУРА HTML-ДОКУМЕНТА

<!DOCTYPE html> ← Тип документа <html lang="ru"> ← Корневой тег │ ├── <head> ← Невидимое (для браузера) │ ├── <meta charset> │ ├── <meta viewport> │ ├── <title> ← Текст на вкладке │ └── <link> / <style> │ └── <body> ← Видимое (для пользователя) └── Весь контент
ТегНазначение
<!DOCTYPE html>Объявление HTML5
<html lang="ru">Корень документа
<head>Метаинформация (невидимая)
<meta charset="UTF-8">Кодировка (русские буквы)
<title>Заголовок вкладки (и для Google)
<body>Всё видимое содержимое
<head> = конверт (информация для почты).
<body> = само письмо (содержимое для читателя).

📚 ЗАГОЛОВКИ h1–h6

<h1>Главный заголовок</h1>  ← только 1 на странице
<h2>Раздел</h2>
<h3>Подраздел</h3>
<h4>...</h4>
<h5>...</h5>
<h6>самый мелкий</h6>
  • <h1> — только один на странице
  • Не перескакивать: h1 → h2 → h3 (не h1 → h3)
  • Заголовки = оглавление книги

📚 ПАРАГРАФЫ И ПЕРЕНОСЫ

ТегЧто делает
<p>...</p>Параграф (абзац) с автоотступами
<br>Перенос строки
<hr>Горизонтальная линия-разделитель
Лишние пробелы и переносы строк в HTML игнорируются браузером! Для переноса нужен <br>.
<br> — для стихов, адресов, коротких строк. Не используйте <br><br><br> для создания отступов — для этого есть CSS!

📚 ФОРМАТИРОВАНИЕ ТЕКСТА

ТегРезультатПример
<strong>Жирный (важный)Ключевые слова
<em>Курсив (акцент)Выделение
<u>ПодчёркнутыйСсылки, термины
<s>ЗачёркнутыйСтарая цена
<mark>ВыделенныйВажное
<small>МелкийСноски
<sub>H2OФормулы
<sup>E=mc2Степени
  • <strong> = важный по смыслу (Google обращает внимание) → используйте его!
  • <b> = просто визуально жирный (без смысла)
  • <em> = смысловой акцент → используйте его!
  • <i> = просто курсив (для терминов, названий)
Запоминалка для реальной жизни:
<s> = старая цена (1000 ₽)
<strong> = новая цена (750 ₽)
<mark> = бейдж (АКЦИЯ)
<small> = мелкий шрифт (условия доставки)
<sub>/<sup> = формулы (H2O, E=mc2)

📝 ИТОГИ ЗАНЯТИЯ 3

  • Теги: парные (<p>...</p>) и одиночные (<br>)
  • Атрибуты: имя="значение" в открывающем теге
  • Вложенность: закрывай в обратном порядке
  • Структура: DOCTYPE → html → head + body
  • head = невидимое, body = видимое
  • h1–h6: иерархия заголовков, h1 один раз
  • p, br, hr — текст, перенос, линия
  • Форматирование: strong, em, mark, s, sub, sup
  • <!-- --> — комментарии
КонцепцияЗапоминалка
Парный тегКоробка с крышкой — кладёшь содержимое, закрываешь
Одиночный тегНаклейка — просто есть, ничего внутрь
АтрибутыСвойства предмета: «какая картинка?», «куда ссылка?»
ВложенностьМатрёшка: что открыл последним — закрывай первым
<head>Конверт: информация для почты (браузера)
<body>Письмо: содержимое для читателя (пользователя)

  1. Создайте страницу-статью на любую тему (минимум 3 раздела h2)
  2. Используйте все изученные теги: h1-h3, p, br, hr, strong, em, mark, s, sub/sup
  3. Добавьте комментарии к разделам
  4. Проверьте вложенность тегов — всё ли закрыто правильно
