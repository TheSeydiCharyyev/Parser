Научиться строить правильную иерархию заголовков
Learn to build a correct heading hierarchy

Условие:

Instructions:

Превратите это оглавление в HTML-код с правильными заголовками:

Convert this table of contents into HTML code with correct headings:

Рецепты (главное название)
├── Завтраки
│   ├── Омлет
│   └── Блинчики

"Рецепты" — h1, "Завтраки/Обеды/Десерты" — h2, specific dishes — h3.
  • h1 используется один раз
  • Иерархия: h1 → h2 → h3 (без пропусков)
  • Каждому блюду добавлен параграф <p> с описанием
  • h1 is used only once
  • Hierarchy: h1 → h2 → h3 (no gaps)
  • Each dish has a paragraph <p> with a description
Задание 3.4: Форматирование текста Task 3.4: Text Formatting
Среднее Medium 10 минут 10 min
Отработать все теги форматирования
Practice all formatting tags

Условие:

Instructions:

Создайте HTML-страницу с карточкой товара, используя теги форматирования:

Create an HTML page with a product card using formatting tags:

<h1>Интернет-магазин</h1>

<h2>Наушники SuperSound Pro</h2>

<p>Цена: <s>5000 руб.</s> <strong>3500 руб.</strong></p>

<p><mark>СКИДКА 30%!</mark></p>

<p><em>Лучшие наушники</em> для любителей музыки.
Частотный диапазон: 20<sub>Гц</sub> — 20000<sub>Гц</sub>.</p>

<p><small>* предложение действует до конца месяца</small></p>

Ваша задача: Создайте свою карточку товара (телефон, игра, одежда, еда — что угодно) используя ВСЕ теги: <strong>, <em>, <s>, <mark>, <small>, <sub> или <sup>.

Your task: Create your own product card (phone, game, clothing, food — anything) using ALL tags: <strong>, <em>, <s>, <mark>, <small>, <sub> or <sup>.

  • Создана карточка товара с уникальным содержимым
  • Использованы минимум 5 разных тегов форматирования
  • Есть старая цена (зачёркнутая) и новая (жирная)
  • Product card created with unique content
  • At least 5 different formatting tags used
  • Old price (strikethrough) and new price (bold) are present

Задание 3.5: Страница-статья Task 3.5: Article Page
Среднее Medium 20 минут 20 min
Создать полноценную HTML-страницу с правильной структурой
Create a complete HTML page with proper structure

Условие:

Instructions:

Создайте страницу-статью на свою тему. Идеи:

Create an article page on your own topic. Ideas:

  • «10 фактов о [ваша тема]»
  • «Руководство по [ваше хобби]»
  • «Обзор [игра/фильм/альбом]»
  • «Биография [известная личность]»
  • «Мой город — путеводитель»
  • "10 Facts About [your topic]"
  • "Guide to [your hobby]"
  • "Review of [game/movie/album]"
  • "Biography of [famous person]"
  • "My City — Travel Guide"

Требования:

Requirements:

ЭлементМинимум
<!DOCTYPE html> + полная структураОбязательно
<title> с осмысленным названиемОбязательно
<h1> — название статьи1
<h2> — разделы3+
<h3> — подразделы2+
<p> — параграфы5+
<br> — переносы строк2+
<hr> — разделительные линии2+
<strong>, <em>По 3+
<mark>, <s> или <small>По 1+
<!-- комментарии -->3+ (для разделов)
ElementMinimum
<!DOCTYPE html> + full structureRequired
<title> with a meaningful nameRequired
<h1> — article title1
<h2> — sections3+
<h3> — subsections2+
<p> — paragraphs5+

<mark>, <s> or <small>1+ each
<!-- comments -->3+ (for sections)

Структура (пример):

Structure (example):

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>10 фактов о футболе</title>
</head>
<body>

    <!-- Заголовок статьи -->
    <h1>10 удивительных фактов о футболе</h1>
    <p>Футбол — <strong>самый популярный спорт</strong> в мире...</p>

    <hr>

    <!-- Раздел 1 -->
    <h2>История</h2>
    <p>...</p>

    <h3>Древний футбол</h3>
    <p>...</p>

    <h3>Современные правила</h3>
    <p>...</p>

    <hr>

    <!-- Раздел 2 -->
    <h2>Рекорды</h2>
    <p>...</p>

    ...

    <!-- Подвал -->
    <hr>
    <p><small>Автор: [Имя] | 2026</small></p>

</body>
</html>
  • Правильная структура HTML-документа (DOCTYPE, html, head, body)
  • Осмысленный <title>
  • Правильная иерархия заголовков (h1 → h2 → h3, без пропусков)
  • Все обязательные элементы из таблицы
  • Правильная вложенность (теги не пересекаются)
  • Аккуратные отступы (форматирование Prettier)
  • Тема — уникальная, текст — свой
  • Correct HTML document structure (DOCTYPE, html, head, body)
  • Meaningful <title>
  • Correct heading hierarchy (h1 → h2 → h3, no gaps)
  • All required elements from the table
  • Proper nesting (tags do not overlap)
  • Clean indentation (Prettier formatting)
  • Topic is unique, text is original
Задание 3.6: Инспекция в DevTools (бонусное) Task 3.6: DevTools Inspection (bonus)
Лёгкое Easy 5 минут 5 min

Check your page using DevTools

Условие:

Instructions:

  1. Откройте свою статью через Live Server
  2. Откройте DevTools (F12)
  3. Проверьте структуру в Elements:
    • Есть ли <!DOCTYPE html>?
    • Правильная ли вложенность?
    • Все ли теги закрыты?
  4. Наведите на разные элементы — посмотрите, как они подсвечиваются
  5. Измените текст заголовка через DevTools
  1. Open your article via Live Server
  2. Open DevTools (F12)
  3. Check the structure in Elements:
    • Is <!DOCTYPE html> present?
    • Is the nesting correct?
    • Are all tags closed?
  4. Hover over different elements — see how they get highlighted
  5. Change the heading text using DevTools
  • Страница проверена в DevTools
  • Ошибки вложенности исправлены (если были)
  • Page checked in DevTools
  • Nesting errors fixed (if any)
