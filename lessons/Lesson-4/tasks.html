Занятие 4: Ссылки, изображения, пути

🎯 УРОК 4.1: ССЫЛКИ

Задание 4.1: Все виды ссылок
Лёгкое 10 минут
Отработать создание разных типов ссылок

Условие:

Создайте файл links.html со всеми видами ссылок:

  1. Ссылка на внешний сайт (Google, YouTube и т.д.) — в новой вкладке
  2. Ссылка на email с адресом student@example.com
  3. Ссылка на телефон
  4. Ссылка с атрибутом title (подсказка при наведении)
  5. Ссылка-якорь: наверху страницы ссылка «К контактам», внизу — раздел с id="contacts"
  6. Ссылка «Наверх» в конце страницы (якорь #top)
Для ссылки «наверх» добавьте id="top" к тегу <body> или первому элементу страницы.
  • Все 6 типов ссылок созданы и работают
  • Внешние ссылки открываются в новой вкладке
  • Якорные ссылки прокручивают к нужному месту
Задание 4.2: Относительные пути — тренировка
Среднее 5 минут
Научиться определять правильные пути к файлам

Условие:

Дана структура проекта:

website/ ├── index.html ├── pages/ │ ├── about.html │ └── blog.html ├── images/ │ ├── logo.svg │ └── photos/ │ ├── cat.jpg │ └── dog.jpg └── css/ └── style.css

Заполните пути:

Из index.html:
Ссылка на about.html: href="_______________"
Картинка logo.svg: src="_______________"
Картинка cat.jpg: src="_______________"
CSS-файл: href="_______________"

Из pages/about.html:
Ссылка на index.html: href="_______________"
Ссылка на blog.html: href="_______________"
Картинка logo.svg: src="_______________"
Картинка dog.jpg: src="_______________"

Из index.html:

  • about.html → pages/about.html
  • logo.svg → images/logo.svg
  • cat.jpg → images/photos/cat.jpg
  • style.css → css/style.css

Из pages/about.html:

  • index.html → ../index.html
  • blog.html → blog.html
  • logo.svg → ../images/logo.svg
  • dog.jpg → ../images/photos/dog.jpg
  • Все 8 путей определены правильно

🎯 УРОК 4.2: ИЗОБРАЖЕНИЯ

Задание 4.3: Галерея изображений
Среднее 15 минут
Научиться работать с изображениями и подписями

Условие:

  1. Создайте папку my-gallery с подпапкой images
  2. Скачайте 5 бесплатных изображений с сайта unsplash.com или pexels.com и сохраните в images/
  3. Создайте index.html с галереей:

Требования к каждому изображению:

  • Тег <img> с src, alt и width
  • Осмысленный alt (не «фото1», а описание!)
  • Обёрнуто в <figure> + <figcaption>
  • Минимум 1 изображение — ссылка (клик → полная версия или внешний сайт)
<h1>Моя фотогалерея</h1>

<figure>
    <a href="images/mountain-full.jpg" target="_blank">
        <img src="images/mountain.jpg"
             alt="Заснеженная горная вершина на рассвете"
             width="400">
    </a>
    <figcaption>Горы Кавказа, январь 2025</figcaption>
</figure>
  • 5 изображений в папке images/
  • У каждого — осмысленный alt
  • Все обёрнуты в <figure> + <figcaption>
  • Минимум 1 изображение-ссылка
  • Все картинки загружаются (пути правильные)

🎯 УРОК 4.3: ПРАКТИЧЕСКИЙ ПРОЕКТ

Задание 4.4: Многостраничный сайт
Продвинутое 20 минут
Создать сайт из 3 страниц с навигацией и изображениями

Условие:

Создайте сайт на тему (выберите одну):

  • Сайт о вашем городе / стране
  • Сайт о любимом виде спорта
  • Сайт о любимой музыкальной группе
  • Сайт о домашнем питомце
  • Своя тема

Структура проекта:

my-website/ ├── index.html ← Главная ├── about.html ← О [теме] ├── gallery.html ← Галерея └── images/ ├── logo.png ← Логотип (можно нарисовать) ├── hero.jpg ← Главное фото ├── photo1.jpg ├── photo2.jpg └── photo3.jpg

Требования:

ЧтоОписание
3 страницыindex.html, about.html, gallery.html
НавигацияОдинаковое меню на всех 3 страницах (ссылки друг на друга)
Логотип-ссылкаКлик по логотипу → на главную
ИзображенияМинимум 5 с правильными alt
Якорная ссылкаМинимум 1 (навигация к разделу)
Внешние ссылкиМинимум 2 (target="_blank")
Email / телефонМинимум 1 ссылка на email или телефон
figure + figcaptionМинимум 2 картинки с подписями

Чек-лист для каждой страницы:

  • ☐ Правильная структура (DOCTYPE, html, head, body)
  • ☐ Осмысленный <title>
  • ☐ Навигация с рабочими ссылками
  • ☐ Заголовки h1 → h2 (правильная иерархия)
  • ☐ Текстовое содержимое (параграфы)
  • ☐ Изображения с alt
Где взять картинки бесплатно:
  • unsplash.com — качественные фото
  • pexels.com — бесплатные фото и видео
  • pixabay.com — фото, иллюстрации, вектор
Скачивайте в маленьком размере (Small или Medium — 640-1280px).
  • 3 страницы созданы с правильной HTML-структурой
  • Навигация работает на всех 3 страницах
  • Логотип ведёт на главную
  • 5+ изображений с осмысленными alt
  • Есть якорная ссылка, внешние ссылки, email/телефон
  • Есть figure + figcaption
  • Все пути правильные — ничего не «сломано»

📚 ДОМАШНЕЕ ЗАДАНИЕ

ДЗ 4: Расширь сайт + исследование
Среднее 30 минут
Закрепить ссылки, изображения и пути к файлам

Часть 1: Расширь свой сайт

  • Добавьте 4-ю страницу (contacts.html) с формой контактов (пока просто текст и ссылки)
  • Обновите навигацию на всех 4 страницах
  • Добавьте на галерею ещё 3 изображения (итого 8+)
  • Сделайте 3 картинки кликабельными (изображения-ссылки)

Часть 2: Исследование

Откройте любой сайт через DevTools и найдите:

Сайт: ________________________________

1. Сколько изображений (<img>) на странице? ________
2. Есть ли у всех alt? Да / Нет
3. Какой формат используется чаще (jpg, png, svg, webp)? ________
4. Есть ли <figure> + <figcaption>? Да / Нет
5. Есть ли ссылки с target="_blank"? Сколько? ________
6. Есть ли якорные ссылки (#)? Где? ________________________________
7. Есть ли ссылки mailto: или tel:? ________________________________
В DevTools нажмите Ctrl + F в панели Elements. Введите <img чтобы найти все картинки, или target="_blank" чтобы найти все внешние ссылки.
  • Сайт расширен до 4 страниц с рабочей навигацией
  • 8+ изображений, 3+ кликабельных
  • Исследование заполнено
