Дата: _______________

📚 ССЫЛКИ <a>

Ссылка — тег <a href="адрес">текст</a>. Атрибут href (Hypertext REFerence) — обязателен. 
<a href="https://google.com">Google</a>
<a href="about.html">О нас</a>
<a href="https://youtube.com" target="_blank">YouTube (новая вкладка)</a>

Виды ссылок

ТипКод
На другой сайтhref="https://google.com"
На свою страницуhref="about.html"
Emailhref="mailto:info@mail.com"
Телефонhref="tel:+79001234567"
Скачиваниеhref="file.pdf" download
Якорь (на этой странице)href="#section-id"

target

  • _self — текущая вкладка (по умолчанию) → для своего сайта
  • _blank — новая вкладка → для чужих сайтов

Якорные ссылки

<!-- 1. Добавь id на элемент -->
<h2 id="contacts">Контакты</h2>

<!-- 2. Создай ссылку с # -->
<a href="#contacts">К контактам</a>

📚 ПУТИ К ФАЙЛАМ

ТипПримерКогда
Абсолютныйhttps://example.com/img.jpgЧужие сайты
Относительныйimages/photo.jpgСвой проект
my-site/ ├── index.html ← мы здесь ├── about.html ← href="about.html" ├── images/ │ └── photo.jpg ← src="images/photo.jpg" └── pages/ └── contacts.html ← href="pages/contacts.html"
  • file.html — файл в той же папке
  • folder/file.html — файл в подпапке
  • ../file.html — файл на уровень выше
  • ../../file.html — файл на 2 уровня выше
Запоминалка:
Абсолютный путь = полный адрес дома (работает из любой точки мира).
Относительный путь = «соседний дом справа» (работает только если знаешь, где ты).
../ = «выйти из подъезда» (подняться на уровень выше).

📚 ИЗОБРАЖЕНИЯ <img>

Изображение — одиночный тег <img src="путь" alt="описание"> 
<img src="images/photo.jpg" alt="Описание фото" width="400">
АтрибутНазначениеОбязателен?
srcПуть к файлуДа
altОписание (если не загрузилась)Да
widthШирина (px)Рекомендуется
heightВысота (px)Рекомендуется

Форматы

ФорматДля чего
JPEG (.jpg)Фотографии (нет прозрачности)
PNG (.png)Логотипы, иконки (есть прозрачность)
SVG (.svg)Иконки, графики (вектор, не теряет качество)
GIF (.gif)Анимации
WebP (.webp)Универсальный (лучшее сжатие)

Подпись к изображению

<figure>
    <img src="sunset.jpg" alt="Закат" width="600">
    <figcaption>Закат на море, 2025</figcaption>
</figure>

Изображение-ссылка

<a href="https://youtube.com">
    <img src="youtube-logo.png" alt="YouTube" width="200">
</a>

📝 ИТОГИ ЗАНЯТИЯ 4

  • <a href="..."> — ссылка. target="_blank" — новая вкладка
  • Виды: сайт, страница, email, телефон, скачивание, якорь
  • Якорь: id="name" + href="#name"
  • Абсолютный путь = полный URL (для чужих сайтов)
  • Относительный путь = от текущего файла (для своих файлов)
  • ../ = на уровень выше
  • <img src="..." alt="..."> — картинка. alt обязателен!
  • JPEG — фото, PNG — прозрачность, SVG — вектор, WebP — современный
  • <figure> + <figcaption> — картинка с подписью
  • <a><img></a> — кликабельная картинка
Что нужноТег / атрибутЗапоминалка
Ссылка<a href="...">Anchor (якорь) + Hypertext Reference
Новая вкладкаtarget="_blank"Для чужих сайтов — чтоб не ушли
