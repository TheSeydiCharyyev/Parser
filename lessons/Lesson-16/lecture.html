1. What we will build

Сегодня создаём галерею карточек — сетку из красивых карточек с изображениями. Это один из самых частых паттернов в вебе: каталог товаров, фильмов, игр, рецептов, статей.

Today we're building a card gallery — a grid of beautiful cards with images. This is one of the most common web patterns: product catalogs, movies, games, recipes, articles.

Цель: Применить все знания по Flexbox (занятия 13-14) для создания реальной галереи с wrap, gap, flex-grow, hover-эффектами и красивым дизайном.
Goal: Apply all Flexbox knowledge (lessons 13-14) to build a real gallery with wrap, gap, flex-grow, hover effects, and beautiful design.

Flexbox-раскладка:

Flexbox layout:

  • display: flex + flex-wrap: wrap — карточки переносятся на новую строку
  • gap: 24px — отступы между карточками
  • flex: 1 1 280px — минимальная ширина 280px, растягиваются равномерно
  • Каждая карточка — тоже flex-column (кнопка внизу)
  • display: flex + flex-wrap: wrap — cards wrap to new line
  • gap: 24px — spacing between cards
  • flex: 1 1 280px — minimum width 280px, grow evenly
  • Each card is also flex-column (button at bottom)

СвойствоЗачем
flex: 1 1 280pxМин. ширина 280px, растягивается равномерно
max-width: 400pxНе шире 400px (чтобы не растягивалась слишком)
overflow: hiddenОбрезает углы изображения по border-radius
display: flex; flex-direction: columnКарточка — вертикальный flex (бейджи внизу)
PropertyPurpose
flex: 1 1 280pxMin width 280px, grows evenly
max-width: 400pxNo wider than 400px
overflow: hiddenClips image corners to border-radius
display: flex; flex-direction: columnCard is vertical flex (badges at bottom)
flex: 1 1 280px — ключевое свойство! Это значит: «Начальная ширина 280px. Можешь расти (1) и сжиматься (1)». Карточки автоматически заполняют ряд и переносятся.
flex: 1 1 280px — the key property! It means: "Initial width 280px. Can grow (1) and shrink (1)." Cards automatically fill the row and wrap.

6. CSS: изображение в карточке

6. CSS: card image

.card img {
    width: 100%;
    height: 200px;
    object-fit: cover;
    display: block;
}

object-fit: cover — изображение заполняет всю область, сохраняя пропорции (как background-size: cover). Лишнее обрезается.

object-fit: cover — the image fills the entire area while keeping proportions (like background-size: cover). Excess is cropped.

margin-top: auto on .badges — badges are pushed to the bottom of the card. All cards look neat, even if titles are different lengths!

9. CSS: hover-эффекты

9. CSS: hover effects

/* Подъём карточки + тень */
.card:hover {
    transform: translateY(-8px);
    box-shadow: 0 20px 40px rgba(0, 0, 0, 0.4);
}

/* Увеличение изображения */
.card img {
    transition: transform 0.3s ease;
}

.card:hover img {
    transform: scale(1.05);
}

Два hover-эффекта:

Two hover effects:

  1. Карточка поднимается (translateY(-8px)) и появляется глубокая тень
  2. Изображение увеличивается (scale(1.05)) — лёгкий «zoom»
  1. Card lifts up (translateY(-8px)) with a deep shadow
  2. Image zooms (scale(1.05)) — subtle zoom effect

Попробуй добавить filter: brightness(1.1) при hover на изображение — оно станет немного ярче!

Try adding filter: brightness(1.1) on image hover — it'll become slightly brighter!

11. Полный код

11. Full code

Что мы применили из Flexbox:
  • display: flex + flex-wrap: wrap — сетка с переносом
  • flex: 1 1 280px — гибкая ширина карточек
  • gap: 24px — отступы
  • flex-direction: column — вертикальная раскладка внутри карточки
  • margin-top: auto — бейджи прижаты к низу
  • flex: 1 на card-body — заполнить доступное место
Новое:
  • object-fit: cover — обрезка изображения
  • overflow: hidden — обрезка по border-radius
  • transform: scale(1.05) — zoom-эффект на hover
Flexbox applied:
  • display: flex + flex-wrap: wrap — wrapping grid
  • flex: 1 1 280px — flexible card width
  • gap: 24px — spacing
  • flex-direction: column — vertical layout inside card
  • margin-top: auto — badges pushed to bottom
  • flex: 1 on card-body — fill available space
New:
  • object-fit: cover — image cropping
  • overflow: hidden — clip to border-radius
  • transform: scale(1.05) — zoom effect on hover
