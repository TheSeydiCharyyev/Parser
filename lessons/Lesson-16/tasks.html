🎯 УРОК 16.1: ПЛАНИРОВАНИЕ

🎯 Lesson 16.1: PLANNING

Задание 15.1: Спланируй галерею Task 15.1: Plan your gallery
Лёгкое Easy 10 минут 10 min
Выбрать тему и спланировать содержание галереи
Choose a theme and plan gallery content

Условие:

Instructions:

  1. Выбери тему: фильмы, игры, музыка, рецепты, места, портфолио
  2. Запиши 6 карточек: для каждой — название, описание, 1-2 бейджа (жанр/категория), рейтинг
  3. Цветовая схема: светлая или тёмная? Основной цвет? Цвет бейджей?
  4. Нарисуй wireframe одной карточки: где изображение, название, бейджи
  1. Choose a theme: movies, games, music, recipes, places, portfolio
  2. Write 6 cards: for each — title, description, 1-2 badges (genre/category), rating
  3. Color scheme: light or dark? Main color? Badge color?
  4. Draw a wireframe of one card: where the image, title, badges go
  • Тема выбрана
  • 6 карточек записаны
  • Цвета определены
  • Theme is chosen
  • 6 cards are written
  • Colors are defined

🎯 УРОК 16.2: ПОВТОРЕНИЕ ПРИМЕРА

🎯 Lesson 16.2: REPRODUCING THE EXAMPLE

Задание 15.2: Повтори галерею фильмов Task 15.2: Reproduce the movie gallery
Среднее Medium 20 минут 20 min
Воспроизвести галерею фильмов из лекции
Reproduce the movie gallery from the lecture

Условие:

Instructions:

  1. Создайте папку movie-gallery с файлами index.html и style.css
  2. Самостоятельно напишите HTML: 6 карточек фильмов (изображение, название, год, рейтинг, бейджи жанров)
  3. Напишите CSS: тёмная тема, flex-сетка с wrap, hover-эффекты
  4. Проверьте: карточки переносятся при уменьшении окна? Hover работает?
  1. Create a folder movie-gallery with files index.html and style.css
  2. Write HTML yourself: 6 movie cards (image, title, year, rating, genre badges)
  3. Write CSS: dark theme, flex grid with wrap, hover effects
  4. Check: do cards wrap when resizing the window? Does hover work?
  • 6 карточек
  • flex-wrap: wrap работает
  • flex: 1 1 280px на карточках
  • Изображения с object-fit: cover
  • Бейджи прижаты к низу (margin-top: auto)
  • Hover: подъём + тень + zoom изображения
  • CSS в отдельном файле
  • 6 cards
  • flex-wrap: wrap works
  • flex: 1 1 280px on cards
  • Images with object-fit: cover
  • Badges pushed to bottom (margin-top: auto)
  • Hover: lift + shadow + image zoom
  • CSS in separate file

🎯 Lesson 16.3: YOUR OWN GALLERY

Задание 15.3: Создай свою уникальную галерею Task 15.3: Create your own unique gallery
Среднее Medium 25 минут 25 min
Создать уникальную галерею на свою тему
Create a unique gallery on your own topic

Обязательные элементы:

Required elements:

  1. Шапка: Заголовок галереи + описание
  2. Минимум 6 карточек с:
    • Изображением (picsum.photos или свои)
    • Названием
    • Дополнительной информацией (год, автор, цена...)
    • Рейтингом или оценкой
    • Бейджами категории
  3. Flexbox-сетка: flex-wrap: wrap + gap
  4. Hover-эффекты: подъём карточки + zoom изображения
  5. Своя тема оформления (не копия примера!)
  1. Header: Gallery title + description
  2. At least 6 cards with:
    • Image (picsum.photos or your own)
    • Title
    • Extra info (year, author, price...)
    • Rating or score
    • Category badges
  3. Flexbox grid: flex-wrap: wrap + gap
  4. Hover effects: card lift + image zoom
  5. Your own design theme (not a copy of the example!)
Бесплатные изображения:
  • picsum.photos — случайные фото (https://picsum.photos/400/250?random=1)
  • unsplash.com — качественные фото
  • pexels.com — бесплатный фотосток
Free images:

Задание 15.4: Фильтры и кнопка «Показать ещё» Task 15.4: Filters and "Show more" button
Сложное Hard 15 минут 15 min
Добавить панель фильтров и дополнительные элементы
Add a filter panel and additional elements

Условие:

Instructions:

  1. Панель фильтров между шапкой и карточками: кнопки «Все», «Экшн», «Драма», «Комедия» (стилизованные, без функционала — это только CSS)
  2. Кнопка «Показать ещё» — внизу, по центру, под всеми карточками
  3. Стилизуйте кнопки фильтров: одна активная (яркий фон), остальные — серые
  1. Filter panel between header and cards: buttons "All", "Action", "Drama", "Comedy" (styled, no functionality — CSS only)
  2. "Show more" button — at the bottom, centered, below all cards
  3. Style filter buttons: one active (bright background), others — gray
Кнопки фильтров — это flex-контейнер с gap: 
.filters {
    display: flex;
    gap: 10px;
    margin-bottom: 24px;
    justify-content: center;
}
.filter-btn {
    padding: 8px 20px;
    border-radius: 20px;
    border: none;
    cursor: pointer;
    background: #334155;
    color: #94a3b8;
}
.filter-btn.active {
    background: #3b82f6;
    color: #fff;
}
