📚 HOVER-ЭФФЕКТЫ

📚 HOVER EFFECTS

/* Подъём карточки */
.card:hover {
    transform: translateY(-8px);
    box-shadow: 0 20px 40px rgba(0,0,0,0.4);
}

/* Zoom изображения */
.card:hover img {
    transform: scale(1.05);
}
Не забудь transition! Без него эффекты будут резкими. Добавь transition: transform 0.3s ease, box-shadow 0.3s ease на карточку и изображение.
Don't forget transition! Without it, effects will be abrupt. Add transition: transform 0.3s ease, box-shadow 0.3s ease to card and image.
