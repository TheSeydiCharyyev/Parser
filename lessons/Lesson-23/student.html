📚 TRANSITION (ПЛАВНЫЙ ПЕРЕХОД)

📚 TRANSITION (SMOOTH CHANGE)

/* Синтаксис: */
transition: property duration timing-function delay;

/* Примеры: */
transition: background 0.3s ease;
transition: all 0.3s ease;
transition: transform 0.3s ease, box-shadow 0.3s ease;
ПараметрЗначениеТипичное

durationДлительность0.3s
timing-functionКриваяease
delayЗадержка0s
ParameterValueTypical
propertyWhich propertyall, transform, background
durationDuration0.3s
timing-functionCurveease
delayDelay0s
transition пишется на базовом состоянии, НЕ на :hover!
transition is written on the base state, NOT on :hover!
Рекомендуемая длительность: 0.2s–0.4s для hover. Меньше — незаметно, больше — раздражает. Для загрузки модалок/попапов — 0.3s–0.5s.
Recommended duration: 0.2s–0.4s for hover. Less — invisible, more — annoying. For modal/popup load — 0.3s–0.5s.

📚 TRANSFORM (ТРАНСФОРМАЦИИ)

📚 TRANSFORM (TRANSFORMATIONS)

transform изменяет элемент визуально, не влияя на соседние элементы (в отличие от margin/width). Поэтому идеален для hover-эффектов — макет не «скачет».
transform visually changes an element without affecting neighbors (unlike margin/width). Perfect for hover effects — the layout doesn't jump.

📚 КОМБИНИРОВАНИЕ И ПОРЯДОК

📚 COMBINING AND ORDER

/* ПРАВИЛЬНО — один transform через пробел */
.card:hover {
    transform: translateY(-8px) scale(1.02);
}

/* НЕПРАВИЛЬНО — второй перекроет первый! */
.card:hover {
    transform: translateY(-8px);
    transform: scale(1.02);   /* работает только scale */
}
Порядок важен! translate + rotate ≠ rotate + translate. Каждая следующая трансформация применяется в системе координат, созданной предыдущей. Обычно ставьте translate первым.
Order matters! translate + rotate ≠ rotate + translate. Each subsequent transform applies in the coordinate system created by the previous one. Usually put translate first.

Для сдвига — transform: translate(), не left/top. Для увеличения — transform: scale(), не width.
For movement — transform: translate(), not left/top. For resizing — transform: scale(), not width.

📚 ДОСТУПНОСТЬ (prefers-reduced-motion)

📚 ACCESSIBILITY (prefers-reduced-motion)

/* Уважаем пользователей, отключивших анимации в ОС */
@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
    }
}
Пользователи с вестибулярными расстройствами / эпилепсией отключают анимации в настройках ОС. Этот блок делает их отключение мгновенным. В продакшене — обязательно.
Users with vestibular disorders / epilepsy disable animations in OS settings. This block makes animations near-instant for them. Mandatory in production.

📚 ГОТОВЫЕ ПАТТЕРНЫ

📚 READY-MADE PATTERNS

/* Карточка */
.card { transition: transform 0.3s, box-shadow 0.3s; }
.card:hover {
    transform: translateY(-8px);
    box-shadow: 0 16px 32px rgba(0,0,0,0.12);
}

/* Зум картинки */
.card { overflow: hidden; }
.card img { transition: transform 0.4s; }
.card:hover img { transform: scale(1.1); }

/* Кнопка */
.btn { transition: all 0.2s; }
.btn:hover { transform: translateY(-2px); }
.btn:active { transform: scale(0.95); }

/* Анимированное подчёркивание ссылки */
.link { position: relative; }
.link::after {
    content: '';
    position: absolute;
    bottom: 0; left: 0;
    width: 0; height: 2px;
    background: currentColor;
    transition: width 0.3s ease;
}
.link:hover::after { width: 100%; }

/* Социальные иконки */
.social-icon {
    color: #94a3b8;
    transition: color 0.2s, transform 0.2s;
}
.social-icon:hover {
    color: #3b82f6;
    transform: scale(1.2);
}
