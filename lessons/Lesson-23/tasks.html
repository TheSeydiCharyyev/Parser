Задание 22.1: Коллекция кнопок Task 22.1: Button collection
Лёгкое Easy 15 минут 15 min
Создать 6 кнопок с разными hover-эффектами
Create 6 buttons with different hover effects

Условие:

Instructions:

Создайте файл buttons.html. Сделайте 6 кнопок, каждая с уникальным hover-эффектом:

Create a file buttons.html. Make 6 buttons, each with a unique hover effect:

  1. Смена цвета: background + color плавно меняются
  2. Подъём: translateY(-3px) + box-shadow
  3. Увеличение: scale(1.1)
  4. Нажатие: :hover = подъём, :active = scale(0.95)
  5. Обводка: прозрачный фон → заполненный + color меняется
  6. Подчёркивание: ::after ширина 0 → 100%
  1. Color change: background + color smoothly change
  2. Lift: translateY(-3px) + box-shadow
  3. Scale: scale(1.1)
  4. Press: :hover = lift, :active = scale(0.95)
  5. Outline: transparent bg → filled + color changes
  6. Underline: ::after width 0 → 100%

Все кнопки: padding: 12px 28px, border-radius: 8px, font-weight: 600, cursor: pointer.

All buttons: padding: 12px 28px, border-radius: 8px, font-weight: 600, cursor: pointer.

Шаблон кнопки с анимированным подчёркиванием: 
.btn-underline { position: relative; }
.btn-underline::after {
    content: '';
    position: absolute;
    bottom: 4px; left: 12px;
    width: 0; height: 2px;
    background: currentColor;
    transition: width 0.3s ease;
}
.btn-underline:hover::after {
    width: calc(100% - 24px);
}
Помните: transition всегда на базовом состоянии (.btn), а не на :hover.
Template for button with animated underline:

Create a card grid with transition + transform

Instructions:

Создайте файл cards-hover.html с Grid-сеткой из 6 карточек:

Create a file cards-hover.html with a Grid of 6 cards:

  1. Сетка: repeat(3, 1fr), gap: 24px
  2. Карточка: белый фон, border-radius: 16px, overflow: hidden
  3. Изображение: width: 100%; height: 200px; object-fit: cover
  4. Hover карточки: translateY(-8px) + box-shadow: 0 16px 32px rgba(0,0,0,0.12)
  5. Hover изображения: scale(1.1) (зум, не выходит за рамки)
  6. Кнопка внутри: hover = смена цвета + translateY(-2px)
  1. Grid: repeat(3, 1fr), gap: 24px
  2. Card: white bg, border-radius: 16px, overflow: hidden
  3. Image: width: 100%; height: 200px; object-fit: cover
  4. Card hover: translateY(-8px) + box-shadow: 0 16px 32px rgba(0,0,0,0.12)
  5. Image hover: scale(1.1) (zoom, doesn't overflow)
  6. Button inside: hover = color change + translateY(-2px)
Готовый рецепт карточки: 
.card {
    overflow: hidden;
    border-radius: 16px;
    transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.card:hover {
    transform: translateY(-8px);
    box-shadow: 0 16px 32px rgba(0,0,0,0.12);
}
.card img {
    transition: transform 0.4s ease;
}
.card:hover img {
    transform: scale(1.1);
}
Обратите внимание: transition у карточки анимирует 2 свойства (transform и box-shadow) через запятую.

Instructions:

Создайте файл transform-lab.html. Сделайте 6 одинаковых квадратов (100x100px) и при hover примените разные transform:

Create a file transform-lab.html. Make 6 identical squares (100x100px) and on hover apply different transforms:

  1. translateX(50px)
  2. translateY(-30px)
  3. scale(1.5)
  4. rotate(45deg)
  5. skewX(15deg)

  1. translateX(50px)
  2. translateY(-30px)
  3. scale(1.5)
  4. rotate(45deg)
  5. skewX(15deg)

Все квадраты одинаковые — разница только в transform при hover: 
.square {
    width: 100px; height: 100px;
    background: #3b82f6;
    transition: transform 0.4s ease;
}
.square-1:hover { transform: translateX(50px); }
.square-2:hover { transform: translateY(-30px); }
/* ... и так далее для 3, 4, 5, 6 */
Расположите их в Flexbox ряду с gap: 40px, чтобы было место для движения.
