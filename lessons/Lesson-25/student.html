📚 ЧТО ТАКОЕ BOOTSTRAP

📚 WHAT IS BOOTSTRAP

Bootstrap — самый популярный CSS-фреймворк (используется на 20%+ всех сайтов). Набор готовых классов для сетки, кнопок, форм, утилит. Ускоряет вёрстку в 3-5 раз.
Bootstrap — the most popular CSS framework (used on 20%+ of all sites). A set of ready classes for grid, buttons, forms, utilities. Speeds up markup 3-5×.
Когда использовать: админки, MVP, клиентские landing без дизайнера, внутренние инструменты. Когда НЕ использовать: продуктовые сайты известных брендов, уникальные портфолио.
When to use: admin panels, MVPs, client landings without a designer, internal tools. When NOT to use: product sites for established brands, unique portfolios.

📚 ПОДКЛЮЧЕНИЕ BOOTSTRAP

📚 BOOTSTRAP SETUP

<!-- В <head>: CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Свой CSS — ПОСЛЕ Bootstrap! -->
<link href="style.css" rel="stylesheet">

<!-- Перед </body>: JS -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
Свой CSS — всегда ПОСЛЕ Bootstrap! Иначе Bootstrap перекроет ваши стили (каскад: кто позже, тот побеждает).
Your CSS — ALWAYS AFTER Bootstrap! Otherwise Bootstrap overrides your styles (cascade: later wins).
