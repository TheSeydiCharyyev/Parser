Задание 24.1: Лаборатория сетки Task 24.1: Grid laboratory
Лёгкое Easy 15 минут 15 min
Освоить 12-колоночную сетку Bootstrap
Master the 12-column Bootstrap grid

Условие:

Instructions:

Создайте файл grid-lab.html с подключённым Bootstrap CDN. Покажите 5 вариантов сетки на одной странице:

Create a file grid-lab.html with Bootstrap CDN connected. Show 5 grid variations on one page:

  1. col-6 + col-6 — 2 равные колонки
  2. col-4 + col-4 + col-4 — 3 равные колонки
  3. col-3 + col-9 — sidebar + content
  4. col-3 + col-3 + col-3 + col-3 — 4 равные колонки
  5. col-12 col-md-6 col-lg-4 — адаптивные (3 карточки)
  1. col-6 + col-6 — 2 equal columns
  2. col-4 + col-4 + col-4 — 3 equal columns
  3. col-3 + col-9 — sidebar + content
  4. col-3 + col-3 + col-3 + col-3 — 4 equal columns
  5. col-12 col-md-6 col-lg-4 — responsive (3 cards)

Каждую колонку раскрасьте (bg-primary, bg-success и т.д.) и добавьте p-3 + text-white.

Color each column (bg-primary, bg-success etc.) and add p-3 + text-white.

Скелет HTML для одного варианта: 
<div class="container my-4">
    <h3>col-6 + col-6</h3>
    <div class="row g-2">
        <div class="col-6">
            <div class="bg-primary text-white p-3 rounded">col-6</div>
        </div>
        <div class="col-6">
            <div class="bg-success text-white p-3 rounded">col-6</div>
        </div>
    </div>
</div>
Повторите для всех 5 вариантов.
HTML skeleton for one variation:

Repeat for all 5 variations.
  • Bootstrap 5 подключён через CDN (версия 5.3.x)
  • Свой CSS (если есть) — ПОСЛЕ Bootstrap
  • 5 вариантов сетки на одной странице
  • Подписи над каждым вариантом (<h3>)
  • Последний вариант — адаптивный: 1 колонка → 2 → 3 (проверить в DevTools)
  • Строго используются container → row → col
  • Сумма col в каждом row ≤ 12
  • Bootstrap 5 connected via CDN (version 5.3.x)
  • Your CSS (if any) — AFTER Bootstrap
  • 5 grid variations on one page

danger    → красный (#dc3545) — удаление, ошибка

light     → светлый (#f8f9fa) — светлый фон
dark      → тёмный (#212529)  — тёмный фон
All 8 Bootstrap colors (memorize — used everywhere):

success   → green (#198754) — success, confirm

warning   → yellow (#ffc107) — warning
info      → cyan (#0dcaf0)  — info
light     → light (#f8f9fa) — light bg

  • Минимум одна кнопка w-100
  • All 8 button colors (btn-primary — btn-dark)
  • Outline variants (min 4: btn-outline-primary — btn-outline-danger)

  • All 8 bg colors (bg-primary — bg-dark)

Instructions:

Create a file bootstrap-page.html. Build a page without a single line of custom CSS — only Bootstrap classes:

  1. Header: bg-dark text-white p-3, внутри row: лого (col-6) + текст справа (col-6 text-end)

  4. Footer: bg-dark text-white text-center p-4 mt-5
  1. Header: bg-dark text-white p-3, inside row: logo (col-6) + text right (col-6 text-end)
  2. Hero: bg-primary text-white text-center py-5, heading (display-4), description (lead), button (btn btn-light btn-lg)
  3. Cards: row g-4 py-5, 3 cards (col-12 col-md-6 col-lg-4), each: bg-white p-4 rounded shadow-sm, heading, text (text-muted), button (btn btn-primary)
  4. Footer: bg-dark text-white text-center p-4 mt-5
Не пишите ни одной строки CSS! Всё через Bootstrap-классы. Если вы хотите отступ — p-3. Тень — shadow. Цвет — bg-primary.
