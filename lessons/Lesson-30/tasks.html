🎯 Lesson 30.1: PROJECT SETUP

Задание 29.1: Анализ макета + tokens.css Task 29.1: Layout analysis + tokens.css
Лёгкое Easy 20 минут 20 min
Провести анализ макета и настроить структуру проекта
Analyze a layout and set up the project structure

Условие:

Instructions:

Откройте макет из Figma Community (из задания 28.1). Создайте папку layout-project с такой структурой:

Open the Figma Community layout (from task 28.1). Create layout-project folder with this structure:

layout-project/
├── index.html
├── analysis.md
├── css/
│   ├── tokens.css
│   ├── base.css
│   ├── components.css
│   └── style.css
├── images/
└── icons/
  1. analysis.md: список секций, компонентов, 5+ цветов (HEX), шрифт, размеры h1-h3
  2. tokens.css: все цвета, шрифты, отступы, скругления в :root как CSS-переменные
  3. index.html: подключить все 4 CSS-файла + Google Fonts в правильном порядке
  4. base.css: сброс (* { margin: 0; padding: 0; box-sizing: border-box }), базовые стили body, контейнер
  5. Остальные файлы CSS оставить пустыми (пока)
  1. analysis.md: list of sections, components, 5+ colors (HEX), font, h1-h3 sizes
  2. tokens.css: all colors, fonts, spacing, radii in :root as CSS variables
  3. index.html: connect all 4 CSS files + Google Fonts in correct order
  4. base.css: reset (* { margin: 0; padding: 0; box-sizing: border-box }), body base styles, container
  5. Leave other CSS files empty (for now)
Пример analysis.md: 
# Analysis: [название макета]

## Секции
1. Header (logo + nav + button)
2. Hero (text + image)
3. Features (3 блока)
4. Cards (6 карточек)
5. CTA (заголовок + кнопка)
6. Footer (3 колонки)

## Компоненты (повторяющиеся)
- .card (используется в секции Cards, 6 раз)
- .btn (используется 5 раз)
- .feature (используется 3 раза)

## Цвета
- Primary: #3B82F6
- Primary Dark: #1D4ED8
- Text: #1E293B
- Muted: #64748B
- Bg: #F8FAFC
- Border: #E2E8F0

## Шрифты
- Font: Inter
- Weights: 400, 600, 700
- h1: 48px / 56px line-height / 700
- h2: 32px / 40px / 600
- h3: 20px / 28px / 600
- body: 16px / 24px / 400

## Отступы
- Section padding: 96px (desktop), 48px (mobile)
- Gap между карточками: 24px
- Container max-width: 1200px

🎯 Lesson 30.2: HTML SKELETON

Задание 29.2: Разметка всей страницы без стилей Task 29.2: Mark up the entire page without styles
Среднее Medium 30 минут 30 min
Написать HTML всей страницы, не трогая CSS для секций/компонентов
Write the full page HTML without touching CSS for sections/components

Условие:

Instructions:

  1. По макету (из 29.1) напишите весь HTML главной страницы
  2. Используйте семантические теги: <header>, <nav>, <main>, <section>, <article>, <footer>
  3. Проставьте классы для будущих стилей: .header, .hero, .feature, .card, .btn, .btn-primary
  4. Никаких inline-стилей! В components.css и style.css ничего не пишите (пока)
  5. Откройте результат в браузере — должен быть «поток тегов сверху вниз», без вёрстки. Это нормально.
  6. Добавьте заглушки-тексты («Lorem ipsum») и заглушки-картинки (picsum.photos)
  1. From the layout (from 29.1) write the entire HTML of the main page
  2. Use semantic tags: <header>, <nav>, <main>, <section>, <article>, <footer>
  3. Add classes for future styling: .header, .hero, .feature, .card, .btn, .btn-primary
  4. No inline styles! Leave components.css and style.css empty (for now)
  5. Open the result in a browser — it should be "a stream of tags top-down", unstyled. That's normal.
  6. Add placeholder texts ("Lorem ipsum") and placeholder images (picsum.photos)
Шаблон структуры страницы: 
<body>
    <header class="header">
        <div class="container">
            <a href="#" class="logo">Brand</a>
            <nav class="nav">
                <a href="#">Link 1</a>
                <a href="#">Link 2</a>
            </nav>
            <a href="#" class="btn btn-primary">CTA</a>
        </div>
    </header>

    <main>
        <section class="hero">...</section>
        <section class="features">...</section>
        <section class="cards">...</section>
        <section class="cta">...</section>
    </main>

    <footer class="footer">...</footer>
</body>
Не забудьте <main> вокруг основного контента (для SEO).

Задание 29.3: Свёрстай hero + 1 секцию pixel-perfect Task 29.3: Code hero + 1 section pixel-perfect
Среднее Medium 40 минут 40 min
Применить 9-шаговый процесс к двум секциям вашего макета
Apply the 9-step process to two sections of your layout

Условие:

Instructions:

Возьмите 2 секции из макета (рекомендуем: hero + features). Свёрстайте их pixel-perfect, следуя шагам 5-9:

Take 2 sections from the layout (recommended: hero + features). Code them pixel-perfect, following steps 5-9:

  1. Шаг 5 — Layout: в style.css напишите display: flex/grid, размеры, отступы секций
  2. Шаг 6 — Детали: цвета (через var(--color-*)), шрифты, тени, скругления
  3. Шаг 7 — Интерактив: hover на кнопках и карточках, transition-all duration-300
  4. Шаг 8 — Адаптив: media query @media (max-width: 768px) с правилом «ряд → стопка»
  5. Шаг 9 — Pixel-perfect: скриншот Figma + скриншот браузера, наложение с opacity 50%
  1. Step 5 — Layout: in style.css write display: flex/grid, sizes, section spacing
  2. Step 6 — Details: colors (via var(--color-*)), fonts, shadows, radii
  3. Step 7 — Interactivity: hover on buttons and cards, transition-all duration-300
  4. Step 8 — Responsive: media query @media (max-width: 768px) with "row → stack" rule
  5. Step 9 — Pixel-perfect: Figma screenshot + browser screenshot, overlay at 50% opacity
Порядок свойств в каждом селекторе: 
.selector {
    /* 1. Layout */
    display: ...;
    /* 2. Размеры */
    width: ...; height: ...;
    /* 3. Отступы */
    padding: ...; margin: ...;
    /* 4. Визуал */
    background: ...; border: ...;
    /* 5. Типография */
    font-size: ...; color: ...;
    /* 6. Интерактив */
    transition: ...;
}
Повторяющиеся компоненты (карточки, кнопки) стилизуйте в components.css, секции — в style.css.
Property order in each selector: 
.selector {
    /* 1. Layout */
    display: ...;
    /* 2. Size */
    width: ...; height: ...;
    /* 3. Spacing */
    padding: ...; margin: ...;
    /* 4. Visual */
    background: ...; border: ...;
    /* 5. Typography */
    font-size: ...; color: ...;
    /* 6. Interactivity */
    transition: ...;
}
Repeating components (cards, buttons) go in components.css, sections in style.css.

  • Все цвета через var(--color-*) (ни одного HEX в коде секций)
  • Все размеры шрифта через var(--fs-*)
  • Компоненты (.card, .btn) в components.css
  • Секции в style.css
  • Hover + transition на кнопках и карточках
  • :focus на input (если есть)
  • Адаптив работает: стопка на мобильном (375px)
  • Pixel-perfect: скриншот наложения с опоцити приложен
  • Допуск ±2px (глаз не видит разницы)
  • 2 sections fully coded (hero + one more)
  • All colors via var(--color-*) (no HEX in section code)
  • All font sizes via var(--fs-*)
  • Components (.card, .btn) in components.css

Задание 29.4: Свёрстай весь макет Task 29.4: Code the entire layout
Сложное Hard 90 минут 90 min
Свёрстать весь макет из Figma Community pixel-perfect
Code the entire Figma Community layout pixel-perfect

Условие:

Instructions:

  7. Покажите это реальному знакомому — получите обратную связь
  1. Code all layout sections (6-7 sections), not just 2

  3. All images and icons exported from Figma (not picsum)
