📚 ГЛАВНЫЙ ПРИНЦИП

📚 THE MAIN PRINCIPLE

Вёрстка — это процесс, а не импровизация. Есть 9 шагов, которым следуют все профессионалы. Порядок важнее скорости печати. С процессом — 2 часа, без — 6 часов на ту же работу.
Coding is a process, not improvisation. There are 9 steps all pros follow. Order matters more than typing speed. With process — 2 hours, without — 6 hours for the same work.
HTML = смысл. CSS = внешний вид. Пишите их раздельно: сначала вся разметка, потом все стили. Не смешивать.
HTML = meaning. CSS = appearance. Write them separately: all markup first, all styles after. Don't mix.

📚 АТОМАРНАЯ РАЗБИВКА

📚 ATOMIC BREAKDOWN

Страница (Layout)
  └─ Секции (Hero, Features, Footer…)
       └─ Компоненты (Card, Button, Form…)
            └─ Элементы (h1, p, img, input…)
                 └─ Атомы (цвет, шрифт, отступ)
Писать снизу вверх: сначала атомы (tokens), потом элементы, потом компоненты, потом секции. Повторяющееся — один раз.
Code bottom-up: atoms first (tokens), then elements, then components, then sections. Repeating things — once.

📚 ШАБЛОН TOKENS.CSS

📚 TOKENS.CSS TEMPLATE

:root {
    /* Colors */
    --color-primary: #3B82F6;
    --color-text: #1E293B;
    --color-text-muted: #64748B;
    --color-bg: #F8FAFC;
    --color-border: #E2E8F0;

    /* Typography */
    --font-primary: 'Inter', sans-serif;
    --fs-h1: 48px;
    --fs-h2: 32px;
    --fs-body: 16px;

    /* Spacing */
    --space-sm: 16px;
    --space-md: 24px;
    --space-lg: 48px;
    --space-xl: 96px;

    /* Other */
    --radius: 12px;
    --shadow-md: 0 8px 16px rgba(0,0,0,0.08);
}
Все цвета, шрифты, отступы — через переменные. Поменять дизайн = править одну строку.
All colors, fonts, spacing — via variables. Redesign = edit one line.

📚 ПОРЯДОК СВОЙСТВ В СЕЛЕКТОРЕ

📚 PROPERTY ORDER IN A SELECTOR

.card {
    /* 1. Layout */
    display: flex;
    flex-direction: column;

    /* 2. Размеры */
    width: 100%;
    max-width: 400px;

    /* 3. Отступы */
    padding: 24px;
    margin: 0 auto;

    /* 4. Визуал */
    background: white;
    border-radius: 12px;
    box-shadow: var(--shadow-md);

    /* 5. Типография */
    font-size: 16px;
    color: var(--color-text);

    /* 6. Интерактив */
    transition: transform 0.3s;
}

Правило «ряд → стопка»: всё горизонтальное на десктопе становится вертикальным на мобильном. Flex → flex-direction: column. Grid → grid-template-columns: 1fr.
"Row → stack" rule: everything horizontal on desktop becomes vertical on mobile. Flex → flex-direction: column. Grid → grid-template-columns: 1fr.

📚 PIXEL-PERFECT — 3 СПОСОБА

  2. Overlay-скриншоты: наложить через Paint/Photoshop/tldraw с opacity 50%
  3. PerfectPixel extension: Chrome-расширение, Figma-скриншот поверх страницы
  1. Side-by-side: Figma and browser next to each other (half screen each) — quick visual
  2. Screenshot overlay: layer in Paint/Photoshop/tldraw at 50% opacity
  3. PerfectPixel extension: Chrome extension, Figma screenshot over the page
