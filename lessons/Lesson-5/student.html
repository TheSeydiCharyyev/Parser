Занятие 5: Списки и семантика

Дата: _______________

📋 СПИСКИ

Маркированный список <ul> (порядок не важен)

<ul>
    <li>Молоко</li>
    <li>Хлеб</li>
    <li>Сыр</li>
</ul>

Нумерованный список <ol> (порядок важен)

<ol>
    <li>Шаг первый</li>
    <li>Шаг второй</li>
    <li>Шаг третий</li>
</ol>

Атрибуты <ol>: type="A" (буквы), start="5" (начать с 5), reversed (обратный)

Вложенные списки

<ul>
    <li>Фрукты
        <ul>
            <li>Яблоки</li>
            <li>Бананы</li>
        </ul>
    </li>
    <li>Овощи</li>
</ul>

Описательный список <dl> (термин — определение)

<dl>
    <dt>HTML</dt>
    <dd>Язык разметки для веб-страниц</dd>

    <dt>CSS</dt>
    <dd>Таблицы стилей для оформления</dd>
</dl>

Используется для: словарь, FAQ, характеристики товара

Навигация (реальный пример)

<nav>
    <ul>
        <li><a href="index.html">Главная</a></li>
        <li><a href="about.html">О нас</a></li>
        <li><a href="contacts.html">Контакты</a></li>
    </ul>
</nav>
  • Внутри <ul> и <ol> — только <li>!
  • Внутри <li> — что угодно (текст, ссылки, картинки, другие списки)
  • Вложенный список размещается внутри <li>, не после него!
Запоминалка — какой список выбрать:
Порядок не важен? → <ul> (список покупок)
Порядок важен? → <ol> (рецепт, рейтинг)
Термин + определение? → <dl> (словарь, FAQ, характеристики)

🏗️ СЕМАНТИЧЕСКИЕ ТЕГИ HTML5

Семантика = теги со смыслом. Вместо безликих <div> используем теги, которые описывают роль содержимого.
┌──────────────────────────────────────┐ │ <header> │ ├──────────────────────────────────────┤ │ <nav> │ ├─────────────────────┬────────────────┤ │ │ │ │ <main> │ <aside> │ │ ┌──────────────┐ │ Боковое │ │ │ <article> │ │ │ │ │ ┌────────┐ │ │ │ │ │ │<section│ │ │ │ │ │ └────────┘ │ │ │ │ └──────────────┘ │ │ ├─────────────────────┴────────────────┤ │ <footer> │ └──────────────────────────────────────┘
ТегРоль
<header>Шапка (логотип, название)
<nav>Навигация
<main>Основной контент (один на странице!)
<article>Самостоятельный контент (статья, пост)
<section>Тематический раздел
<aside>Боковой контент (sidebar)
<footer>Подвал (копирайт, контакты)

Дополнительные теги

ТегЧто делает
<details> + <summary>Раскрывающийся блок (без JS!)
<time datetime="...">Дата/время (для поисковиков)
<figure> + <figcaption>Картинка с подписью

HTML-сущности

КодСимвол
&copy;©
&amp;&
&lt; / &gt;< / >
&nbsp;Неразрывный пробел
  • <div> используй только когда ни один семантический тег не подходит
  • <main> — только один на странице!
  • <article> = самостоятелен (можно вырезать → понятен отдельно)
  • <section> = часть чего-то большего
Запоминалка: Семантические теги = подписанные коробки при переезде.
<div> = неподписанная коробка (что внутри — неизвестно).
<header> = коробка с надписью «Кухня» (сразу понятно).

📝 ИТОГИ ЗАНЯТИЯ 5

  • <ul> — маркированный (порядок не важен)
  • <ol> — нумерованный (порядок важен)
  • <dl><dt><dd> — описательный (термин — определение)
  • Списки можно вкладывать друг в друга
  • Навигация = nav > ul > li > a
  • Семантика: header, nav, main, article, section, aside, footer
  • <main> — один на странице
  • <details> — раскрывающийся блок без JS
  • &copy; — символ ©

  2. Добавьте 2 статьи (<article>) с разделами (<section>)
  3. Используйте все 3 типа списков (ul, ol, dl)
  4. Добавьте <details> с FAQ (3+ вопроса)
  5. Навигация через <nav> > <ul> > <li> > <a>
