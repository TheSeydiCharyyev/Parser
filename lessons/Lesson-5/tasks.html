Задание 5.1: Три типа списков Task 5.1: Three Types of Lists
Лёгкое Easy 10 минут 10 min
Отработать создание всех типов списков
Practice creating all types of lists

Условие:

Instructions:

Создайте файл lists.html с тремя секциями:

Create a file lists.html with three sections:

  1. Маркированный список <ul> — «Мои навыки» (5+ пунктов)
  2. Нумерованный список <ol> — «Мой ТОП-5 [фильмов/игр/песен]» с reversed (обратный отсчёт: 5, 4, 3, 2, 1)
  3. Описательный список <dl> — «Словарь веб-разработчика» (5 терминов с определениями: HTML, CSS, тег, атрибут, браузер)
  1. Unordered list <ul> — "My Skills" (5+ items)
  2. Ordered list <ol> — "My TOP 5 [movies/games/songs]" with reversed (countdown: 5, 4, 3, 2, 1)
  3. Description list <dl> — "Web Developer Dictionary" (5 terms with definitions: HTML, CSS, tag, attribute, browser)
  • Все 3 типа списков использованы
  • ul — минимум 5 пунктов
  • ol — с атрибутом reversed
  • dl — 5 пар dt + dd
  • All 3 list types are used
  • ul — at least 5 items
  • ol — with the reversed attribute
  • dl — 5 pairs of dt + dd
Задание 5.2: Вложенные списки — меню ресторана Task 5.2: Nested Lists — Restaurant Menu
Среднее Medium 10 минут 10 min
Научиться создавать многоуровневые списки
Learn to create multi-level lists

Условие:

Instructions:

Создайте меню ресторана с вложенными списками:

Create a restaurant menu with nested lists:

  • Категории (маркированный список): Завтраки, Супы, Главные блюда, Десерты, Напитки
  • Внутри каждой категории — вложенный список с 2-3 блюдами
  • У одного блюда добавьте ещё один уровень вложенности (например, варианты: маленькая/большая порция)
  • Categories (unordered list): Breakfasts, Soups, Main Courses, Desserts, Drinks
  • Inside each category — a nested list with 2-3 dishes
  • For one dish add one more level of nesting (e.g., options: small/large portion)

    </li>
</ul>

                </ul>
            </li>

    </li>
</ul>

  • По 2-3 блюда в каждой

  • Цены указаны
