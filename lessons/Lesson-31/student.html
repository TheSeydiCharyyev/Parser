📚 GIT: КОМАНДЫ НА ПЕРВЫЙ ДЕНЬ

📚 GIT: DAY ONE COMMANDS

# В папке проекта:
git init
git add .
git commit -m "Initial setup: structure + plan"

# Создайте public-репозиторий на github.com, потом:
git remote add origin https://github.com/USERNAME/PROJECT.git
git branch -M main
git push -u origin main
Репозиторий должен быть public — иначе не задеплоите бесплатно на GitHub Pages.
Repo must be public — otherwise can't deploy free on GitHub Pages.
