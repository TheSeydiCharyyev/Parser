📚 ПРЕФИКСЫ СОСТОЯНИЙ — ГЛАВНОЕ

📚 STATE PREFIXES — THE KEY

Любой Tailwind-класс можно «обвязать» префиксом состояния: md:, hover:, focus:, active:, dark:, group-hover:. Префиксы можно комбинировать: md:hover:text-blue-500.
Any Tailwind class can be wrapped with a state prefix: md:, hover:, focus:, active:, dark:, group-hover:. Prefixes can be combined: md:hover:text-blue-500.

Mobile-first логика: базовый класс = мобильный. Префикс = «С этого размера и выше». Если на md и lg выглядит одинаково — пишите только md:, lg автоматически наследует.
Mobile-first logic: base class = mobile. Prefix = "from this size up". If it looks same on md and lg — write only md:, lg inherits automatically.
Breakpoints Tailwind ≠ Bootstrap! sm=640 (у Bs 576), lg=1024 (у Bs 992), xl=1280 (у Bs 1200). Только md=768 совпадает.

📚 СОСТОЯНИЯ (HOVER, FOCUS, ACTIVE)

📚 STATES (HOVER, FOCUS, ACTIVE)

<!-- Hover -->
hover:bg-blue-700      hover:-translate-y-2     hover:shadow-xl

<!-- Focus -->
focus:ring-2           focus:border-blue-500    focus:outline-none

<!-- Active -->
active:scale-95

<!-- Transition (обязательно для плавности!) -->
transition-all duration-300
Правило трёх transitions:
  • Кнопки: transition-colors duration-200
  • Карточки: transition-all duration-300
  • Модалки, большие анимации: transition-all duration-500 ease-out
Rule of three transitions:
  • Buttons: transition-colors duration-200
  • Cards: transition-all duration-300
  • Modals, big animations: transition-all duration-500 ease-out
Везде где есть hover: — должен быть focus:. Это доступность: люди с клавиатуры (Tab) видят где они находятся.
Wherever there's hover: — add focus:. That's accessibility: keyboard users (Tab) see where they are.

📚 ГРАДИЕНТЫ И DARK MODE

📚 GRADIENTS AND DARK MODE

<!-- Градиент (направление + цвета) -->
bg-gradient-to-r from-blue-600 to-purple-600
bg-gradient-to-br from-orange-500 to-pink-500
bg-gradient-to-r from-green-400 via-blue-500 to-purple-600

<!-- Направления: r, l, t, b, tr, tl, br, bl -->

<!-- Dark mode -->
bg-white dark:bg-gray-900
text-gray-800 dark:text-gray-100
Рецепт красивого градиента: берите соседние цвета (blue+purple, orange+pink, green+blue), оттенки 500-700. Очень яркие контрасты (red+green) выглядят аляповато.
Recipe for a pretty gradient: use adjacent colors (blue+purple, orange+pink, green+blue), shades 500-700. Too much contrast (red+green) looks gaudy.
Палитра dark mode: фон — bg-gray-900 (не чистый bg-black), карточки — bg-gray-800, текст — text-gray-100 (не text-white).
Dark mode palette: bg — bg-gray-900 (not pure bg-black), cards — bg-gray-800, text — text-gray-100 (not text-white).
Активация dark mode: добавить class="dark" на <html> — все dark: классы включатся.
Activate dark mode: add class="dark" to <html> — all dark: classes activate.

📚 GROUP-HOVER

📚 GROUP-HOVER

<!-- Родитель: class="group" -->
<div class="group hover:shadow-xl">
    <img class="group-hover:scale-110 transition-transform">
    <h3 class="group-hover:text-blue-600 transition-colors">
</div>
group на родителе → group-hover: на детях = при hover на карточку меняются дочерние элементы.
group on parent → group-hover: on children = on card hover, child elements change.
Если group-hover: не работает — первым делом проверьте, стоит ли group на родителе. Самая частая ошибка.
If group-hover: doesn't work — first check group is on the parent. Most common mistake.
