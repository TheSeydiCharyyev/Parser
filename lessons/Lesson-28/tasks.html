Задание 27.1: Адаптивная сетка и hover Task 27.1: Responsive grid and hover
Лёгкое Easy 15 минут 15 min
Освоить responsive-префиксы и hover в Tailwind
Master responsive prefixes and hover in Tailwind

Условие:

Instructions:

Создайте файл responsive-tw.html:

Create a file responsive-tw.html:

  1. Адаптивная сетка: 6 цветных блоков. grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-4
  2. Адаптивный текст: text-xl md:text-3xl lg:text-5xl font-bold text-center py-8
  3. Скрыть/показать: блок «Desktop Only» (hidden md:block) + блок «Mobile Only» (block md:hidden)
  4. Hover-кнопки: 3 кнопки с hover:bg-{color}-700 + hover:-translate-y-1 + transition-all duration-200
  5. Hover-карточка: hover:shadow-xl hover:-translate-y-2 transition-all duration-300
  1. Responsive grid: 6 colored blocks. grid grid-cols-1 sm:grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-4
  2. Responsive text: text-xl md:text-3xl lg:text-5xl font-bold text-center py-8
  3. Show/hide: "Desktop Only" block (hidden md:block) + "Mobile Only" block (block md:hidden)
  4. Hover buttons: 3 buttons with hover:bg-{color}-700 + hover:-translate-y-1 + transition-all duration-200
  5. Hover card: hover:shadow-xl hover:-translate-y-2 transition-all duration-300
Breakpoints Tailwind: sm=640, md=768, lg=1024, xl=1280. При тесте в DevTools переключайте iPhone SE (375), iPad (768), Desktop (1280+) — проверьте, что сетка реально меняется на каждом breakpoint. 
<!-- Полная адаптивная сетка -->
<div class="grid
    grid-cols-1
    sm:grid-cols-2
    md:grid-cols-3
    lg:grid-cols-4
    gap-4">
    <!-- 6 цветных блоков -->
</div>
Tailwind breakpoints: sm=640, md=768, lg=1024, xl=1280. Test in DevTools: toggle iPhone SE (375), iPad (768), Desktop (1280+) — verify grid actually changes at each breakpoint. 
<!-- Full responsive grid -->
<div class="grid
    grid-cols-1
    sm:grid-cols-2
    md:grid-cols-3
    lg:grid-cols-4
    gap-4">
    <!-- 6 colored blocks -->
</div>
  • Responsive-сетка: 1 → 2 → 3 → 4 колонки
  • Адаптивный размер текста (text-xl md:text-3xl lg:text-5xl)
  • hidden md:block и block md:hidden работают в DevTools
  • 3 hover-кнопки с transition (разные цвета)
  • Hover-карточка с hover:shadow-xl hover:-translate-y-2 transition-all duration-300
  • Протестировано: iPhone (375px), iPad (768px), Desktop (1280+)
  • На каждом breakpoint сетка и скрытие реально меняются
  • Responsive grid: 1 → 2 → 3 → 4 columns
  • Responsive text size (text-xl md:text-3xl lg:text-5xl)
  • hidden md:block and block md:hidden work in DevTools
  • 3 hover buttons with transition (different colors)
  • Hover card with hover:shadow-xl hover:-translate-y-2 transition-all duration-300
  • Tested: iPhone (375px), iPad (768px), Desktop (1280+)
  • At each breakpoint grid and hiding actually change

Instructions:

Создайте файл tailwind-landing.html. Соберите лендинг из 6 секций без единой строки CSS:

Create a file tailwind-landing.html. Build a landing with 6 sections without a single line of CSS:

  2. Hero: min-h-screen flex items-center justify-center bg-gradient-to-r from-blue-600 to-purple-600 text-white text-center px-4. Заголовок text-3xl md:text-5xl lg:text-6xl font-bold, описание text-lg md:text-xl mt-4 opacity-90, кнопка с hover
  3. Features: max-w-6xl mx-auto px-4 py-16. Grid grid-cols-1 md:grid-cols-3 gap-8. Каждая фича: иконка (большой эмодзи text-4xl), заголовок, текст
  4. Cards: grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-6. Карточки с group: изображение (group-hover:scale-105 transition-transform), текст, кнопка, hover:shadow-xl hover:-translate-y-2 transition-all
  5. CTA: bg-gray-900 text-white text-center py-16 px-4. Заголовок + кнопка с hover:bg-blue-700
  6. Footer: bg-gray-800 text-gray-400. Grid grid-cols-1 md:grid-cols-3 gap-8 p-8 md:p-12 + копирайт
  1. Header: flex items-center justify-between p-4 bg-white shadow-sm, logo + 3 links (hidden md:flex gap-6) + button

Добавить тёмную тему к лендингу через dark: классы
Add dark theme to the landing via dark: classes

Условие:

Instructions:

Возьмите лендинг из задания 27.3 и добавьте dark mode:

Take the landing from task 27.3 and add dark mode:

  1. Добавьте на <html class="dark">
  2. К каждому элементу добавьте dark: варианты:
    • Фон: bg-white dark:bg-gray-900
    • Текст: text-gray-800 dark:text-gray-100
    • Карточки: bg-white dark:bg-gray-800
    • Бордеры: border-gray-200 dark:border-gray-700
  3. Проверьте: убирая/добавляя class="dark" на html — тема переключается
  1. Add <html class="dark">
  2. Add dark: variants to each element:
    • Background: bg-white dark:bg-gray-900
    • Text: text-gray-800 dark:text-gray-100
    • Cards: bg-white dark:bg-gray-800
    • Borders: border-gray-200 dark:border-gray-700
  3. Verify: removing/adding class="dark" on html toggles the theme
Палитра dark mode: 
Фон страницы:    bg-white dark:bg-gray-900
Карточки:        bg-white dark:bg-gray-800   (чуть светлее фона)
Основной текст:  text-gray-800 dark:text-gray-100
Приглушённый:    text-gray-500 dark:text-gray-400
Бордеры:         border-gray-200 dark:border-gray-700
Кнопка:          bg-blue-600 dark:bg-blue-500
Не используйте bg-black и text-white — слишком контрастно, «выжигает» глаза.
