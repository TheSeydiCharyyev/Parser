Занятие 6: Введение в CSS

Что такое CSS. Способы подключения. Селекторы, цвета, шрифты и фон

Сегодня мы изучим CSS — язык, который превращает скучный HTML в красивый сайт. Без CSS интернет выглядел бы как текстовый документ из 90-х: чёрный текст Times New Roman на белом фоне.

Представьте, что HTML — это скелет, а CSS — одежда, макияж и причёска. Один и тот же HTML можно «одеть» в совершенно разные стили!

После этого занятия вы сможете:

  • Подключать стили тремя способами (и знать, какой правильный)
  • Выбирать элементы через селекторы: тег, класс, id
  • Задавать цвета в любом формате: HEX, RGB, имена
  • Создавать красивые градиенты
  • Подключать шрифты из Google Fonts
  • Настраивать текст: выравнивание, межстрочный интервал, оформление

1. Что такое CSS и зачем он нужен

CSS (Cascading Style Sheets — каскадные таблицы стилей) — это язык, который отвечает за внешний вид веб-страницы: цвета, шрифты, отступы, размеры, расположение элементов.

Если HTML — это скелет страницы (структура), то CSS — это одежда, макияж и причёска (оформление). Один и тот же HTML можно одеть в совершенно разные стили.

Без CSS веб-страница выглядит как обычный текстовый документ — чёрный текст на белом фоне, стандартный шрифт Times New Roman. С CSS — это красивый, современный сайт.

CSS был создан Хокон Виум Ли (Hakon Wium Lie) и Бертом Босом (Bert Bos) в 1996 году. До этого стили писали прямо в HTML-тегах через атрибуты color, bgcolor, face — это было ужасно неудобно!

Зачем нужен CSS:

  • Разделение — HTML отвечает за содержание, CSS — за оформление
  • Повторное использование — один CSS-файл стилизует все страницы сайта
  • Гибкость — можно полностью изменить дизайн, не трогая HTML
  • Адаптивность — разные стили для телефона, планшета и компьютера

Откройте любой современный сайт (например, google.com или apple.com). Нажмите F12 и посмотрите вкладку Styles — вы увидите сотни CSS-правил, которые создают этот дизайн. Без CSS эти сайты выглядели бы одинаково скучно.

2. Синтаксис CSS

CSS состоит из правил. Каждое правило описывает, какой элемент стилизовать и как:

селектор { свойство: значение; свойство: значение; } Пример: ────────────────────────── h1 { color: blue; font-size: 32px; } ────────────────────────── h1 → селектор (ЧТО стилизуем) color → свойство (ЧТО меняем) blue → значение (НА ЧТО меняем) ; → точка с запятой (конец строки) { } → фигурные скобки (блок стилей)

Частые ошибки в синтаксисе CSS:

  • Забыли ; в конце строки — следующее свойство не сработает
  • Забыли закрыть } — все стили после сломаются
  • Написали = вместо : (CSS использует двоеточие, не знак равно!)
❌ Неправильно
h1 {
    color = blue;
    font-size: 32px
}
✅ Правильно
h1 {
    color: blue;
    font-size: 32px;
}

3. Способ 1: Inline-стили (встроенные)

Стили пишутся прямо в HTML-теге через атрибут style:

<h1 style="color: red; font-size: 36px;">Привет, мир!</h1>

<p style="color: green; background-color: yellow;">Зелёный текст на жёлтом фоне</p>

<a href="#" style="color: white; background-color: blue; padding: 10px;">Кнопка</a>

Привет, мир!

Зелёный текст на жёлтом фоне

Кнопка

Плюсы: быстро проверить один элемент.

Минусы: стиль применяется только к одному элементу. Если у вас 50 заголовков — придётся писать style="" 50 раз. Нет повторного использования.

Inline-стили — плохая практика. Используйте их только для быстрого тестирования, но не в реальных проектах.

4. Способ 2: Internal (внутренний)

Стили пишутся в теге <style> внутри <head>:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <style>
        h1 {
            color: darkblue;
            font-size: 36px;
        }
        p {
            color: #333;
            line-height: 1.8;
        }
        a {
            color: orange;
        }
    </style>
</head>
<body>
    <h1>Заголовок</h1>
    <p>Параграф текста...</p>
    <a href="#">Ссылка</a>
</body>
</html>

Плюсы: стили применяются ко всем нужным элементам на странице. Не нужно повторять style="" у каждого тега.

Минусы: стили работают только на этой одной странице. Если сайт имеет 10 страниц — копировать стили в каждую.

Когда использовать: Для одностраничных проектов, быстрого прототипирования или когда стили уникальны для конкретной страницы. Мы будем использовать этот способ на занятиях для простоты.

5. Способ 3: External (внешний)

Стили хранятся в отдельном файле с расширением .css и подключаются через тег <link>:

Файл style.css:

h1 {
    color: darkblue;
    font-size: 36px;
}
p {
    color: #333;
    line-height: 1.8;
}
a {
    color: orange;
}

Файл index.html:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Моя страница</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Заголовок</h1>
    <p>Параграф текста...</p>
    <a href="#">Ссылка</a>
</body>
</html>
Структура проекта: ────────────────────────── my-site/ ├── index.html ← подключает style.css ├── about.html ← подключает style.css ├── contacts.html ← подключает style.css └── style.css ← один файл для всех страниц!

Плюсы:

  • Один файл стилизует весь сайт (все страницы)
  • Чистый HTML — в коде только содержание
  • Браузер кэширует CSS — сайт загружается быстрее
  • Легко менять дизайн — правишь один файл
Это главный способ! В реальных проектах всегда используют внешние CSS-файлы. Все профессиональные сайты работают именно так.
Тег <link> — одиночный (без закрывающего тега). Обязательные атрибуты:
rel="stylesheet" — тип файла (таблица стилей)
href="style.css" — путь к CSS-файлу

В больших проектах обычно создают несколько CSS-файлов: reset.css (сброс стилей), layout.css (структура), components.css (компоненты). Это помогает организовать код и упрощает работу в команде.

6. Сравнение трёх способов

СпособГде пишемОбласть действияКогда использовать
Inline В атрибуте style="" Один элемент Быстрый тест, никогда в продакшене
Internal В теге <style> в <head> Одна страница Одностраничные проекты, прототипы
External В отдельном .css файле Весь сайт Всегда! Основной способ
  • Inline = наклейка на одной чашке (надпись «Моя»)
  • Internal = правила в одной комнате (только тут не курить)
  • External = правила для всего здания (пожарная безопасность)
  • Inline — быстро, но не масштабируется. Только для тестов.
  • Internal — удобно для одной страницы. Мы используем на занятиях.
  • External — единственный правильный способ в реальных проектах.

7. Селекторы: тег

Селектор тега стилизует все элементы этого типа на странице:

/* Все заголовки h1 — синие */
h1 {
    color: blue;
}

/* Все параграфы — серые, с отступом */
p {
    color: #555;
    margin-bottom: 16px;
}

/* Все ссылки — оранжевые, без подчёркивания */
a {
    color: orange;
    text-decoration: none;
}

Селектор тега записывается без точки и решётки — просто имя тега:

СелекторВыбирает
h1Все <h1> на странице
pВсе <p> на странице
aВсе <a> на странице
ulВсе <ul> на странице
bodyТело страницы (фон, общий шрифт)

Когда использовать: для базовых стилей — общий шрифт (body), сброс отступов, стилизация всех ссылок или всех заголовков.

Селектор тега — самый простой, но и самый «грубый». Он стилизует ВСЕ элементы данного типа. Если вы напишете p { color: red; }, то ВСЕ параграфы на странице станут красными. Иногда это то, что нужно, но часто хочется стилизовать только конкретные элементы — для этого существуют классы.

8. Селекторы: класс

Класс — самый популярный и мощный селектор! Позволяет стилизовать конкретные элементы, помечая их атрибутом class:

HTML:

<p class="intro">Это вводный параграф — выделенный</p>
<p>Это обычный параграф — без класса</p>
<p class="intro">Это тоже вводный — тот же стиль</p>

CSS:

/* Точка = класс */
.intro {
    color: darkblue;
    font-size: 1.2rem;
    font-weight: bold;
    border-left: 4px solid blue;
    padding-left: 12px;
}

Это вводный параграф — выделенный

Это обычный параграф — без класса

Это тоже вводный — тот же стиль

Правила классов:

  • В CSS класс пишется с точкой: .intro
  • В HTML — без точки: class="intro"
  • Один класс можно использовать на многих элементах
  • У элемента может быть несколько классов: class="card featured"
  • Имя класса — на английском, без пробелов, начинается с буквы

Несколько классов у одного элемента

<!-- HTML -->
<div class="card featured">Важная карточка</div>
<div class="card">Обычная карточка</div>

<!-- CSS -->
.card {
    padding: 16px;
    border: 1px solid #ccc;
    border-radius: 8px;
    margin: 10px 0;
}

.featured {
    background-color: #fff3cd;
    border-color: #ffc107;
    font-weight: bold;
}

Помни: В CSS — .имя-класса (с точкой). В HTML — class="имя-класса" (без точки). Это самая частая ошибка новичков!

❌ Неправильно
<p class=".intro">
intro { color: red; }
✅ Правильно
<p class="intro">
.intro { color: red; }

Классы используются в 95% случаев на реальных сайтах. Откройте DevTools на любом сайте — вы увидите десятки классов: .header, .nav-link, .btn-primary, .card. Профессионалы почти никогда не используют селекторы тегов (кроме body).

9. Селекторы: id

ID (идентификатор) — уникальный! Используется для одного элемента на странице:

HTML:

<header id="main-header">
    <h1>Мой сайт</h1>
</header>

CSS:

/* Решётка = id */
#main-header {
    background-color: #1e293b;
    color: white;
    padding: 20px;
    text-align: center;
}
СелекторСимволHTMLCSSКол-во на странице
Тегбез символа<h1>h1 { }Много
Классточка .class="card".card { }Много (повторяемый)
IDрешётка #id="header"#header { }Один (уникальный)
На практике: классы используются в 95% случаев. ID — редко, в основном для якорных ссылок и JavaScript. Для стилизации предпочитайте классы.

Многие опытные разработчики вообще не используют id для стилей. Причина: id имеет слишком высокий приоритет, и потом сложно «перебить» его стили. Используйте id только для якорных ссылок (<a href="#section">) и JavaScript.

10. Приоритет селекторов (специфичность)

Что произойдёт, если разные правила конфликтуют? CSS имеет систему приоритетов:

Приоритет (от низшего к высшему): ────────────────────────────────── 1. Селектор тега h1 { } → вес: 0-0-1 2. Селектор класса .title { } → вес: 0-1-0 3. Селектор id #header { } → вес: 1-0-0 4. Inline-стиль style="..." → перебивает всё!
<!-- HTML -->
<h1 class="title" id="main-title">Заголовок</h1>

<!-- CSS -->
h1 { color: blue; }           /* Вес: 0-0-1 */
.title { color: green; }      /* Вес: 0-1-0 — Выше! */
#main-title { color: red; }   /* Вес: 1-0-0 — Ещё выше! */

/* Результат: заголовок будет КРАСНЫМ (id побеждает) */

Представьте армию: тег = рядовой солдат, класс = офицер, id = генерал, inline = главнокомандующий. Приказ генерала важнее приказа рядового.

Ещё одно правило: при одинаковом весе побеждает правило, которое написано позже (ниже) в CSS:

p { color: blue; }
p { color: red; }   /* Это правило позже — текст будет красным */

Вопрос: Какого цвета будет текст?

<p class="text" id="special">Привет</p>

p { color: blue; }
.text { color: green; }
#special { color: orange; }

Ответ: оранжевый, потому что id (#special) имеет наибольший вес (1-0-0).

11. Цвета в CSS

В CSS есть несколько способов указать цвет:

1. Именованные цвета (Color Names)

CSS знает 147 названий цветов на английском:

НазваниеЦветНазваниеЦвет
red Красныйblue Синий
green Зелёныйorange Оранжевый
white Белыйblack Чёрный
gray Серыйpurple Фиолетовый
coral Коралловыйtomato Томатный
gold Золотойteal Бирюзовый

2. HEX (шестнадцатеричный)

Самый популярный формат. Начинается с # и содержит 6 символов (Red, Green, Blue):

color: #ff0000;    /* Красный (ff=255, 00=0, 00=0) */
color: #00ff00;    /* Зелёный */
color: #0000ff;    /* Синий */
color: #333333;    /* Тёмно-серый (сокращённо: #333) */
color: #ffffff;    /* Белый (сокращённо: #fff) */
color: #1e293b;    /* Тёмно-синий (как в этом курсе) */
Если пары символов одинаковые, можно сократить: #ff0000 → #f00, #333333 → #333

3. RGB и RGBA

RGB = Red, Green, Blue — каждый канал от 0 до 255:

color: rgb(255, 0, 0);      /* Красный */
color: rgb(0, 128, 0);      /* Зелёный */
color: rgb(51, 51, 51);     /* Тёмно-серый */

/* RGBA — с прозрачностью (Alpha: 0 = невидимый, 1 = полностью видимый) */
color: rgba(0, 0, 0, 0.5);         /* Чёрный, 50% прозрачный */
background: rgba(255, 0, 0, 0.3);  /* Красный фон, 30% прозрачный */
В DevTools Chrome можно кликнуть на цветной квадратик рядом с цветом — откроется пипетка (color picker), где можно выбрать любой цвет! Также можно зажать Shift и кликать на квадратик, чтобы переключаться между HEX, RGB, HSL.

4. HSL (оттенок, насыщенность, яркость)

color: hsl(0, 100%, 50%);    /* Красный */
color: hsl(120, 100%, 25%);  /* Тёмно-зелёный */
color: hsl(240, 100%, 50%);  /* Синий */
color: hsla(0, 100%, 50%, 0.5); /* Красный, 50% прозрачный */

H — оттенок (0-360: 0=красный, 120=зелёный, 240=синий), S — насыщенность (0-100%), L — яркость (0-100%).

На практике чаще всего используют HEX (короткий и удобный) и RGBA (когда нужна прозрачность). HSL реже, но его преимущество — легко подбирать оттенки: меняете только первое число (H), а насыщенность и яркость оставляете.

  1. Откройте DevTools на любом сайте
  2. Найдите свойство color или background-color
  3. Кликните на цветной квадратик — откроется палитра
  4. Попробуйте HEX, RGB и HSL — переключайтесь

12. Фон и градиенты

background-color — цвет фона

body {
    background-color: #f8fafc;      /* Светло-серый фон */
}

.card {
    background-color: white;
}

.warning {
    background-color: #fef2f2;      /* Светло-красный */
}

Градиенты

Градиент — плавный переход между двумя или более цветами:

/* Линейный градиент (сверху вниз) */
.header {
    background: linear-gradient(to bottom, #3b82f6, #1d4ed8);
}

/* Градиент под углом */
.banner {
    background: linear-gradient(135deg, #f97316, #ec4899);
}

/* Градиент с тремя цветами */
.rainbow {
    background: linear-gradient(to right, red, yellow, green);
}
linear-gradient(to bottom, #3b82f6, #1d4ed8)
linear-gradient(135deg, #f97316, #ec4899)
linear-gradient(to right, red, yellow, green)
НаправлениеЗначение
Сверху внизto bottom (по умолчанию)
Слева направоto right
По диагоналиto bottom right или 135deg
Снизу вверхto top

Градиенты — один из самых простых способов сделать сайт визуально привлекательным. Шапка с градиентом, кнопка с градиентом, баннер с градиентом — всё это выглядит профессионально и современно.

Мысленно ответьте:

  1. Какой формат цвета самый популярный среди разработчиков? (HEX — #3b82f6)
  2. Что значит rgba(0, 0, 0, 0.5)? (Чёрный цвет с 50% прозрачностью)
  3. Как написать градиент слева направо, от красного к синему? (linear-gradient(to right, red, blue))
  4. Какой цвет даёт #000? А #fff? (Чёрный и белый)

13. Шрифты и Google Fonts

font-family — семейство шрифтов

body {
    font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif;
}

h1 {
    font-family: Georgia, 'Times New Roman', serif;
}

code {
    font-family: 'Consolas', 'Courier New', monospace;
}

Указывайте несколько шрифтов через запятую — если первый не найден, браузер попробует следующий. Последним всегда пишите общее семейство:

СемействоОписаниеПример
sans-serifБез засечек (современный)Текст без засечек
serifС засечками (классический)Текст с засечками
monospaceМоноширинный (для кода)Моноширинный текст

font-size — размер шрифта

h1 { font-size: 36px; }
h2 { font-size: 28px; }
p  { font-size: 16px; }

/* Также можно использовать rem (относительные единицы) */
h1 { font-size: 2.2rem; }     /* 2.2 × 16px = 35.2px */
p  { font-size: 1rem; }       /* 1 × 16px = 16px */

font-weight — толщина шрифта

.normal { font-weight: normal; }    /* или 400 */
.bold   { font-weight: bold; }      /* или 700 */
.light  { font-weight: 300; }
.black  { font-weight: 900; }

font-style — наклон

.italic { font-style: italic; }
.normal { font-style: normal; }

Google Fonts — красивые бесплатные шрифты

На сайте fonts.google.com можно выбрать из 1500+ бесплатных шрифтов и подключить к сайту:

Шаг 1: Добавьте ссылку в <head>:

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap">

Шаг 2: Используйте шрифт в CSS:

body {
    font-family: 'Inter', sans-serif;
}

  4. Скопируйте тег <link> и вставьте в <head>
  5. Пропишите font-family: 'Inter', sans-serif; для body

Не подключайте больше 2-3 шрифтов на сайт — это замедляет загрузку. Используйте один шрифт для заголовков и один для текста. Также подключайте только нужные начертания (400, 600, 700), а не все.

text-align — выравнивание текста

.left   { text-align: left; }      /* По левому краю (по умолчанию) */
.center { text-align: center; }    /* По центру */
.right  { text-align: right; }     /* По правому краю */

text-align: left — текст по левому краю (по умолчанию)

text-align: center — текст по центру

text-align: right — текст по правому краю

text-decoration — оформление текста

a {
    text-decoration: none;         /* Убрать подчёркивание у ссылок */
}
.underline {
    text-decoration: underline;    /* Подчёркнутый */
}
.line-through {
    text-decoration: line-through; /* Зачёркнутый */
}

text-transform — изменение регистра

.upper { text-transform: uppercase; }   /* ВСЕ ЗАГЛАВНЫЕ */
.lower { text-transform: lowercase; }   /* все строчные */
.cap   { text-transform: capitalize; }  /* Каждое Слово С Заглавной */

line-height — межстрочный интервал

p {
    line-height: 1.6;   /* 1.6 × размер шрифта — комфортно для чтения */
}

/* Сравнение: */
.tight  { line-height: 1.0; }    /* Плотный */
.normal { line-height: 1.5; }    /* Обычный */
.loose  { line-height: 2.0; }    /* Просторный */
Совет: Для основного текста используйте line-height: 1.5-1.8 — это оптимально для комфортного чтения.

Итоги занятия

  • CSS — язык стилей для оформления веб-страниц
  • 3 способа подключения: inline (в теге), internal (в <style>), external (отдельный .css файл)
  • External — основной способ в реальных проектах
  • Синтаксис: селектор { свойство: значение; }
  • Селектор тега: h1 { } — все элементы этого типа
  • Селектор класса: .card { } — элементы с class="card" (самый используемый!)
  • Селектор id: #header { } — один уникальный элемент
  • Приоритет: тег < класс < id < inline
  • Цвета: имена (red), HEX (#ff0000), RGB (rgb(255,0,0))
  • Градиенты: background: linear-gradient(направление, цвет1, цвет2)
  • Шрифты: font-family, font-size, font-weight, Google Fonts
  • Текст: text-align, text-decoration, text-transform, line-height
