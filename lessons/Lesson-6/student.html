🎨 ЧТО ТАКОЕ CSS

🎨 WHAT IS CSS

CSS (Cascading Style Sheets) — язык стилей, отвечающий за внешний вид веб-страницы: цвета, шрифты, отступы, размеры и расположение элементов.
CSS (Cascading Style Sheets) — a styling language responsible for the appearance of a web page: colors, fonts, spacing, sizes, and layout of elements.

HTML = структура (скелет), CSS = оформление (одежда)

HTML = structure (skeleton), CSS = styling (clothing)

Синтаксис CSS

CSS Syntax

селектор {
    свойство: значение;
}
h1 {
    color: blue;
    font-size: 32px;
}

Inline

<h1 style="color: red; font-size: 36px;">Привет!</h1>

Internal

<head>
    <style>
        h1 { color: red; font-size: 36px; }
    </style>
</head>

External (основной!)

External (primary!)

<!-- В HTML: -->
<link rel="stylesheet" href="style.css">

<!-- В style.css: -->
h1 { color: red; font-size: 36px; }
В реальных проектах всегда используют External (внешний CSS-файл). Inline — плохая практика!
In real projects, always use External (an external CSS file). Inline is bad practice!

Примеры

Examples

/* Селектор тега — ВСЕ параграфы */
p { color: #333; }

/* Селектор класса — только элементы с class="intro" */
.intro { font-weight: bold; color: darkblue; }

/* Селектор id — ОДИН элемент с id="main-header" */
#main-header { background-color: #1e293b; color: white; }

Несколько классов

Multiple Classes

<div class="card featured">...</div>
<!-- У элемента ДВА класса: card и featured -->

Приоритет (специфичность)

Priority (Specificity)

тег → 0-0-1 (низший) класс → 0-1-0 id → 1-0-0 inline → перебивает всё!
tag → 0-0-1 (lowest) class → 0-1-0 id → 1-0-0 inline → overrides everything!
  • В CSS: .класс (с точкой). В HTML: class="класс" (без точки!)
  • В CSS: #id (с решёткой). В HTML: id="id" (без решётки!)
  • Классы используются в 95% случаев. Предпочитайте классы, не id
  • Один элемент может иметь несколько классов: class="card featured"
  • In CSS: .class (with dot). In HTML: class="class" (no dot!)
  • In CSS: #id (with hash). In HTML: id="id" (no hash!)
  • Classes are used 95% of the time. Prefer classes over id
  • One element can have multiple classes: class="card featured"
Запоминалка приоритетов: Тег (1) < Класс (10) < ID (100) < Inline (1000).
Чем точнее селектор — тем выше приоритет. Inline перебивает всё (поэтому его не используют).
Priority mnemonic: Tag (1) < Class (10) < ID (100) < Inline (1000).
The more specific the selector — the higher the priority. Inline overrides everything (that's why we don't use it).
