Задание 6.1: Три способа CSS Task 6.1: Three Ways of CSS
Лёгкое Easy 10 минут 10 min
Понять разницу между inline, internal и external CSS
Understand the difference between inline, internal, and external CSS

Условие:

Instructions:

Создайте файл styles-test.html. На одной странице продемонстрируйте все 3 способа подключения CSS:

Create a file styles-test.html. On one page, demonstrate all 3 ways to include CSS:

  1. Inline: Создайте заголовок <h1> с inline-стилем: красный цвет, размер 36px
  2. Internal: В <style> в <head> задайте стили для <p>: тёмно-серый цвет (#333), межстрочный интервал 1.8
  3. External: Создайте файл style.css, подключите через <link>. В нём задайте стиль для <h2>: синий цвет, нижняя граница
  1. Inline: Create an <h1> heading with an inline style: red color, size 36px
  2. Internal: In <style> inside <head>, set styles for <p>: dark gray color (#333), line-height 1.8
  3. External: Create a file style.css, link it via <link>. In it, set a style for <h2>: blue color, bottom border

└── style.css          ← external стили для h2
