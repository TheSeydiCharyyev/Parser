📚 BASE.CSS — TEMPLATE

/* 1. Reset */
*, *::before, *::after {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}

ul, ol { list-style: none; }

a { color: inherit; text-decoration: none; }

img, svg {
    max-width: 100%;
    height: auto;
    display: block;
}

button, input, textarea, select {
    font-family: inherit;
    font-size: inherit;
    color: inherit;
}

html {
    scroll-behavior: smooth;
    scroll-padding-top: 80px;
}

/* 2. Body */
body {
    font-family: var(--font-primary);
    font-size: var(--fs-body);
    line-height: 1.6;
    color: var(--color-text);
    background: var(--color-bg);
}

/* 3. Типографика */
h1, h2, h3, h4 {
    font-weight: 700;
    line-height: 1.2;
    color: var(--color-text);
}
h1 {
    font-size: var(--fs-h1);
    letter-spacing: -0.02em;
}
h2 { font-size: var(--fs-h2); }
h3 { font-size: var(--fs-h3); }
h4 { font-size: var(--fs-h4); }

p { margin-bottom: var(--space-md); }

/* 4. Ссылки */
a {
    color: var(--color-primary);
    transition: color 0.2s;
}
a:hover {
    color: var(--color-primary-dark);
}

/* 5. Контейнер */
.container {
    width: 90%;
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 var(--space-md);
}
box-sizing: border-box — индустриальный стандарт. Padding/border включены в width → предсказуемые размеры.
box-sizing: border-box — industry standard. Padding/border included in width → predictable sizing.

📚 COMPONENT PATTERN: .btn

📚 COMPONENT PATTERN: .btn

/* Базовый класс */
.btn {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    padding: 12px 28px;
    font-weight: 600;
    border: 2px solid transparent;
    border-radius: var(--radius-md);
    cursor: pointer;
    transition: all 0.2s ease;
}

/* Модификаторы цвета */
.btn-primary { background: var(--color-primary); color: white; }
.btn-outline { background: transparent; color: var(--color-primary);
                border-color: var(--color-primary); }
.btn-ghost   { background: transparent; color: var(--color-text); }

/* Модификаторы размера */
.btn-sm   { padding: 8px 16px; font-size: var(--fs-small); }
.btn-lg   { padding: 16px 36px; font-size: 18px; }
.btn-full { width: 100%; }

/* Состояния */
.btn:hover   { transform: translateY(-2px); box-shadow: var(--shadow-md); }
.btn:focus-visible {
    outline: none;
    box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.4);
}
.btn:active  { transform: translateY(0); }
.btn:disabled { opacity: 0.5; cursor: not-allowed; }

Использование: <a class="btn btn-primary btn-lg">

Usage: <a class="btn btn-primary btn-lg">

:focus-visible, не :focus. Срабатывает только при клавиатурной навигации, не при клике мышью. Правильно для accessibility.
:focus-visible, not :focus. Triggers only on keyboard navigation, not mouse click. Correct for accessibility.

📚 КАРТОЧКА .card

📚 CARD .card

.card {
    background: white;
    border-radius: var(--radius-lg);
    box-shadow: var(--shadow-sm);
    overflow: hidden;       /* ОБЯЗАТЕЛЬНО! */
    transition: transform 0.3s, box-shadow 0.3s;
}
.card:hover {
    transform: translateY(-4px);
    box-shadow: var(--shadow-lg);
}
.card-image { width: 100%; height: 240px; object-fit: cover; }
.card-body  { padding: var(--space-md); }
.card-title { font-size: var(--fs-h4); font-weight: 700; }
.card-text  { color: var(--color-text-muted); }
.card-price { font-size: var(--fs-h3); font-weight: 700;
              color: var(--color-primary); }
overflow: hidden + border-radius = обязательная пара. Иначе прямоугольное фото «вылезает» за скруглённые углы.
overflow: hidden + border-radius = mandatory pair. Otherwise rectangular photo "breaks out" of rounded corners.

📚 FORMS

.form-group { margin-bottom: var(--space-md); }

.form-label {
    display: block;
    font-weight: 600;
    margin-bottom: var(--space-xs);
}

.form-input,
.form-textarea {
    width: 100%;
    padding: 12px 16px;
    font-family: inherit;   /* наследовать шрифт body! */
    border: 1px solid var(--color-border);
    border-radius: var(--radius-md);
    transition: border-color 0.2s, box-shadow 0.2s;
}

.form-input:focus,
.form-textarea:focus {
    outline: none;
    border-color: var(--color-primary);
    box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.15);
}

.form-textarea {
    min-height: 120px;
    resize: vertical;       /* только по высоте */
}

.form-checkbox input {
    accent-color: var(--color-primary);  /* цвет галочки */
}
ДетальЗачем
font-family: inheritInputs используют шрифт сайта, не системный
resize: verticalTextarea тянется только по высоте
box-shadow focus-ringЗамена outline, видна с клавиатуры
accent-colorСтилизует нативный checkbox одной строкой
DetailWhy
font-family: inheritInputs use site font, not system
resize: verticalTextarea resizes only vertically
box-shadow focus-ringReplaces outline, visible on keyboard
accent-colorStyles native checkbox in one line

📚 ПОРЯДОК СВОЙСТВ В СЕЛЕКТОРЕ

📚 PROPERTY ORDER IN A SELECTOR

.selector {
    /* 1. Layout */     display, position
    /* 2. Размеры */    width, height
    /* 3. Отступы */    padding, margin
    /* 4. Визуал */     background, border, border-radius, box-shadow
    /* 5. Типография */ font-*, color, text-*, line-height
    /* 6. Интерактив */ transition, transform, cursor
}
