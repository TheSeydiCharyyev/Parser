🎯 Lesson 33.2: COMPONENTS.CSS — BUTTONS, CARDS, FORMS

Задание 32.2: Стилизация компонентов Task 32.2: Style components
Среднее Medium 45 минут 45 min
Написать стили для переиспользуемых компонентов
Write styles for reusable components

Условие:

Instructions:

  1. Кнопки (15 мин): Напишите в components.css:
    • Базовый класс .btn: display: inline-flex, padding, border, border-radius, font-weight, transition, cursor
    • Модификаторы цвета: .btn-primary, .btn-outline, .btn-ghost
    • Модификаторы размера: .btn-sm, .btn-lg
    • Модификатор ширины: .btn-full
    • Состояния: :hover (translateY + shadow), :focus-visible (box-shadow ring), :active (translateY 0), :disabled (opacity 0.5 + cursor not-allowed)
  2. Карточки (15 мин): Напишите:
    • .card: background, border-radius, box-shadow, overflow: hidden, transition
    • .card:hover: translateY(-4px) + усиление тени
    • .card-image: width: 100%, height: 240px, object-fit: cover
    • .card-body: padding
    • .card-title: font-size, font-weight, margin-bottom
    • .card-text: color muted
    • .card-price: крупный, цветной
  3. Формы (10 мин):
    • .form-group: margin-bottom
    • .form-label: display block, font-weight, margin-bottom
    • .form-input, .form-textarea: width 100%, padding, border, border-radius, font-family: inherit
    • .form-input:focus: border-color primary + box-shadow focus-ring (rgba primary 0.15)
    • .form-textarea: min-height, resize: vertical
  4. Проверка (5 мин): Откройте страницу — кнопки, карточки, формы выглядят профессионально. Hover работает, focus видимый.
  1. Buttons (15 min): Write in components.css:
    • Base class .btn: display: inline-flex, padding, border, border-radius, font-weight, transition, cursor
    • Color modifiers: .btn-primary, .btn-outline, .btn-ghost
    • Size modifiers: .btn-sm, .btn-lg
    • Width modifier: .btn-full
    • States: :hover (translateY + shadow), :focus-visible (box-shadow ring), :active (translateY 0), :disabled (opacity 0.5 + cursor not-allowed)
  2. Cards (15 min): Write:
    • .card: background, border-radius, box-shadow, overflow: hidden, transition
    • .card:hover: translateY(-4px) + stronger shadow
    • .card-image: width: 100%, height: 240px, object-fit: cover

    • .card-text: muted color
    • .card-price: large, colored
  3. Forms (10 min):
    • .form-group: margin-bottom
    • .form-label: display block, font-weight, margin-bottom
    • .form-input, .form-textarea: width 100%, padding, border, border-radius, font-family: inherit
    • .form-input:focus: border-color primary + box-shadow focus-ring (rgba primary 0.15)
    • .form-textarea: min-height, resize: vertical
  4. Check (5 min): Open the page — buttons, cards, forms look professional. Hover works, focus visible.
Готовый шаблон .btn (скопируйте и измените под свою палитру): 
.btn {
    display: inline-flex;
    align-items: center;
    justify-content: center;
    gap: var(--space-sm);
    padding: 12px 28px;
    font-size: var(--fs-body);
    font-weight: 600;
    line-height: 1;
    border: 2px solid transparent;
    border-radius: var(--radius-md);
    text-decoration: none;
    cursor: pointer;
    transition: all 0.2s ease;
    white-space: nowrap;
}

.btn-primary {
    background: var(--color-primary);
    color: white;
    border-color: var(--color-primary);
}
.btn-primary:hover {
    background: var(--color-primary-dark);
    border-color: var(--color-primary-dark);
}

.btn:hover { transform: translateY(-2px); box-shadow: var(--shadow-md); }
.btn:focus-visible {
    outline: none;
    box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.4);
}
.btn:active { transform: translateY(0); }
.btn:disabled {
    opacity: 0.5;
    cursor: not-allowed;
    transform: none;
    box-shadow: none;
}
Замените rgba(59, 130, 246, 0.4) на ваш primary цвет в rgba-формате.

Instructions:

Create styleguide.html at the project root — a reference page for you (not public). Shows all your components in various states:

  5. Формы: полный набор полей — text, email, tel, textarea, checkbox, radio, select.
  6. Alerts и badges (если есть в вашем дизайне).
  1. Typography: h1, h2, h3, h4, paragraph, text link, bold, italic, small text.
  2. Color palette: 8 blocks with your colors and HEX codes below them.
  3. Buttons (min 15):
    • 3 colors × 3 sizes = 9 variants

Зачем styleguide:
  • Тестирует все компоненты сразу
  • Видно сразу, если какой-то вариант сломан
  • При работе над секциями вы открываете styleguide и копируете код компонента
  • Показывает работодателю уровень подхода (у профи всегда есть styleguide)
Styleguide не включается в публичное меню сайта — это инструмент для разработки.
Why styleguide:
  • Tests all components at once
  • Obvious if any variant is broken
  • When working on sections you open styleguide and copy component code
  • Shows employers your level (pros always have a styleguide)
Styleguide isn't in the public menu — it's a development tool.
