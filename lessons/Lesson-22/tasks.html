🎯 Lesson 22.1: PLANNING

Задание 21.1: Спланируй сайт ресторана Task 21.1: Plan the restaurant website
Лёгкое Easy 10 минут 10 min
Выбрать тему и спланировать содержание
Choose a theme and plan the content

Условие:

Instructions:

  1. Выбери тему: итальянский ресторан, суши-бар, кофейня, пиццерия, кондитерская, национальная кухня
  2. Название и слоган: короткое название + описание (1 предложение)
  3. Меню: 6 блюд — название, описание, цена
  4. Цветовая схема: основной цвет, тёмный, светлый фон (запиши HEX-коды)
  5. Заполни таблицу — что на каждом размере экрана (desktop, tablet, mobile)
  1. Choose a theme: Italian restaurant, sushi bar, coffee shop, pizzeria, bakery, national cuisine
  2. Name and tagline: short name + description (1 sentence)
  3. Menu: 6 dishes — name, description, price
  4. Color scheme: primary color, dark, light background (write HEX codes)
  5. Fill in the table — what on each screen size (desktop, tablet, mobile)
Пример таблицы адаптации:
Header — Desktop: лого + 4 ссылки | Tablet: то же | Mobile: лого + бургер
Hero — Desktop: 100vh | Tablet: 80vh | Mobile: 70vh
Menu — Desktop: 3 колонки | Tablet: 2 | Mobile: 1
Gallery — Desktop: 4 колонки | Tablet: 3 | Mobile: 2
Сохраните эту таблицу в отдельный файл plan.md — пригодится при написании CSS.
Example adaptation table:

Hero — Desktop: 100vh | Tablet: 80vh | Mobile: 70vh

Gallery — Desktop: 4 cols | Tablet: 3 | Mobile: 2
Save this table as a separate file plan.md — it'll help when you write CSS.

  • 5 цветов определены: primary, dark, light, text, muted

Задание 21.4: Smooth scroll + якорные ссылки Task 21.4: Smooth scroll + anchor links
Сложное Hard 10 минут 10 min
Добавить плавную прокрутку к якорным ссылкам
Add smooth scrolling to anchor links

Условие:

Instructions:

  1. Добавьте html { scroll-behavior: smooth; }
  2. Убедитесь, что навигация ссылается на #about, #menu, #gallery, #contact
  3. Добавьте scroll-padding-top: 80px на html (чтобы фиксированный header не перекрывал)
  4. Проверьте — при клике на ссылку страница плавно прокручивается к нужной секции
  1. Add html { scroll-behavior: smooth; }
  2. Make sure navigation links to #about, #menu, #gallery, #contact
  3. Add scroll-padding-top: 80px to html (so fixed header doesn't overlap)
  4. Verify — clicking a link smoothly scrolls to the right section
scroll-behavior: smooth — одна строка CSS, и все якорные ссылки (href="#section") будут плавно прокручивать!
scroll-behavior: smooth — one line of CSS, and all anchor links (href="#section") will scroll smoothly!

  • Header не перекрывает начало секций
