📚 ПРИНЦИП РАБОТЫ

📚 APPROACH

1. Сначала план, потом код. До написания HTML нарисуйте макет для 3 разрешений (desktop, tablet, mobile). Определите: где колонки превращаются в стопку, где появляется бургер, какие шрифты растут через clamp().
1. Plan first, code later. Before writing HTML, sketch the layout for 3 resolutions (desktop, tablet, mobile). Decide: where columns turn into a stack, where the burger appears, which fonts scale via clamp().
2. HTML → Десктоп-CSS → Media queries. Не пишите адаптив сразу. Сначала красивая десктоп-версия, потом добавляем media queries, которые перекрывают конкретные свойства.
2. HTML → Desktop CSS → Media queries. Don't write responsive code upfront. First build a nice desktop version, then add media queries that override specific properties.
Desktop-first в этом проекте: базовые стили под 1024px+, затем @media (max-width: 992px) и @media (max-width: 768px). В продакшене чаще mobile-first (min-width), но для учебного проекта desktop-first проще.
Desktop-first in this project: base styles for 1024px+, then @media (max-width: 992px) and @media (max-width: 768px). Production often uses mobile-first (min-width), but desktop-first is simpler for learning.

📚 БАЗОВЫЙ СБРОС CSS

📚 CSS BASE RESET

* { margin: 0; padding: 0; box-sizing: border-box; }

body { font-family: ...; line-height: 1.7; }

img { max-width: 100%; height: auto; }

.container {
    width: 90%;
    max-width: 1200px;
    margin: 0 auto;
}
box-sizing: border-box — padding и border включены в width. Без этого ширина блока «уплывает» за счёт padding. Индустриальный стандарт, ставят в 99% проектов.
box-sizing: border-box — padding and border are included in width. Without it, block widths "drift" due to padding. Industry standard, used in 99% of projects.

Don't write everything with <div>. Semantic tags are important for SEO (Google ranks higher) and screen readers (users with visual impairments navigate via landmarks).

📚 FIXED HEADER + BACKDROP-FILTER

📚 FIXED HEADER + BACKDROP-FILTER

.header {
    position: fixed;
    top: 0; left: 0; right: 0;
    height: 70px;
    background: rgba(255, 255, 255, 0.95);
    backdrop-filter: blur(10px);
    z-index: 100;
}
backdrop-filter: blur(10px) — «матовое стекло»: контент под хедером размывается. Даёт современный премиум-вид. Так делают Apple, Stripe, GitHub.
backdrop-filter: blur(10px) — "frosted glass": content behind the header is blurred. Gives a modern premium look. Used by Apple, Stripe, GitHub.
z-index: 100 — гарантирует, что header над остальными элементами. Без большого z-index секции ниже могут перекрыть header.
z-index: 100 — ensures the header is above other elements. Without a high z-index, sections below could cover the header.

📚 HERO С ФОНОВЫМ ИЗОБРАЖЕНИЕМ

📚 HERO WITH BACKGROUND IMAGE

.hero {
    height: 100vh;
    background:
        linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)),
        url('image.jpg') center/cover;
    display: flex;
    align-items: center;
    justify-content: center;
}

.hero h1 {
    font-size: clamp(2rem, 6vw, 4rem);
}
Overlay: linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)) — полупрозрачный чёрный слой поверх картинки, чтобы текст был читаемым.
Overlay: linear-gradient(rgba(0,0,0,0.5), rgba(0,0,0,0.5)) — semi-transparent black layer over the image so text is readable.
center/cover: center — картинка по центру. cover — заполняет блок, сохраняя пропорции (может обрезаться).
center/cover: center — image centered. cover — fills block, preserves proportions (may crop).

📚 ГРИДЫ ДЛЯ МЕНЮ, ГАЛЕРЕИ, FOOTER

📚 GRIDS FOR MENU, GALLERY, FOOTER

/* Меню блюд: 3 колонки */
.menu-grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 24px;
}

/* Карточка с фото */
.menu-card {
    overflow: hidden;       /* для скруглённых фото */
    border-radius: 16px;
}
.menu-card img {
    width: 100%;
    height: 200px;
    object-fit: cover;      /* заполнить + обрезать */
}
1fr — «одна доля свободного места». repeat(3, 1fr) = 3 равные колонки. В отличие от %, fr учитывает gap.
1fr — "one fraction of available space". repeat(3, 1fr) = 3 equal columns. Unlike %, fr accounts for gap.
overflow: hidden + border-radius — обязательная пара. Без overflow: hidden прямоугольные фото вылезают за скруглённые углы карточки.
overflow: hidden + border-radius — an essential pair. Without overflow: hidden, rectangular photos stick out past rounded card corners.

📚 BREAKPOINTS ПРОЕКТА

📚 PROJECT BREAKPOINTS

/* Планшет */
@media (max-width: 992px) {
    .menu-grid { grid-template-columns: repeat(2, 1fr); }
    .gallery-grid { grid-template-columns: repeat(3, 1fr); }
}

/* Мобильный */
@media (max-width: 768px) {
    /* бургер, 1 колонка, стопки, меньше отступы */
}
Каскад media queries: мобильный (≤768px) наследует правила планшета (≤992px), плюс добавляет свои. Пишите сверху вниз — от больших экранов к меньшим.
Media query cascade: mobile (≤768px) inherits tablet rules (≤992px), plus adds its own. Write top-down — from larger screens to smaller.
