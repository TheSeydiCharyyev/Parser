📚 УРОК 12.1: АУДИО И ВИДЕО

📚 Lesson 12.1: AUDIO AND VIDEO

Мультимедиа — это аудио и видео контент, встроенный прямо в веб-страницу. HTML5 позволяет воспроизводить медиа без сторонних плагинов (Flash больше не нужен!).
Multimedia — audio and video content embedded directly in a web page. HTML5 allows playing media without third-party plugins (no more Flash!).
<audio> — тег для встраивания аудиоплеера на страницу. Внутри используется <source> для указания файла и формата.
<audio> — tag for embedding an audio player on a page. Uses <source> inside to specify the file and format.
<video> — тег для встраивания видеоплеера на страницу. Поддерживает обложку (poster), размеры и управление воспроизведением.
<video> — tag for embedding a video player on a page. Supports cover image (poster), dimensions, and playback controls.

Аудио

Audio

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
</audio>

Видео

Video

<video controls width="640" poster="cover.jpg">
    <source src="video.mp4" type="video/mp4">
</video>
controls обязателен! Без атрибута controls пользователь не увидит кнопки play/pause, громкость и полосу прокрутки. Плеер будет невидимым.
controls is required! Without the controls attribute, the user won't see play/pause buttons, volume, or the progress bar. The player will be invisible.

autoplay + muted: Браузеры блокируют автовоспроизведение со звуком. Чтобы autoplay работал, нужно добавить muted. Это правило безопасности браузера.
autoplay + muted: Browsers block autoplay with sound. For autoplay to work, you must also add muted. This is a browser security rule.

📚 УРОК 12.2: IFRAME, ФАВИКОНКА, МЕТА-ТЕГИ

📚 Lesson 12.2: IFRAME, FAVICON, META TAGS

iframe — встраивает другую веб-страницу внутрь вашей. Используется для YouTube-видео, Google Maps и других сервисов.
iframe — embeds another web page inside yours. Used for YouTube videos, Google Maps, and other services.
Фавиконка (favicon) — маленькая иконка сайта, которая отображается во вкладке браузера рядом с названием страницы. Задаётся через <link> в <head>.
Favicon — a small site icon displayed in the browser tab next to the page title. Set via <link> in <head>.
Мета-теги — теги <meta> в <head>, которые содержат информацию о странице для браузеров и поисковых систем (кодировка, описание, автор и т.д.).
Meta tags — <meta> tags in <head> that contain page information for browsers and search engines (encoding, description, author, etc.).

YouTube iframe

YouTube iframe

<iframe width="560" height="315"
    src="https://www.youtube.com/embed/VIDEO_ID"
    title="Video" allowfullscreen>
</iframe>
URL для YouTube iframe: Используйте youtube.com/embed/VIDEO_ID, а НЕ youtube.com/watch?v=VIDEO_ID! Обычная ссылка не будет работать в iframe.
YouTube iframe URL: Use youtube.com/embed/VIDEO_ID, NOT youtube.com/watch?v=VIDEO_ID! A regular link won't work in an iframe.

Фавиконка

Favicon

<link rel="icon" href="favicon.png" type="image/png">
Размер фавиконки: обычно 32x32 или 16x16 пикселей. Форматы: PNG, ICO, SVG. Файл должен лежать в корне сайта или рядом с HTML.
Favicon size: usually 32x32 or 16x16 pixels. Formats: PNG, ICO, SVG. The file should be in the site root or next to the HTML.
