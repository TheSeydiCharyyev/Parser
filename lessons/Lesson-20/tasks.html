Задание 19.1: Цветовой индикатор Task 19.1: Color indicator
Лёгкое Easy 10 минут 10 min
Понять, как работают media queries, через визуальную обратную связь
Understand how media queries work through visual feedback

Условие:

Instructions:

Создайте файл responsive-test.html. Сделайте блок, который меняет цвет фона и текст при разных размерах экрана:

Create a file responsive-test.html. Make a block that changes background color and text at different screen sizes:

  1. Базовый (мобильный): зелёный фон (#22c55e), текст «Mobile (до 576px)»
  2. 576px+: жёлтый фон (#eab308), текст «Mobile L (576px — 768px)»
  3. 768px+: оранжевый фон (#f97316), текст «Tablet (768px — 992px)»
  4. 992px+: синий фон (#3b82f6), текст «Laptop (992px — 1200px)»
  5. 1200px+: фиолетовый фон (#8b5cf6), текст «Desktop (1200px+)»
  1. Base (mobile): green background (#22c55e), text "Mobile (up to 576px)"
  2. 576px+: yellow background (#eab308), text "Mobile L (576px — 768px)"
  3. 768px+: orange background (#f97316), text "Tablet (768px — 992px)"
  4. 992px+: blue background (#3b82f6), text "Laptop (992px — 1200px)"
  5. 1200px+: purple background (#8b5cf6), text "Desktop (1200px+)"
Для переключения текста: создайте 5 элементов <span> и показывайте нужный через display: none / block в media queries. Или используйте CSS ::after с content.
To switch text: create 5 <span> elements and show the right one via display: none / block in media queries. Or use CSS ::after with content.
  • 5 breakpoints с разными цветами
  • Текст показывает текущий диапазон
  • Mobile-first подход (min-width)
  • Плавно сужайте окно и проверяйте переходы
  • 5 breakpoints with different colors
  • Text shows current range
  • Mobile-first approach (min-width)
  • Smoothly resize window and check transitions

Задание 19.2: Сетка карточек с breakpoints Task 19.2: Card grid with breakpoints
Среднее Medium 15 минут 15 min
Создать адаптивную сетку карточек с media queries
Create a responsive card grid with media queries

Условие:

Instructions:

Создайте файл responsive-grid.html с 6 карточками. Используйте mobile-first:

Create a file responsive-grid.html with 6 cards. Use mobile-first:

  1. Базовые стили (мобильный):
    • Grid: grid-template-columns: 1fr
    • padding: 16px, gap: 16px
    • h1 { font-size: 1.5rem; }
  2. @media (min-width: 768px) — планшет:
    • Grid: repeat(2, 1fr)
    • padding: 24px, gap: 20px
    • h1 { font-size: 2rem; }
  3. @media (min-width: 1024px) — десктоп:
    • Grid: repeat(3, 1fr)
    • padding: 32px, gap: 24px
    • h1 { font-size: 2.5rem; }
  1. Base styles (mobile):
    • Grid: grid-template-columns: 1fr
    • padding: 16px, gap: 16px
    • h1 { font-size: 1.5rem; }
  2. @media (min-width: 768px) — tablet:
    • Grid: repeat(2, 1fr)
    • padding: 24px, gap: 20px
    • h1 { font-size: 2rem; }
  3. @media (min-width: 1024px) — desktop:
    • Grid: repeat(3, 1fr)
    • padding: 32px, gap: 24px
    • h1 { font-size: 2.5rem; }

Карточки: изображение (picsum.photos), заголовок, описание. Белый фон, border-radius: 12px, тень.

Cards: image (picsum.photos), title, description. White background, border-radius: 12px, shadow.

  • Mobile-first подход (min-width)
  • 3 уровня: 1 колонка → 2 → 3
  • Шрифты и отступы тоже меняются
  • 6 карточек с изображениями
  • Проверено в DevTools Device Toolbar
