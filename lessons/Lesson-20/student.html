📚 META VIEWPORT (ОБЯЗАТЕЛЬНО!)

📚 META VIEWPORT (REQUIRED!)

Без этого тега media queries не работают на мобильных:
Without this tag media queries don't work on mobile: 
<meta name="viewport" content="width=device-width, initial-scale=1.0">

📚 СИНТАКСИС MEDIA QUERIES

📚 MEDIA QUERIES SYNTAX

/* Desktop-first (max-width = «если ≤») */
@media (max-width: 768px) {
    /* стили для мобильных */
}

/* Mobile-first (min-width = «если ≥») */
@media (min-width: 768px) {
    /* стили для десктопа */
}

📚 MOBILE-FIRST ШАБЛОН

📚 MOBILE-FIRST TEMPLATE

/* Мобильный (базовые стили) */
.grid { grid-template-columns: 1fr; }
h1 { font-size: 1.5rem; }
.container { padding: 16px; }
.sidebar { display: none; }

/* Планшет (768px+) */
@media (min-width: 768px) {
    .grid { grid-template-columns: repeat(2, 1fr); }
    h1 { font-size: 2rem; }
    .container { padding: 24px; }
}

/* Десктоп (1024px+) */
@media (min-width: 1024px) {
    .grid { grid-template-columns: repeat(3, 1fr); }
    h1 { font-size: 2.5rem; }
    .container { padding: 32px; }
    .sidebar { display: block; }
}
