📚 СВОЙСТВА FLEX-ЭЛЕМЕНТОВ

📚 FLEX ITEM PROPERTIES

flex-grow — коэффициент растяжения. Определяет, какую долю свободного пространства элемент заберёт. По умолчанию 0 (не растягиваться).
flex-grow — growth factor. Determines what share of free space the item will take. Default is 0 (don't grow).
flex-shrink — коэффициент сжатия. Определяет, насколько элемент уменьшится, когда места не хватает. По умолчанию 1 (можно сжимать).
flex-shrink — shrink factor. Determines how much the item will shrink when there's not enough space. Default is 1 (can shrink).
flex-basis — начальный размер элемента до распределения свободного места. По умолчанию auto (размер контента или width/height).
flex-basis — initial size of the item before free space is distributed. Default is auto (content size or width/height).

flex: 1 — самое важное сокращение! Используй его везде, когда нужно, чтобы элемент занял всё свободное место. Это решение 90% задач с flex-элементами.
flex: 1 — the most important shorthand! Use it everywhere you need an item to fill all free space. This solves 90% of flex item tasks.
flex: 1 vs flex: auto — в чём разница?
flex: 1 = basis: 0 — все элементы стартуют с нуля, потом делят место поровну.
flex: auto = basis: auto — элементы стартуют от своего контента, потом делят оставшееся место.
Результат: при flex: 1 колонки одинаковой ширины, при flex: auto — пропорциональны контенту.
flex: 1 vs flex: auto — what's the difference?
flex: 1 = basis: 0 — all items start from zero, then split space equally.
flex: auto = basis: auto — items start from their content size, then split remaining space.
Result: with flex: 1 columns are equal width, with flex: auto — proportional to content.
flex-shrink: 0 — для фиксированных сайдбаров. Если sidebar должен быть ровно 250px и не сжиматься при уменьшении окна, ставь flex: 0 0 250px (grow:0, shrink:0, basis:250px).
flex-shrink: 0 — for fixed sidebars. If a sidebar must be exactly 250px and never shrink when the window gets smaller, use flex: 0 0 250px (grow:0, shrink:0, basis:250px).

📚 ORDER И ALIGN-SELF

📚 ORDER AND ALIGN-SELF

order — визуальный порядок

order — visual order

order — меняет визуальный порядок элемента, не трогая HTML. По умолчанию 0. Чем меньше число — тем раньше элемент. Можно использовать отрицательные значения.
order — changes the visual order of an item without touching HTML. Default is 0. Lower number = earlier position. Negative values are allowed. 
/* HTML: A  B  C */
.item-c { order: -1; }  /* Визуально: C  A  B */
.item-a { order: 2; }   /* Визуально: C  B  A */

align-self — индивидуальное выравнивание

align-self — individual alignment

align-self — переопределяет align-items контейнера для одного конкретного элемента. Значения те же: stretch | flex-start | flex-end | center | baseline.
align-self — overrides the container's align-items for one specific item. Same values: stretch | flex-start | flex-end | center | baseline. 
.container { display: flex; align-items: flex-start; }
.special   { align-self: center; }  /* Только этот — по центру */

📚 ТРЮК С MARGIN AUTO

📚 MARGIN AUTO TRICK

margin-left: auto / margin-top: auto — мощный трюк! Во flex-контейнере margin: auto «съедает» всё свободное пространство в указанном направлении. Это заменяет justify-content для отдельных элементов.
margin-left: auto / margin-top: auto — powerful trick! In a flex container margin: auto "eats" all free space in the given direction. This replaces justify-content for individual items. 
/* Толкнуть последний элемент вправо (в row) */
.last-item { margin-left: auto; }

/* Толкнуть кнопку вниз карточки (в column) */
.card-btn  { margin-top: auto; }

/* Центрировать элемент по обеим осям */
.centered  { margin: auto; }
