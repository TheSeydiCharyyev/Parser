2. flex-grow — растяжение

2. flex-grow — growing

flex-grow определяет, насколько элемент может растянуться, чтобы заполнить свободное пространство.

flex-grow determines how much an item can grow to fill available space.

ЗначениеЧто делает
0Не растягивается (по умолчанию)
1Занимает свою долю свободного пространства
2Занимает в 2 раза больше, чем элемент с grow: 1
ValueWhat it does
0Doesn't grow (default)
1Takes its share of available space
2Takes 2x more than an item with grow: 1
<div class="container">
    <div class="sidebar">Sidebar</div>
    <div class="content">Content</div>
</div>
.container { display: flex; }
.sidebar   { flex-grow: 0; width: 250px; }  /* фиксированная ширина */
.content   { flex-grow: 1; }                 /* занимает ВСЁ остальное */
flex-grow: 0 у всех (по умолчанию): [ 1 ][ 2 ][ 3 ]________________ ← свободное место flex-grow: 1 у всех: [ 1 ][ 2 ][ 3 ] ← заняли всё grow:1, grow:2, grow:1: [ 1 ][ 2 ][ 3 ] ← 2-й в 2 раза шире
flex-grow: 0 on all (default): [ 1 ][ 2 ][ 3 ]________________ ← free space flex-grow: 1 on all: [ 1 ][ 2 ][ 3 ] ← filled all grow:1, grow:2, grow:1: [ 1 ][ 2 ][ 3 ] ← 2nd is 2x wider

flex-grow — как жадность элемента. 0 — не жадный, берёт только своё. 1 — делит свободное место поровну. 2 — берёт вдвое больше.

flex-grow is like an element's greediness. 0 — not greedy, takes only what it needs. 1 — splits free space equally. 2 — takes twice as much.

Как считается flex-grow (математика): Допустим, контейнер 600px, три элемента по 100px. Свободное место = 600 - 300 = 300px. Если grow = 1, 2, 1 (сумма = 4), то первый получит 300 * 1/4 = 75px, второй 300 * 2/4 = 150px, третий 300 * 1/4 = 75px. Итого: 175px, 250px, 175px.
How flex-grow is calculated (the math): Say the container is 600px, three items are 100px each. Free space = 600 - 300 = 300px. If grow = 1, 2, 1 (sum = 4), the first gets 300 * 1/4 = 75px, the second 300 * 2/4 = 150px, the third 300 * 1/4 = 75px. Totals: 175px, 250px, 175px.

Средний блок (grow: 2) получает вдвое больше свободного пространства, чем боковые (grow: 1).

grow: 1

The middle block (grow: 2) gets twice as much free space as the side blocks (grow: 1).

flex-grow + flex-basis: auto — если у элемента уже есть контент или width, то flex-grow распределяет только оставшееся свободное место. Элемент с grow:1; basis:auto и элемент с grow:1; basis:0 получат разные размеры!

flex-grow + flex-basis: auto — if an item already has content or width, flex-grow only distributes the remaining free space. An item with grow:1; basis:auto and an item with grow:1; basis:0 will end up different sizes!

/* basis:auto — распределяет СВОБОДНОЕ место после контента */
.a { flex: 1 1 auto; }  /* "Привет" + доля свободного */
.b { flex: 1 1 auto; }  /* "Здравствуйте, друзья!" + доля свободного */
/* Результат: .b шире, потому что контент длиннее */

/* basis:0 — ВСЁ пространство делится поровну */
.a { flex: 1 1 0; }  /* ровно 50% */
.b { flex: 1 1 0; }  /* ровно 50% */

Свойство flex-grow принимает не только целые числа! Можно написать flex-grow: 0.5 — и элемент получит половину от того, что получил бы элемент с flex-grow: 1. Это бывает полезно для тонкой настройки пропорций, хотя на практике чаще используют целые числа.

The flex-grow property accepts not just integers! You can write flex-grow: 0.5 — and the item will get half of what an item with flex-grow: 1 would get. This can be useful for fine-tuning proportions, though whole numbers are more common in practice.

Создайте контейнер с тремя блоками. Дайте первому flex-grow: 1, второму flex-grow: 3, третьему flex-grow: 1. Как изменяются пропорции? Теперь поставьте всем flex-grow: 0 — что произошло?

Create a container with three blocks. Give the first flex-grow: 1, the second flex-grow: 3, the third flex-grow: 1. How do the proportions change? Now set all to flex-grow: 0 — what happened?

3. flex-shrink — сжатие

3. flex-shrink — shrinking

flex-shrink определяет, насколько элемент может сжиматься, когда места не хватает.

flex-shrink determines how much an item can shrink when there's not enough space.

ЗначениеЧто делает
1Может сжиматься (по умолчанию)
0НЕ сжимается (сохраняет размер)
2Сжимается в 2 раза сильнее, чем с shrink: 1
ValueWhat it does
1Can shrink (default)
0Does NOT shrink (keeps size)
2Shrinks 2x more than shrink: 1
/* Sidebar не сжимается, content — сжимается */
.sidebar { flex-shrink: 0; width: 250px; }
.content { flex-shrink: 1; }

Container 400px, items 200px each (total 600px — don't fit!): All shrink: 1 (shrink equally): [ 1: 133px ][ 2: 133px ][ 3: 133px ] shrink:0, shrink:2, shrink:1 (first doesn't shrink): [ 1: 200px ][ 2: 100px ][ 3: 100px ] All shrink: 0 (nobody shrinks — overflow!): [ 1: 200px ][ 2: 200px ][ 3: 200px ] → overflow container!

flex-shrink — как уступчивость в переполненном автобусе. Представьте автобус Ашхабад-Мары, в котором мало места. shrink: 0 — пассажир, который не двигается ни на сантиметр. shrink: 1 — обычный пассажир, готовый немного подвинуться. shrink: 2 — самый вежливый, уступает вдвое больше места.

flex-shrink is like willingness to give up space on a crowded bus. Imagine a packed bus with limited room. shrink: 0 — the passenger who won't budge an inch. shrink: 1 — a regular passenger willing to move over a little. shrink: 2 — the most polite person, giving up twice as much space.

Типичный случай: flex-shrink: 0 на sidebar — чтобы боковая панель не сжималась на узких экранах.
Typical case: flex-shrink: 0 on sidebar — so the sidebar doesn't shrink on narrow screens.

4. flex-basis — начальный размер

4. flex-basis — initial size

flex-basis — начальный размер элемента до распределения свободного места (вместо width/height).

flex-basis — the initial size of an item before free space is distributed (instead of width/height).

ЗначениеЧто делает
autoРазмер по содержимому или width/height (по умолчанию)
0Начальный размер = 0, потом растёт через flex-grow
200pxНачальный размер = 200px
30%30% от контейнера
ValueWhat it does
autoSize from content or width/height (default)
0Initial size = 0, then grows via flex-grow
200pxInitial size = 200px
30%30% of container
/* Sidebar = 300px, content = остальное */
.sidebar { flex-basis: 300px; flex-grow: 0; flex-shrink: 0; }
.content { flex-basis: 0;     flex-grow: 1; }

flex-basis — как стартовая позиция бегуна на стадионе. Один бегун стартует с 0 метров, другой — с 200 метров. После старта они могут бежать дальше (flex-grow) или их могут оттеснить назад (flex-shrink). Но flex-basis — это то, откуда начинается движение.

flex-basis is like a runner's starting position on a track. One runner starts at 0 meters, another at 200 meters. After the start, they can run further (flex-grow) or be pushed back (flex-shrink). But flex-basis is where the movement begins.

Зачем flex-basis, если есть width? Потому что flex-basis — это «размер до начала расчётов flex». Он учитывается до flex-grow и flex-shrink, а обычный width может быть переопределён flexbox-ом. Если задать оба, flex-basis побеждает (кроме flex-basis: auto, который берёт значение из width).

Why flex-basis when we have width? Because flex-basis is the "size before flex calculations begin." It is considered before flex-grow and flex-shrink, while a regular width can be overridden by flexbox. If both are set, flex-basis wins (except flex-basis: auto, which takes the value from width).

.item {
    width: 200px;
    flex-grow: 1;
}
/* width игнорируется, если
   flex-basis не auto */
flex-basis: 200px
flex-basis: 200px
.item {
    flex-basis: 200px;
    flex-grow: 1;
}
/* Начальный размер 200px,
   потом растёт */

Создайте два flex-элемента. Первому дайте width: 300px; flex-basis: 100px, второму — width: 100px; flex-basis: 300px. Какой из них шире? Теперь поменяйте оба на flex-basis: auto — что произошло? Вывод: flex-basis побеждает width, но auto использует значение width.

Create two flex items. Give the first width: 300px; flex-basis: 100px, the second width: 100px; flex-basis: 300px. Which one is wider? Now change both to flex-basis: auto — what happened? Conclusion: flex-basis beats width, but auto uses the width value.

Приоритет размеров в flex: flex-basis: 200px > width: 200px > содержимое (1-й) (2-й) (3-й) Исключение: flex-basis: auto → берёт width Если нет width → размер по содержимому
Size priority in flex: flex-basis: 200px > width: 200px > content (1st) (2nd) (3rd) Exception: flex-basis: auto → takes width value If no width → sizes by content

5. Сокращение flex

5. flex shorthand

Свойство flex — сокращение для flex-grow, flex-shrink и flex-basis:

The flex property is a shorthand for flex-grow, flex-shrink, and flex-basis:

/* flex: grow shrink basis */

flex: 0 1 auto;    /* по умолчанию */
flex: 1;           /* = flex: 1 1 0  — растянуться, заполнить */
flex: auto;        /* = flex: 1 1 auto */
flex: none;        /* = flex: 0 0 auto — не растягивать, не сжимать */
flex: 0 0 300px;   /* фиксированный 300px */
Самые частые значения:
  • flex: 1 — элемент заполняет доступное место (равные колонки)
  • flex: none или flex: 0 0 250px — фиксированный размер (sidebar)
Most common values:
  • flex: 1 — item fills available space (equal columns)
  • flex: none or flex: 0 0 250px — fixed size (sidebar)
Расшифровка самых частых значений: flex: 1 → flex-grow: 1 flex-shrink: 1 flex-basis: 0 flex: auto → flex-grow: 1 flex-shrink: 1 flex-basis: auto flex: none → flex-grow: 0 flex-shrink: 0 flex-basis: auto flex: 0 0 250px → flex-grow: 0 flex-shrink: 0 flex-basis: 250px flex: 2 → flex-grow: 2 flex-shrink: 1 flex-basis: 0 flex: 0 1 auto → (это значение по умолчанию!)
Decoding the most common values: flex: 1 → flex-grow: 1 flex-shrink: 1 flex-basis: 0 flex: auto → flex-grow: 1 flex-shrink: 1 flex-basis: auto flex: none → flex-grow: 0 flex-shrink: 0 flex-basis: auto flex: 0 0 250px → flex-grow: 0 flex-shrink: 0 flex-basis: 250px flex: 2 → flex-grow: 2 flex-shrink: 1 flex-basis: 0 flex: 0 1 auto → (this is the default value!)

Всегда предпочитайте сокращение flex вместо отдельных flex-grow, flex-shrink, flex-basis. Сокращение flex корректно сбрасывает неуказанные значения. Например, flex: 1 устанавливает basis: 0, а если написать просто flex-grow: 1, то basis останется auto — результат будет другим!

Always prefer the flex shorthand over separate flex-grow, flex-shrink, flex-basis. The flex shorthand correctly resets unspecified values. For example, flex: 1 sets basis: 0, but if you just write flex-grow: 1, then basis stays auto — the result will be different!

6. order — порядок элементов

6. order — item order

order меняет визуальный порядок элементов (не в HTML, только на экране):

order changes the visual order of items (not in HTML, only on screen):

.item-a { order: 2; }  /* покажется третьим */
.item-b { order: 0; }  /* по умолчанию — первый */
.item-c { order: 1; }  /* покажется вторым */

/* В HTML: A B C → На экране: B C A */

1, 2, 3...Чем больше — тем позже

In HTML: A, B, C. On screen: B (order:0), C (order:1), A (order:2).

order — как пульт от телевизора. Вы можете переключить каналы так, чтобы канал 3 показывался на кнопке 1, а канал 1 — на кнопке 3. Физическое оборудование (HTML-код) осталось на месте, но пользователь видит другой порядок. Так же order меняет только визуальное расположение, не трогая DOM.

order is like a TV remote control. You can remap channels so channel 3 appears on button 1 and channel 1 on button 3. The physical equipment (HTML code) stays in place, but the user sees a different order. Similarly, order only changes the visual arrangement without touching the DOM.

Когда полезно: Изменить порядок на мобильных. Например, на десктопе sidebar слева, на мобильном — после контента.
When useful: Change order on mobile. For example, sidebar on the left on desktop, after content on mobile.

Не используйте order для критически важного контента! Скринридеры (для незрячих людей) и клавиатурная навигация (Tab) читают элементы в порядке HTML, а не в визуальном порядке. Если кнопка «Оплатить» визуально первая, но в HTML последняя — человек с клавиатурой дойдёт до неё в последнюю очередь.

Don't use order for critical content! Screen readers (for visually impaired users) and keyboard navigation (Tab) read elements in HTML order, not visual order. If the "Pay" button is visually first but last in HTML, a keyboard user will reach it last.

Создайте навигацию из 4 ссылок: Главная, О нас, Контакты, Блог. Используя order, сделайте так, чтобы «Блог» был визуально первым, а «О нас» — последним. Проверьте: если нажать Tab, в каком порядке выделяются ссылки?

Create a navigation with 4 links: Home, About, Contacts, Blog. Using order, make "Blog" appear first visually and "About" last. Check: when you press Tab, in what order are the links highlighted?

Как это работает? В flex-контейнере margin: auto ведёт себя особенно: автоматический margin поглощает всё свободное пространство. Это мощнее, чем justify-content, потому что можно точечно «оттолкнуть» один элемент, а не двигать всю группу.

How does this work? In a flex container, margin: auto behaves specially: auto margin absorbs all available free space. This is more powerful than justify-content because you can precisely "push" one item away, rather than moving the whole group.

The name "Holy Grail Layout" emerged in the early 2000s. Свойства flex-элементов (детей):
  • flex-grow — насколько может растянуться (0 = нет, 1+ = да)
  • flex-shrink — насколько может сжаться (0 = нет, 1 = да)
  • flex-basis — начальный размер (auto, 0, px, %)
  • flex — сокращение: flex: 1 (заполнить), flex: 0 0 250px (фиксир.)
  • order — визуальный порядок (0 по умолчанию)
  • align-self — индивидуальное выравнивание по поперечной оси

  • margin-left: auto — толкает элемент вправо
  • margin-top: auto — толкает элемент вниз (в column)
  • Вложенные flex — flex внутри flex
Flex item (children) properties:
  • flex-grow — how much it can grow (0 = no, 1+ = yes)
  • flex-shrink — how much it can shrink (0 = no, 1 = yes)
  • flex-basis — initial size (auto, 0, px, %)
  • flex — shorthand: flex: 1 (fill), flex: 0 0 250px (fixed)
  • order — visual order (0 by default)
  • align-self — individual cross-axis alignment
Tricks:
  • margin-left: auto — pushes item to the right
  • margin-top: auto — pushes item to the bottom (in column)
