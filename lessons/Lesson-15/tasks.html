Задание 14.1: Эксперименты с flex-grow Task 14.1: flex-grow experiments
Лёгкое Easy 10 минут 10 min
Понять как работает flex-grow на практике
Understand how flex-grow works in practice

Условие:

Instructions:

Создайте файл flex-grow.html. Сделайте flex-контейнер с 3 блоками. Покажите 4 варианта на одной странице:

Create a file flex-grow.html. Make a flex container with 3 blocks. Show 4 variations on one page:

  1. Все grow: 0 — блоки занимают только свой размер
  2. Все grow: 1 — равные колонки, заполняют всю ширину
  3. grow: 1, 2, 1 — средний в 2 раза шире
  4. grow: 0, 1, 0 — первый и третий фиксированные (width: 150px), средний заполняет остальное
  1. All grow: 0 — blocks take only their size
  2. All grow: 1 — equal columns, fill full width
  3. grow: 1, 2, 1 — middle is 2x wider
  4. grow: 0, 1, 0 — first and third fixed (width: 150px), middle fills the rest

Требования:

Requirements:

  • CSS можно писать в <style> или в отдельном файле
  • Каждый вариант подписан заголовком <h3> (например: «Вариант 1: все grow: 0»)
  • Внутри каждого блока — текст, показывающий его значение grow (например: «grow: 1»)
  • Контейнеры имеют min-height: 60px для наглядности
  • Блоки имеют разные цвета фона для визуального различия
  • CSS can be in <style> or in a separate file
  • Each variation labeled with an <h3> heading (e.g., "Variation 1: all grow: 0")
  • Inside each box — text showing its grow value (e.g., "grow: 1")
  • Containers have min-height: 60px for clarity
  • Boxes have different background colors for visual distinction
Базовые стили для контейнера и блоков: 
.container {
    display: flex;
    gap: 10px;
    margin-bottom: 30px;
    min-height: 60px;
}
.box {
    padding: 20px;
    text-align: center;
    color: white;
    font-weight: bold;
    border-radius: 8px;
}
.box-1 { background: #e74c3c; }
.box-2 { background: #3498db; }
.box-3 { background: #2ecc71; }

Create a classic page layout with sidebar

Условие:

Instructions:

Создайте папку holy-grail с файлами index.html и style.css. Сделайте макет:

Create a folder holy-grail with files index.html and style.css. Make the layout:

  1. Header: Тёмный фон, логотип + навигация (flex, space-between)
  2. Sidebar (250px): Светло-серый фон, список ссылок (5 пунктов)
  3. Content (flex: 1): Белый фон, заголовок + 2-3 параграфа текста
  4. Footer: Тёмный фон, копирайт
  5. Страница занимает минимум 100vh (footer всегда внизу)
  1. Header: Dark background, logo + navigation (flex, space-between)
  2. Sidebar (250px): Light gray background, list of links (5 items)
  3. Content (flex: 1): White background, heading + 2-3 paragraphs

CSS requirements:

  • Content заполняет всё оставшееся место: flex: 1
  • Footer — тёмный фон (#333 или подобный), светлый текст
  • Header — flex-навигация с justify-content: space-between
  • CSS подключён через <link> (отдельный файл style.css)
  • Page takes min-height: 100vh (footer sticks to bottom even with little content)
  • Sidebar doesn't shrink: use flex: 0 0 250px (flex-shrink: 0)
  • Content fills all remaining space: flex: 1
  • Footer — dark background (#333 or similar), light text
  • Header — flex navigation with justify-content: space-between
  • CSS linked via <link> (separate file style.css)

Задание 14.3: Макет блога на Flexbox Task 14.3: Blog layout with Flexbox
Среднее Medium 25 минут 25 min
Создать полноценный макет блога с Flexbox
Create a complete blog layout with Flexbox

Условие:

Instructions:

Создайте папку blog-layout с файлами index.html и style.css. Сделайте макет блога:

Create a folder blog-layout with files index.html and style.css. Make a blog layout:

  1. Header: Логотип + навигация (space-between) + кнопка «Написать» (margin-left: auto)
  2. Main content: 3 карточки статей в ряд (flex: 1, равная высота):
    • Заголовок статьи
    • Дата
    • Текст-превью (2-3 строки)
    • Кнопка «Читать далее» — прижата к низу (margin-top: auto)
  3. Sidebar (300px): «Популярные посты» — 3-4 ссылки, «Категории» — 5 тегов
  4. Footer: Копирайт + соцсети (space-between)
  1. Header: Logo + navigation (space-between) + "Write" button (margin-left: auto)
  2. Main content: 3 article cards in a row (flex: 1, equal height):
    • Article title
    • Date
    • Preview text (2-3 lines)
    • "Read more" button — pushed to bottom (margin-top: auto)
  3. Sidebar (300px): "Popular posts" — 3-4 links, "Categories" — 5 tags
  4. Footer: Copyright + social links (space-between)

CSS-требования:

CSS requirements:

  • Каждая карточка — flex-контейнер с flex-direction: column
  • Карточки одинаковой высоты: родитель с display: flex + карточки с flex: 1
  • Кнопка «Читать далее» прижата к низу через margin-top: auto
  • Sidebar не сжимается: flex: 0 0 300px
  • Карточки стилизованы: тени (box-shadow), скругления (border-radius), :hover эффект
  • CSS подключён через <link> (отдельный файл style.css)
  • Each card is a flex container with flex-direction: column
  • Cards have equal height: parent with display: flex + cards with flex: 1
  • "Read more" button pushed to bottom via margin-top: auto
  • Sidebar doesn't shrink: flex: 0 0 300px
  • Cards styled: shadows (box-shadow), rounded corners (border-radius), :hover effect
  • CSS linked via <link> (separate file style.css)
Ключевой CSS для карточек — flex-direction: column + margin-top: auto для кнопки: 
.cards {
    display: flex;
    gap: 20px;
}
.card {
    flex: 1;
    display: flex;

}
.card .btn {
    margin-top: auto;
    /* кнопка всегда прижата к низу карточки */
}
