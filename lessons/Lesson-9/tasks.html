🎯 УРОК 9.1: ПЛАНИРОВАНИЕ

🎯 Lesson 9.1: PLANNING

Задание 8.1: Спланируй свою визитку Task 8.1: Plan your business card
Лёгкое Easy 10 минут 10 min
Научиться планировать веб-страницу перед кодированием
Learn to plan a web page before coding

Условие:

Instructions:

На бумаге (или в тетради) выполните следующее:

On paper (or in a notebook) do the following:

  1. Нарисуй wireframe — простой набросок своей визитки. Покажи, где будет фото, имя, описание, навыки, ссылки
  2. Запиши содержание — своё имя (или вымышленное), профессию, 3-5 навыков, 2-3 ссылки на соцсети
  3. Выбери цветовую схему — основной цвет фона, цвет акцента, цвет текста
  4. Запиши HTML-теги — рядом с каждым блоком wireframe напиши, какой тег будешь использовать
  1. Draw a wireframe — a simple sketch of your card. Show where the photo, name, description, skills, links will be
  2. Write down content — your name (or fictional), profession, 3-5 skills, 2-3 social media links
  3. Choose a color scheme — main background color, accent color, text color
  4. Write HTML tags — next to each wireframe block, write which tag you'll use

Пример записи:

Имя: Айгуль Мередова
Профессия: Начинающий веб-разработчик
Описание: Учусь создавать сайты. Люблю дизайн и программирование.
Навыки: HTML, CSS, Photoshop, Figma
Соцсети: GitHub, Instagram, Telegram
Цвета: фон #667eea, карточка #fff, акцент #667eea

Example entry:

Name: Aygul Meredova
Profession: Beginner web developer
Description: Learning to create websites. Love design and programming.
Skills: HTML, CSS, Photoshop, Figma
Social: GitHub, Instagram, Telegram
Colors: background #667eea, card #fff, accent #667eea
  • Wireframe нарисован (хотя бы простой набросок)
  • Содержание записано (имя, профессия, навыки, соцсети)
  • Цвета выбраны (минимум 3: фон, карточка, акцент)
  • HTML-теги определены для каждого блока
  • Wireframe is drawn (at least a simple sketch)
  • Content is written down (name, profession, skills, social)
  • Colors are chosen (at least 3: background, card, accent)
  • HTML tags are defined for each block

🎯 УРОК 9.2: ПОВТОРЕНИЕ ПРИМЕРА

🎯 Lesson 9.2: REPRODUCING THE EXAMPLE

Задание 8.2: Повтори визитку по образцу Task 8.2: Reproduce the example card
Среднее Medium 20 минут 20 min
Самостоятельно воспроизвести готовую визитку из лекции
Independently reproduce the business card from the lecture

Условие:

Instructions:

  1. Создайте папку card-example
  2. Создайте файлы index.html и style.css
  3. Самостоятельно (не копируя!) напишите HTML-разметку визитки:
    • Аватар (используйте https://i.pravatar.cc/150?img=11)
    • Имя: Алексей Петров
    • Профессия: Frontend-разработчик
    • Описание (2-3 предложения)
    • Контакты: email и телефон
    • Навыки: HTML, CSS, JavaScript, Git, VS Code
    • Соцсети: GitHub, Telegram, LinkedIn
  4. Напишите CSS:
    • Фон страницы — градиент
    • Карточка — белая, скруглённая, с тенью
    • Аватар — круглый, с рамкой
    • Навыки — бейджи (inline-block)
    • Соцсети — кнопки с hover-эффектом
  5. Откройте в браузере и сравните с примером из лекции
  1. Create a folder card-example
  2. Create files index.html and style.css
  3. Independently (without copying!) write the HTML markup:
    • Avatar (use https://i.pravatar.cc/150?img=11)
    • Name: Alexey Petrov
    • Profession: Frontend Developer
    • Description (2-3 sentences)
    • Contacts: email and phone
    • Skills: HTML, CSS, JavaScript, Git, VS Code
    • Social: GitHub, Telegram, LinkedIn
  4. Write CSS:
    • Page background — gradient
    • Card — white, rounded, with shadow
    • Avatar — round, with border
    • Skills — badges (inline-block)
    • Social links — buttons with hover effect
  5. Open in browser and compare with the lecture example
Если застрял — подсматривай в лекцию, но старайся писать сам! Мышечная память при кодировании — очень важна.
If you get stuck — peek at the lecture, but try to write it yourself! Muscle memory in coding is very important.
  • Файлы index.html и style.css созданы
  • CSS подключён через <link> (external)
  • Аватар круглый (border-radius: 50%)
  • Карточка с тенью (box-shadow)
  • Навыки отображаются как бейджи
  • Кнопки соцсетей меняют цвет при наведении
  • Карточка отцентрирована на странице
  • Files index.html and style.css are created
  • CSS is linked via <link> (external)
  • Avatar is round (border-radius: 50%)
  • Card has shadow (box-shadow)
  • Skills are displayed as badges
  • Social buttons change color on hover
  • Card is centered on the page

🎯 УРОК 9.3: СВОЯ ВИЗИТКА

🎯 Lesson 9.3: YOUR OWN CARD

Задание 8.3: Создай свою уникальную визитку Task 8.3: Create your own unique business card
Среднее Medium 25 минут 25 min
Создать персональную визитку с уникальным дизайном
Create a personal business card with unique design

Условие:

Instructions:

Используя план из задания 8.1, создай свою визитку. Она должна быть уникальной — не копия примера!

Using your plan from task 8.1, create your own business card. It must be unique — not a copy of the example!

Обязательные элементы:

Required elements:

  1. HTML-файл (index.html):
    • Круглый аватар (своё фото или pravatar.cc)
    • Имя и фамилия
    • Профессия / специальность / статус
    • Краткое описание (о себе, 2-3 предложения)
    • Минимум 1 контакт (email или телефон)
    • Минимум 3 навыка (бейджи)
    • Минимум 2 ссылки на соцсети (кнопки)
  2. CSS-файл (style.css):
    • Цветной или градиентный фон страницы
    • Белая или цветная карточка с тенью
    • Круглый аватар с рамкой
    • Стилизованные бейджи навыков
    • Кнопки соцсетей с :hover
    • Центрирование карточки
  1. HTML file (index.html):
    • Round avatar (your photo or pravatar.cc)
    • First and last name
    • Profession / specialty / status
    • Short description (about me, 2-3 sentences)
    • At least 1 contact (email or phone)
    • At least 3 skills (badges)
    • At least 2 social media links (buttons)
  2. CSS file (style.css):
    • Colored or gradient page background
    • White or colored card with shadow
    • Round avatar with border
    • Styled skill badges
    • Social buttons with :hover
    • Card centering

Бонусные элементы (для продвинутых):

Bonus elements (for advanced students):

  • Добавь раздел «Образование» или «Хобби»
  • Сделай кнопки соцсетей разных цветов (отдельный класс для каждой)
  • Добавь разделительную линию (<hr>) между секциями
  • Используй Google Fonts для красивого шрифта
  • Добавь градиент на аватар (border через outline или обёртку)
  • Add an "Education" or "Hobbies" section
  • Make social buttons different colors (separate class for each)
  • Add a divider line (<hr>) between sections
  • Use Google Fonts for a beautiful typeface
  • Add a gradient to the avatar (border via outline or wrapper)
Выбери цветовую тему из конспекта или придумай свою! Сайт coolors.co помогает подобрать сочетающиеся цвета.
Choose a color theme from the notes or create your own! The site coolors.co helps you find matching colors.
  • Файлы index.html и style.css созданы
  • CSS подключён через <link>
  • Данные — свои (не из примера)
  • Цветовая тема — отличается от примера
  • Аватар круглый
  • Карточка с тенью и скруглёнными углами
  • Навыки — бейджи, соцсети — кнопки
  • Hover-эффект на кнопках
  • Карточка отцентрирована
  • Страница выглядит аккуратно
  • Files index.html and style.css are created
  • CSS is linked via <link>
  • Data is your own (not from the example)
  • Color theme is different from the example
  • Avatar is round
  • Card has shadow and rounded corners
  • Skills are badges, social links are buttons
  • Hover effect on buttons
  • Card is centered
  • Page looks neat

⭐ BONUS TASK

Задание 8.4: Визитка для друга Task 8.4: Card for a friend
Сложное Hard 15 минут 15 min
Закрепить навыки, создав вторую визитку с другим дизайном
Reinforce skills by creating a second card with a different design

Условие:

Instructions:

  1. Создайте ещё одну визитку — для друга, одноклассника или вымышленного персонажа
  2. Используйте другую цветовую тему (например, тёмную, если первая была светлой)
  3. Используйте тот же HTML-шаблон, но замените CSS
  4. Покажите, как одна и та же HTML-разметка может выглядеть совершенно по-разному с другим CSS!
  1. Create one more business card — for a friend, classmate, or fictional character
  2. Use a different color theme (e.g., dark if the first one was light)
  3. Use the same HTML template, but replace the CSS
  4. Show how the same HTML markup can look completely different with different CSS!
Скопируй папку my-card в friend-card. Измени данные в HTML и полностью перепиши style.css с другими цветами, шрифтами, тенями.
Copy the folder my-card to friend-card. Change the data in HTML and completely rewrite style.css with different colors, fonts, shadows.
  • Создана вторая визитка с другими данными
  • Цветовая тема отличается от первой визитки
  • HTML-структура такая же (или похожая)
  • CSS полностью отличается
  • A second card is created with different data
  • Color theme differs from the first card
  • HTML structure is the same (or similar)
  • CSS is completely different
