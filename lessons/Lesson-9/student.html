📚 УРОК 9.1: ПЛАНИРОВАНИЕ СТРАНИЦЫ

📚 Lesson 9.1: PAGE PLANNING

Главное правило: Всегда планируй перед кодированием! Сначала — содержание, потом — структура, потом — стили.
Main rule: Always plan before coding! First — content, then — structure, then — styles.

Этапы планирования

Planning steps

  1. Определить содержание — какой текст, изображения, ссылки будут на странице
  2. Нарисовать wireframe — простой набросок расположения элементов
  3. Определить HTML-теги — какие теги использовать для каждого блока
  4. Определить CSS-свойства — какие стили понадобятся
  1. Define content — what text, images, links will be on the page
  2. Draw a wireframe — simple sketch of element placement
  3. Choose HTML tags — which tags to use for each section
  4. Plan CSS properties — which styles you'll need
Wireframe — это простой набросок (схема) страницы. Показывает расположение блоков без деталей оформления.
Wireframe — a simple sketch (diagram) of a page. Shows block placement without design details.

Пошаговый план

Step-by-step plan

  1. Создать папку my-card
  2. Создать index.html — базовая структура
  3. Создать style.css — подключить через <link>
  4. Написать HTML: карточка с аватаром, именем, описанием
  5. Добавить CSS: фон, карточка, аватар
  6. Добавить навыки (бейджи) и соцсети (кнопки)
  7. Выбрать цветовую тему
  8. Проверить в браузере
  1. Create a folder my-card
  2. Create index.html — basic structure
  3. Create style.css — link it via <link>
  4. Write HTML: card with avatar, name, description
  5. Add CSS: background, card, avatar
  6. Add skills (badges) and social links (buttons)
  7. Choose a color theme

Шаблон HTML

HTML template

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя визитка</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <div class="card">
        <img src="photo.jpg" alt="Моё фото" class="avatar">
        <h1>Ваше Имя</h1>
        <p class="role">Ваша профессия</p>
        <p class="bio">Краткое описание...</p>
        <div class="contacts">
            <a href="mailto:you@mail.com">📧 you@mail.com</a>
        </div>
        <div class="skills">
            <span class="skill">HTML</span>
            <span class="skill">CSS</span>
        </div>
        <div class="socials">
            <a href="#" class="social-link">GitHub</a>
            <a href="#" class="social-link">Telegram</a>
        </div>
    </div>
</body>
</html>
