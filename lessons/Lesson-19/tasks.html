🎯 УРОК 19.1: ПЛАНИРОВАНИЕ

🎯 Lesson 19.1: PLANNING

Задание 18.1: Спланируй макет журнала Task 18.1: Plan the magazine layout
Лёгкое Easy 10 минут 10 min
Выбрать тему и спланировать структуру макета
Choose a theme and plan the layout structure

Условие:

Instructions:

  1. Выбери тему: технологии, кулинария, путешествия, спорт, мода, наука
  2. Название журнала: придумай короткое запоминающееся название
  3. Запиши 7 статей:
    • 1 Featured (главная) — длинный заголовок + описание
    • 6 обычных — заголовок, короткое описание, тег (категория), автор, дата
  4. Sidebar: запиши 4-5 категорий и 3 популярные статьи
  5. Нарисуй wireframe на бумаге: header, main (featured + 6 карточек), sidebar, footer
  1. Choose a theme: technology, cooking, travel, sports, fashion, science
  2. Magazine name: come up with a short memorable name
  3. Write 7 articles:
    • 1 Featured (main) — long title + description
    • 6 regular — title, short description, tag (category), author, date
  4. Sidebar: write 4-5 categories and 3 popular articles
  5. Draw a wireframe on paper: header, main (featured + 6 cards), sidebar, footer
  • Тема и название выбраны
  • 7 статей записаны (1 featured + 6 обычных)
  • Sidebar спланирован
  • Wireframe нарисован
  • Theme and name chosen
  • 7 articles written (1 featured + 6 regular)
  • Sidebar planned
  • Wireframe drawn

🎯 УРОК 19.2: HTML-СТРУКТУРА И GRID

🎯 Lesson 19.2: HTML STRUCTURE AND GRID

Задание 18.2: Собери структуру и раскладку Task 18.2: Build structure and layout
Среднее Medium 20 минут 20 min
Создать HTML-структуру и Grid-раскладку макета
Create HTML structure and Grid layout

Условие:

Instructions:

Создайте папку magazine с файлами index.html и style.css.

Create a folder magazine with files index.html and style.css.

Шаг 1: HTML

Step 1: HTML

<div class="magazine">
    <header class="mag-header">...</header>
    <main class="mag-main">
        <article class="card featured">...</article>
        <article class="card">...</article>
        <!-- ещё 5 карточек -->
    </main>
    <aside class="mag-sidebar">...</aside>
    <footer class="mag-footer">...</footer>
</div>

Шаг 2: Grid-раскладка

Step 2: Grid layout

  1. Внешний Grid (.magazine):
    • grid-template-columns: 1fr 300px
    • grid-template-rows: 64px 1fr auto
    • grid-template-areas: "header header" "main sidebar" "footer footer"
  2. Вложенный Grid (.mag-main):
    • grid-template-columns: repeat(3, 1fr)
    • gap: 20px
  3. Featured: grid-column: 1 / -1
  4. Header: display: flex; align-items: center; gap: 24px
  1. Outer Grid (.magazine):
    • grid-template-columns: 1fr 300px
    • grid-template-rows: 64px 1fr auto
    • grid-template-areas: "header header" "main sidebar" "footer footer"
  2. Nested Grid (.mag-main):
    • grid-template-columns: repeat(3, 1fr)
    • gap: 20px
  3. Featured: grid-column: 1 / -1
  4. Header: display: flex; align-items: center; gap: 24px
На этом этапе не нужны красивые стили! Добавьте временные фоны (background: lightblue) к каждой области, чтобы проверить раскладку.
No need for pretty styles at this stage! Add temporary backgrounds (background: lightblue) to each area to check the layout.
  • HTML-структура: header, main (7 карточек), sidebar, footer
  • Внешний Grid с grid-template-areas
  • Вложенный Grid для карточек (3 столбца)
  • Featured = grid-column: 1 / -1
  • Header на Flexbox
  • CSS в отдельном файле
  • HTML structure: header, main (7 cards), sidebar, footer
  • Outer Grid with grid-template-areas
  • Nested Grid for cards (3 columns)
  • Featured = grid-column: 1 / -1
  • Header with Flexbox

🎯 Lesson 19.3: COMPLETE MAGAZINE LAYOUT

Задание 18.3: Заверши макет журнала Task 18.3: Complete the magazine layout

Add styles, images, hover effects and finish the project

Условие:

Instructions:

Продолжите работу над макетом из задания 18.2. Добавьте:

Continue working on the layout from task 18.2. Add:

  1. Карточки:
    • Белый фон, border-radius: 12px, overflow: hidden
    • Изображение: width: 100%; height: 180px; object-fit: cover

    • Блок «Популярное» — 3 мини-карточки (заголовок + дата)
  3. Hover-эффекты:
    • Карточки: transform: translateY(-4px) + box-shadow
    • Изображения: transform: scale(1.05) (с transition)
  4. Header: лого + навигация + кнопка «Subscribe» (margin-left: auto)
  5. Footer: тёмный фон, копирайт по центру
  1. Cards:

  4. Header: logo + navigation + "Subscribe" button (margin-left: auto)
  5. Footer: dark background, centered copyright

Задание 18.4: Тёмная тема Task 18.4: Dark theme
Сложное Hard 15 минут 15 min
Создать альтернативную тёмную версию макета
Create an alternative dark version of the layout

Условие:

Instructions:

Добавьте класс .dark на <div class="magazine dark"> и напишите стили для тёмной темы:

Add class .dark to <div class="magazine dark"> and write styles for dark theme:

  1. Фон страницы: #0f172a
  2. Фон карточек: #1e293b
  3. Текст: #e2e8f0
  4. Sidebar: #1e293b, бордер #334155
  5. Header: #1e293b
  6. Бордеры карточек: #334155
  1. Page background: #0f172a
  2. Card background: #1e293b
  3. Text: #e2e8f0
  4. Sidebar: #1e293b, border #334155
  5. Header: #1e293b
  6. Card borders: #334155
Используйте селектор .dark .card, .dark .mag-header и т.д. Не меняйте оригинальные стили — только добавляйте новые правила!
Use selectors like .dark .card, .dark .mag-header etc. Don't change original styles — only add new rules!
  • Тёмная тема работает через класс .dark
  • Все тексты читаемы на тёмном фоне
  • Бордеры и тени адаптированы
  • Можно переключить убрав/добавив класс .dark
  • Dark theme works via .dark class
  • All text readable on dark background
  • Borders and shadows adapted
  • Can toggle by removing/adding .dark class
