  • grid-column: 1 / -1 — элемент на всю ширину сетки
  • Grid = макет страницы, Flexbox = компоненты внутри
  • Вложенный Grid: mag-main сам является Grid для карточек
  • overflow: hidden на карточке + scale на картинке = zoom-эффект
  • margin-top: auto — прижать последний элемент к низу
  • object-fit: cover — заполнить область, обрезать лишнее
  • margin-left: auto в Flexbox — прижать элемент вправо
  • grid-template-areas — draw layout with text
  • grid-column: 1 / -1 — item spans full grid width
  • Grid = page layout, Flexbox = components inside
  • Nested Grid: mag-main is itself a Grid for cards

  1. Журнал: Создайте макет журнала / блога с grid-template-areas: header, main (3 колонки карточек + featured), sidebar (300px), footer.
  2. Карточки: 7 статей — 1 Featured (grid-column: 1 / -1) + 6 обычных. Каждая: изображение, тег, заголовок, описание, автор + дата.
  3. Hover: Карточки поднимаются (translateY(-4px)) + тень. Картинки увеличиваются (scale(1.05)).
  1. Magazine: Create a magazine / blog layout with grid-template-areas: header, main (3-column cards + featured), sidebar (300px), footer.
  2. Cards: 7 articles — 1 Featured (grid-column: 1 / -1) + 6 regular. Each: image, tag, title, description, author + date.
  3. Hover: Cards lift (translateY(-4px)) + shadow. Images zoom (scale(1.05)).
