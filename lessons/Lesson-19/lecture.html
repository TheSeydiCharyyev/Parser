1. Что мы будем строить

1. What we will build

Сегодня мы создаём макет журнала / блога — реальную страницу с шапкой, Featured-статьёй, сеткой статей, sidebar и подвалом. Этот проект объединяет всё, что мы изучили о Grid:

Today we're building a magazine / blog layout — a real page with header, Featured article, article grid, sidebar, and footer. This project combines everything we've learned about Grid:

  • grid-template-areas — общая структура страницы
  • grid-column: span — Featured-статья на 2 колонки
  • Вложенный Grid — сетка карточек внутри main
  • Flexbox — навигация, содержимое карточек, sidebar
  • grid-template-areas — overall page structure
  • grid-column: span — Featured article spanning 2 columns
  • Nested Grid — card grid inside main
  • Flexbox — navigation, card content, sidebar

4. CSS: общая раскладка (Grid areas)

4. CSS: overall layout (Grid areas)

* { margin: 0; padding: 0; box-sizing: border-box; }

body {
    font-family: 'Segoe UI', sans-serif;
    background: #f1f5f9;
    color: #1e293b;
    line-height: 1.6;
}

.magazine {
    display: grid;
    grid-template-columns: 1fr 300px;
    grid-template-rows: 64px 1fr auto;
    grid-template-areas:
        "header  header"
        "main    sidebar"
        "footer  footer";
    min-height: 100vh;
    max-width: 1200px;
    margin: 0 auto;
}

.mag-header  { grid-area: header; }
.mag-main    { grid-area: main; }
.mag-sidebar { grid-area: sidebar; }
.mag-footer  { grid-area: footer; }
Ключевой момент: grid-template-areas делает код читаемым. Любой разработчик сразу видит структуру страницы, просто прочитав 3 строки.
Key point: grid-template-areas makes the code readable. Any developer can immediately see the page structure just by reading 3 lines.

Flexbox for header! Header is a single line of items. margin-left: auto on the button pushes it to the right. This is a classic pattern.

6. CSS: Featured article

.featured img {
    width: 100%;

    object-fit: cover;
}

.featured h2 {

grid-column: 1 / -1 — Featured занимает все столбцы внутри сетки статей. Это делает её шире обычных карточек.

grid-column: 1 / -1 — Featured spans all columns within the article grid. This makes it wider than regular cards.

Два уровня Grid:
  1. Внешний Grid (.magazine) — header, main, sidebar, footer
  2. Вложенный Grid (.mag-main) — сетка карточек 3 колонки

Two Grid levels:
  1. Outer Grid (.magazine) — header, main, sidebar, footer
  2. Nested Grid (.mag-main) — 3-column card grid
Grids can be nested inside each other without limits!

10. CSS: hover-эффекты

10. CSS: hover effects

.card:hover {
    transform: translateY(-4px);
    box-shadow: 0 12px 24px rgba(0, 0, 0, 0.1);
}

.card img {
    transition: transform 0.3s;
}
.card:hover img {
    transform: scale(1.05);
}

.nav a {
    position: relative;
}
.nav a::after {
    content: '';
    position: absolute;
    bottom: -2px;
    left: 0;
    width: 0;
    height: 2px;
    background: #1e293b;
    transition: width 0.3s;
}
.nav a:hover::after { width: 100%; }

Hover на изображении scale(1.05) + overflow: hidden на карточке = картинка увеличивается, но не выходит за рамки. Красивый эффект!

Hover on image scale(1.05) + overflow: hidden on card = image zooms in but stays within bounds. Beautiful effect!

Чему мы научились в этом проекте:

  • grid-column: 1 / -1 — Featured spanning full width
  • Flexbox for navigation, cards, sidebar
  • overflow: hidden + hover scale — zoom effect on images
  • margin-top: auto — push meta to the bottom of card
