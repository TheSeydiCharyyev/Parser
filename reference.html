Структура документа
Каркас любой HTML-страницы
<!DOCTYPE html>
Объявление типа документа. Говорит браузеру, что это HTML5. Всегда первая строка.
Занятие 1
<html lang="ru">
Корневой элемент страницы. Атрибут lang указывает язык содержимого.
Занятие 1
<head>
Голова документа. Содержит мета-информацию, заголовок, подключение стилей. Не отображается на странице.
Занятие 1
<meta charset="UTF-8">
Кодировка символов. UTF-8 поддерживает кириллицу, эмодзи и все языки мира.
Занятие 1
<meta name="viewport">
Настройка отображения на мобильных устройствах. Обязательный тег для адаптивности.
Занятие 1
<meta name="description">
Описание страницы для поисковиков. Отображается в результатах Google.
Занятие 3
<title>
Заголовок страницы. Отображается во вкладке браузера и в результатах поиска.
Занятие 1
<body>
Тело документа. Всё видимое содержимое страницы находится здесь.
Занятие 1

HTML-комментарий. Не отображается на странице, виден только в коде.

🔍 Мета-теги для SEO и соцсетей

Мета-тегНазначение
<meta name="description">Описание страницы для поисковиков (показывается в Google)
<meta name="keywords">Ключевые слова (сейчас почти не учитываются Google)

Мультимедиа и iframe
Аудио, видео, встраивание YouTube, карт
<audio controls>
Встраиваемый аудиоплеер. Атрибут controls обязателен — без него плеер невидим. Источник через src или вложенный <source>.

Встраиваемый видеоплеер. Атрибуты: width, height, poster (обложка). autoplay работает только с muted!

Источник для <audio> или <video>. Несколько <source> = fallback (браузер выберет поддерживаемый формат).
Занятие 12
<iframe src="...">
Встраивает внешнюю страницу: YouTube-видео, Google Maps, Yandex Maps, виджеты. Парный тег.

Синтаксис и подключение CSS
Как писать и подключать стили
селектор { свойство: значение; }
Базовая структура CSS-правила. Селектор выбирает элемент, в фигурных скобках — стили.
Занятие 6
/* комментарий */
CSS-комментарий. Не влияет на стили, виден только в коде. Для пояснений и заметок.
Занятие 6
<link rel="stylesheet" href="style.css">
Внешний CSS (лучший способ). Отдельный файл, кэшируется браузером, удобно поддерживать.
Занятие 6
<style> ... </style>
Внутренний CSS. Пишется в <head>. Для одностраничных проектов или быстрых тестов.
Занятие 6
style="color: red;"
Инлайн CSS (избегать). Прямо в атрибуте тега. Сложно поддерживать, перебивает все остальные стили.
Занятие 6
🎯
Селекторы
Как выбрать элемент для стилизации
* { }
Универсальный селектор — выбирает все элементы на странице. Используется для сброса стилей: * { margin: 0; padding: 0; box-sizing: border-box; }
Занятие 7
тег { }
Селектор по тегу. Выбирает все элементы данного типа. Пример: p { color: red; }. Вес: 0-0-1
Занятие 6
.класс { }
Селектор по классу (с точкой). Можно применять к нескольким элементам. Пример: .card { }. Вес: 0-1-0
Занятие 6
#id { }
Селектор по ID (с решёткой). Только для одного уникального элемента. Пример: #header { }. Вес: 1-0-0
Занятие 6
Специфичность (приоритет)
Кто победит при конфликте: тег (0-0-1) < класс (0-1-0) < ID (1-0-0) < инлайн (перебивает всё).
Занятие 6
:hover
Псевдокласс — стили при наведении мыши. Пример: a:hover { color: #3b82f6; } или .btn:hover { background: #5a6fd6; }. Работает с любым элементом.
Занятие 7, 9
селектор селектор { }
Вложенный (потомок) селектор. Выбирает элемент внутри другого. Пример: .contacts a { color: #333; } — все ссылки внутри .contacts.
Занятие 6, 9
:focus
Псевдокласс — стили при фокусе (курсор в поле ввода, Tab-навигация). Пример: input:focus { border-color: #3b82f6; }. Обязательно, если убрали outline!
Занятие 11
:nth-child()
Псевдокласс — выбор элемента по номеру. :nth-child(even) — чётные, :nth-child(odd) — нечётные, :nth-child(3) — третий. Полосатые таблицы!

Цвета и фон
Форматы цветов, фоны, градиенты
color
Цвет текста. Принимает любой формат: имя, HEX, RGB, HSL. Пример: color: #1e293b;
Занятие 2, 6
background-color
Цвет фона элемента. Пример: background-color: #f8fafc;
Занятие 2, 6
background
Сокращённое свойство фона. Принимает цвет, изображение или градиент.
Занятие 6
linear-gradient()
Градиентный фон. Пример: background: linear-gradient(135deg, #3b82f6, #1d4ed8);
Занятие 6
Имена цветов
147 именованных цветов: red, tomato, darkblue, orange, white, black и др.
Занятие 6
HEX-цвета
Шестнадцатеричный код: #ff0000 (красный), #333 (сокращённый). 6 или 3 символа после #.
Занятие 2, 6
rgb() / rgba()
RGB: rgb(255, 0, 0). RGBA добавляет прозрачность: rgba(0, 0, 0, 0.5) (0 = прозрачный, 1 = непрозрачный).
Занятие 2, 6
hsl()
Тон, насыщенность, светлота. Пример: hsl(0, 100%, 50%) — красный. Удобно подбирать оттенки.

Пространство вокруг и внутри элементов
padding
Внутренний отступ — от границы до содержимого. Пример: padding: 16px 20px; (верх-низ, лево-право). 4 значения: top right bottom left (по часовой).
Занятие 2, 6, 7
margin
Внешний отступ — от элемента до соседних. margin: 0 auto; — центрирование блока. Вертикальные margin схлопываются (побеждает больший).
Занятие 2, 6, 7
border
Рамка элемента (толщина, стиль, цвет). Стили: solid, dashed, dotted, double, none.
Занятие 2, 6, 7

Занятие 6

transition
Плавный переход при изменении свойства. Пример: transition: background 0.2s ease; или transition: all 0.3s ease;. Ставится на элемент, а не на :hover!

Ширина, единицы, тип элемента

display

box-sizing
Как считать размеры. content-box — width = только content. border-box — width включает padding и border. Всегда используйте * { box-sizing: border-box; }

Занятие 7

📍
Позиционирование (position)
5 значений position, координаты top/left, z-index, containing block
position: static
Значение по умолчанию. Элемент в обычном потоке. Свойства top/right/bottom/left и z-index не работают. Используется чтобы «сбросить» унаследованное позиционирование.
Занятие 8
position: relative
Элемент остаётся в потоке (место сохраняется), но можно сдвинуть через top/left. Главное применение — без координат, как «привязка» для absolute-потомков.
Занятие 8
position: absolute
Вырывает элемент из потока. Позиционируется от ближайшего relative/absolute/fixed/sticky-предка. Если такого нет — от <html>. Бейджи, иконки, оверлеи на фото.
Занятие 8
position: fixed
Привязан к окну браузера (viewport), не двигается при скролле. Кнопка «Наверх», fixed-шапка, чат-кнопка, модалка-фон. Игнорирует relative-родителей.
Занятие 8
position: sticky
Гибрид relative + fixed. Ведёт себя как relative, пока не достигнет порога — потом «прилипает» как fixed. Пример: position: sticky; top: 0;. Не забудь background!
Занятие 8
top / right / bottom / left
Координаты сдвига от соответствующего края. Работают только при position ≠ static. Можно отрицательные (top: -10px — выше). top: 0; bottom: 0; + без height — растянуть на всю высоту контейнера.
Занятие 8
z-index
«Этаж» элемента (стек по оси Z). Больше — выше. Работает только с position (не static). Шкала: -1 (под контентом), 1-10 (бейджи), 50-100 (sticky/fixed шапка), 1000+ (модалки).
Занятие 8
containing block
«Контейнер», от которого absolute считает координаты. Это ближайший предок с position ≠ static. Если такого нет — это <html>. Главная причина «улетающего» absolute — у родителя забыли position: relative.
Занятие 8

Flexbox — контейнер
Свойства родителя: задают раскладку для всех дочерних элементов
display: flex
Включает Flexbox-раскладку для контейнера. Дочерние элементы становятся flex-элементами и выстраиваются в ряд по главной оси.
Занятие 9 (превью), 14
flex-direction
Направление главной оси: row (по умолчанию, слева направо), row-reverse, column (сверху вниз), column-reverse.
Занятие 14
flex-wrap
Перенос элементов на новую строку: nowrap (по умолчанию — всё в одну строку), wrap (переносить), wrap-reverse.
Занятие 14
flex-flow
Сокращение для flex-direction + flex-wrap. Пример: flex-flow: row wrap;
Занятие 14
justify-content
Выравнивание по главной оси (по умолчанию — горизонтально). Значения: flex-start, center, flex-end, space-between, space-around, space-evenly.
Занятие 9, 14
align-items
Выравнивание по поперечной оси (по умолчанию — вертикально). Значения: stretch (по умолчанию), flex-start, center, flex-end, baseline.
Занятие 9, 14
align-content
Выравнивание строк (только при flex-wrap: wrap и нескольких строках). Значения как у justify-content + stretch.
Занятие 14
gap / row-gap / column-gap
Отступы между flex-элементами. Пример: gap: 20px; или gap: 12px 20px; (между строками, между столбцами). Лучше, чем margin.
Занятие 9, 14

Flexbox — элементы
Свойства дочерних элементов: индивидуальное поведение
flex-grow
«Жадность» элемента — насколько он растягивается, заполняя свободное место. 0 (по умолчанию) — не растягивается, 1 — берёт всё свободное, 2 — вдвое больше соседа с 1.
Занятие 15
flex-shrink
Насколько элемент сжимается, если не хватает места. 1 (по умолчанию) — сжимается, 0 — не сжимается (фиксированная ширина).
Занятие 15
flex-basis
Начальный размер элемента до распределения свободного места. Значения: auto (по содержимому), 0, 200px, 30%.
Занятие 15
flex (сокращение)
Шорткат: flex: grow shrink basis. Часто: flex: 1 (= 1 1 0%), flex: 1 1 280px (карточки с минимумом 280px), flex: 0 0 auto (фикс).
Занятие 15
order
Порядок элемента в контейнере. По умолчанию 0. Меньше — раньше, больше — позже. Можно отрицательное (-1) — встанет первым. Не меняет HTML!
Занятие 15
align-self
Индивидуальное выравнивание элемента по поперечной оси (перебивает align-items родителя). Значения те же: auto, flex-start, center, flex-end, stretch.
Занятие 15
margin: auto (трюк)
В flex-контейнере margin-left: auto отталкивает элемент вправо (всё свободное место — слева). Идеально для «logo слева, кнопки справа» в навигации.
Занятие 15

CSS Grid
Двумерная сетка: колонки + строки, span, areas, auto-fit
display: grid
Превращает контейнер в Grid. Дочерние элементы становятся ячейками сетки. Главная альтернатива Flex для двумерных макетов.
Занятие 17
grid-template-columns
Колонки сетки. 200px 1fr 1fr — фикс + 2 гибких. repeat(3, 1fr) — 3 равные. 1fr 300px — main + sidebar.
Занятие 17
grid-template-rows
Строки сетки. Аналогично columns. auto 1fr auto — шапка по контенту, main растягивается, футер по контенту. Классический макет.
Занятие 17
gap
Отступы между ячейками. gap: 20px — одинаковый по строкам и колонкам. gap: 20px 10px — между строками 20, между колонками 10. Заменяет margin.
Занятие 17
fr (фракция)
Единица «гибкая часть» свободного места. 1fr 2fr — вторая колонка вдвое шире первой. Не пиксели — пропорции. Альтернатива процентам без проблем с gap.
Занятие 17
repeat()
Краткая запись. repeat(4, 1fr) = 1fr 1fr 1fr 1fr. Можно repeat(3, 200px 1fr) — повтор паттерна.
Занятие 17
minmax(MIN, MAX)
Размер от MIN до MAX. minmax(200px, 1fr) — не меньше 200px, дальше растягивается. Идёт в паре с auto-fit для «магической» галереи.
Занятие 18
auto-fit / auto-fill
repeat(auto-fit, minmax(280px, 1fr)) — сколько колонок поместится — столько и сделай. Магия без media queries: сетка сама перестраивается под ширину.
Занятие 18
grid-auto-rows
Высота автоматически созданных строк. grid-auto-rows: 200px — каждая строка ровно 200px. Нужно когда grid создаёт строки сам (для span).
Занятие 18
grid-column: span N
Ячейка занимает N колонок вместо одной. span 2 — на две колонки. Самый простой способ сделать «большую» карточку среди обычных.
Занятие 18
grid-row: span N
Аналогично — на N строк. Комбо grid-column: span 2; grid-row: span 2 = featured-карточка 2×2.
Занятие 18
grid-column: 1 / -1
«От первой линии до последней» = во всю ширину сетки. -1 — это «последняя линия». Не нужно считать колонки — Grid сам разберётся. Баннеры, заголовки секций.
Занятие 18
grid-template-areas
Именованные области. На контейнере — «карта» макета строками: "header header" "sidebar main" "footer footer". На детях — grid-area: имя.
Занятие 18
grid-area
Привязка элемента к именованной области из template-areas. grid-area: sidebar. Самый понятный способ собрать макет — буквально рисуешь его словами.
Занятие 18
justify-items
Выравнивание содержимого ячеек по горизонтали: start / center / end / stretch. На контейнере — для всех, на ребёнке — justify-self.
Занятие 17
align-items
Выравнивание по вертикали в ячейках: start / center / end / stretch. На ребёнке — align-self. Ключевое для sticky-sidebar: align-self: start.
Занятие 17

Адаптивный дизайн
Media queries, viewport-единицы, clamp(), бургер-меню, sticky footer
<meta viewport>
<meta name="viewport" content="width=device-width, initial-scale=1.0">. Обязательно в head — иначе media queries не работают на мобильных. Жалоба №1 у новичков.
Занятие 20
@media (min-width)
«Если экран ≥ значения». @media (min-width: 768px) { ... } — стили для планшета и десктопа. Mobile-first подход (рекомендуется).
Занятие 20
@media (max-width)
«Если экран ≤ значения». @media (max-width: 768px) { ... } — стили для мобильных. Desktop-first подход (старый, иногда удобный).
Занятие 20
Breakpoints
Стандартные точки: 576px (мобильный L), 768px (планшет), 992px (ноутбук), 1200px (десктоп). Используют Bootstrap/Tailwind. Для большинства сайтов хватает 2-3.
Занятие 20
@media (and)
Комбинация условий. @media (min-width: 768px) and (max-width: 992px) — только планшеты. and (orientation: landscape) — только горизонтальная.
Занятие 20
@media print
Стили для печати. Скрыть навигацию/тени/фон, оставить только контент. @media print { .nav { display: none } body { background: #fff } }.
Занятие 20
prefers-color-scheme
Определить тёмный режим ОС. @media (prefers-color-scheme: dark) { ... }. Тёмная тема автоматически — без JavaScript.
Занятие 20
% проценты
Относительно размера родителя. width: 50% — половина родителя. Удобно для жидких колонок и адаптивных контейнеров.
Занятие 21
vw / vh
1% от ширины/высоты окна. 100vh = вся высота. 5vw = 5% ширины. Идеально для hero на весь экран и плавных шрифтов.
Занятие 21
rem
Относительно font-size элемента <html> (по умолчанию 16px). 1.5rem = 24px. Меняется единым центром — удобно для масштабирования всего сайта.
Занятие 21
em
Относительно font-size родителя (не html). Каскадирует. 1.2em в h1 = 1.2 × font-size h1. Опаснее rem (наследуется).
Занятие 21
ch
Ширина символа «0» в текущем шрифте. max-width: 65ch — не шире ~65 символов. Стандартный приём типографики: текст не растягивается на полстраницы.
Занятие 21
clamp(MIN, VAL, MAX)
«Не меньше MIN, не больше MAX, иначе VAL». font-size: clamp(2rem, 6vw, 4rem) — плавный шрифт от 2 до 4rem. Главная функция адаптивного дизайна.
Занятие 21
min() / max()
Возвращает меньшее/большее из двух. max-width: min(1200px, 95%) — на широком экране 1200px, на узком 95%. Без media queries.

Эффекты и трансформации
transition, transform, hover-паттерны, 3D-флип, фильтры
aspect-ratio
Соотношение сторон элемента. Пример: aspect-ratio: 16 / 9; — для адаптивного видео, iframe, превью. Современный способ (поддержка 96%+).
Занятие 12
object-fit
Как изображение заполняет контейнер. cover — заполнить всё, лишнее обрезать (как фон). contain — вписать целиком. fill — растянуть.
Занятие 16
transition
Плавный переход между состояниями. Формат: transition: свойство длительность функция задержка. Пример: transition: background 0.3s ease 0s. Ставится на БАЗОВЫЙ селектор, новое значение — на :hover.
Занятие 23
timing-function
«Характер» анимации. ease (по умолч., мягко) · linear (равномерно) · ease-in (медленный старт) · ease-out (медленный финиш) · ease-in-out.
Занятие 23
cubic-bezier()
Своя кривая ускорения. cubic-bezier(0.34, 1.56, 0.64, 1) — второе число > 1 даёт перелёт = эффект пружины (bounce). Готовые ease — её частные случаи.
Занятие 23
transition-delay
Пауза перед стартом. 4-й параметр transition: transition: transform 0.35s ease 0.13s. Разные задержки на соседних элементах = каскад (появляются по очереди).
Занятие 23
transform: translate
Сдвиг без смещения соседей. translateY(-8px) — вверх. translateX(20px) — вправо. Соседи стоят на месте, страница не дёргается. Главный приём hover-подъёма.
Занятие 23
transform: scale
Масштаб. scale(1.1) — на 10% больше. scale(0.9) — меньше. Центр на месте. Внутри overflow: hidden родителя — даёт зум-эффект.
Занятие 23
transform: rotate
Поворот в плоскости. rotate(45deg) — по часовой. rotate(-15deg) — против. rotate(360deg) — полный оборот.
Занятие 23
transform: skew
Наклон. skewX(-20deg) — наклон по X. Часто используется для диагональных полос-разделителей и косых блоков.
Занятие 23
комбо transform
Несколько функций через пробел. transform: translateY(-8px) scale(1.05) rotate(2deg). Применяются справа налево. Порядок важен: rotate потом translate даёт другой результат.
Занятие 23
perspective
«Глубина сцены» для 3D. Свойство на родителе: perspective: 1000px. Функция внутри transform: transform: perspective(800px) rotateY(15deg). Меньше значение — сильнее искажение.
Занятие 23
transform-style: preserve-3d
«Сохранять 3D» для потомков. Без неё дочерние элементы сплющиваются в 2D. Нужно для 3D-флипа: ставится на крутящийся .flip-card-inner.
Занятие 23
backface-visibility: hidden
Скрывает «изнанку» при 3D-повороте. Без неё через переднюю сторону просвечивает задняя. Ставится на обе грани flip-карты (.flip-card-front, .flip-card-back).
Занятие 23
transform-origin
«Якорь» трансформации. По умолчанию центр. transform-origin: top left — поворот/масштаб от верхнего левого угла. Меняет ощущение от rotate и scale.
Занятие 23
filter
Графические фильтры. brightness(1.1) — ярче, blur(4px) — размытие, grayscale(100%) — ч/б, contrast(1.2).
